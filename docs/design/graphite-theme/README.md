# Graphite theme

Soft charcoal greys with a sky-blue accent, from Myiles.

- `graphite-theme.css`: plain hex CSS variables for any project.
- `graphite-theme.json`: the same colours as JSON tokens.
- `graphite-theme-myiles-vars.css`: the exact block Myiles uses (HSL triplets, shadcn-style names, layered on a `.dark` base).

Pair it with the Sky Classic icon in `../sky-classic-icon/`.
