# FND-035 – A check that compares the published site with the site that was built

**Phase:** 1 – Foundation
**Depends on:** FND-031, FND-034, FND-036 (all merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §14, `docs/WORKFLOW.md`, `TESTING.md`
("Gates", "Deployment"), `scripts/audit.py` (for the style of a script and
its tests), `.github/workflows/checks.yml` (the `site` job, to see what is
handed over)

## Objective

One command says whether an address serves exactly the site that was
built, and says what differs when it does not.

## Why

"Publish the site" proves that GitHub accepted a deployment. It does not
say what a visitor gets: a deployment can succeed and leave an older site,
a missing file, or a script served as text. This task writes the check and
its tests. The job that runs it after each deployment is the next task
(FND-037) and is not part of this one: no workflow file changes here.

## Design in short

- A new script, `python scripts/live.py <site.tar> <address>`, with the
  Python standard library only.
- `site.tar` is the built site exactly as the job "Build the site" hands it
  over: a plain tar whose members are named `./index.html`,
  `./data/manifest.json` and so on.
- The script asks the address for every file in the tar, and for the
  address itself, which must answer with the page. An answer is right when
  its status is 200 (a redirect is not followed and is wrong), its content
  type is one a browser accepts for that kind of file, and its content is
  the built file, byte for byte.
- The data manifest names the moment it was exported, so an older
  deployment never matches: no separate "is it fresh" rule is needed.
- A new deployment needs a moment to reach every server. The script tries
  again every 10 seconds, for up to 5 minutes, and writes one line per try,
  sent at once so that a log shows the waiting while it happens. A site
  that gives no answer at all is tried again in the same way.
- It fails, in a plain sentence and without a traceback, when the check
  cannot be carried out: an address that is not `https` (plain `http` is
  accepted for this computer only, which is what the tests use), an
  address with a query, a fragment or a password, a tar that holds a link
  or a path that leaves the site, a tar without `index.html`.
- The tests run the script against a small web server on this computer
  that serves whatever a test tells it to. No test reaches the internet.

### 1. `scripts/live.py` – the whole file

```python
"""Checks that the published site is the site that was built.

    python scripts/live.py <site.tar> <address>

`site.tar` is the built site as it was handed to GitHub Pages, and `address`
is where the site is published, for example
`https://bigdaddy284.github.io/MotoSphere/`. Every file of the built site is
fetched from the address and compared, byte for byte, with the built one, and
its content type is checked. The data manifest names the moment it was
exported, so a site that is an older deployment never matches.

A deployment takes a little while to reach every server, so the check tries
again for a few minutes before it gives its verdict.

The script uses the Python standard library only. Its exit code is 0 when
every file is the built one and 1 when not, or when the check could not be
carried out.
"""

import argparse
import functools
import sys
import tarfile
import time
import urllib.error
import urllib.parse
import urllib.request
from collections.abc import Callable, Iterator
from dataclasses import dataclass
from pathlib import Path, PurePosixPath
from typing import TextIO

# How long the check keeps trying, and how long it waits between tries.
WAIT_SECONDS = 300
PAUSE_SECONDS = 10

# How long one answer may take.
TIMEOUT_SECONDS = 30

# The page a visitor gets at the address itself.
INDEX = "index.html"

# What a browser must be told each kind of file is. A script served as plain
# text is not run, so the content type is part of the site working.
CONTENT_TYPES: dict[str, tuple[str, ...]] = {
    ".html": ("text/html",),
    ".js": ("text/javascript", "application/javascript"),
    ".css": ("text/css",),
    ".json": ("application/json",),
    ".svg": ("image/svg+xml",),
    ".png": ("image/png",),
    ".ico": ("image/x-icon", "image/vnd.microsoft.icon"),
}

# Computers that are this one. Only they may be reached without encryption.
THIS_COMPUTER = ("127.0.0.1", "localhost", "::1")


class UnusableError(Exception):
    """The check could not be carried out. The message says why, in plain words."""


class UnreachableError(UnusableError):
    """The address gave no answer at all. That may pass, so it is tried again."""


@dataclass(frozen=True)
class Answer:
    """What a server answered: the status, the content type and the content."""

    status: int
    content_type: str
    body: bytes


Fetch = Callable[[str], Answer]


class _NoRedirects(urllib.request.HTTPRedirectHandler):
    """A file of the site is where it is: being sent elsewhere is a failure."""

    def redirect_request(self, *_: object, **__: object) -> None:
        return None


@functools.cache
def _opener() -> urllib.request.OpenerDirector:
    """One opener for every fetch: making one reads this computer's certificates."""
    return urllib.request.build_opener(_NoRedirects)


def fetch(url: str) -> Answer:
    """Fetch an address once. An answer that is not 200 is still an answer."""
    request = urllib.request.Request(url, headers={"Cache-Control": "no-cache"})  # noqa: S310
    try:
        with _opener().open(request, timeout=TIMEOUT_SECONDS) as response:
            kind = response.headers.get_content_type()
            return Answer(response.status, kind, response.read())
    except urllib.error.HTTPError as error:
        return Answer(error.code, error.headers.get_content_type(), b"")
    except (OSError, ValueError) as error:
        raise UnreachableError(f"{url} could not be reached: {error}") from None


def checked_address(address: str) -> str:
    """The address of the site, which must be a folder on an encrypted connection."""
    parts = urllib.parse.urlsplit(address)
    if parts.scheme not in ("http", "https") or not parts.hostname:
        raise UnusableError(f"{address} is not a web address")
    if parts.scheme == "http" and parts.hostname not in THIS_COMPUTER:
        raise UnusableError(f"{address} must start with https://")
    if parts.query or parts.fragment or parts.username or parts.password:
        raise UnusableError(f"{address} must be an address and nothing else")
    if not parts.path.endswith("/"):
        raise UnusableError(f"{address} must end with a slash")
    return address


def built_files(archive: Path) -> Iterator[tuple[str, bytes]]:
    """Every file of the built site, as its path inside the site and its content."""
    try:
        opened = tarfile.open(archive)  # noqa: SIM115
    except (OSError, tarfile.TarError):
        raise UnusableError(f"{archive.name} cannot be read as the built site") from None
    with opened:
        for member in opened:
            path = PurePosixPath(member.name)
            if member.isdir():
                continue
            if (
                not member.isfile()
                or path.is_absolute()
                or ".." in path.parts
                or "\\" in member.name
            ):
                raise UnusableError(
                    f"{archive.name} holds {member.name}, which is not a plain file of the site"
                )
            content = opened.extractfile(member)
            if content is None:
                raise UnusableError(f"{archive.name}: {member.name} cannot be read")
            yield path.as_posix(), content.read()


def expected_types(name: str) -> tuple[str, ...]:
    """The content types a file may be served as; none when its kind has no rule."""
    return CONTENT_TYPES.get(PurePosixPath(name).suffix.lower(), ())


def judge(answer: Answer, name: str, content: bytes) -> str | None:
    """What is wrong with one answer, in plain words, or None when it is right."""
    if answer.status != 200:
        return f"answered {answer.status}"
    kinds = expected_types(name)
    if kinds and answer.content_type not in kinds:
        return f"is served as {answer.content_type}, expected {kinds[0]}"
    if answer.body != content:
        return "differs from the built file"
    return None


def compare(archive: Path, address: str, fetcher: Fetch) -> tuple[int, dict[str, str]]:
    """Fetch every file once. Returns how many were looked at and what is wrong."""
    wrong: dict[str, str] = {}
    looked_at = 0
    seen_index = False
    for name, content in built_files(archive):
        looked_at += 1
        problem = judge(fetcher(address + urllib.parse.quote(name)), name, content)
        if problem is not None:
            wrong[name] = problem
        if name == INDEX:
            seen_index = True
            # The page a visitor gets without naming a file.
            problem = judge(fetcher(address), name, content)
            if problem is not None:
                wrong[address] = problem
    if not seen_index:
        raise UnusableError(f"{archive.name} holds no {INDEX}, so it is not the built site")
    return looked_at, wrong


def main(
    arguments: list[str] | None = None,
    out: TextIO = sys.stdout,
    fetcher: Fetch = fetch,
    pause: Callable[[float], None] = time.sleep,
    wait: float = WAIT_SECONDS,
) -> int:
    """Run the check and write what it found. Returns the exit code."""
    parser = argparse.ArgumentParser(
        description="Check that the published site is the site that was built."
    )
    parser.add_argument("site", type=Path, help="the built site, as a tar file")
    parser.add_argument("address", help="where the site is published, ending with a slash")
    options = parser.parse_args(arguments)

    try:
        address = checked_address(options.address)
        waited = 0.0
        tries = 0
        while True:
            tries += 1
            try:
                looked_at, wrong = compare(options.site, address, fetcher)
                waiting_for = f"{len(wrong)} of {looked_at} files are not the built ones yet"
            except UnreachableError as error:
                if waited >= wait:
                    raise
                looked_at, wrong = 0, {address: "could not be reached"}
                waiting_for = str(error)
            if not wrong or waited >= wait:
                break
            # A new deployment needs a moment to reach every server. The line is
            # sent at once, so that a log shows the waiting while it happens.
            out.write(f"Try {tries}: {waiting_for}.\n")
            out.flush()
            pause(PAUSE_SECONDS)
            waited += PAUSE_SECONDS
    except UnusableError as error:
        out.write(f"The published site could not be checked: {error}\n")
        return 1

    if wrong:
        out.write(f"FAILED: {address} is not the site that was built:\n")
        for name, problem in wrong.items():
            out.write(f"  - {name} {problem}\n")
        return 1
    out.write(f"{address} is the site that was built: {looked_at} of {looked_at} files.\n")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### 2. `tests/scripts/test_live.py` – the whole file, 42 tests

```python
"""Tests for the check of the published site, `scripts/live.py` (task FND-035).

Run from the repository root:

    python -m unittest discover -s tests/scripts -v

No test reaches the internet. The published site is played by a small web
server on this computer, which serves whatever a test tells it to.
"""

import http.server
import io
import shutil
import subprocess
import sys
import tarfile
import tempfile
import threading
import unittest
from pathlib import Path

# The script is not an installed package, so its folder is added to the places
# Python imports from.
sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "scripts"))

import live

ROOT = Path(__file__).resolve().parents[2]
SCRIPT = ROOT / "scripts" / "live.py"

PAGE = b"<!doctype html><title>MotoSphere</title>"
MANIFEST = b'{"format_version": 1, "generated_at": "2026-11-17T19:32:40Z"}'
OLDER = b'{"format_version": 1, "generated_at": "2026-11-16T02:00:00Z"}'

# A small built site: its files, as the upload step names them in the tar.
SITE = {
    "./index.html": PAGE,
    "./favicon.svg": b"<svg xmlns='http://www.w3.org/2000/svg'/>",
    "./favicon.ico": b"\x00\x00\x01\x00",
    "./assets/index-2wkFWPoH.css": b"body{margin:0}",
    "./assets/index-DS90V5py.js": b"console.log('MotoSphere')",
    "./data/manifest.json": MANIFEST,
}
TYPES = {
    "html": "text/html; charset=utf-8",
    "svg": "image/svg+xml",
    "ico": "image/vnd.microsoft.icon",
    "css": "text/css; charset=utf-8",
    "js": "application/javascript; charset=utf-8",
    "json": "application/json; charset=utf-8",
}

Served = dict[str, tuple[int, str, bytes]]


class StandInHandler(http.server.BaseHTTPRequestHandler):
    """Answers with what the test put into the server's `served` table."""

    def do_GET(self) -> None:
        served: Served = self.server.served  # type: ignore[attr-defined]
        self.server.asked.append(self.path)  # type: ignore[attr-defined]
        status, kind, body = served.get(self.path, (404, "text/html", b"not here"))
        self.send_response(status)
        self.send_header("Content-Type", kind)
        if status in (301, 302):
            self.send_header("Location", "/elsewhere/")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def log_message(self, *_: object) -> None:
        """Keep the test output free of the server's own lines."""


def as_served(site: dict[str, bytes], under: str = "/MotoSphere/") -> Served:
    """The table of a server that publishes this site correctly."""
    served: Served = {}
    for name, content in site.items():
        path = under + name.removeprefix("./")
        served[path] = (200, TYPES[name.rsplit(".", 1)[-1]], content)
    served[under] = served[under + "index.html"]
    return served


class SiteTest(unittest.TestCase):
    """A temporary folder for the built site and a stand-in for the published one."""

    def setUp(self) -> None:
        folder = tempfile.mkdtemp()
        self.addCleanup(shutil.rmtree, folder, ignore_errors=True)
        self.folder = Path(folder).resolve()

        self.server = http.server.ThreadingHTTPServer(("127.0.0.1", 0), StandInHandler)
        self.server.served = as_served(SITE)  # type: ignore[attr-defined]
        self.server.asked = []  # type: ignore[attr-defined]
        # The short interval keeps stopping the server from slowing every test.
        serving = {"poll_interval": 0.01}
        thread = threading.Thread(target=self.server.serve_forever, kwargs=serving, daemon=True)
        thread.start()
        self.addCleanup(thread.join)
        self.addCleanup(self.server.server_close)
        self.addCleanup(self.server.shutdown)
        self.address = f"http://127.0.0.1:{self.server.server_port}/MotoSphere/"

    @property
    def served(self) -> Served:
        table: Served = self.server.served  # type: ignore[attr-defined]
        return table

    @property
    def asked(self) -> list[str]:
        paths: list[str] = self.server.asked  # type: ignore[attr-defined]
        return paths

    def built(self, site: dict[str, bytes] | None = None, name: str = "artifact.tar") -> Path:
        """Write the built site as a tar file, the way the upload step does."""
        archive = self.folder / name
        with tarfile.open(archive, "w") as tar:
            folder = tarfile.TarInfo("./")
            folder.type = tarfile.DIRTYPE
            tar.addfile(folder)
            for path, content in (SITE if site is None else site).items():
                member = tarfile.TarInfo(path)
                member.size = len(content)
                tar.addfile(member, io.BytesIO(content))
        return archive

    def check(self, archive: Path | None = None, wait: float = 0) -> tuple[int, str, list[float]]:
        """Run the check against the stand-in. Returns the code, the output and the pauses."""
        out = io.StringIO()
        pauses: list[float] = []
        code = live.main(
            [str(archive or self.built()), self.address], out, pause=pauses.append, wait=wait
        )
        return code, out.getvalue(), pauses


def no_answer(url: str) -> live.Answer:
    """A fetcher for a site that gives no answer at all."""
    raise live.UnreachableError(f"{url} could not be reached: no answer")


class Recorder(io.StringIO):
    """Output that remembers how much of it had been written each time it was sent."""

    def __init__(self) -> None:
        super().__init__()
        self.sent: list[str] = []

    def flush(self) -> None:
        super().flush()
        self.sent.append(self.getvalue())


class AddressTest(unittest.TestCase):
    def test_accepts_an_encrypted_address_that_ends_with_a_slash(self) -> None:
        address = "https://bigdaddy284.github.io/MotoSphere/"
        self.assertEqual(live.checked_address(address), address)

    def test_accepts_this_computer_without_encryption(self) -> None:
        for address in ("http://127.0.0.1:4173/MotoSphere/", "http://localhost/"):
            with self.subTest(address=address):
                self.assertEqual(live.checked_address(address), address)

    def refused(self, address: str, why: str) -> None:
        with self.assertRaises(live.UnusableError) as caught:
            live.checked_address(address)
        self.assertEqual(str(caught.exception), f"{address} {why}")

    def test_refuses_another_computer_without_encryption(self) -> None:
        self.refused("http://bigdaddy284.github.io/MotoSphere/", "must start with https://")

    def test_refuses_what_is_not_a_web_address(self) -> None:
        for address in (
            "",
            "MotoSphere/",
            "file:///etc/passwd/",
            "ftp://example.org/",
            "https:///",
        ):
            with self.subTest(address=address):
                self.refused(address, "is not a web address")

    def test_refuses_an_address_that_is_not_a_folder(self) -> None:
        self.refused("https://bigdaddy284.github.io/MotoSphere", "must end with a slash")
        self.refused("https://bigdaddy284.github.io", "must end with a slash")

    def test_refuses_an_address_that_carries_more_than_an_address(self) -> None:
        for address in (
            "https://example.org/site/?page=1",
            "https://example.org/site/#top",
            "https://someone:secret@example.org/site/",
        ):
            with self.subTest(address=address):
                self.refused(address, "must be an address and nothing else")


class BuiltFilesTest(SiteTest):
    def refused(self, archive: Path, why: str) -> None:
        with self.assertRaises(live.UnusableError) as caught:
            list(live.built_files(archive))
        self.assertEqual(str(caught.exception), why)

    def test_reads_every_file_with_its_path_inside_the_site(self) -> None:
        self.assertEqual(
            dict(live.built_files(self.built())),
            {path.removeprefix("./"): content for path, content in SITE.items()},
        )

    def test_refuses_a_file_that_is_not_a_tar(self) -> None:
        archive = self.folder / "artifact.tar"
        archive.write_bytes(b"this is not a tar file")

        self.refused(archive, "artifact.tar cannot be read as the built site")

    def test_refuses_a_file_that_is_not_there(self) -> None:
        self.refused(self.folder / "missing.tar", "missing.tar cannot be read as the built site")

    def test_refuses_a_link_inside_the_site(self) -> None:
        archive = self.built()
        with tarfile.open(archive, "a") as tar:
            link = tarfile.TarInfo("./passwords")
            link.type = tarfile.SYMTYPE
            link.linkname = "/etc/passwd"
            tar.addfile(link)

        self.refused(
            archive, "artifact.tar holds ./passwords, which is not a plain file of the site"
        )

    def test_refuses_a_path_that_leaves_the_site(self) -> None:
        for path in ("../outside.txt", "/etc/outside.txt", "assets/../../outside.txt"):
            with self.subTest(path=path):
                archive = self.built({"./index.html": PAGE, path: b"x"}, name="odd.tar")
                self.refused(
                    archive, f"odd.tar holds {path}, which is not a plain file of the site"
                )


class JudgeTest(unittest.TestCase):
    def test_the_built_file_with_its_content_type_is_right(self) -> None:
        answer = live.Answer(200, "application/json", MANIFEST)
        self.assertIsNone(live.judge(answer, "data/manifest.json", MANIFEST))

    def test_an_answer_that_is_not_200_is_wrong(self) -> None:
        for status in (204, 301, 404, 500):
            with self.subTest(status=status):
                answer = live.Answer(status, "application/json", MANIFEST)
                self.assertEqual(
                    live.judge(answer, "data/manifest.json", MANIFEST), f"answered {status}"
                )

    def test_another_content_is_wrong(self) -> None:
        answer = live.Answer(200, "application/json", OLDER)
        self.assertEqual(
            live.judge(answer, "data/manifest.json", MANIFEST), "differs from the built file"
        )

    def test_a_content_type_a_browser_would_not_accept_is_wrong(self) -> None:
        answer = live.Answer(200, "text/plain", b"x")
        self.assertEqual(
            live.judge(answer, "assets/index.js", b"x"),
            "is served as text/plain, expected text/javascript",
        )

    def test_every_kind_of_file_of_the_site_has_a_content_type_rule(self) -> None:
        for name in SITE:
            with self.subTest(file=name):
                self.assertTrue(live.expected_types(name))
        self.assertEqual(live.expected_types("apple-touch-icon.png"), ("image/png",))
        self.assertEqual(live.expected_types("ICON.SVG"), ("image/svg+xml",))

    def test_a_script_may_be_served_under_either_of_its_names(self) -> None:
        for kind in ("text/javascript", "application/javascript"):
            with self.subTest(kind=kind):
                self.assertIsNone(live.judge(live.Answer(200, kind, b"x"), "assets/a.js", b"x"))

    def test_a_file_of_a_kind_without_a_rule_is_judged_by_its_content(self) -> None:
        self.assertIsNone(live.judge(live.Answer(200, "font/woff2", b"x"), "a.woff2", b"x"))
        self.assertEqual(
            live.judge(live.Answer(200, "font/woff2", b"y"), "a.woff2", b"x"),
            "differs from the built file",
        )


class FetchTest(SiteTest):
    def test_returns_the_status_the_content_type_and_the_content(self) -> None:
        self.assertEqual(
            live.fetch(self.address + "data/manifest.json"),
            live.Answer(200, "application/json", MANIFEST),
        )

    def test_an_answer_that_is_not_200_is_returned_not_raised(self) -> None:
```
