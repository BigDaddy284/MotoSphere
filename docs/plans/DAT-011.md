## Objective

The store holds countries, so that everything else can say where it
is.

## Why

A track, an event, a rider and a source are each in a country, and the
globe is entered by country (DESIGN.md). Nothing can refer to a
country before there is a table of them. It is also the first table of
collected records: until now the eight columns by which a record says
where it came from (DAT-008), their index (DAT-045) and their rule
(DAT-046) were proved on tables made for the tests. "Every record must
retain its source and collection history." (CLAUDE.md §11).

## What this task is, and what it is not

- **It is** one table, `country`, its model `Country`, the thirteenth
  migration that makes it, and their tests.
- **It is not** the countries themselves. The table has no rows; the
  countries of ISO 3166-1 are loaded by DAT-012, from a source whose
  licence allows it. No country is written into the code or a
  migration here, and the tests use a handful of real codes as
  examples only.
- **It is not** the country of a source. `TASKS.md` had that in this
  task; it is a second objective with a migration of its own, which
  changes a table that is there, and is now DAT-057 (PLAN-042).
- **It is not** a list of the standard's codes in the table. The table
  holds a code to its form; which codes there are is what the source
  says.

## Design in short

    class Country(Collected):
        __tablename__ = "country"
        __table_args__ = (_capitals("alpha_2", 2), _capitals("alpha_3", 3))

        alpha_2: Mapped[str] = mapped_column(unique=True)
        alpha_3: Mapped[str] = mapped_column(unique=True)
        name: Mapped[NotEmpty]

and each check as SQLite is given it:

    CONSTRAINT ck_country_alpha_2_two_capitals
        CHECK ((alpha_2 GLOB '[A-Z][A-Z]') AND instr(alpha_2, char(0)) = 0)

The table then has fourteen columns: the key, the three above, the
eight of a collected record, and the two times. `Collected` gives the
eight with their checks, the reference to `source`, the index
`ix_country_source_id` and the check of the two times. The migration
writes all of it out as plain SQL, as every migration does, and the
test of the models and the migrations holds the two together.

## What the task left open, and what the trial settled

- **Which of the standard's things are columns.** The two codes of
  letters and the English short name, as `TASKS.md` says. Not the
  number the standard gives each country: nothing in the design asks
  for it, and a column nobody reads is a column that can be wrong
  unseen. It can be added by a migration when something needs it.
- **What the columns are called.** `alpha_2` and `alpha_3`, the
  standard's own words for the two codes, and `name`.
- **How a code is held to its form.** By a check with SQLite's `GLOB`
  and one character class for each letter: `[A-Z][A-Z]`. `GLOB` tells
  small letters from large ones on every machine, whatever a
  connection has been told about `LIKE`, and its ranges are by the
  number of the character, so `[A-Z]` is the 26 letters and no letter
  with an accent, of another alphabet or of double width. The trial
  asked the SQLite of this machine about fifteen texts; the tests ask
  about eighteen for each code, on both machines.
- **A character with the number 0.** `GLOB` reads text up to such a
  character and no further, so `'NZ' || char(0) || 'L'` passes
  `[A-Z][A-Z]`. `length` stops there as well. The check therefore asks
  a second question, `instr(alpha_2, char(0)) = 0`, as the check of a
  web address does (DAT-037), and for the same reason. Three of the
  eighteen texts have such a character.
- **Capitals are not made, they are required.** Neither the model nor
  the table puts a code into capitals. A source that writes `nz` has
  written something other than the standard's code. Whoever reads
  that source decides what it means, in the open; a code put right in
  silence would hide it (CLAUDE.md §11).
- **A helper in the model's module, not a new column type.** The two
  checks differ only in the column and the number of letters, so one
  small function, `_capitals`, gives both. A type that brings its
  check (`DATABASE.md`, "Column types that bring a check") is for
  what many tables have; codes of this form are in one table. The
  codes of regions (DAT-013) have another form.
- **Each code is unique by itself**: `uq_country_alpha_2` and
  `uq_country_alpha_3`. One rule over both together would let two
  countries share a code of two letters.
- **The name is not unique.** A country is known by its codes. Two
  rows with one name are a mistake of a source or a matter for a
  person, and the table does not judge it; nor does it hold a name to
  any form beyond not being empty. A test puts that on record.
- **A country is a collected record**, the first real one. So
  `country` is not on the list `NOT_COLLECTED`, the rule of DAT-046
  holds it to the eight columns from now on, and nothing in that rule
  or its tests had to change.
- **Nothing gives itself a value**, as `Collected` has it: the model
  gives no code, no name and none of the seven things that are known
  of every record.
- **Deleting.** A source that countries came from cannot be deleted
  (the reference, with nothing said of deleting, as in every table of
  collected records). A country can be deleted while nothing refers
  to it. The first table that refers to the countries decides what
  holds them.
- **History.** `change` (DAT-047) works on a country as on the tables
  made for its tests: a new name and a new moment it was last seen
  give one row of history each, and a change the table refuses leaves
  neither. Two tests hold that, on the real table.
- **The index.** `ix_country_source_id`, over `source_id` alone, which
  `Collected` gives. SQLite says it uses it to find the countries of
  one source, and reads no table whole when a source is to be
  deleted.
- **Nothing else names the tables of the store.** The trial added the
  table and ran every test of the pipeline before writing a test:
  only the list of the migrations' names had to change. The export,
  the commands and the rules take the tables as they find them.
- **A defect of the documents, found on the way.** The table in
  `DATABASE.md` of the tables that hold no collected records has four
  rows; the list in the code has five, with `review_item` since
  DAT-010. The row is added here, in the words of the code.

### 1. `backend/src/motosphere/db/models/country.py` – new, the whole file

```python
"""The countries: where in the world everything else is.

A country is known by its two codes of ISO 3166-1, the international
standard for the names of countries: the code of two letters ("NZ") and
the code of three ("NZL"). This module has the model of the table that
knows them, :class:`Country`.

A country is a collected record. Its codes and its name are read from a
source, and every row says which one and when
(:class:`motosphere.db.models.provenance.Collected`).
"""

from sqlalchemy import CheckConstraint, ColumnClause, and_, column, func
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.models.provenance import Collected
from motosphere.db.texts import NotEmpty

__all__ = ["Country"]


def _capitals(name: str, count: int) -> CheckConstraint:
    """Give the check that the column ``name`` holds ``count`` capital letters and no more.

    The letters are the 26 of the English alphabet, "A" to "Z". SQLite's
    GLOB tells small letters from large ones on every machine, and takes
    a letter with an accent, or one of another alphabet, for none of the
    26.
    """
    text: ColumnClause[str] = column(name)
    are_capitals = text.bool_op("GLOB")("[A-Z]" * count)
    # GLOB reads text up to a character with the number 0 and no further,
    # so anything after one would go unseen.
    has_no_nought = func.instr(text, func.char(0)) == 0
    words = {2: "two", 3: "three"}
    return CheckConstraint(
        and_(are_capitals, has_no_nought), name=f"{name}_{words[count]}_capitals"
    )


class Country(Collected):
    """One country: its two codes of ISO 3166-1 and what it is called in English.

    The codes are what a country is known by: no two countries have one
    code of two letters, and no two have one code of three. A code is
    stored in capitals, and the table itself refuses every other form.
    """

    __tablename__ = "country"
    __table_args__ = (_capitals("alpha_2", 2), _capitals("alpha_3", 3))

    # Its code of two letters, as "NZ" for New Zealand.
    alpha_2: Mapped[str] = mapped_column(unique=True)
    # Its code of three letters, as "NZL".
    alpha_3: Mapped[str] = mapped_column(unique=True)
    # What it is called in English: the short name of the standard, as its
    # source writes it. Two rows can hold one name: a country is known by
    # its codes, and a name is not held to be anything but text.
    name: Mapped[NotEmpty]
```

    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:

def keep(store: Engine, country: Country) -> int:
    """Store a country in a unit of work of its own, and give its key."""
    with unit_of_work(store) as work:
        work.add(country)
    return country.id


def the_country(store: Engine, key: int) -> Country:
    """Read a country anew from the store."""
    with unit_of_work(store) as work:
        return work.execute(select(Country).where(Country.id == key)).scalar_one()

def held(store: Engine) -> list[tuple[object, ...]]:
    """The rows of the table as SQLite holds them, by their key."""
    with store.connect() as connection:
        return [
            tuple(row) for row in connection.exec_driver_sql("SELECT * FROM country ORDER BY id")

def codes(store: Engine) -> list[tuple[str, str, str]]:
    """The two codes and the name of every country, by their key."""
    with store.connect() as connection:
        found = connection.exec_driver_sql("SELECT alpha_2, alpha_3, name FROM country ORDER BY id")
        return [(str(two), str(three), str(name)) for two, three, name in found]
