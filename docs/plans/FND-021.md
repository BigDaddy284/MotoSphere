# FND-021 – Data manifest export command

**Phase:** 1 – Foundation
**Depends on:** FND-020 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §11, §14, `docs/WORKFLOW.md`, `ARCHITECTURE.md` §4, §6

## Objective

The pipeline produces its first real published file.
`python -m motosphere export --out <directory>` writes `manifest.json`: the
version of the data format, when the data was generated (UTC), the MotoSphere
version that generated it, and the number of published records of each kind.

Nothing is published yet, so the record counts are an empty object. They are
not filled with invented kinds or numbers: later tasks add each kind when its
data exists. The list of published files with content hashes (PUB-001) and
the JSON Schema file (PUB-002) are later tasks too.

## Design in short

- `motosphere.publish` is a new package for everything that leaves the
  pipeline.
  - `publish/manifest.py`: the `Manifest` model (Pydantic, immutable, no
    unknown fields), `build_manifest(now)` and `manifest_to_json(manifest)`.
  - `publish/files.py`: `write_text_atomically(path, text)`.
  - `publish/export.py`: `export_published_data(directory, now)`, the export
    step. Later tasks add more files to it.
- `cli/export.py` is the command. It takes the time from the clock, calls
  the export step, writes the manifest's path to standard output and logs
  one line. A failure to write gives one line on standard error and exit
  code 1.
- The JSON text is deterministic: sorted keys, two-space indentation, UTF-8,
  `\n` line breaks on every operating system, one line break at the end.
  The same inputs always give the same bytes.
- A file is written to a temporary file in the same directory, which then
  replaces the target in one step. A failure never leaves a partial file,
  and never damages an earlier one.
- The generation time is passed in (`now`), never read inside the model or
  the export step, so tests control it.

### 2. `backend/src/motosphere/publish/manifest.py`

Exactly this content:

```python
"""The manifest: the first published file the site reads.

It says which version of the data format the files use, when they were
generated and by which MotoSphere version, and how many records of each kind
they contain.
"""

import json
from datetime import UTC, datetime
from typing import Annotated

from pydantic import (
    AwareDatetime,
    BaseModel,
    ConfigDict,
    Field,
    NonNegativeInt,
    StringConstraints,
    field_validator,
)

import motosphere

__all__ = [
    "FORMAT_VERSION",
    "MANIFEST_FILE_NAME",
    "Manifest",
    "build_manifest",
    "manifest_to_json",
]

# Raised whenever a published file changes in a way an older site could not read.
FORMAT_VERSION = 1
MANIFEST_FILE_NAME = "manifest.json"

type RecordKind = Annotated[str, StringConstraints(pattern=r"^[a-z][a-z_]*$")]


class Manifest(BaseModel):
    """The content of ``manifest.json``."""

    model_config = ConfigDict(frozen=True, extra="forbid")

    format_version: int = Field(ge=1, description="The version of the published data format.")
    generated_at: AwareDatetime = Field(
        description="When the published files were generated, in UTC, to the second."
    )
    application_version: str = Field(
        min_length=1, description="The MotoSphere version that generated the files."
    )
    counts: dict[RecordKind, NonNegativeInt] = Field(
        description="The number of published records of each kind, for example tracks."
    )

    @field_validator("generated_at", mode="after")
    @classmethod
    def _to_utc_seconds(cls, value: datetime) -> datetime:
        return value.astimezone(UTC).replace(microsecond=0)


def build_manifest(now: datetime) -> Manifest:
    """Return the manifest for the data as it is at ``now``.

    ``now`` must carry its time zone. Nothing is published yet, so there are no
    record counts.
    """
    return Manifest(
        format_version=FORMAT_VERSION,
        generated_at=now,
        application_version=motosphere.__version__,
        counts={},
    )


def manifest_to_json(manifest: Manifest) -> str:
    """Return the manifest as JSON text.

    The same manifest always gives the same text: keys are sorted, the layout
    is fixed and the text ends with one line break.
    """
    return (
        json.dumps(manifest.model_dump(mode="json"), indent=2, sort_keys=True, ensure_ascii=False)
        + "\n"
    )
```

### 3. `backend/src/motosphere/publish/files.py`

Exactly this content:

```python
"""Writing published files safely."""

import contextlib
import os
import secrets
from pathlib import Path

__all__ = ["write_text_atomically"]


def write_text_atomically(path: Path, text: str) -> None:
    """Write ``text`` to ``path`` as UTF-8 so that a reader never sees half a file.

    The text goes to a temporary file in the same directory, which then takes
    the place of ``path`` in one step. If anything fails, the temporary file is
    removed and whatever was at ``path`` before is left untouched. Line breaks
    are written exactly as given, on every operating system.
    """
    temporary = path.with_name(f"{path.name}.{secrets.token_hex(8)}.tmp")
    try:
        with temporary.open("xb") as handle:
            handle.write(text.encode("utf-8"))
            handle.flush()
            os.fsync(handle.fileno())
        temporary.replace(path)
    except BaseException:
        with contextlib.suppress(FileNotFoundError):
            temporary.unlink()
        raise
```

The file is opened in binary mode on purpose: text mode would turn `\n` into
`\r\n` on Windows, and published files must be identical on every system.
Mode `x` refuses to reuse an existing temporary file.

### 4. `backend/src/motosphere/publish/export.py`

Exactly this content:

```python
"""The export step: write the published files into a directory."""

from datetime import datetime
from pathlib import Path

from motosphere.publish.files import write_text_atomically
from motosphere.publish.manifest import MANIFEST_FILE_NAME, build_manifest, manifest_to_json

__all__ = ["export_published_data"]


def export_published_data(directory: Path, now: datetime) -> Path:
    """Write the published files into ``directory`` and return the manifest's path.

    The directory is created if it does not exist. ``now`` is the generation
    time recorded in the manifest and must carry its time zone. Raises
    :class:`OSError` if the directory cannot be created or written to.
    """
    directory.mkdir(parents=True, exist_ok=True)
    manifest_path = directory / MANIFEST_FILE_NAME
    write_text_atomically(manifest_path, manifest_to_json(build_manifest(now)))
    return manifest_path
```

### 5. `backend/src/motosphere/cli/export.py`

Exactly this content:

```python
"""The ``export`` command: write the published data files into a directory."""

import argparse
import logging
import sys
from datetime import UTC, datetime
from pathlib import Path

from motosphere.core.settings import Settings
from motosphere.publish.export import export_published_data

__all__ = ["EXIT_EXPORT_FAILED", "add_parser", "run"]

EXIT_EXPORT_FAILED = 1

_logger = logging.getLogger(__name__)


def _directory(value: str) -> Path:
    if value.strip() == "":
        raise argparse.ArgumentTypeError("the directory must not be empty")
    return Path(value)


def add_parser(commands: "argparse._SubParsersAction[argparse.ArgumentParser]") -> None:
    """Register the ``export`` command."""
    parser = commands.add_parser(
        "export",
        help="write the published data files",
        description="Write the published data files into a directory.",
        allow_abbrev=False,
    )
    parser.add_argument(
        "--out",
        required=True,
        type=_directory,
        metavar="<directory>",
        help="the directory to write into; it is created if it does not exist",
    )
    parser.set_defaults(handler=run)


def _one_line(text: str) -> str:
    return " ".join(text.split())


def run(arguments: argparse.Namespace, _settings: Settings) -> int:
    """Export into ``--out`` and write the manifest's path to standard output."""
    directory: Path = arguments.out
    try:
        manifest_path = export_published_data(directory, datetime.now(UTC))
    except OSError as error:
        reason = _one_line(error.strerror or str(error))
        sys.stderr.write(f"Export failed: cannot write to {directory}: {reason}\n")
        return EXIT_EXPORT_FAILED

    _logger.info("Exported the published data to %s", directory)
    sys.stdout.write(f"{manifest_path}\n")
    return 0
```

## Acceptance criteria

1. `python -m motosphere export --out <directory>` creates the directory if
   needed, writes a `manifest.json` that validates against the model, prints
   its path and exits 0.
2. The same inputs give byte-identical output; two real runs differ only in
   the generation time. Line breaks are `\n` on every system.
3. A failed write never leaves a partial or temporary file and never damages
   an earlier manifest.
4. An output path that cannot be written gives one line starting
   `Export failed: ` on standard error and exit code 1. A missing or empty
   `--out` is a usage error with exit code 2.
5. The manifest holds no invented data: `counts` is empty.
6. `uv run pytest` reports 114 passed; mypy, ruff check, ruff format check
   and the lock check pass; repository checks pass (9); the frontend is
   untouched.
7. Only the files under "Scope" changed; no dependency changed.
