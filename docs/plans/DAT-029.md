## Objective

Every table has the same key, one whole-number column `id` that a model
gets without naming it, and SQLite never gives a key twice; a test holds
every table to that.

## Why

Records will be pointed at by their key from other tables: a record's
change history, where it was collected from, the review queue. SQLite, left
alone, gives the key of a deleted last row to the next new row. The history
of the deleted row would then be the history of a row it has nothing to do
with, and nothing would show it. So the key is decided once, before the
first table: every table has it, and no key is ever given twice.

This is the first half of what PLAN-017 called "DAT-029 – Every table's key
and timestamps". The planner's trial found the key to be a task of its own
(PLAN-018, in `PROGRESS.md`); the timestamps follow as DAT-031.

## Design in short

- **`Base` gives every model its key**: one line,
  `id: Mapped[int] = mapped_column(primary_key=True, sort_order=-1)`. A
  model does not name it. `sort_order=-1` makes `id` the first column of
  every table.
- **No key is given twice.** `Base` already makes each model's table
  strict when the model is defined (`__init_subclass__`). In the same
  place it now also asks SQLite for a key that is never given twice
  (SQLAlchemy's `sqlite_autoincrement`), so a model cannot leave it out,
  also not by saying something else of its table. In the file the key is
  written `id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT`.
- **The key has no name any more.** SQLAlchemy writes such a key with its
  column, and there it has no name; so the `pk` line of `NAMING` goes, and
  `broken_rules` no longer holds the key to the naming rule. Nothing is
  lost: SQLite cannot change a key by its name (a key changes only by
  building the table anew), and it reports a key that is there twice by
  table and column ("UNIQUE constraint failed: item.id"), named or not.
- **`broken_rules` gets one more rule**: a table must have exactly this
  key. One sentence names a table that does not: it has no key, a key of
  another name, of several columns, not a whole number, one that is the
  key of another table (a foreign key), or one that may be given twice.
  These are the cases in which SQLite would not do what the rule promises.
  The sentences of a table come in the order strict, key, names.
- **A row may be stored with a key of its own**, and later keys come
  after it. The store will be rebuilt from text files (DAT-020), and the
  rebuilt rows must keep their keys.
- **SQLite keeps the last key each table gave** in a table of its own,
  `sqlite_sequence`. A copy of the store that is to keep the promise has
  to keep it too; `TASKS.md` says so in DAT-019 and DAT-020.
- No new package, no table, no migration.

### 1. `backend/tests/integration/test_key.py` – new, the whole file, 12 tests

```python
"""Tests of the key every table has, with tables made in a real SQLite file.

The two models here are made for the tests. They are subclasses of the
real ``Base`` and name no key, so they prove what it gives them, but they
are kept in a schema of their own (``Proof.metadata``), so the real schema
never sees them.
"""

import pytest
from sqlalchemy import Engine, ForeignKey, MetaData, UniqueConstraint, delete, select
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.work import unit_of_work


class Proof(Base):
    """Models of the tests' own: the key ``Base`` gives, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofThing(Proof):
    __tablename__ = "proof_thing"

    name: Mapped[str]


class ProofPart(Proof):
    __tablename__ = "proof_part"
    # A model that says something of its table itself. Its key is the same all the same.
    __table_args__ = (UniqueConstraint("thing_id", "name"),)

    thing_id: Mapped[int] = mapped_column(ForeignKey("proof_thing.id"))
    name: Mapped[str]


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the two tables of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def add(made: Engine, *names: str) -> list[int]:
    """Store a thing of each name, each in a unit of work of its own, and say their keys."""
    keys = []
    for name in names:
        with unit_of_work(made) as work:
            thing = ProofThing(name=name)
            work.add(thing)
            work.flush()
            keys.append(thing.id)
    return keys


def remove(made: Engine, *keys: int) -> None:
    with unit_of_work(made) as work:
        work.execute(delete(ProofThing).where(ProofThing.id.in_(keys)))


def test_the_models_of_these_tests_break_no_rule() -> None:
    assert broken_rules(Proof.metadata) == []


@pytest.mark.parametrize(
    ("table", "others"),
    [("proof_thing", ["name"]), ("proof_part", ["thing_id", "name"])],
    ids=["a model that says nothing of its table", "a model that says something of its table"],
)
def test_the_key_is_the_first_column_and_a_whole_number(
    made: Engine, table: str, others: list[str]
) -> None:
    with made.connect() as connection:
        columns = [
            (name, declared, bool(required), key)
            for _, name, declared, required, _, key in connection.exec_driver_sql(
                f"PRAGMA table_info({table})"
            )
        ]

    assert columns[0] == ("id", "INTEGER", True, 1)
    assert [(name, key) for name, _, _, key in columns[1:]] == [(other, 0) for other in others]


@pytest.mark.parametrize("table", ["proof_thing", "proof_part"])
def test_the_file_says_that_a_key_is_never_given_twice(made: Engine, table: str) -> None:
    with made.connect() as connection:
        written = connection.exec_driver_sql(
            "SELECT sql FROM sqlite_master WHERE name = ?", (table,)
        ).scalar_one()

    assert "id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT" in written


def test_new_rows_get_the_next_key(made: Engine) -> None:
    assert add(made, "first", "second", "third") == [1, 2, 3]


def test_the_key_of_the_last_row_is_not_given_again_when_the_row_is_deleted(made: Engine) -> None:
    add(made, "first", "second")
    remove(made, 2)

    assert add(made, "third") == [3]


def test_no_key_is_given_again_when_every_row_is_deleted(made: Engine) -> None:
    add(made, "first", "second", "third")
    remove(made, 1, 2, 3)

    assert add(made, "fourth") == [4]


def test_no_key_is_given_again_after_the_store_was_closed(made: Engine) -> None:
    add(made, "first", "second")
    remove(made, 1, 2)
    made.dispose()

    assert add(made, "third") == [3]


def test_a_row_written_past_the_model_gets_a_key_that_was_never_given(made: Engine) -> None:
    add(made, "first", "second")
    remove(made, 2)

    with made.begin() as connection:
        connection.exec_driver_sql("INSERT INTO proof_thing (name) VALUES ('third')")
        keys = connection.exec_driver_sql("SELECT id FROM proof_thing ORDER BY id").scalars().all()

    assert keys == [1, 3]


def test_a_row_stored_with_a_key_of_its_own_keeps_it_and_later_keys_come_after_it(
    made: Engine,
) -> None:
    add(made, "first")
    with unit_of_work(made) as work:
        work.add(ProofThing(id=40, name="fortieth"))

    assert add(made, "next") == [41]
    with unit_of_work(made) as work:
        assert work.scalars(select(ProofThing.id).order_by(ProofThing.id)).all() == [1, 40, 41]


def test_every_table_counts_its_own_keys(made: Engine) -> None:
    (thing,) = add(made, "first")
    with unit_of_work(made) as work:
        part = ProofPart(thing_id=thing, name="a part")
        work.add(part)
        work.flush()
        first_part = part.id
    add(made, "second", "third")

    with made.connect() as connection:
        last_keys = connection.exec_driver_sql(
            "SELECT name, seq FROM sqlite_sequence ORDER BY name"
        ).all()

    assert first_part == 1
    assert [tuple(row) for row in last_keys] == [("proof_part", 1), ("proof_thing", 3)]
```

## Acceptance criteria

1. A model that names no key has the column `id`, a whole number, as the
   first column and the key of its table, also when the model says
   something of its table itself.
2. In the file, the key of such a table is written
   `id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT`.
3. A key is not given again: not the key of a deleted last row, not any
   key after every row is deleted, not after the store was closed, and
   not to a row written with plain SQL past the model.
4. A row stored with a key of its own keeps it, and later keys come after
   it. Every table counts its own keys.
5. `broken_rules` names, with one sentence each, a table that has no key,
   a key of another name, of two columns, of text, one that is the key of
   another table, or one that may be given twice; and it gives an empty
   list for the real schema and for the models of the tests.
6. Constraints other than the key, and indexes, are held to the naming
   rule as before.
7. The type check passes with no `ignore`, and the lint with no `noqa`.
8. The full run reports 19 of 19 gates and 993 tests (backend tests
   363).
9. On the pull request, "All gates (Linux)" and "All gates (Windows)" are
   green with those numbers, and the three jobs after the gates are
   skipped.
10. Only the files under "Scope" changed.
