**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §11, §12, `docs/WORKFLOW.md`, `DATABASE.md`

`backend/tests/integration/test_store.py`, `backend/tests/conftest.py`

## Objective

Everything the pipeline writes to the store is written in units of work,
each of which is kept as a whole or not at all.

## Why

DAT-021 gave the pipeline one way to open its store, and every connection
of that engine takes failed work back as a whole. But a connection is not
what the pipeline's code will work with: it will add, change and read
records through an SQLAlchemy session. A session by itself promises
nothing about when work is kept:

1. **Nothing says where a piece of work ends.** A session commits when it
   is told to. A collector that commits after every record leaves half a
   collection behind when the next record fails, and `CLAUDE.md` §11 wants
   accuracy before quantity.
2. **A session can be used again after it was closed.** It then opens a new
   connection that nothing commits and nothing closes, and on Windows the
   store's file can no longer be moved or removed.
3. **What a session loaded is forgotten when it commits**, and reading it
   afterwards asks the database again, which a finished unit cannot do.

This is the last third of the old "DAT-002 – Store settings and connection
module" (PLAN-013).

## Design in short

- One new module, `motosphere.db.work`, with one function,
  `unit_of_work(store)`, used in a `with` statement on the engine
  `open_store` returned. It gives an SQLAlchemy `Session`.
- **Kept as a whole or not at all.** The function is SQLAlchemy's own
  pattern, `with Session(...) as work, work.begin():`. When the block ends,
  the work is committed; when it raises, it is taken back; the session is
  closed either way, and with it the connection.
- **The error is the caller's.** Nothing catches or wraps it.
- **No commit part-way.** The session is a small subclass whose `commit()`
  raises `RuntimeError` with one plain sentence. The end of the unit does
  not go through that method, so it still commits. Work that took itself
  back with `rollback()` cannot go on in the same unit: SQLAlchemy refuses
  the next statement, and nothing is kept.
- **Over means over**: `close_resets_only=False`, so the session refuses to
  be used after its unit has ended.
- **What the work read or wrote stays readable**:
  `expire_on_commit=False`. The unit is over at the commit, and nothing
  could load the values again.
- No new package: the session is part of SQLAlchemy, which DAT-021 added.
- No table and no model of the application, no fixture, no command:
  DAT-003 and later. The tests bring two small tables of their own.

## Implementation detail

### 1. `backend/src/motosphere/db/work.py` – new, the whole file

```python
"""Units of work: how the pipeline writes to its data store.

``unit_of_work`` gives a session on the opened store for one piece of work.
The work is kept as a whole when it ends and taken back as a whole when it
fails, and its connection is closed either way.
"""

from collections.abc import Iterator
from contextlib import contextmanager

from sqlalchemy import Engine
from sqlalchemy.orm import Session

__all__ = ["unit_of_work"]


class _Work(Session):
    """The session of one unit of work. Only the end of the unit commits it."""

    def commit(self) -> None:
        raise RuntimeError(
            "A unit of work is kept as a whole when it ends; it cannot be committed part-way."
        )


@contextmanager
def unit_of_work(store: Engine) -> Iterator[Session]:
    """Give a session for one unit of work on the store ``open_store`` returned.

    Use it in a ``with`` statement. When the block ends, everything the work
    did is committed together. When the block raises, everything it did is
    taken back, a new table included, and the error reaches the caller as it
    was raised. The connection is closed either way.

    What the work read or wrote can still be read after the unit has ended,
    as it was at that moment. The session itself cannot be used again.
    """
    with (
        _Work(
            store,
            # What was loaded stays readable after the commit: the unit is over
            # then, and nothing could load it again.
            expire_on_commit=False,
            # Closed means closed. Used again, the session would open a
            # connection that nothing commits and nothing closes.
            close_resets_only=False,
        ) as work,
        work.begin(),
    ):
        yield work
```

### 2. `backend/tests/integration/test_work.py` – new, the whole file, 18 tests

```python
"""Tests of units of work, against a real SQLite file in the test's own folder."""

from collections.abc import Callable
from pathlib import Path

import pytest
from sqlalchemy import Engine, ForeignKey, event, select, text
from sqlalchemy.exc import IntegrityError, InvalidRequestError
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column

from motosphere.db.store import open_store
from motosphere.db.work import unit_of_work

Step = Callable[[Session], object]

BROKEN_KEY = "FOREIGN KEY constraint failed"


class Base(DeclarativeBase):
    pass


class Parent(Base):
    __tablename__ = "parent"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str]


class Child(Base):
    __tablename__ = "child"

    id: Mapped[int] = mapped_column(primary_key=True)
    parent_id: Mapped[int] = mapped_column(ForeignKey("parent.id"))


class StoppedFromOutside(BaseException):
    """Like Ctrl+C: an error that is not an ordinary exception."""


def a_store(path: Path) -> Engine:
    store = open_store(path)
    Base.metadata.create_all(store)
    return store


def names(store: Engine) -> list[str]:
    with store.connect() as connection:
        found = connection.exec_driver_sql("SELECT name FROM parent ORDER BY name")
        return [str(name) for (name,) in found]


def tables(store: Engine) -> list[str]:
    with store.connect() as connection:
        found = connection.exec_driver_sql("SELECT name FROM sqlite_master ORDER BY name")
        return [str(name) for (name,) in found]


def connections(store: Engine) -> tuple[list[object], list[object]]:
    """The connections the store opens and closes from now on, as two growing lists."""
    opened: list[object] = []
    closed: list[object] = []
    event.listen(store, "connect", lambda connection, _record: opened.append(connection))
    event.listen(store, "close", lambda connection, _record: closed.append(connection))
    return opened, closed


def do(store: Engine, *steps: Step) -> Session:
    """Do the steps as one unit of work and give back its session."""
    with unit_of_work(store) as work:
        for step in steps:
            step(work)
    return work


def write(name: str) -> Step:
    """A row written with a statement, at once."""
    statement = text("INSERT INTO parent (name) VALUES (:name)")
    return lambda work: work.execute(statement, {"name": name})


def add(*rows: Base) -> Step:
    """Rows that are only added: they are written when the work ends."""
    return lambda work: work.add_all(rows)


def fail_with(error: BaseException) -> Step:
    def step(_work: Session) -> None:
        raise error

    return step


def fail() -> Step:
    return fail_with(RuntimeError("the work failed part-way"))


def test_work_that_ends_is_kept_for_the_next_unit_of_work(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    do(store, write("first"))

    with unit_of_work(store) as work:
        found = work.scalars(select(Parent.name)).all()
    assert found == ["first"]


def test_work_that_ends_is_there_when_the_store_is_opened_again(tmp_path: Path) -> None:
    path = tmp_path / "store.sqlite3"

    do(a_store(path), write("first"))

    assert names(open_store(path)) == ["first"]


def test_rows_that_were_only_added_are_written_when_the_work_ends(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    do(store, add(Parent(name="first"), Parent(name="second")))

    assert names(store) == ["first", "second"]


def test_work_that_fails_leaves_no_row(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    with pytest.raises(RuntimeError, match="part-way"):
        do(store, write("first"), add(Parent(name="second")), lambda work: work.flush(), fail())

    assert names(store) == []


def test_work_that_fails_leaves_no_new_table(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    new_table = text("CREATE TABLE extra (id INTEGER PRIMARY KEY)")

    with pytest.raises(RuntimeError, match="part-way"):
        do(store, lambda work: work.execute(new_table), write("first"), fail())

    assert tables(store) == ["child", "parent"]


def test_the_store_can_be_worked_on_after_work_that_failed(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    with pytest.raises(RuntimeError, match="part-way"):
        do(store, write("first"), fail())

    do(store, write("second"))

    assert names(store) == ["second"]


def test_the_error_that_ended_the_work_reaches_the_caller_unchanged(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    error = RuntimeError("the work failed part-way")

    with pytest.raises(RuntimeError) as caught:
        do(store, write("first"), fail_with(error))

    assert caught.value is error


def test_work_that_is_stopped_from_outside_is_taken_back_too(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    with pytest.raises(StoppedFromOutside):
        do(store, write("first"), fail_with(StoppedFromOutside()))

    assert names(store) == []


def test_a_row_without_its_parent_ends_the_whole_unit_of_work(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    an_orphan = text("INSERT INTO child (parent_id) VALUES (7)")

    with pytest.raises(IntegrityError, match=BROKEN_KEY):
        do(store, write("first"), lambda work: work.execute(an_orphan), write("second"))

    assert names(store) == []


def test_a_row_without_its_parent_that_was_only_added_ends_the_unit_when_it_ends(
    tmp_path: Path,
) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    with pytest.raises(IntegrityError, match=BROKEN_KEY):
        do(store, write("first"), add(Child(parent_id=7)))

    assert names(store) == []


def test_a_unit_of_work_uses_one_connection_and_closes_it(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    opened, closed = connections(store)

    do(store, write("first"), write("second"), add(Parent(name="third")))

    assert len(opened) == 1
    assert closed == opened


def test_the_connection_is_closed_after_work_that_fails(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    opened, closed = connections(store)

    with pytest.raises(RuntimeError, match="part-way"):
        do(store, write("first"), fail())

    assert len(opened) == 1
    assert closed == opened


def test_the_file_can_be_removed_after_units_of_work(tmp_path: Path) -> None:
    path = tmp_path / "store.sqlite3"
    store = a_store(path)
    do(store, write("first"))
    with pytest.raises(RuntimeError, match="part-way"):
        do(store, write("second"), fail())

    path.unlink()

    assert not path.exists()


def test_work_cannot_be_committed_part_way(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    with pytest.raises(RuntimeError) as refusal:
        do(store, write("first"), lambda work: work.commit(), write("second"))

    assert str(refusal.value) == (
        "A unit of work is kept as a whole when it ends; it cannot be committed part-way."
    )
    assert names(store) == []


def test_work_that_took_itself_back_cannot_go_on(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")

    with pytest.raises(InvalidRequestError):
        do(store, write("first"), lambda work: work.rollback(), write("second"))

    assert names(store) == []


def test_what_a_unit_of_work_wrote_can_be_read_after_it_has_ended(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    opened, _closed = connections(store)
    row = Parent(name="first")

    do(store, add(row))

    assert (row.id, row.name) == (1, "first")
    assert len(opened) == 1


def test_what_a_unit_of_work_read_can_be_read_after_it_has_ended(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    do(store, write("first"))
    opened, _closed = connections(store)

    with unit_of_work(store) as work:
        row = work.scalars(select(Parent)).one()

    assert (row.id, row.name) == (1, "first")
    assert len(opened) == 1


def test_a_unit_of_work_cannot_be_used_after_it_has_ended(tmp_path: Path) -> None:
    store = a_store(tmp_path / "store.sqlite3")
    opened, closed = connections(store)
    work = do(store, write("first"))

    try:
        with pytest.raises(InvalidRequestError):
            work.execute(text("SELECT 1"))
    finally:
        work.close()

    assert len(opened) == 1
    assert closed == opened
```

The steps that call a method of the session are written as
`lambda work: work.commit()`, not as `Session.commit`: the second would
call the method of SQLAlchemy's own class and pass the guard by.

The last test closes the session again in a `finally`. With the code as it
is that does nothing. If the session could still be used, it would have
opened a connection by then, and the `finally` closes it, so that the test
fails for its own reason only.

## Acceptance criteria

1. Work done in `with unit_of_work(store) as work:` is committed when the
   block ends, rows that were only added included. It is there for the next
   unit of work and when the store is opened again.
2. Work that raises leaves nothing behind, neither a row nor a new table,
   whether an ordinary exception ended it or one that is not (as Ctrl+C
   is). The store can be worked on afterwards.
3. The error that ended the work reaches the caller as the same object.
4. A row that breaks a foreign key ends the whole unit, whether its
   statement was sent at once or the row is written when the unit ends.
5. A unit of work uses one connection and closes it, when the work ends
   and when it fails; the file can be removed afterwards, on Windows too.
6. A unit that calls `commit()` is refused with "A unit of work is kept as
   a whole when it ends; it cannot be committed part-way." and nothing of
   it is kept. A unit that called `rollback()` cannot go on, and nothing of
   it is kept.
7. After the unit has ended, what it read or wrote can be read without a
   new connection, and the session refuses to be used.
8. The type check passes with SQLAlchemy's own types and no `ignore`.
9. No existing test changed, and all pass. The full run reports 19 of 19
   gates and 828 tests (backend tests 198).
10. On the pull request, "All gates (Linux)" and "All gates (Windows)" are
    green with those numbers, and the three jobs after the gates are
    skipped.
11. Only the files under "Scope" changed.
