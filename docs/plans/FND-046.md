## Objective

The project asks for the oldest Node.js that every package in the
frontend's lock file runs on, which is 22.22.2, in the package file, the
lock file and the README, and a repository check holds it there.

## Why

The planner's trial of GLB-001, which adds the engine of the globe, read
which Node.js each locked package says it runs on, to see what the
engine needs. It found that the number the project gives today is wrong
without the engine:

- `frontend/package.json` says `"node": ">=22.12"`, and the README says
  "Node.js 22.12 or newer" in three places.
- In `frontend/package-lock.json`, `jsdom` 31.0.1 and `w3c-xmlserializer`
  6.0.0, on which every unit test of the frontend runs, say
  `^22.22.2 || ^24.15.0 || >=26.0.0`. `undici` says `>=22.19.0`, and
  six more packages need 22.13 or 22.14.

Nothing failed, because npm installs a package on an older Node.js with
a warning only, and every computer that runs the gates has a newer one
(22.23.4 at the planner's, the newest 22 on GitHub). But
`python scripts/tools.py` says `FOUND` for a Node.js 22.12, and the
README tells a person that it is enough. It is a known defect, and
"Do not move known bugs into future tasks" (CLAUDE.md §3). The tasks of
the globe add packages with needs of their own, so the number must be
held by a check before they start.

## What this task is, and what it is not

- **It is** one number in three files: `>=22.22.2` in
  `frontend/package.json` and in the project's own entry of
  `frontend/package-lock.json`, and "22.22.2 or newer" in the three
  places of `README.md`.
- **It is** one new file of repository checks,
  `tests/repo/test_node_version.py`, which holds that number to the lock
  file from now on.
- **It is not** a change of any package: the lock file changes in one
  line, and `npm ci` installs what it installed.
- **It is not** a change to `scripts/tools.py` or its tests. The check
  of the tools reads the number where it is written and prints
  `(22.22.2 or newer is needed)` by itself; its tests write package
  files of their own.
- **It is not** a change to the workflow. GitHub installs the newest
  Node.js 22, and the existing check that the workflow's Node.js is the
  one the project asks for (`>=22.`) holds as it is.
- **It is not** a rule for Python: its least version is the oldest the
  pipeline supports by decision, and the workflow tests on exactly it.

## Design in short

The checks are standard library only and stand in one file, as the
repository checks do. What they need to read is in small functions of
that file:

- `alternatives(written)` reads a range as a package writes it, into
  where each alternative begins and before which version it ends.
  `allows(written, node)` says whether a range allows a Node.js.
- `oldest_enough(ranges)` is the oldest Node.js that every one of the
  ranges allows. Only where a range begins can the answer change, so
  those versions are tried.
- `ranges_of(lock)` is every package of a lock file that names a
  Node.js, without the project's own entry; `least_of(package)` is the
  least Node.js a package file asks for, as written; `asked_for_in(text)`
  is every Node.js a text tells a person to have.

Twelve tests, in three classes:

- **Reading a range** (3): what each form allows and does not, at its
  edges; that a form the lock file does not use is refused and not
  guessed at; the oldest Node.js that made-up sets of ranges allow.
- **Going by the files** (4): the ranges of a made-up lock file; a lock
  file that cannot be gone by; the one form of a least version; the
  Node.js a made-up text asks for.
- **The least Node.js** (5), on the real files: the lock file's own
  entry says what the package file says; the lock file holds the
  packages the project names; every locked package allows the least
  Node.js; the least Node.js is the oldest that all of them allow; the
  README names it wherever it names one.

## What the task left open, and what the trial settled

- **Which number?** 22.22.2: the oldest Node.js that all 126 ranges of
  the lock file allow. It is where the range of `jsdom` begins.
- **Whose ranges count?** Those of every package in the lock file:
  packages the application ships, packages only the tests and the build
  use, and the optional ones for other systems. A person who works on
  the project installs them all, and one rule for all is simpler than
  three.
- **Enough for what?** The least Node.js itself is allowed by every
  package. Not every newer Node.js is: `jsdom` allows no Node.js 23 and
  no 25, and two optional packages none from 23.0 to 23.4. The form
  `>=22.22.2` is the one the check of the tools reads and cannot say
  that. Node.js 23 and 25 are short-lived releases; this is recorded as
  a known limitation and not solved here.
- **May the project ask for more than is needed?** No. The check holds
  the least Node.js to exactly the oldest that every package allows, so
  that the number is never chosen by hand. A later task that adds or
  updates a package changes the number in the same pull request when
  the lock file asks for it, up or down. A number above what is needed
  would turn people away for nothing; `>=24.15.0`, which every package
  allows too, is caught by this check and by the existing one of the
  workflow.
- **Which forms of a range are read?** The four the lock file uses:
  `>=22.12.0` (also `>= 12.0.0` and `>=v12.22.7`), `^20.19.0` (also
  `^13.7` and `^10`), a number alone (`20`, `20.19`), and several with
  `||` between. Any other form (`<23`, `~22.12.0`, `>=22 <23`, `*`,
  `22.x`, a whole version alone) raises `NotReadError`, and the check
  fails: the task that brings a package with such a range teaches the
  check to read it. A range that is guessed at could be read wrongly
  for years.
- **How is the checks' own reading tested?** On ranges, lock files and
  texts made up for it. Otherwise a fault in the reading could only
  show when the real files are wrong at the same time: the planner's
  first version of the file let two such faults pass, and the made-up
  cases are what caught them.
- **What is held in the README?** Every place where it names Node.js
  with a number must be of the form "Node.js 22.22.2 or newer", with or
  without the link, and the number is written exactly as in the package
  file. A place that names a number in other words ("at least",
  "v22.12") fails the check instead of being passed over.
- **Is the lock file's entry for the project held too?** Yes: npm
  writes the project's `engines` there, and `npm ci` does not complain
  when the two differ. One test holds them equal.

### 1. `tests/repo/test_node_version.py` – new, the whole file, 12 tests

```python
"""Checks that the project asks for the Node.js its locked packages need (FND-046).

A package in the frontend's lock file may say which Node.js it runs on. The
project says the least Node.js it works with in one place, the `engines` of
`frontend/package.json`; the check of the tools a computer needs
(`scripts/tools.py`) reads it there, and the README repeats it for people.
These checks hold the lock file, that one place and the README together.

Standard library only, as all repository checks. Run from the repository
root:

    python -m unittest discover -s tests/repo -v
"""

import json
import re
import unittest
from collections.abc import Iterable
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
PACKAGE = ROOT / "frontend" / "package.json"
LOCK = ROOT / "frontend" / "package-lock.json"
README = ROOT / "README.md"

Version = tuple[int, int, int]

# The one form in which the project names its least Node.js, which is the
# form the check of the tools reads: `>=22.22.2`.
LEAST = re.compile(r">=(\d+\.\d+(?:\.\d+)?)")
# A version as a package writes it: `22`, `22.13`, `22.13.0`, `v12.22.7`.
WRITTEN = re.compile(r"v?(\d+)(?:\.(\d+))?(?:\.(\d+))?")
# Where the README tells a person which Node.js to have, and any place where
# it names Node.js with a number at all.
README_SAYS = re.compile(r"Node\.js(?:\]\([^)]*\))? (\d+(?:\.\d+)+) or newer")
README_NAMES_A_NUMBER = re.compile(r"Node\.js(?:\]\([^)]*\))?\s+v?\d")


class NotReadError(Exception):
    """A range is written in a form these checks do not read."""


class UnusableError(Exception):
    """A file of the project is not what these checks can go by."""


def parts(written: str) -> tuple[int, ...]:
    """The numbers of a version as they are written: `22.13` is (22, 13)."""
    found = WRITTEN.fullmatch(written)
    if found is None:
        raise NotReadError(written)
    return tuple(int(part) for part in found.groups() if part is not None)


def whole(numbers: tuple[int, ...]) -> Version:
    """A version with all three numbers: (22, 13) is (22, 13, 0)."""
    major, minor, patch = (*numbers, 0, 0)[:3]
    return (major, minor, patch)


def alternatives(written: str) -> list[tuple[Version, Version | None]]:
    """A range as its alternatives: where each begins and, if it ends, before which version.

    Read are the forms the lock file uses: `>=22.12.0`, `>= 12.0.0`, `^20.19.0`,
    `20`, and several of them with `||` between. Anything else is not guessed at.
    """
    read: list[tuple[Version, Version | None]] = []
    for alternative in written.split("||"):
        text = alternative.strip()
        if text.startswith(">="):
            read.append((whole(parts(text[2:].strip())), None))
        elif text.startswith("^"):
            numbers = parts(text[1:])
            if numbers[0] == 0:
                raise NotReadError(written)
            read.append((whole(numbers), (numbers[0] + 1, 0, 0)))
        else:
            numbers = parts(text)
            if len(numbers) == 3:
                raise NotReadError(written)
            ends = (numbers[0] + 1, 0, 0) if len(numbers) == 1 else (numbers[0], numbers[1] + 1, 0)
            read.append((whole(numbers), ends))
    return read


def allows(written: str, node: Version) -> bool:
    """Whether a range a package gives allows this Node.js."""
    return any(
        begins <= node and (ends is None or node < ends) for begins, ends in alternatives(written)
    )


def oldest_enough(ranges: Iterable[str]) -> Version | None:
    """The oldest Node.js that every one of the ranges allows; None when there is none.

    Only where one of the ranges begins can the answer change, so those are
    the versions that are tried.
    """
    every = list(ranges)
    begin = {begins for written in every for begins, _ in alternatives(written)}
    enough = [node for node in begin if all(allows(written, node) for written in every)]
    return min(enough) if enough else None


def node_of(package: object) -> object:
    """What a package, or the project, says of Node.js under `engines`; None when nothing."""
    engines = package.get("engines") if isinstance(package, dict) else None
    return engines.get("node") if isinstance(engines, dict) else None


def packages_of(lock: dict[str, object]) -> dict[str, object]:
    """Every entry of a lock file; the one with no name is the project itself."""
    packages = lock.get("packages")
    if not isinstance(packages, dict):
        raise UnusableError("the lock file has no packages")
    return packages


def ranges_of(lock: dict[str, object]) -> dict[str, str]:
    """Every package of a lock file that says which Node.js it runs on, with its range.

    The project's own entry is left out: it is what is being checked.
    """
    ranges: dict[str, str] = {}
    for name, package in packages_of(lock).items():
        said = node_of(package)
        if name == "" or said is None:
            continue
        if not isinstance(said, str):
            raise UnusableError(f"the lock file: {name} names its Node.js as {said!r}")
        ranges[name] = said
    return ranges


def least_of(package: dict[str, object]) -> str:
    """The least Node.js a package file asks for, as it is written: `22.22.2`."""
    said = node_of(package)
    found = LEAST.fullmatch(said) if isinstance(said, str) else None
    if found is None:
        raise UnusableError(f"the package file names no least Node.js in the form >=1.2: {said!r}")
    return found[1]


def asked_for_in(text: str) -> list[str]:
    """Every Node.js a text tells a person to have, as written: `22.22.2`.

    A text that names Node.js with a number in other words than "or newer"
    is not gone by: a number these checks did not read would not be held.
    """
    said = README_SAYS.findall(text)
    if len(said) != len(README_NAMES_A_NUMBER.findall(text)):
        raise UnusableError("the text names Node.js with a number in words that are not read")
    return said


def names_in(package: dict[str, object], group: str) -> list[str]:
    """The packages the project names in one group of its package file."""
    named = package.get(group)
    return list(named) if isinstance(named, dict) else []


def load(path: Path) -> dict[str, object]:
    loaded = json.loads(path.read_text(encoding="utf-8"))
    if not isinstance(loaded, dict):
        raise UnusableError(f"{path.name} is not a list of names and values")
    return loaded

    def test_the_oldest_node_that_every_range_allows(self) -> None:
        cases: tuple[tuple[tuple[str, ...], Version | None], ...] = (
            ((">=18",), (18, 0, 0)),
            ((">=18", ">=22.12"), (22, 12, 0)),

            ((">=18", "^20.19.0 || >=22.12.0"), (20, 19, 0)),
            (("^20.19.0 || >=22.12.0", "^22.13.0 || >=24.0.0"), (22, 13, 0)),
            (("^20.19.0 || >=22.12.0", "^22.13.0 || >=24.0.0", ">=22.17.0"), (22, 17, 0)),
            (("^22.22.2 || ^24.15.0 || >=26.0.0", ">=22.19.0", ">=22.17.0"), (22, 22, 2)),
            (("^20.19.0 || ^22.13.0 || >=23.5.0", "^22.14.0 || >=24.0.0"), (22, 14, 0)),

            (("^20.19.0 || >=24.0.0", "^22.13.0 || >=26.0.0"), (26, 0, 0)),
            (("^20.19.0", "^22.13.0"), None),
            (("20", ">=22"), None),
            ((), None),
        )
        for ranges, oldest in cases:
            with self.subTest(ranges=ranges):
                self.assertEqual(oldest_enough(ranges), oldest)


class GoingByTheFilesTest(unittest.TestCase):
    def test_the_ranges_of_a_lock_file_are_those_of_its_packages_and_not_the_projects_own(
        self,
    ) -> None:
        lock: dict[str, object] = {
            "packages": {
                "": {"name": "the project", "engines": {"node": ">=30"}},
                "node_modules/one": {"engines": {"node": ">=18"}},
                "node_modules/two": {"engines": {"node": "^20.19.0 || >=22.12.0", "npm": ">=6"}},
                "node_modules/three": {"engines": {"npm": ">=6"}},
                "node_modules/four": {"version": "1.0.0"},
                "node_modules/five": {"engines": ["node >=4"]},
            }
        }

        self.assertEqual(
            ranges_of(lock),
            {"node_modules/one": ">=18", "node_modules/two": "^20.19.0 || >=22.12.0"},
        )

    def test_a_lock_file_these_checks_cannot_go_by_is_said_to_be_one(self) -> None:
        unusable: tuple[dict[str, object], ...] = (
            {},
            {"packages": []},
            {"packages": {"node_modules/one": {"engines": {"node": 22}}}},
        )
        for lock in unusable:
            with self.subTest(lock=lock), self.assertRaises(UnusableError):
                ranges_of(lock)

    def test_the_least_node_of_a_package_file_is_read_in_one_form_only(self) -> None:
        self.assertEqual(least_of({"engines": {"node": ">=22.22.2"}}), "22.22.2")
        self.assertEqual(least_of({"engines": {"node": ">=22.12"}}), "22.12")
        for said in ("^22.22.2", ">= 22.22.2", "22.22.2", ">=22", ">=22.22.2 ", "", None, 22):
            with self.subTest(said=said), self.assertRaises(UnusableError):
                least_of({"engines": {"node": said}})
        without: tuple[dict[str, object], ...] = ({}, {"engines": {}}, {"engines": ">=22.22.2"})
        for package in without:
            with self.subTest(package=package), self.assertRaises(UnusableError):
                least_of(package)

    def test_the_node_a_text_asks_for_is_read_wherever_it_names_one(self) -> None:
        self.assertEqual(asked_for_in("Node.js is needed, and npm with it."), [])

class LeastNodeTest(unittest.TestCase):
    def test_the_lock_file_says_the_same_of_the_project(self) -> None:
        self.assertIsNotNone(node_of(load(PACKAGE)))
        self.assertEqual(node_of(packages_of(load(LOCK))[""]), node_of(load(PACKAGE)))
```
