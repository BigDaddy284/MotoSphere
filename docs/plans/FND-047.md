# FND-047 – The licences of the shipped packages go with the site

**Phase:** 1 – Foundation
**Track:** B (see `TASKS.md`, "Two tracks")
**Depends on:** GLB-001, FND-048 (both merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §12 and §14, `docs/WORKFLOW.md`, `TASKS.md`
("Two tracks" and the entry of this task), `PROGRESS.md` (PLAN-035,

## Objective

The published site carries the licence text of every package it is
built with.

## Why

The site ships code of other people: React today, and from GLB-002 on
the engine of the globe with the packages it needs. Each is used under a
licence, and most of those licences ask the same thing of whoever passes
the code on: that the copyright notice and the licence go with every
copy. The build takes such notices out of the code it makes, so the site
as it is published today carries none. That is a defect of what is
published, found by the trial of GLB-001 (PLAN-035), and CLAUDE.md §3
does not let a known defect wait. It stands before GLB-022, the first
task that puts files of the engine into the site.

## What this task is, and what it is not

- **It is** one step of the build, `frontend/sitebuild/licences.ts`,
  that writes one file into the site, `licences.txt`: the name, the
  version and the licence of every package the lock file installs that
  is not only for the work, each with the licence files the installed
  package brings.
- **It is** the tests of that step: 70 unit tests
  (`frontend/sitebuild/licences.test.ts`) and 5 browser tests
  (`frontend/e2e/licences.spec.ts`).
- **It is** one comment in the source of the page that says where the
  file is.
- **It is not** a list of licences the project accepts. That a package
  under a licence nobody has read is not shipped unnoticed is a check of
  its own, FND-050 (PLAN-038).
- **It is not** a link a visitor sees. Where the application shows its
  credits is decided with the globe's imagery, which must show whose it
  is (ARCHITECTURE.md §8).
- **It is not** a new package. The step uses Node.js and Vite as they
  are installed.
- **It is not** a change to the check of the published site: that check
  compares every file the build made, and the new file is one of them.

## Design in short

- **Which packages.** Every package the lock file
  (`frontend/package-lock.json`) installs that it does not mark as only
  for the work (`"dev": true`): 32 today. That is more than the build
  takes code from today (React and what it needs), and it is what the
  build may take code from, which is the list a person can check
  against the lock file. A package that is put in two places is written
  for each.
- **Which files of a package.** Those in the top folder of the installed
  package whose name is `LICENSE`, `LICENCE`, `COPYING` or `NOTICE`, in
  any case, alone, with a part after a hyphen (`LICENSE-MIT`,
  `LICENSE-APACHE-2.0`) and with `.md`, `.txt` or `.markdown` or
  nothing at the end. A file like `license.js` or `licence-check.sh` is
  not one.
- **The text is kept letter for letter**, but for three things: the line
  ends are plain ones, a byte-order mark at the start is not part of
  the text, and empty lines before the first line and whatever is
  empty after the last are left out. A file that is not text in UTF-8,
  or that is empty, stops the build.
- **A package that brings no licence file stops the build**, unless the
  step names the package whose file gives its licence
  (`TEXT_GIVEN_WITH`). Five packages are named there today, all given
  with `@cesium/engine`, whose licence file has a part "Third-Party
  Code" with their notices: `bitmap-sdf`, `draco3d`, `lerc`,
  `mersenne-twister`, and `@cesium/wasm-splats`, which is Cesium's own
  and stands under the engine's licence.
  A person who has read both files puts a name there; the planner has
  read these. The list is held from both sides: a package on it that
  brings a text, one that is not shipped, and one given with a package
  that brings no text each stop the build.
- **A package that is not installed.** One the lock file marks as
  optional is left out, as npm leaves it out on a computer it is not
  made for. Any other stops the build, with the sentence
  `… is not installed. Run "npm ci" first.`
- **The file.** A head of four lines, then for each package a line of
  78 equals signs, the name and the version, `Licence: ` with what the
  lock file names, and each text under a line that says which file it
  is from. The order is by name, so the file is the same on every
  computer.
- **The step** is a Vite plugin for the build only (`apply: 'build'`),
  which gives the file to the build as an asset with a fixed name. The
  development server does not have it.
- **Where the file is said to be.** In a comment of the page's source,
  `<!-- The licences of the packages this site is built with are in
  licences.txt, beside this page. -->`. Not `<link rel="license">`:
  that says under which licence the page's own content stands, which is
  another matter.
- **Where the code lives.** In `frontend/sitebuild/`, not
  `frontend/build/`: the repository ignores every folder called `build`.
  The unit tests are found there by one more pattern in
  `vitest.config.ts`, and the type check by one more folder in
  `tsconfig.node.json`.

## What the task left open, and what the trial settled

- **Every package that is not only for the work, or only those whose
  code is in the build?** The first. What the build takes is known only
  after the build and changes with every import; the lock file is
  written down and reviewed. The file's first lines say "built with",
  which is true of both.
- **What when a package ships no licence file?** The build stops. Five
  do today; see above.
- **Where does a visitor find the file?** At `licences.txt` beside the
  page (`https://bigdaddy284.github.io/MotoSphere/licences.txt` once
  published), and the source of the page says so.
- **How big is the file?** About 171 kB today, most of it the eight
  copies of the Apache licence. Nothing loads it but a person who asks
  for it.
- **Which licences are there?** As the lock file names them: MIT (15),
  Apache-2.0 (8), ISC (4), BSD-3-Clause (2), 0BSD (1),
  `(MPL-2.0 OR Apache-2.0)` (1, `dompurify`) and `(MIT AND Zlib)` (1,
  `pako`).
- **Is the file the same on Linux and on Windows?** Yes: the order is by
  name and the line ends are made plain. The trial on GitHub builds it
  on both.
- **Does the test server show a missing file?** No: it answers a path
  under the site that it does not know with the page itself and the
  status 200. So the browser tests go by the kind and the text of the
  answer.

+/**
+ * The licences of the packages the site ships.
+ *
+ * The site ships code of other people: React, the engine of the globe and the
+ * packages those need. Each is used under a licence, and most licences ask
+ * that their text go with every copy. The build takes such notices out of the
+ * code it makes, so it writes them into one file of the site instead, as each
+ * package brings them.
+ *
+ * Which packages: every one the lock file installs that is not only for the
+ * work of building and testing. That is what the build may take code from.

+/**
+ * The packages that bring no licence text of their own, each with the package

+ * has read both, never by the build.
+ */
+export const TEXT_GIVEN_WITH: Readonly<Record<string, string>> = {
+  '@cesium/wasm-splats': '@cesium/engine',
+  'bitmap-sdf': '@cesium/engine',
+  draco3d: '@cesium/engine',
+  lerc: '@cesium/engine',

+/** A file of a package that holds a licence, or a notice that goes with one. */
+const HOLDS_A_LICENCE =
+  /^(licen[cs]e|copying|notice)(-[a-z0-9]+(\.[0-9]+)*)*(\.(md|txt|markdown))?$/i

+/** The licences cannot be written, and why. */

+/** A package the lock file installs for the site. */
+export interface Locked {
+  /** Where it is put, as the lock file says: `node_modules/react`. */
+  where: string
+  name: string
+  version: string
+  /** The licence as the package names it: `MIT`, `(MIT AND Zlib)`. */
+  licence: string
+  /** Whether it may be left out on a computer it is not made for. */
+  optional: boolean
+}

+/** One file of a package with a licence in it. */
+export interface LicenceText {
+  file: string
+  text: string

+/** A package the site ships, with the licence texts it brings. */
+export interface Shipped extends Locked {
+  texts: LicenceText[]

+function isRecord(value: unknown): value is Record<string, unknown> {
+  return typeof value === 'object' && value !== null && !Array.isArray(value)
+}
+
+/** The name of a package from where the lock file puts it. */
+function nameAt(where: string): string {
+  const marker = 'node_modules/'
+  return where.slice(where.lastIndexOf(marker) + marker.length)
+}
+
+/** The packages a lock file installs that are not only for the work, by name. */
+export function shippedIn(lock: unknown): Locked[] {
+  if (!isRecord(lock) || !isRecord(lock['packages'])) {
+    throw new LicencesError('The lock file has no list of packages.')
+  }
+  const found: Locked[] = []
+  for (const [where, said] of Object.entries(lock['packages'])) {
+    if (where === '' || !isRecord(said) || said['dev'] === true) {
+      continue
+    }
+    const { version, license: licence } = said
+    if (typeof version !== 'string' || version === '') {
+      throw new LicencesError(`The lock file gives no version for ${where}.`)
+    }
+    if (typeof licence !== 'string' || licence.trim() === '') {
+      throw new LicencesError(`The lock file names no licence for ${where}.`)
+    }
+    found.push({
+      where,
+      name: nameAt(where),
+      version,
+      licence,
+      optional: said['optional'] === true,
+    })
+  }
+  // By name, and the copies of one package by where they are put. No two
+  // packages are put in one place, so no two of these keys are the same.
+  const byKey = new Map(found.map((one) => [`${one.name}\n${one.where}`, one]))
+  return [...byKey.keys()].toSorted().flatMap((key) => byKey.get(key) ?? [])
+}

+/** The licence files of an installed package, by name, as text with plain line ends. */
+export function textsOf(folder: string): LicenceText[] {
+  const reader = new TextDecoder('utf-8', { fatal: true })
+  return readdirSync(folder)
+    .filter((file) => HOLDS_A_LICENCE.test(file) && statSync(join(folder, file)).isFile())
+    .toSorted()
+    .map((file) => {
+      let text: string
+      try {
+        text = reader.decode(readFileSync(join(folder, file)))
+      } catch {
+        throw new LicencesError(`${join(folder, file)} is not text in UTF-8.`)
+      }
+      // Plain line ends, and no empty lines before or after; the rest is
+      // kept letter for letter.
+      text = text
+        .replaceAll('\r\n', '\n')
+        .replaceAll('\r', '\n')
+        .replace(/^(\s*\n)+/, '')
+        .trimEnd()
+      if (text === '') {
+        throw new LicencesError(`${join(folder, file)} is empty.`)
+      }
+      return { file, text }
+    })
+}

+/**
+ * The packages a project ships, each with its licence texts, read from the
+ * project's lock file and its installed packages.
+ */
+export function gather(
+  project: string,
+  givenWith: Readonly<Record<string, string>> = TEXT_GIVEN_WITH,
+): Shipped[] {
+  const lockFile = join(project, 'package-lock.json')
+  let lock: unknown
+  try {
+    lock = JSON.parse(readFileSync(lockFile, 'utf-8'))
+  } catch {
+    throw new LicencesError(`${lockFile} cannot be read.`)
+  }
+  const shipped: Shipped[] = []
+  for (const locked of shippedIn(lock)) {
+    const folder = join(project, locked.where)
+    if (!existsSync(folder)) {
+      if (locked.optional) {
+        continue
+      }
+      throw new LicencesError(`${locked.name} is not installed. Run "npm ci" first.`)
+    }
+    shipped.push({ ...locked, texts: textsOf(folder) })
+  }
+  const withText = new Set(shipped.filter((one) => one.texts.length > 0).map((one) => one.name))
+  const names = new Set(shipped.map((one) => one.name))
+  for (const one of shipped) {
+    const carrier = givenWith[one.name]
+    if (one.texts.length === 0 && carrier === undefined) {
+      throw new LicencesError(
+        `${one.name} brings no licence text, and nothing says which package gives it.`,
+      )
+    }
+    if (one.texts.length > 0 && carrier !== undefined) {
+      throw new LicencesError(
+        `${one.name} brings a licence text of its own and is still listed as bringing none.`,
+      )
+    }
+  }
+  for (const [name, carrier] of Object.entries(givenWith)) {
+    if (!names.has(name)) {
+      throw new LicencesError(`${name} is listed as bringing no licence text and is not shipped.`)
+    }
+    if (!withText.has(carrier)) {
+      throw new LicencesError(
+        `${name} is said to have its licence given with ${carrier}, which brings no licence text.`,
+      )
+    }
+  }
+  return shipped
+}
