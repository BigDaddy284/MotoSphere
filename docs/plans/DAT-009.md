## Objective

The store has a table that keeps, for one field of one record, what it
held before it was changed and what it holds now, when it was changed,
and which collection run or which person caused the change.

## Why

"Preserve original records and update history wherever practical."
(CLAUDE.md §11). A track that a source renames, an event whose date
moves, a result that is corrected: what the store said before must not
be lost when it says something new, and "Historical information must
retain its original date." The first step is the place where the old
value is kept. It comes before the first table of collected records
(DAT-011), so that no record is ever changed without it.

## What this task is, and what it is not

The task as it stood named four things: the table, the function that
writes a change with its history, that history cannot be edited or
deleted, and (in passing) how the history is found. The trial cut it
down to the first, and the other three are tasks of their own
(PLAN-028; CLAUDE.md §1: when uncertain, the smaller task):

- **DAT-009, this task:** the table, its model, its migration, and its
  place on the list of the tables that hold no collected records.
- **DAT-047:** one function changes a field of a record and writes the
  change in the same unit of work.
- **DAT-048:** a row of the history can be neither edited nor deleted.
- **DAT-049:** indexes for the history of one record and for the
  changes a run caused.

So after this task nothing writes a change yet, the model does not stop
an edit, and there is no index. `DATABASE.md` says all three.

## Design in short

- **One table, `record_change`, one row for one field of one record
  that was changed.** Columns after the key: `record_table`,
  `record_id`, `field`, `old_value`, `new_value`, `collection_run_id`,
  `decided_by`, and the two times every table has.
- **One table for the changes of every table.** The record is named by
  the name of its table and its key there. SQLite cannot hold those two
  to a row that exists; the function of DAT-047 will.
- **Values as text**, in the form the store keeps them in. No value is
  a value: `old_value` or `new_value` may be without.
- **Three checks of its own:** the key of the record is above 0; the
  new value is not the old (`old_value IS NOT new_value`); a run caused
  the change or a person did, one of the two
  (`(collection_run_id IS NULL) != (decided_by IS NULL)`). And the
  three checks that the type `NotEmpty` brings, for `record_table`,
  `field` and `decided_by`.
- **One reference**, to the run, which says nothing of what happens
  when the run is deleted: SQLite then refuses.
- **The fifth migration**, `make_the_record_changes`, in plain SQL. The
  schema is at version 5.
- **On the list** `NOT_COLLECTED`, with its reason, between
  `collection_run` and `source`.

## What the task left open, and what the trial settled

- **One table for all, or a table of history for each table of
  records?** One for all. A table beside each would say the same
  columns again every time, with a migration and tests of its own, and
  a question such as "what did this run change" would be asked of all
  of them. The price is that `record_table` and `record_id` are not a
  reference. A test stores a change to a track in a store that has no
  table of tracks, so that nobody takes the table to hold more than it
  does.
- **One row for a field, or one row for a change with all its fields?**
  One for a field. The history of one field is then read without
  taking a row apart, a field that did not change has no row, and the
  acceptance of the task ("one history row with the old and new value")
  is said by the row itself. Whether the rows of one change to several
  fields carry the same moment is for the function that writes them
  (DAT-047).
- **How a value is kept.** As text, in TEXT columns of a strict table.
  Everything the store keeps is text or a whole number already (see
  `DATABASE.md`, "Times", "Calendar days", "Yes or no", "One of a
  list"), and a number has a text. SQLite's column kind `ANY`, which a
  strict table allows, would keep a value as it is given: then `'7'`
  and `7` are two values, and whether a field changed would depend on
  how its value was handed over. A test gives the number 7 past the
  model and reads the text `'7'` back.
- **`IS NOT`, and not `!=`.** In SQL `NULL != NULL` is not true and not
  false, and a check lets through what is not false. So `old_value !=
  new_value` would take a row whose field had no value and has none.
  `IS NOT` says of two missing values that they are the same. The
  trial planted `!=` in the migration and in the model: three tests
  fail each time.
- **"When" is `created_at`.** A change and its history are written in
  one unit of work (DAT-047), so the moment the row was stored is the
  moment of the change. A column `changed_at` would say the same a
  second time, and two columns that must agree need a check to hold
  them.
- **The cause.** A run, by reference, or a person, by name: "which
  collection run or which person's decision". Exactly one. A person is
  a name and not a reference, because the store has no table of people
  and needs none: one owner administers it. The review queue (DAT-010)
  does not exist yet; its task decides whether a change names the
  review item it came from.
- **A run that caused a change cannot be deleted.** The reference has
  no `ON DELETE`. A test deletes a run that caused a change (refused,
  and the change is as it was), changes its key (refused), and deletes
  a run that caused none (taken).
- **No rule that two changes cannot be alike.** A field can change from
  A to B, back, and to B again; that is three true rows, two of them
  alike. The order is the order of the keys, which the store never
  gives twice (`AUTOINCREMENT`, as every table).
- **No index.** `test_in_the_file_the_table_is_as_the_model_says_it`
  holds that there is none, and DAT-049 will change that line, as
  DAT-045 changed the same line for the collected records.
- **The table holds no collected records**, so it goes on the list
  with its reason (DAT-046), and the test that takes each real table
  off the list in turn gets a case for it. Without the entry the
  existing test of the real schema fails and says what to do, which
  the trial saw before it wrote the entry.

### 1. `backend/src/motosphere/db/models/record_change.py` – new, the whole file

```python
"""The changes: what a record said before it was changed.

Nothing MotoSphere has collected is written over without a trace
(DESIGN.md 8, CLAUDE.md 11). When a field of a record is changed, what
it held before is kept, with what it holds now, when it was changed and
what caused the change. This module has the model of the table that
keeps them, :class:`RecordChange`.

One row is one field of one record that was changed. A change to three
fields of a record is three rows.

The table can keep the changes of any table of the store, so it names
the record by the name of its table and its key there, and SQLite does
not hold the two to a row that exists: a reference is to one table. The
store's code, which writes a change with its history, is what holds
them.
"""

from sqlalchemy import CheckConstraint, ForeignKey
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base
from motosphere.db.texts import NotEmpty

__all__ = ["RecordChange"]


class RecordChange(Base):
    """One field of one record that was changed: what it held, what it holds, and why.

    When it was changed is when the row was stored (``created_at``): a
    change and its history are written together. The table itself refuses
    a change that changed nothing, a change that nothing caused and one
    that two things caused, and a key that no record can have.
    """

    __tablename__ = "record_change"
    __table_args__ = (
        CheckConstraint("record_id > 0", name="record_id_positive"),
        # IS NOT, and not !=: no value is a value here, and a field that
        # had none and has none has not changed either.
        CheckConstraint("old_value IS NOT new_value", name="new_value_not_old_value"),
        # A run caused it or a person did: one of the two, and not both.
        CheckConstraint(
            "(collection_run_id IS NULL) != (decided_by IS NULL)",
            name="caused_by_a_run_or_a_person",
        ),
    )

    # The record that was changed: the name of its table, and its key there.
    record_table: Mapped[NotEmpty]
    record_id: Mapped[int]
    # The field that was changed: the name of its column.
    field: Mapped[NotEmpty]
    # What the field held before and what it holds now, as text, in the
    # form the store keeps the value in. No value: the field had none, or
    # has none now.
    old_value: Mapped[str | None]
    new_value: Mapped[str | None]
    # What caused the change: the collection run that found the record
    # changed at its source, or the person who decided it, by name.
    collection_run_id: Mapped[int | None] = mapped_column(ForeignKey("collection_run.id"))
    decided_by: Mapped[NotEmpty | None]
```

### 2. `backend/tests/integration/test_record_change.py` – new, the whole file, 43 tests

```python
"""Tests of the table of the changes to records, against a real SQLite file.

The store of every test is built by the migrations, as a real store is.
What the table must refuse is also written past the model.
"""

from collections.abc import Iterator
from contextlib import contextmanager
from datetime import UTC, datetime

import pytest
from sqlalchemy import Engine, delete, select
from sqlalchemy.exc import IntegrityError

from motosphere.db.models import CollectionRun, RecordChange, Source
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.work import unit_of_work

MOMENT = "2026-11-25T22:00:00.000000+00:00"
BROKEN_KEY = "FOREIGN KEY constraint failed"
NOTHING_CHANGED = "CHECK constraint failed: ck_record_change_new_value_not_old_value"
NO_ONE_CAUSE = "CHECK constraint failed: ck_record_change_caused_by_a_run_or_a_person"
# A row written past the model: every column but the key, in the table's order.
PAST_THE_MODEL = (
    "INSERT INTO record_change (record_table, record_id, field, old_value, new_value, "
    "collection_run_id, decided_by, created_at, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)"
)
WHAT_IT_HOLDS = (
    "SELECT record_table, record_id, field, old_value, new_value, collection_run_id, "
    "decided_by FROM record_change ORDER BY id"
)


@contextmanager
def refused(why: str) -> Iterator[None]:
    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:
        yield
    assert str(refusal.value.orig) == why


def a_run(store: Engine) -> int:
    """Store a source and a run of it, and give the key of the run."""
    source = Source(
        name="Example Federation",
        website="https://federation.example",
        category=SourceCategory.GOVERNING_BODY,
        collection_method=CollectionMethod.RSS,
    )
    with unit_of_work(store) as work:
        work.add(source)
        work.flush()
        run = CollectionRun(source_id=source.id, started_at=datetime(2026, 11, 25, 21, tzinfo=UTC))
        work.add(run)
    return run.id


def write(store: Engine, **given: object) -> None:
    """Write a change past the model, as plain SQL: one a person decided, but for what is given."""
    row: dict[str, object] = {
        "record_table": "track",
        "record_id": 7,
        "field": "name",
        "old_value": "Example Park",
        "new_value": "Example Raceway",
        "collection_run_id": None,
        "decided_by": "Jo Example",
        "created_at": MOMENT,
        "updated_at": MOMENT,
    }
    assert set(given) <= set(row)
    row.update(given)
    with store.begin() as connection:
        connection.exec_driver_sql(PAST_THE_MODEL, tuple(row.values()))


def held(store: Engine) -> list[tuple[object, ...]]:
    """What the table holds, as SQLite holds it, by the key, without the two times."""
    with store.connect() as connection:
        return [tuple(row) for row in connection.exec_driver_sql(WHAT_IT_HOLDS)]


def test_in_the_file_the_table_is_as_the_model_says_it(newest: Engine) -> None:
    with newest.connect() as connection:
        columns = [
            (name, kind, bool(must), bool(key))
            for _, name, kind, must, _, key in connection.exec_driver_sql(
                "PRAGMA table_info(record_change)"
            )
        ]
        refers = [
            (to, here, there, on_update, on_delete)
            for _, _, to, here, there, on_update, on_delete, _ in connection.exec_driver_sql(
                "PRAGMA foreign_key_list(record_change)"
            )
        ]
        indexes = connection.exec_driver_sql("PRAGMA index_list(record_change)").all()
        strict = connection.exec_driver_sql(
            "SELECT strict FROM pragma_table_list WHERE name = 'record_change'"
        ).scalar_one()
        written = str(
            connection.exec_driver_sql(
                "SELECT sql FROM sqlite_master WHERE name = 'record_change'"
            ).scalar_one()
        )

    assert columns == [
        ("id", "INTEGER", True, True),
        ("record_table", "TEXT", True, False),
        ("record_id", "INTEGER", True, False),
        ("field", "TEXT", True, False),
        ("old_value", "TEXT", False, False),
        ("new_value", "TEXT", False, False),
        ("collection_run_id", "INTEGER", False, False),
        ("decided_by", "TEXT", False, False),
        ("created_at", "TEXT", True, False),
        ("updated_at", "TEXT", True, False),
    ]
    assert refers == [("collection_run", "collection_run_id", "id", "NO ACTION", "NO ACTION")]
    assert indexes == []
    assert strict == 1
    assert "AUTOINCREMENT" in written
    in_one_line = " ".join(written.split())
    assert "CONSTRAINT ck_record_change_record_id_positive CHECK (record_id > 0)" in in_one_line
    assert (
        "CONSTRAINT ck_record_change_new_value_not_old_value CHECK (old_value IS NOT new_value)"
        in in_one_line
    )
    assert (
        "CONSTRAINT ck_record_change_caused_by_a_run_or_a_person "
        "CHECK ((collection_run_id IS NULL) != (decided_by IS NULL))" in in_one_line
    )
    assert in_one_line.count("CONSTRAINT ck_record_change_") == 6
    for column in ("record_table", "field", "decided_by"):
        assert f"CONSTRAINT ck_record_change_{column}_not_empty CHECK (trim({column}," in (
            in_one_line
        )


def test_a_change_that_a_run_caused_is_stored_and_read_back(
    newest: Engine, clock: list[datetime]
) -> None:
    run = a_run(newest)

    with unit_of_work(newest) as work:
        work.add(
            RecordChange(
                record_table="track",
                record_id=7,
                field="name",
                old_value="Example Park",
                new_value="Example Raceway",
                collection_run_id=run,
            )
        )

    with unit_of_work(newest) as work:
        found = work.execute(select(RecordChange)).scalar_one()
    assert found.id == 1
    assert (found.record_table, found.record_id, found.field) == ("track", 7, "name")
    assert (found.old_value, found.new_value) == ("Example Park", "Example Raceway")
    assert found.collection_run_id == run
    assert found.decided_by is None
    # When it was changed is when the row was stored, and the store's clock says it.
    assert found.created_at == found.updated_at == clock[-1]
    assert held(newest) == [("track", 7, "name", "Example Park", "Example Raceway", run, None)]


def test_a_change_that_a_person_decided_is_stored_and_read_back(newest: Engine) -> None:
    with unit_of_work(newest) as work:
        work.add(
            RecordChange(
                record_table="track",
                record_id=7,
                field="length_in_metres",
                old_value="1600",
                new_value="1750",
                decided_by="Jo Example",
            )
        )

    with unit_of_work(newest) as work:
        found = work.execute(select(RecordChange)).scalar_one()
    assert found.collection_run_id is None
    assert found.decided_by == "Jo Example"
    assert held(newest) == [("track", 7, "length_in_metres", "1600", "1750", None, "Jo Example")]


@pytest.mark.parametrize(
    ("old", "new"),
    [
        (None, "1600"),
        ("1600", None),
        (None, ""),
        ("", None),
        ("Example Park", "example park"),
        ("Example Park", "Example Park "),
        ("1", "1.0"),
        ("", " "),
    ],
    ids=[
        "from no value to one",
        "from a value to none",
        "from no value to empty text",
        "from empty text to no value",
        "a large letter made small",
        "a space at the end",
        "a number written otherwise",
        "from empty text to a space",
    ],
)
def test_a_value_is_kept_as_the_text_it_was_and_no_value_is_a_value_too(
    newest: Engine, old: str | None, new: str | None
) -> None:
    with unit_of_work(newest) as work:
        work.add(
            RecordChange(
                record_table="track",
                record_id=7,
                field="name",
                old_value=old,
                new_value=new,
                decided_by="Jo Example",
            )
        )
    write(newest, old_value=old, new_value=new)

    assert held(newest) == [("track", 7, "name", old, new, None, "Jo Example")] * 2


@pytest.mark.parametrize(
    "value",
    [None, "Example Park", "", " "],
    ids=["no value", "a text", "empty text", "a space"],
)
def test_a_change_that_changed_nothing_is_refused(newest: Engine, value: str | None) -> None:
    with refused(NOTHING_CHANGED), unit_of_work(newest) as work:
        work.add(
            RecordChange(
                record_table="track",
                record_id=7,
                field="name",
                old_value=value,
                new_value=value,
                decided_by="Jo Example",
            )
        )
    with refused(NOTHING_CHANGED):
        write(newest, old_value=value, new_value=value)

    assert held(newest) == []


def test_a_change_that_nothing_caused_is_refused(newest: Engine) -> None:
```

   read back with every column; values are kept as the text they were,
