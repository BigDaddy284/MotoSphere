## Objective

The store itself refuses a second review item for a doubt it already
holds.

## Why

A collection run that meets the same doubt as the run before it must
not put a second item into the queue, and a doubt that a person has
decided must not be put to them again. "Use review queues when
information conflicts." (CLAUDE.md §11) is of use only while the queue
holds each question once. The function that opens an item (DAT-051)
will look whether the doubt is there, but what holds is what the store
refuses: whatever writes an item, the function or a statement past it,
the same doubt is not stored twice. This task says what the same doubt
is, and makes the store refuse it.

## What this task is, and what it is not

- **It is** two indexes on `review_item` that let no two rows be
  alike, in the model and in a ninth migration, and their tests.
- **It is not** the function that opens an item (DAT-051), nor
  anything that keeps a decision (DAT-052). No column, check or table
  changes.
- **It is not** the indexes by which the open items, or all the items
  about one record, are found. Nothing asks for them yet; they come
  with what does.

## Design in short

- **A possible duplicate is the same doubt** when it is about the same
  two records of the same table. Index
  `ix_review_item_record_table_record_id_other_record_id`, unique,
  over `record_table`, `record_id`, `other_record_id`, and over the
  rows that name another record only (`WHERE other_record_id IS NOT
  NULL`).
- **A doubt about a field is the same doubt** when it is about the
  same field of the same record and the same source says the same
  thing of it. Index
  `ix_review_item_record_table_record_id_field_source_id_source_value`,
  unique, over `record_table`, `record_id`, `field`, `source_id`,
  `source_value`, and over the rows that name a field only (`WHERE
  field IS NOT NULL`).
- **In the model** each is an `Index(None, …, unique=True,
  sqlite_where=text("…"))` in `__table_args__` of `ReviewItem`, named
  by the naming rule.
- **The ninth migration**, `hold_one_doubt_to_one_review_item`, makes
  the two in plain SQL. The schema is at version 9.

## What the task left open, and what the trial settled

- **Does a decided item count?** Yes. Neither index looks at the
  state. A doubt that was rejected and is found again by the next run
  is refused, and so is one that was accepted: the person has
  answered. A source that then says something new opens a new doubt,
  because what it says is part of what makes the doubt.
- **Does the kind belong to it, between the two that are about a
  field?** No. Whether what a source says is "another value" or "a
  value the rules refuse" depends on the rules of the field, which
  can change; the question to the person is the same one. So the same
  source saying the same thing of the same field is one doubt, of
  whichever of the two kinds each item is. Twelve tests hold that:
  the first of either kind, the second of either, the first in each
  of the three states.
- **Nor do the address, the reason or the note.** A source that says
  the same thing at another address has not said anything new.
- **What a source says is compared as the text it is.** `1750`,
  `1750.0`, `1750` with a space after it and empty text are four
  things said. Whether two texts mean the same is for the code that
  collects to say before it opens an item; the store does not guess.
- **One index, or two?** Two. SQLite counts two missing values as two
  different values in a unique index, and every item is without some
  of the six columns: under one unique index over all six, the trial
  stored the same possible duplicate twice. An index over the rows of
  one shape only has no missing value in it.
- **By which words does an index know its rows?** By a column that
  only they have, not by their kind. Both forms refuse the same rows.
  They differ for the question "is this doubt there already?", which
  DAT-051 will ask: a statement with `other_record_id = ?` in it can
  only be answered by rows that name another record, SQLite knows
  that, and it uses the index, whatever else the statement says. With
  `WHERE kind = 'possible duplicate'` the trial saw SQLite 3.53.1
  read the whole table for a statement that does not name the kind as
  well. So the tests read SQLite's own plan for that question,
  written with the model for each shape, and hold it to one search of
  the index. That is also what tells the two forms apart: a planted
  defect that writes the index by the kind, in the model and the
  migration alike, refuses everything it should and fails only those
  tests and the two that read the statement in the file.
- **A unique index, or a unique constraint?** An index. A constraint
  of a table cannot be over some of its rows, and a table of SQLite
  cannot be given one afterwards without being made anew. The naming
  rule names an index `ix_…` whether or not it lets rows be alike; the
  statement in the file says `UNIQUE`, and a test reads it.
- **A store that holds a doubt twice already.** The table of DAT-010
  allowed it, though nothing wrote items. The migration does not
  choose which of two items to keep: `CREATE UNIQUE INDEX` fails, the
  migration fails with it, and the store stays at version 8 with
  neither index, for a person to look at. Two tests hold that, one
  for each shape; for a doubt about a field the first index has been
  made by then, and is taken back.
- **What the test of the models and the migrations sees.** It
  compares the statements SQLite keeps, so `UNIQUE` and the `WHERE`
  of each index are part of what must agree. Planted defects that
  change either in the model only, or in the migration only, fail it.
- **The index of the source stays.** SQLite still looks for the items
  of a source by `ix_review_item_source_id` when a source is deleted;
  neither new index begins with the source. The tests of that are
  unchanged and pass.
- **`INSERT OR REPLACE` is not refused.** SQLite puts the new row in
  the place of the item it clashes with, as it would for a clash of
  keys before this task. Nothing in the store's code says that. That
  a decided item is kept from it belongs to DAT-052, whose entry in
  `TASKS.md` now says so, and `DATABASE.md` says it too.
- **The indexes of the open items and of the items about one record**
  are not made here. The planner's `TASKS.md` entry left that to the
  trial: nothing asks for them, and an index is made for a question
  that is asked (DAT-049 did the same).

```python
"""Tests that one doubt is one review item, against a real SQLite file.

The store of every test is built by the migrations, as a real store is.
The store itself refuses the same doubt a second time, by two indexes,
and these tests say what the same doubt is and what is another.
"""

from collections.abc import Callable, Iterator, Sequence
from contextlib import contextmanager
from typing import Any

import pytest
from sqlalchemy import Connection, Engine, event, select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from motosphere.db.models import ReviewItem, Source
from motosphere.db.models.review_item import ReviewKind
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.work import unit_of_work

MOMENT = "2026-11-26T09:00:00.000000+00:00"
OF_A_PAIR = "ix_review_item_record_table_record_id_other_record_id"
OF_WHAT_A_SOURCE_SAYS = "ix_review_item_record_table_record_id_field_source_id_source_value"
OF_A_SOURCE = "ix_review_item_source_id"
# What SQLite says when it refuses the same doubt a second time.
THE_PAIR_IS_THERE = (
    "UNIQUE constraint failed: review_item.record_table, review_item.record_id, "
    "review_item.other_record_id"
)
WHAT_THE_SOURCE_SAYS_IS_THERE = (
    "UNIQUE constraint failed: review_item.record_table, review_item.record_id, "
    "review_item.field, review_item.source_id, review_item.source_value"
)
# A row written past the model: every column but the key, in the table's order.
PAST_THE_MODEL = (
    "INSERT INTO review_item (kind, record_table, record_id, other_record_id, field, "
    "source_id, source_address, source_value, reason, state, decided_by, decided_at, note, "
    "created_at, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)"
)
WHAT_IT_HOLDS = (
    "SELECT kind, record_table, record_id, other_record_id, field, source_id, source_address, "
    "source_value, reason, state, decided_by, decided_at, note FROM review_item ORDER BY id"
)
# The three states an item can be in when its doubt comes a second time.
DECIDED: dict[str, object] = {
    "state": "accepted",
    "decided_by": "Jo Example",
    "decided_at": MOMENT,
}
STATES: dict[str, dict[str, object]] = {
    "open": {},
    "accepted": DECIDED,
    "rejected": {**DECIDED, "state": "rejected"},
}
IN_EACH_STATE = pytest.mark.parametrize("state", list(STATES))
OF_A_FIELD = ["sources disagree", "value outside its rules"]


@contextmanager
def refused(why: str) -> Iterator[None]:
    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:
        yield
    assert str(refusal.value.orig) == why


def a_pair(**given: object) -> dict[str, object]:
    """A possible duplicate that nobody has decided, as a row, but for what is given."""
    row: dict[str, object] = {
        "kind": "possible duplicate",
        "record_table": "track",
        "record_id": 7,
        "other_record_id": 12,
        "field": None,
        "source_id": None,
        "source_address": None,
        "source_value": None,
        "reason": "The two tracks have one name and lie 140 metres apart.",
        "state": "open",
        "decided_by": None,
        "decided_at": None,
        "note": None,
    }
    assert set(given) <= set(row)
    row.update(given)
    return row


def of_a_field(**given: object) -> dict[str, object]:
    """A doubt about what the first source says of a field, as a row, but for what is given."""
    return a_pair(
        **{
            "kind": "sources disagree",
            "other_record_id": None,
            "field": "length_in_metres",
            "source_id": 1,
            "source_address": "https://federation.example/tracks/7",
            "source_value": "1750",
            "reason": "The record says 1600.",
            **given,
        }
    )


def write(store: Engine, row: dict[str, object]) -> None:
    """Write an item past the model, as plain SQL."""
    with store.begin() as connection:
        connection.exec_driver_sql(PAST_THE_MODEL, (*row.values(), MOMENT, MOMENT))


def held(store: Engine) -> list[tuple[object, ...]]:
    """What the table holds, as SQLite holds it, by the key, without the two times."""
    with store.connect() as connection:
        return [tuple(row) for row in connection.exec_driver_sql(WHAT_IT_HOLDS)]


@pytest.fixture
def queue(newest: Engine) -> Engine:
    """The newest store with two sources, and no item yet."""
    with unit_of_work(newest) as work:
        for name in ("Example Federation", "Example Club"):
            work.add(
                Source(
                    name=name,
                    website="https://federation.example",
                    category=SourceCategory.GOVERNING_BODY,
                    collection_method=CollectionMethod.RSS,
                )
            )
            # One at a time, so that the keys follow the order above.
            work.flush()
    return newest


def test_in_the_file_the_review_queue_has_its_two_indexes_of_one_doubt(newest: Engine) -> None:
    with newest.connect() as connection:
        listed = sorted(
            (name, bool(unique), made_by, bool(partial))
            for _, name, unique, made_by, partial in connection.exec_driver_sql(
                "PRAGMA index_list(review_item)"
            )
        )
        indexed = {
            index: [
                name for _, _, name in connection.exec_driver_sql(f"PRAGMA index_info({index})")
            ]
            for index in (OF_A_PAIR, OF_WHAT_A_SOURCE_SAYS)
        }
        written = {
            str(name): " ".join(str(sql).split())
            for name, sql in connection.exec_driver_sql(
                "SELECT name, sql FROM sqlite_master WHERE type = 'index' "
                "AND tbl_name = 'review_item'"
            )
        }

    # Its name, that no two rows can be alike in it, that a statement made
    # it, and that it is over some of the rows only. The index of the
    # source is as it was.
    assert listed == [
        (OF_WHAT_A_SOURCE_SAYS, True, "c", True),
        (OF_A_PAIR, True, "c", True),
        (OF_A_SOURCE, False, "c", False),
    ]
    assert indexed == {
        OF_A_PAIR: ["record_table", "record_id", "other_record_id"],
        OF_WHAT_A_SOURCE_SAYS: ["record_table", "record_id", "field", "source_id", "source_value"],
    }
    # Which rows each is over, letter for letter: those that name another
    # record, and those that name a field.
    assert written[OF_A_PAIR] == (
        f"CREATE UNIQUE INDEX {OF_A_PAIR} ON review_item "
        "(record_table, record_id, other_record_id) WHERE other_record_id IS NOT NULL"
    )
    assert written[OF_WHAT_A_SOURCE_SAYS] == (
        f"CREATE UNIQUE INDEX {OF_WHAT_A_SOURCE_SAYS} ON review_item "
        "(record_table, record_id, field, source_id, source_value) WHERE field IS NOT NULL"
    )


@IN_EACH_STATE
def test_the_same_possible_duplicate_is_refused_a_second_time(newest: Engine, state: str) -> None:
    # Whatever became of the first: a doubt that a person has decided is
    # not put to them again.
    first = a_pair(**STATES[state])
    write(newest, first)

    with refused(THE_PAIR_IS_THERE):
        write(newest, a_pair(reason="Found again by the next run.", note="Seen twice."))

    assert held(newest) == [tuple(first.values())]


@IN_EACH_STATE
@pytest.mark.parametrize("again", OF_A_FIELD)
@pytest.mark.parametrize("kind", OF_A_FIELD)
def test_the_same_doubt_about_a_field_is_refused_a_second_time(
    queue: Engine, kind: str, again: str, state: str
) -> None:
    # The same record and field, and the same source saying the same thing
    # of it. Whether that thing is another value or one the rules refuse
    # does not make it another doubt, nor does the address at which the
    # source says it, nor what became of the first.
    first = of_a_field(kind=kind, **STATES[state])
    write(queue, first)

    with refused(WHAT_THE_SOURCE_SAYS_IS_THERE):
        write(
            queue,
            of_a_field(
                kind=again,
                source_address="https://federation.example/venues/7",
                reason="Found again by the next run.",
            ),
        )

    assert held(queue) == [tuple(first.values())]


@pytest.mark.parametrize(
    "first",
    [
        ReviewItem(
            kind=ReviewKind.POSSIBLE_DUPLICATE,
            record_table="track",
            record_id=7,
            other_record_id=12,
            reason="They have one name.",
        ),
        ReviewItem(
            kind=ReviewKind.SOURCES_DISAGREE,
            record_table="track",
            record_id=7,
            field="length_in_metres",
            source_id=1,
            source_address="https://federation.example/tracks/7",
            source_value="1750",
            reason="The record says 1600.",
        ),
    ],
    ids=["a possible duplicate", "a doubt about a field"],
)
def test_the_same_doubt_is_refused_through_the_model_and_nothing_of_its_work_is_kept(
    queue: Engine, first: ReviewItem
) -> None:
    said = {
        column.key: getattr(first, column.key)
        for column in ReviewItem.__table__.columns
        if column.key not in {"id", "state", "created_at", "updated_at"}
    }
    with unit_of_work(queue) as work:
        work.add(ReviewItem(**said))
    stored = held(queue)

    def another_doubt_and_then_the_same() -> None:
        # Another doubt, stored in the same unit of work before the one
        # that is refused: it goes with it.
        with unit_of_work(queue) as work:
            work.add(ReviewItem(**{**said, "record_id": 3}))
            work.flush()
            work.add(ReviewItem(**said))

    with pytest.raises(IntegrityError, match="UNIQUE constraint failed: review_item"):
        another_doubt_and_then_the_same()

    assert len(stored) == 1
    assert held(queue) == stored


@pytest.mark.parametrize(
    "other",
    [
        {"record_table": "rider"},
        {"record_id": 8},
        {"other_record_id": 13},
        # The other record of the first pair, with a third record.
        {"record_id": 12, "other_record_id": 15},

    ids=["of another table", "another record", "with another record", "the other with a third"],
)
def test_a_possible_duplicate_of_other_records_is_another_doubt(

) -> None:

    write(newest, a_pair(**other))

    assert held(newest) == [tuple(a_pair().values()), tuple(a_pair(**other).values())]


@pytest.mark.parametrize(
    "other",
    [
        {"record_table": "event"},
        {"record_id": 8},
        {"field": "name"},
        {"source_id": 2},
        {"source_value": "1751"},
        {"source_value": ""},
        {"source_value": "1750 "},
        {"source_value": "1750.0"},
    ],
    ids=[
        "of another table",
        "of another record",
        "about another field",
        "from another source",
        "another value",
        "empty text",
        "a space after the value",
        "the number written otherwise",

def test_a_doubt_that_differs_in_one_thing_is_another_doubt(
    queue: Engine, other: dict[str, object]
) -> None:
    # What a source says is compared as the text it is, letter for letter.

def sent_by(store: Engine, ask: Callable[[Session], Any]) -> list[tuple[str, Sequence[object]]]:
    """Every statement a question sends, with what it is given."""
    sent: list[tuple[str, Sequence[object]]] = []

    def remember(
        _connection: Connection,
        _cursor: object,
        statement: str,
        given: Sequence[object],
        _context: object,
        _many: bool,
    ) -> None:
        sent.append((statement, given))

    event.listen(store, "before_cursor_execute", remember)
    try:
        with Session(store) as work:
            ask(work)
    finally:
        event.remove(store, "before_cursor_execute", remember)
    return sent


def plan_of(store: Engine, statement: str, given: Sequence[object]) -> list[str]:
    """SQLite's own account of how it will answer a statement, step by step."""
    with store.connect() as connection:
        steps = connection.exec_driver_sql("EXPLAIN QUERY PLAN " + statement, tuple(given))
        return [str(step[3]) for step in steps]
```
