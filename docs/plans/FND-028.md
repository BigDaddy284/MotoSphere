# FND-028 – Data status in the top bar

**Phase:** 1 – Foundation
**Depends on:** FND-016 (merged), FND-027 (merged), FND-026 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §8, §11, `docs/WORKFLOW.md`, `ARCHITECTURE.md` §3 and §6

## Objective

The user can see in the top bar how current the data is, or that it could
not be loaded. With this, something the pipeline published reaches the
user's screen for the first time.

## Design in short

- A hook, `useManifest`, loads the manifest once when the application starts
  and reports one of three states: loading, ready (with the manifest) or
  failed (with the reason). It stops the request when its component goes
  away and ignores the answer to a request it has stopped.
- A component, `DataStatus`, shows one line in plain language:
  - `Loading data…` while the manifest is on its way;
  - `Data updated 17 November 2026` when it has arrived: the day the data
    was generated, written out in the language of the user's browser, for
    the day where the user is, in a `time` element whose `datetime` is the
    exact moment from the manifest;
  - `Data unavailable` when the manifest could not be fetched or is not a
    manifest;
  - `Reload the page to see the data` when the data is in a newer format
    than this copy of the application reads, because loading the page again
    fetches the newer application.
- The line is an `output` element, so a screen reader announces changes
  (its built-in role is `status`). The project's linter asks for the element
  in place of `role="status"`.
- It sits in the top bar's information slot, before the date. The pieces in
  that slot stay ordinary inline text with a margin between them. Do **not**
  make the slot a flex container: its children then become boxes as tall as
  the bar, stick out of it by a few pixels and are cut off.
- The loader can be passed in, so the unit tests need no network. The browser
  tests of the normal case read the data that the real export command wrote
  for the run (FND-027); only the tests of what can go wrong, and of other
  time zones, replace the server's answer.

### 1. `frontend/src/data/useManifest.ts`

```ts
import { useEffect, useState } from 'react'
import {
  loadManifest,
  type Manifest,
  type ManifestProblem,
  type ManifestResult,
} from './manifest.ts'

/** Where the application is with the published data's manifest. */
export type ManifestState =
  | { readonly status: 'loading' }
  | { readonly status: 'ready'; readonly manifest: Manifest }
  | { readonly status: 'failed'; readonly problem: ManifestProblem }

/** Loads the manifest; `signal` stops the request. */
export type ManifestLoader = (signal: AbortSignal) => Promise<ManifestResult>

/** Loads the manifest published next to the application. */
export const loadPublishedManifest: ManifestLoader = (signal) =>
  loadManifest(import.meta.env.BASE_URL, { signal })

/**
 * Loads the manifest once and says how far that has got. The request is
 * stopped, and its answer ignored, when the component that asked goes away.
 */
export function useManifest(load: ManifestLoader = loadPublishedManifest): ManifestState {
  const [state, setState] = useState<ManifestState>({ status: 'loading' })

  useEffect(() => {
    const controller = new AbortController()

    function finish(result: ManifestResult) {
      if (controller.signal.aborted) {
        return
      }
      setState(
        result.ok
          ? { status: 'ready', manifest: result.manifest }
          : { status: 'failed', problem: result.problem },
      )
    }

    load(controller.signal).then(finish, () => {
      finish({ ok: false, problem: 'unavailable' })
    })

    return () => {
      controller.abort()
    }
  }, [load])

  return state
}
```

### 3. `frontend/src/data/DataStatus.tsx`

```tsx
import { formatDataDate } from './dataDate.ts'
import { useManifest, type ManifestLoader, type ManifestState } from './useManifest.ts'

interface DataStatusProps {
  /** Loads the manifest. Left out, the published manifest is loaded. */
  load?: ManifestLoader
}

function message(state: ManifestState) {
  switch (state.status) {
    case 'loading':
      return 'Loading data…'
    case 'ready':
      return (
        <>
          Data updated{' '}
          <time dateTime={state.manifest.generatedAt}>
            {formatDataDate(state.manifest.generatedAt)}
          </time>
        </>
      )
    case 'failed':
      // An application older than the data is put right by loading it again.
      return state.problem === 'unsupported'
        ? 'Reload the page to see the data'
        : 'Data unavailable'
  }
}

/**
 * One line that tells the user how current the data is, or that it could not
 * be loaded. Changes are announced to people who use a screen reader.
 */
export function DataStatus({ load }: DataStatusProps) {
  const state = useManifest(load)

  return <output>{message(state)}</output>
}
```

### 6. `frontend/src/data/useManifest.test.ts` – 10 tests

```ts
import { act, renderHook } from '@testing-library/react'
import { describe, expect, it, vi } from 'vitest'
import type { Manifest, ManifestResult } from './manifest.ts'
import { loadPublishedManifest, useManifest, type ManifestLoader } from './useManifest.ts'

const MANIFEST: Manifest = {
  formatVersion: 1,
  generatedAt: '2026-11-17T12:53:59Z',
  applicationVersion: '0.1.0',
  counts: new Map(),
}
const READY: ManifestResult = { ok: true, manifest: MANIFEST }

/** A loader whose answer the test gives when it chooses. */
function heldLoader() {
  const signals: AbortSignal[] = []
  const waiting: {
    resolve: (result: ManifestResult) => void
    reject: (reason: unknown) => void
  }[] = []
  const load = vi.fn<ManifestLoader>((signal) => {
    signals.push(signal)
    return new Promise<ManifestResult>((resolve, reject) => {
      waiting.push({ resolve, reject })
    })
  })
  return {
    load,
    signals,
    answer: (result: ManifestResult) => act(async () => waiting[0]?.resolve(result)),
    refuse: (reason: unknown) => act(async () => waiting[0]?.reject(reason)),
  }
}

describe('useManifest', () => {
  it('is loading until the manifest arrives', () => {
    const { load } = heldLoader()

    const { result } = renderHook(() => useManifest(load))

    expect(result.current).toEqual({ status: 'loading' })
  })

  it('is ready with the manifest once it has arrived', async () => {
    const loader = heldLoader()
    const { result } = renderHook(() => useManifest(loader.load))

    await loader.answer(READY)

    expect(result.current).toEqual({ status: 'ready', manifest: MANIFEST })
  })

  it.each(['unavailable', 'malformed', 'unsupported'] as const)(
    'has failed with the reason when the manifest is %s',
    async (problem) => {
      const loader = heldLoader()
      const { result } = renderHook(() => useManifest(loader.load))

      await loader.answer({ ok: false, problem })

      expect(result.current).toEqual({ status: 'failed', problem })
    },
  )

  it('treats a loader that throws as unavailable data', async () => {
    const loader = heldLoader()
    const { result } = renderHook(() => useManifest(loader.load))

    await loader.refuse(new Error('boom'))

    expect(result.current).toEqual({ status: 'failed', problem: 'unavailable' })
  })

  it('loads once, however often the component is drawn again', () => {
    const { load } = heldLoader()
    const { rerender } = renderHook(() => useManifest(load))

    rerender()
    rerender()

    expect(load).toHaveBeenCalledTimes(1)
  })

  it('stops the request when the component goes away', () => {
    const loader = heldLoader()
    const { unmount } = renderHook(() => useManifest(loader.load))
    expect(loader.signals[0]?.aborted).toBe(false)

    unmount()

    expect(loader.signals[0]?.aborted).toBe(true)
  })

  it('ignores the answer to a request it has stopped', async () => {
    const first = heldLoader()
    const second = heldLoader()
    const { result, rerender } = renderHook(({ load }) => useManifest(load), {
      initialProps: { load: first.load },
    })

    rerender({ load: second.load })
    expect(first.signals[0]?.aborted).toBe(true)
    await second.answer(READY)
    await first.answer({ ok: false, problem: 'unavailable' })

    expect(result.current).toEqual({ status: 'ready', manifest: MANIFEST })
  })
})

describe('loadPublishedManifest', () => {
  it("fetches the manifest under the application's base path, with the signal", async () => {
    const fetched = vi
      .spyOn(globalThis, 'fetch')
      .mockResolvedValue(new Response('{"format_version": 2}'))
    const { signal } = new AbortController()

    const result = await loadPublishedManifest(signal)

    expect(fetched).toHaveBeenCalledWith(`${import.meta.env.BASE_URL}data/manifest.json`, {
      cache: 'no-cache',
      signal,
    })
    expect(import.meta.env.BASE_URL).toBe('/')
    expect(result).toEqual({ ok: false, problem: 'unsupported' })
  })
})
```

```ts
// The moment is built from local calendar values, so that these tests give

describe('formatDataDate', () => {
```

### 8. `frontend/src/data/DataStatus.test.tsx` – 6 tests

```tsx
import { render, screen } from '@testing-library/react'
import { describe, expect, it, vi } from 'vitest'
import { formatDataDate } from './dataDate.ts'
import { DataStatus } from './DataStatus.tsx'
import type { ManifestResult } from './manifest.ts'
import type { ManifestLoader } from './useManifest.ts'

// Exactly what `python -m motosphere export` wrote on 17 November 2026.
const EXPORTED = `{
  "application_version": "0.1.0",
  "counts": {},
  "format_version": 1,
  "generated_at": "2026-11-17T12:53:59Z"
}
`
const GENERATED_AT = '2026-11-17T12:53:59Z'

function loaderGiving(result: ManifestResult): ManifestLoader {
  return () => Promise.resolve(result)
}

const READY: ManifestResult = {
  ok: true,
  manifest: {
    formatVersion: 1,
    generatedAt: GENERATED_AT,
    applicationVersion: '0.1.0',
    counts: new Map(),
  },
}

describe('DataStatus', () => {
  it('says the data is loading until it arrives', () => {
    render(<DataStatus load={() => new Promise(() => {})} />)

    expect(screen.getByRole('status')).toHaveTextContent(/^Loading data…$/)
  })

  it('says when the data was updated, with the moment in machine-readable form', async () => {
    render(<DataStatus load={loaderGiving(READY)} />)

    const date = await screen.findByText(formatDataDate(GENERATED_AT))
    expect(date.tagName).toBe('TIME')
    expect(date).toHaveAttribute('datetime', GENERATED_AT)
    expect(screen.getByRole('status')).toHaveTextContent(
      `Data updated ${formatDataDate(GENERATED_AT)}`,
    )
    expect(screen.getByRole('status').textContent).toContain('2026')
  })

  it.each(['unavailable', 'malformed'] as const)(
    'says the data is unavailable when the manifest is %s',
    async (problem) => {
      render(<DataStatus load={loaderGiving({ ok: false, problem })} />)

      expect(await screen.findByText('Data unavailable')).toBe(screen.getByRole('status'))
    },
  )

  it('asks for a reload when the data is in a newer format than the application reads', async () => {
    render(<DataStatus load={loaderGiving({ ok: false, problem: 'unsupported' })} />)

    expect(await screen.findByText('Reload the page to see the data')).toBe(
      screen.getByRole('status'),
    )
  })

  it('loads the published manifest when it is given no loader', async () => {
    const fetched = vi.spyOn(globalThis, 'fetch').mockResolvedValue(new Response(EXPORTED))

    render(<DataStatus />)

    expect(await screen.findByText(/^Data updated/)).toBe(screen.getByRole('status'))
    expect(fetched).toHaveBeenCalledTimes(1)
    expect(fetched.mock.calls[0]?.[0]).toBe('/data/manifest.json')
  })
})
```

### 12. `frontend/e2e/status.spec.ts` – 9 browser tests

```ts
import type { APIRequestContext, Page } from '@playwright/test'
import { manifestUrl } from '../src/data/manifest.ts'
import { expect, test } from './fixtures'

/**
 * The data status in the top bar. The built site under test carries data
 * that the real export command wrote for this run (see `data.spec.ts`), and
 * the tests of the normal case read that data. Only the tests of what can go
 * wrong replace the server's answer.
 */

const MANIFEST = `**${manifestUrl('/')}`

function dataStatus(page: Page) {
  return page.getByRole('banner').getByRole('status')
}

/** When the served data was generated, as the manifest says it. */
async function generatedAt(request: APIRequestContext): Promise<string> {
  const response = await request.get(manifestUrl('/'))
  const manifest: unknown = await response.json()
  if (
    typeof manifest !== 'object' ||
    manifest === null ||
    !('generated_at' in manifest) ||
    typeof manifest.generated_at !== 'string'
  ) {
    throw new Error('The served manifest has no generation time.')
  }
  return manifest.generated_at
}

/** A manifest as the pipeline writes it, generated at the given moment. */
function manifestAt(moment: string) {
  return { format_version: 1, generated_at: moment, application_version: '0.1.0', counts: {} }
}

function writtenOut(moment: string, locale: string, timeZone: string): string {
  return new Intl.DateTimeFormat(locale, {
    day: 'numeric',
    month: 'long',
    year: 'numeric',
    timeZone,
  }).format(new Date(moment))
}

test.describe('data status', () => {
  test.describe('for a British user in London', () => {
    test.use({ locale: 'en-GB', timezoneId: 'Europe/London' })

    test('says when the published data was updated', async ({ page, request }) => {
      const moment = await generatedAt(request)
      await page.goto('/')

      const expected = writtenOut(moment, 'en-GB', 'Europe/London')
      expect(expected).toMatch(/^\d{1,2} [A-Z][a-z]+ \d{4}$/)
      await expect(dataStatus(page)).toHaveText(`Data updated ${expected}`)
      await expect(dataStatus(page).locator('time')).toHaveAttribute('datetime', moment)
    })

    test('sits between the tagline and the date, in the quiet text colour', async ({ page }) => {
      await page.setViewportSize({ width: 1366, height: 768 })
      await page.goto('/')

      const status = dataStatus(page)
      await expect(status).toHaveText(/^Data updated /)
      await expect(status).toBeInViewport({ ratio: 1 })
      await expect(status).toHaveCSS('color', 'rgb(169, 172, 179)')
      await expect(status).toHaveCSS('font-size', '14px')
      const tagline = await page.getByText('The World of Motocross, Connected.').boundingBox()
      const statusBox = await status.boundingBox()
      const date = await page.getByRole('banner').locator('time:not(output time)').boundingBox()
      if (tagline === null || statusBox === null || date === null) {
        throw new Error('The tagline, the data status or the date is not visible.')
      }
      expect(statusBox.x).toBeGreaterThan(tagline.x + tagline.width)
      // A clear gap between the status and the date, and both on one line.
      expect(date.x - (statusBox.x + statusBox.width)).toBeGreaterThanOrEqual(12)
      expect(Math.abs(date.y - statusBox.y)).toBeLessThanOrEqual(1)
    })
  })

  // The served data was generated a moment ago, so its day is today in every
  // time zone. To check that the day is the user's own, these two tests answer
  // with a manifest whose moment falls on different days around the world.
  test.describe('for an American user in Los Angeles', () => {
    test.use({ locale: 'en-US', timezoneId: 'America/Los_Angeles' })

    test('writes the date the American way, for the day in Los Angeles', async ({ page }) => {
      await page.route(MANIFEST, (route) =>
        route.fulfill({ json: manifestAt('2026-11-17T02:00:00Z') }),
      )
      await page.goto('/')

      await expect(dataStatus(page)).toHaveText('Data updated November 16, 2026')
    })
  })

  test.describe('for a German user in Tokyo', () => {
    test.use({ locale: 'de-DE', timezoneId: 'Asia/Tokyo' })

    test('writes the date the German way, for the day in Tokyo', async ({ page }) => {
      await page.route(MANIFEST, (route) =>
        route.fulfill({ json: manifestAt('2026-11-17T20:00:00Z') }),
      )
      await page.goto('/')

      await expect(dataStatus(page)).toHaveText('Data updated 18. November 2026')
      await expect(dataStatus(page).locator('time')).toHaveAttribute(
        'datetime',
        '2026-11-17T20:00:00Z',
      )
    })
  })

  test('says the data is loading until it arrives', async ({ page }) => {
    const held: (() => Promise<void>)[] = []
    await page.route(MANIFEST, (route) => {
      held.push(() => route.continue())
    })
    await page.goto('/')

    await expect(dataStatus(page)).toHaveText('Loading data…')
    expect(held).toHaveLength(1)

    await held[0]?.()
    await expect(dataStatus(page)).toHaveText(/^Data updated /)
  })

  test('says the data is unavailable when the answer is a web page', async ({ page }) => {
    // A server that answers every address with the application's page does
    // this when the data has not been published.
    await page.route(MANIFEST, (route) =>
      route.fulfill({ contentType: 'text/html', body: '<!doctype html><title>MotoSphere</title>' }),
    )
    await page.goto('/')

    await expect(dataStatus(page)).toHaveText('Data unavailable')
  })

  test('says the data is unavailable when the manifest is damaged', async ({ page }) => {
    await page.route(MANIFEST, (route) =>
      route.fulfill({ json: { format_version: 1, generated_at: 'yesterday' } }),
    )
    await page.goto('/')

    await expect(dataStatus(page)).toHaveText('Data unavailable')
  })

  test('asks for a reload when the data is in a newer format', async ({ page }) => {
    await page.route(MANIFEST, (route) =>
      route.fulfill({ json: { format_version: 2, layout: 'something new' } }),
    )
    await page.goto('/')

    await expect(dataStatus(page)).toHaveText('Reload the page to see the data')
  })

  test('keeps the rest of the page working when the data is unavailable', async ({ page }) => {
    await page.route(MANIFEST, (route) => route.fulfill({ contentType: 'text/html', body: '' }))
    await page.goto('/')
    await expect(dataStatus(page)).toHaveText('Data unavailable')

    await page.getByRole('button', { name: 'Tracks' }).click()

    await expect(page.getByRole('button', { name: 'Tracks' })).toHaveAttribute(
      'aria-current',
      'page',
    )
    await expect(page.getByRole('banner').locator('time:not(output time)')).toBeVisible()
  })
})
```

## Acceptance criteria

1. While the manifest is on its way the top bar says `Loading data…`.
2. With the manifest of the real export it says `Data updated` and the day
   the data was generated, in the language of the browser and for the day
   where the user is (verified for British English in London, American
   English in Los Angeles on the previous day, German in Tokyo on the next
   day). The `time` element's `datetime` is the moment in the manifest.
3. A manifest that cannot be fetched, is a web page, or is damaged gives
   `Data unavailable`; a newer format gives `Reload the page to see the
   data`. Nothing is thrown, the console stays clean, and the rest of the
   page keeps working.
4. The line is announced to assistive technology (role `status`), sits
   between the tagline and the date in the quiet text colour, and the whole
   top bar still fits at 1366 pixels.
5. Leaving the page stops the request, and a late answer changes nothing.
6. `npm test` reports 199 passed in 12 files; `npm run e2e` reports 62
   passed; every other gate passes.
7. Only the files under "Scope" changed; no dependency changed.
