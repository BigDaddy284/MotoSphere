## Objective

One function adds to the store every country of the reference file that
the store does not have, each naming the source and the release it came
from, and changes nothing else: run again, it writes nothing.

## Why

Everything MotoSphere will hold is somewhere: a track, an event, a
rider and a source are each of a country. The table of the countries is
there (DAT-011), the file of the countries is in the repository
(DAT-012), and the source of that file can be put in a store (DAT-060).
What is left is to bring the 249 countries of the file into the table,
each saying where it came from: "Every record must retain its source
and collection history." (CLAUDE.md §11).

DAT-059 was cut into three tasks (PLAN-049). This is the second: the
loading, by a function. The command that calls it is DAT-061.

## What this task is, and what it is not

- **It is** one new module,
  `backend/src/motosphere/reference/countries_load.py`: the release the
  file is from, what a loading gives back (`CountriesLoaded`), and the
  function `load_countries(work, countries)`.
- **It is** 40 new tests in two new files, 8 without a store and 32
  against a real SQLite file.
- **It is** the documents: `DATABASE.md`, `DATA_SOURCES.md`,
  `TESTING.md`, `ARCHITECTURE.md`, `CHANGELOG.md` and the note beside
  the file.
- **It is not** countries in anybody's store. Nothing calls the
  function yet; the command of DAT-061 will.
- **It is not** a command, a migration or a change to a model. The
  schema stays at version 15.
- **It is not** a way to change a country. The loading adds, and it
  does nothing else (see "What the trial settled").

## Design in short

`countries_load.py` says three things of the release, as the note
beside the file has them: `RELEASE` (`4.20.1`), `PUBLISHED_ON`
(1 January 2026) and `ADDRESS`, the file of the release where it was
fetched
(`https://archive.ubuntu.com/ubuntu/pool/main/i/iso-codes/iso-codes_4.20.1.orig.tar.xz`).

`load_countries(work, countries)` is handed what the file says, as
`countries_of_the_project()` gives it. It asks for the source of the
countries (`source_of_the_countries`, DAT-060), which stores it when it
is not there; reads the clock once; reads the two codes and the name of
every country the store has; and goes through the countries of the
file. A country is known by its code of two letters.

| What the store has of a country of the file | What the loading does |
|---|---|
| Nothing: neither its code of two letters nor its code of three | Adds it |
| The code of two letters, with the same code of three and the same name | Leaves it as it is |
| The code of two letters, with another code of three or another name | Leaves it as it is, and names it |
| The code of three letters, under another code of two | Adds nothing, and names it |

A country of the store whose code of two letters the file does not have
is left as it is and named too.

A new row says: the source of the countries; `ADDRESS`; the moment of
the loading, as when it was collected and as when it was last seen;
`PUBLISHED_ON`; `public dataset`; `high`; `independent`.

It gives back a `CountriesLoaded`, four lists of codes of two letters:
`added`, `as_they_were` and `said_otherwise` in the order of the file,
and `not_in_the_file` in the order of the codes.

The new rows are written to the unit of work before the function
returns. Everything is part of the unit of work it is handed.

## What the trial settled

- **A loading is not a collection run.** A run is one attempt to
  collect from one source (`DATABASE.md`, "The collection runs").
  Nothing is collected here: the file was fetched once, by hand
  (DAT-012), and is part of the project. That is also why the source
  need not be switched on for its countries to be loaded, which DAT-060
  settled. So a loading stores no run, and the store does not come to
  say that a source nobody switched on was scanned.
- **So the loading does not change a country.** A record is changed
  with its history, and a change names what caused it: a collection
  run, or the person who decided it (`change`, DAT-047). A loading is
  neither, and no cause is made up for it. The entry of this task said
  before that a country whose name the file has changed is changed
  through the history; that is taken back (PLAN-050 in `PROGRESS.md`).
  The store and the file can come to say different things of a country
  in two ways only: a person changed the store by hand, or a newer
  release was taken into the repository. Either way a person is at
  hand, and "Do not automatically merge uncertain rider or track
  identities." and "Use review queues when information conflicts."
  (CLAUDE.md §11) point the same way: the loading names the country
  and leaves the decision.
- **And it deletes none.** A country of the store that the file does
  not have is named and left. Other records will point to countries,
  and "Preserve original records and update history wherever
  practical." (CLAUDE.md §11).
- **What the two times of a row say.** `collected_at` and
  `last_verified_at` are the moment of the loading: when the store took
  the row from the file. The clock is read once, so all rows of one
  loading say one moment. When the file itself was fetched (2026-11-27)
  is in the note beside it; the store is not told a time of day that
  nobody wrote down.
- **A second loading writes nothing.** A country that is there as the
  file has it is not touched, not even to say that it was seen again:
  the file is the same file, and the source itself was not looked at.
  A test listens to the statements that are sent to SQLite and hears
  none that writes.
- **The address is the file, not a page.** A record says at which
  address it was found: "the page, the feed or the file that says it,
  not the front page of the site" (`Collected`). That is the file of
  the release at the Ubuntu archive, from which it was fetched; the
  project's own server could not be reached (`DATA_SOURCES.md`).
- **High and independent.** The file gives each value in a field made
  for it, which is what `high` means. iso-codes is not the body that
  keeps the standard, so its word is `independent`, however sure the
  reading.
- **Compared letter for letter.** A name with another capital, a space
  after it, or a letter written as two (a letter and its accent) is
  another name. Nothing is put in a common form to compare it: the
  store keeps a name as its source writes it.
- **A country that is there is left whatever source it names.** Only
  the two codes and the name are compared. A country a person put in
  from another source, and that is as the file has it, stays that
  source's.
- **A code of three under another code of two.** The store holds every
  code of three once. A country of the file whose code of three the
  store has under another code of two cannot be added, and is named as
  one the store says otherwise of; the store's row is named as one the
  file does not have, when that is so.
- **A list with one code twice.** The reader refuses a file that has
  one (DAT-012). A list that is handed to the function with one all the
  same is refused by the store itself, with SQLite's own words, and
  nothing is kept. The function does not check what the store checks.
- **The release is written twice.** The tests write the address and
  the day out a second time, and hold the release, the day, the file
  and the folder to the note beside the file, so that whoever takes a
  newer release changes them together. The note says so now.

  collection run, no history and no item of the review queue;

  a loading that does write; a later loading adds only what the store
  does not have; a country that is there from another source is left;
- a country the store says otherwise of is left and named (6 cases:
  another name, a capital, a letter written as two, a space, another
  code of three, both); a code of three under another code of two; a
  country the file does not have; the order of the codes; the order of
  the file; nothing changed and nothing deleted with all of it at once;
- a list given one country at a time; no countries; a list that has
  one code twice (3 cases);
- a source that is described otherwise refuses the loading; the rows
  are written when the function returns; nothing is kept when the unit
  of work fails afterwards; what the unit of work did before goes with
  a refused loading.

+"""Bringing the countries of the reference file into the store.
+
+:func:`load_countries` is handed the countries the reference file says
+and adds to the store every one of them the store does not have. Each
+new row says where it came from: the source of the countries

+left as it is, also when the file says something else of it, and no

+    # In the order of the file.
+    added: tuple[str, ...]
+    # The countries of the file that the store had already, with the same
+    # two codes and the same name. In the order of the file.
+    as_they_were: tuple[str, ...]

+    # has the code of two letters with another code of three or another
+    # name, or it has the code of three letters under another code of
+    # two. Nothing was done about them. In the order of the file.
+    said_otherwise: tuple[str, ...]

+    # not have. Nothing was done about them. In the order of their codes.
+    not_in_the_file: tuple[str, ...]
+

+def load_countries(work: Session, countries: Iterable[ReferenceCountry]) -> CountriesLoaded:
+    """Add the countries of the reference file that the store does not have, and say what was found.
+
+    ``countries`` is what the file says, as
+    :func:`motosphere.reference.countries.countries_of_the_project` gives
+    it. A country is known by its code of two letters. One the store
+    does not have is added, with the source of the countries as its
+    source, which is stored first when the store does not have it. One
+    the store has with the same code of three letters and the same name
+    is left alone. One the store says something else of is left alone
+    too, and so is a country of the store that the file does not have:
+    both are named in what is given back, and nothing is changed and
+    nothing deleted.
+
+    All rows of one loading say one moment, for when they were collected
+    and when they were last seen: the clock is read once. A loading
+    that finds nothing to add writes no country, and nothing at all
+    when the store has the source already.
+
+    Everything is part of the unit of work ``work`` and is written to it
+    before the function returns, so what the store refuses is refused
+    here: a source called as the source of the countries that is
+    described otherwise
+    (:class:`motosphere.reference.countries_source.CountriesSourceError`),
+    and a list that has one code twice.
+    """
+    source = source_of_the_countries(work)
+    moment = times.now()
+    stored = work.execute(select(Country.alpha_2, Country.alpha_3, Country.name)).all()
+    by_code = {row.alpha_2: (row.alpha_3, row.name) for row in stored}
+    codes_of_three = {row.alpha_3 for row in stored}
+
+    new: list[Country] = []
+    as_they_were: list[str] = []
+    said_otherwise: list[str] = []
+    in_the_file: set[str] = set()
+    for country in countries:
+        in_the_file.add(country.alpha_2)
+        there = by_code.get(country.alpha_2)
+        if there == (country.alpha_3, country.name):
+            as_they_were.append(country.alpha_2)
+        elif there is not None or country.alpha_3 in codes_of_three:
+            said_otherwise.append(country.alpha_2)
+        else:
+            new.append(
+                Country(
+                    alpha_2=country.alpha_2,
+                    alpha_3=country.alpha_3,
+                    name=country.name,
+                    source_id=source.id,
+                    source_address=ADDRESS,
+                    collected_at=moment,
+                    published_on=PUBLISHED_ON,
+                    last_verified_at=moment,
+                    extraction_method=CollectionMethod.DATASET,
+                    # The file gives each value in a field made for it.
+                    confidence=Confidence.HIGH,
+                    # iso-codes is not the body that keeps the standard.
+                    verification_status=VerificationStatus.INDEPENDENT,
+                )
+            )
+    work.add_all(new)
+    work.flush()
+    return CountriesLoaded(
+        added=tuple(country.alpha_2 for country in new),
+        as_they_were=tuple(as_they_were),
+        said_otherwise=tuple(said_otherwise),
+        not_in_the_file=tuple(sorted(code for code in by_code if code not in in_the_file)),
+    )

## Acceptance criteria

1. `motosphere.reference.countries_load` has `RELEASE`, `PUBLISHED_ON`,
   `ADDRESS`, `CountriesLoaded` and `load_countries`.
2. In a store without countries, `load_countries` with the countries of
   the project's file stores 249 rows in the order of the file, each
   with its two codes and its name as the file writes them, and gives
   them back as added.
3. Every new row names the source of the countries, `ADDRESS`, one
   moment of the loading as when it was collected and last seen,
   `PUBLISHED_ON`, `public dataset`, `high` and `independent`.
4. A second loading of the same countries sends SQLite no statement
   that writes, and gives every country back as it was.
5. A country the store has with another name or another code of three,
   and a country whose code of three the store has under another code
   of two, is not added and not changed, and is named in
   `said_otherwise`. A name is compared letter for letter.
6. A country of the store that the file does not have is left as it is
   and named in `not_in_the_file`, in the order of the codes.
7. A loading stores no collection run, no row of the history and no
   item of the review queue.
8. The rows are written when the function returns, and are kept or
   taken back with their unit of work. A source that is described
   otherwise, and a list that has one code twice, refuse the loading,
   and nothing is kept.
9. The release, its day and its address are the ones the note beside
   the file names.
10. No model, migration, command or existing test changed.
11. The five documents and the note beside the file say what the task
    did, and that a loading adds and changes nothing.
12. `python scripts/check.py` reports 19 of 19 gates, with 2519
    backend tests, and 40 tests more in all than `main` gives at the
    commit the branch starts from (3487 when that is `403d1fd`).
13. On the pull request both gates jobs are green (Linux and Windows)
    at the first attempt, and the three jobs after the gates are
    skipped.
14. Only the nine files under "Scope" changed.
