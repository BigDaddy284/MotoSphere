# FND-019 – Local use: a check of the tools a computer needs

**Phase:** 1 – Foundation
**Depends on:** FND-042 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §12, `docs/WORKFLOW.md`, `TESTING.md`,
`ARCHITECTURE.md` §12, `scripts/live.py` and `tests/scripts/test_live.py`
(the style of a script and of its tests), `backend/pyproject.toml`,
`frontend/package.json`

## Objective

One command says whether a computer has the tools MotoSphere needs, which
version of each it found, and where to get one that is missing, too old or
broken.

## Why

The owner will start MotoSphere on a Windows 11 PC. That is the last piece
of the foundation, and it is four small tasks (PLAN-010): this check, a
server for the built site on this computer (FND-043), one command that
builds the site and opens it (FND-044), and the commands a Windows user
starts (FND-045). Only the last needs a Windows 11 PC. This is the first:
before anything is built or started, a new computer has to be told, in
plain words, what it lacks. Without it the first sign of a missing tool is
an error message from deep inside a build.

## Design in short

- `python scripts/tools.py`, with the Python standard library only, like
  the other scripts. It looks and reports. It installs nothing and changes
  nothing.
- Five tools, in the order a new computer needs them: Python, Git, uv,
  Node.js, npm. Each is one line: `FOUND` with its version, or `MISSING`,
  `TOO OLD` or `BROKEN` with the place to get it. The last line says how
  many of the five are ready. Exit code 0 only when all five are.
- **Each least version is written once.** Python's is read from
  `backend/pyproject.toml` (`requires-python`) and Node.js's from
  `frontend/package.json` (`engines`, `node`): the files where uv and npm
  read them. Only the form `>=1.2` is read; anything else ends the check
  in plain words, so a least version written another way one day is
  noticed, not misread.
- **"Python" is the Python that runs the script**, not whatever `python`
  is on the search path: that is the one the user has just shown to work.
  Everything else is looked up on the search path, which on Windows finds
  `npm.cmd` for `npm`.
- **A tool is asked by its full path** for its version, with 30 seconds to
  answer. One that cannot be started, stops with an error, gives no answer
  or prints no version is `BROKEN`, with the reason.
- **An older Python is told so in plain words.** The first lines of the
  script run on any Python 3 and stop one older than 3.12 with a sentence,
  before it reaches lines it cannot run. A test ties that 3.12 to the one
  in `backend/pyproject.toml`.
- It is not a gate of `scripts/check.py`: a gate whose tool is missing
  already fails by itself and says so. Its tests are part of the script
  tests, which the gates run on Linux and on Windows.

## Implementation detail

### 1. `scripts/tools.py` – new, the whole file

```python
"""Says whether this computer has the tools MotoSphere needs.

    python scripts/tools.py

MotoSphere needs Python, Git, uv, Node.js and npm (README.md). For each of
them the script says which version it found and, where the project asks for
a least version, which one. A tool that is missing, too old or broken is
named with the place to get it. The script installs nothing and changes
nothing.

The least versions are read from the project's own files, where the tools
themselves read them: Python's from `backend/pyproject.toml` and Node.js's
from `frontend/package.json`.

The script uses the Python standard library only. Its exit code is 0 when
every tool is ready and 1 when one is not, or when the check could not be
carried out.
"""

import sys

# The least Python this script itself runs on: the one the project asks for
# (a test compares the two). An older Python cannot run the lines below, so
# it is told here, in plain words, before it reaches them.
LEAST_PYTHON = (3, 12)
if sys.version_info < LEAST_PYTHON:
    sys.exit(
        "MotoSphere needs Python {}.{} or newer, and this is Python {}.{}. "
        "Get a newer one from https://www.python.org/downloads/".format(
            *LEAST_PYTHON, *sys.version_info[:2]
        )
    )

import argparse  # noqa: E402
import json  # noqa: E402
import re  # noqa: E402
import shutil  # noqa: E402
import subprocess  # noqa: E402
import tomllib  # noqa: E402
from collections.abc import Callable, Sequence  # noqa: E402
from dataclasses import dataclass  # noqa: E402
from pathlib import Path  # noqa: E402
from typing import TextIO  # noqa: E402

ROOT = Path(__file__).resolve().parent.parent

# Where each least version is written.
PYTHON_FILE = "backend/pyproject.toml"
NODE_FILE = "frontend/package.json"

# How long a tool may take to say its version.
TIMEOUT_SECONDS = 30

Version = tuple[int, ...]


class UnusableError(Exception):
    """The check could not be carried out. The message says why, in plain words."""


class BrokenError(Exception):
    """A tool is there but does not work. The message says why, in plain words."""


@dataclass(frozen=True)
class Tool:
    """One tool: its name, the program that starts it and where to get it."""

    name: str
    program: str
    source: str
    # The key of this tool's least version in `least_versions`, if it has one.
    least: str = ""


# In the order a new computer needs them.
TOOLS: tuple[Tool, ...] = (
    Tool("Python", "python", "https://www.python.org/downloads/", "python"),
    Tool("Git", "git", "https://git-scm.com/downloads"),
    Tool("uv", "uv", "https://docs.astral.sh/uv/getting-started/installation/"),
    Tool("Node.js", "node", "https://nodejs.org/en/download", "node"),
    Tool("npm", "npm", "https://nodejs.org/en/download (it comes with Node.js)"),
)


@dataclass(frozen=True)
class Finding:
    """What the check found out about one tool."""

    tool: Tool
    # FOUND, TOO OLD, MISSING or BROKEN.
    state: str
    version: Version | None = None
    least: Version | None = None
    # For a broken tool: what went wrong.
    reason: str = ""

    @property
    def ready(self) -> bool:
        return self.state == "FOUND"


Find = Callable[[str], str | None]
Ask = Callable[[str], str]


def text_of(version: Version) -> str:
    """A version the way people write it: 22.12."""
    return ".".join(str(part) for part in version)


def read_version(text: str) -> Version | None:
    """The first version number in what a tool printed, or None without one.

    `git version 2.56.0.windows.4` is 2.56.0, `v22.23.4` is 22.23.4 and
    `uv 0.11.32 (x86_64-unknown-linux-gnu)` is 0.11.32.
    """
    found = re.search(r"\d+(?:\.\d+)+", text)
    if found is None:
        return None
    return tuple(int(part) for part in found[0].split("."))


def new_enough(version: Version, least: Version) -> bool:
    """Whether a version is the least version or a newer one. 22.12 is 22.12.0."""
    width = max(len(version), len(least))
    padded = version + (0,) * (width - len(version))
    return padded >= least + (0,) * (width - len(least))


def read_least(text: object, where: str) -> Version:
    """A least version written as `>=3.12`, the only form this check reads."""
    found = re.fullmatch(r"\s*>=\s*(\d+(?:\.\d+)*)\s*", text) if isinstance(text, str) else None
    if found is None:
        raise UnusableError(f"{where} does not name a least version in the form >=1.2")
    return tuple(int(part) for part in found[1].split("."))


def least_versions(root: Path) -> dict[str, Version]:
    """The least versions the project asks for, read from the project's own files."""
    try:
        project = tomllib.loads((root / PYTHON_FILE).read_text(encoding="utf-8"))
    except (OSError, UnicodeDecodeError, tomllib.TOMLDecodeError):
        raise UnusableError(f"{PYTHON_FILE} is missing or cannot be read") from None
    try:
        package = json.loads((root / NODE_FILE).read_text(encoding="utf-8"))
    except (OSError, UnicodeDecodeError, json.JSONDecodeError):
        raise UnusableError(f"{NODE_FILE} is missing or cannot be read") from None

    requires = project.get("project", {})
    engines = package.get("engines", {}) if isinstance(package, dict) else {}
    return {
        "python": read_least(
            requires.get("requires-python") if isinstance(requires, dict) else None,
            f"{PYTHON_FILE} (requires-python)",
        ),
        "node": read_least(
            engines.get("node") if isinstance(engines, dict) else None,
            f"{NODE_FILE} (engines, node)",
        ),
    }


def find_program(name: str) -> str | None:
    """The full path of a program, or None when it is not installed.

    "python" is the Python that runs this script. Everything else is looked
    up on the PATH, which on Windows also finds `npm.cmd` for "npm".
    """
    if name == "python":
        return sys.executable
    return shutil.which(name)


def ask_version(
    program: str,
    arguments: Sequence[str] = ("--version",),
    timeout: float = TIMEOUT_SECONDS,
) -> str:
    """What a program prints when asked for its version."""
    try:
        # The program is one of the five named in TOOLS, by its full path.
        finished = subprocess.run(  # noqa: S603
            [program, *arguments],
            capture_output=True,
            text=True,
            encoding="utf-8",
            errors="replace",
            check=False,
            timeout=timeout,
        )
    except subprocess.TimeoutExpired:
        raise BrokenError(f"it gave no answer within {timeout:g} seconds") from None
    except OSError:
        raise BrokenError("it could not be started") from None
    if finished.returncode != 0:
        raise BrokenError(f"it stopped with exit code {finished.returncode}")
    return finished.stdout + finished.stderr


def look_at(tool: Tool, least: Version | None, find: Find, ask: Ask) -> Finding:
    """Find one tool, ask its version and compare it with the least version."""
    program = find(tool.program)
    if program is None:
        return Finding(tool, "MISSING", least=least)
    try:
        answer = ask(program)
    except BrokenError as error:
        return Finding(tool, "BROKEN", least=least, reason=str(error))
    version = read_version(answer)
    if version is None:
        return Finding(tool, "BROKEN", least=least, reason="it did not say its version")
    if least is not None and not new_enough(version, least):
        return Finding(tool, "TOO OLD", version, least)
    return Finding(tool, "FOUND", version, least)


def line_for(finding: Finding) -> str:
    """One line of the report about one tool."""
    tool = finding.tool
    needed = "" if finding.least is None else f" ({text_of(finding.least)} or newer is needed)"
    if finding.state == "MISSING":
        return f"  MISSING  {tool.name}{needed}. Get it from {tool.source}"
    if finding.state == "BROKEN":
        return f"  BROKEN   {tool.name}: {finding.reason}. Get it again from {tool.source}"
    found = "" if finding.version is None else f" {text_of(finding.version)}"
    if finding.state == "TOO OLD":
        return f"  TOO OLD  {tool.name}{found}{needed}. Get a newer one from {tool.source}"
    return f"  FOUND    {tool.name}{found}{needed}"


def main(
    arguments: Sequence[str] | None = None,
    root: Path = ROOT,
    out: TextIO = sys.stdout,
    find: Find = find_program,
    ask: Ask = ask_version,
) -> int:
    """Look at every tool and write what was found. Returns the exit code."""
    parser = argparse.ArgumentParser(
        description="Say whether this computer has the tools MotoSphere needs."
    )
    parser.parse_args(arguments)

    try:
        least = least_versions(root)
    except UnusableError as error:
        out.write(f"The tools could not be checked: {error}\n")
        return 1

    findings = [look_at(tool, least.get(tool.least), find, ask) for tool in TOOLS]
    out.write("The tools MotoSphere needs on this computer:\n\n")
    for finding in findings:
        out.write(line_for(finding) + "\n")
    ready = sum(finding.ready for finding in findings)
    out.write(f"\n{ready} of {len(findings)} tools are ready.\n")
    return 0 if ready == len(findings) else 1


if __name__ == "__main__":
    sys.exit(main())
```

The imports after the version check carry `# noqa: E402` because they must
come after it: Python 3.10 and older do not have `tomllib`, and would stop
with an error trace instead of the sentence.

### 2. `tests/scripts/test_tools.py` – new, the whole file, 42 tests

```python
"""Tests for the check of the tools, `scripts/tools.py` (task FND-019).

Run from the repository root:

    python -m unittest discover -s tests/scripts -v

The lines the tools print were copied from real runs: Git, uv, Node.js, npm
and Python on Linux, and Git on Windows from a log of GitHub's Windows
machine. Where a test needs a tool that is missing, too old or broken, a
stand-in answers for it, and the stand-in programs are run by the real Python.
"""

import io
import os
import shutil
import subprocess
import sys
import tempfile
import unittest
from pathlib import Path
from unittest import mock

# The script is not an installed package, so its folder is added to the places
# Python imports from.
sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "scripts"))

import tools

ROOT = Path(__file__).resolve().parents[2]
SCRIPT = ROOT / "scripts" / "tools.py"

# What each tool printed, in a real run, when asked for its version.
PRINTED = {
    "python": "Python 3.13.18\n",
    "git": "git version 2.43.0\n",
    "uv": "uv 0.11.32 (x86_64-unknown-linux-gnu)\n",
    "node": "v22.23.4\n",
    "npm": "10.9.9\n",
}
GIT_ON_WINDOWS = "git version 2.56.0.windows.4\n"

EVERYTHING_FOUND = (
    "The tools MotoSphere needs on this computer:\n"
    "\n"
    "  FOUND    Python 3.13.18 (3.12 or newer is needed)\n"
    "  FOUND    Git 2.43.0\n"
    "  FOUND    uv 0.11.32\n"
    "  FOUND    Node.js 22.23.4 (22.12 or newer is needed)\n"
    "  FOUND    npm 10.9.9\n"
    "\n"
    "5 of 5 tools are ready.\n"
)


def find(name: str) -> str | None:
    """A computer that has every tool: each program is found under its name."""
    return name


def ask(program: str) -> str:
    """A computer whose tools print what the real ones printed."""
    return PRINTED[program]


class ProjectTest(unittest.TestCase):
    """A stand-in for the project: a folder with the two files that name versions."""

    def setUp(self) -> None:
        self.folder = Path(tempfile.mkdtemp())
        self.addCleanup(shutil.rmtree, self.folder)
        self.write(tools.PYTHON_FILE, '[project]\nname = "x"\nrequires-python = ">=3.12"\n')
        self.write(tools.NODE_FILE, '{"engines": {"node": ">=22.12"}}\n')

    def write(self, name: str, text: str) -> None:
        path = self.folder / name
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(text, encoding="utf-8")


class ReadVersionTest(unittest.TestCase):
    def test_reads_what_each_tool_really_prints(self) -> None:
        self.assertEqual(tools.read_version(PRINTED["python"]), (3, 13, 18))
        self.assertEqual(tools.read_version(PRINTED["git"]), (2, 43, 0))
        self.assertEqual(tools.read_version(PRINTED["uv"]), (0, 11, 32))
        self.assertEqual(tools.read_version(PRINTED["node"]), (22, 23, 4))
        self.assertEqual(tools.read_version(PRINTED["npm"]), (10, 9, 9))

    def test_reads_git_on_windows_without_what_follows_the_version(self) -> None:
        self.assertEqual(tools.read_version(GIT_ON_WINDOWS), (2, 56, 0))

    def test_finds_no_version_where_none_is_printed(self) -> None:
        self.assertIsNone(tools.read_version(""))
        self.assertIsNone(tools.read_version("this program cannot be run\n"))

    def test_a_lone_number_is_not_a_version(self) -> None:
        self.assertIsNone(tools.read_version("stopped with error 127\n"))


class NewEnoughTest(unittest.TestCase):
    def test_the_least_version_itself_is_new_enough(self) -> None:
        self.assertTrue(tools.new_enough((22, 12), (22, 12)))
        self.assertTrue(tools.new_enough((22, 12, 0), (22, 12)))
        self.assertTrue(tools.new_enough((22, 12), (22, 12, 0)))

    def test_a_newer_version_is_new_enough(self) -> None:
        self.assertTrue(tools.new_enough((22, 23, 4), (22, 12)))
        self.assertTrue(tools.new_enough((24, 0, 1), (22, 12)))
        self.assertTrue(tools.new_enough((23,), (22, 12)))

    def test_an_older_version_is_not(self) -> None:
        self.assertFalse(tools.new_enough((22, 11, 9), (22, 12)))
        self.assertFalse(tools.new_enough((20, 19, 0), (22, 12)))
        self.assertFalse(tools.new_enough((22,), (22, 12)))

    def test_the_parts_are_compared_as_numbers_not_as_text(self) -> None:
        self.assertFalse(tools.new_enough((3, 9, 18), (3, 12)))
        self.assertTrue(tools.new_enough((3, 100), (3, 12)))


class ReadLeastTest(unittest.TestCase):
    def test_reads_a_least_version(self) -> None:
        self.assertEqual(tools.read_least(">=3.12", "the file"), (3, 12))
        self.assertEqual(tools.read_least(" >= 22.12.1 ", "the file"), (22, 12, 1))
        self.assertEqual(tools.read_least(">=22", "the file"), (22,))

    def test_refuses_any_other_form_and_says_where_it_is_written(self) -> None:
        for written in ("^22.12", ">=3.12,<4", "3.12", ">3.12", "", ">=", None, 3.12):
            with self.subTest(written=written), self.assertRaises(tools.UnusableError) as raised:
                tools.read_least(written, "the file (the key)")
            self.assertEqual(
                str(raised.exception),
                "the file (the key) does not name a least version in the form >=1.2",
            )

class FindProgramTest(unittest.TestCase):
    def test_python_is_the_python_that_runs_the_script(self) -> None:
        # Whatever "python" the search path holds, it is not looked up there.
        with mock.patch.object(shutil, "which", return_value="another-python") as which:
            found = tools.find_program("python")

        self.assertEqual(found, sys.executable)
        which.assert_not_called()

    def test_finds_a_program_that_is_installed(self) -> None:
        found = tools.find_program("git")

        self.assertIsNotNone(found)
        self.assertEqual(found, shutil.which("git"))

    def test_finds_nothing_for_a_program_that_is_not_installed(self) -> None:
        self.assertIsNone(tools.find_program("motosphere-no-such-tool"))


class AskVersionTest(unittest.TestCase):
    """Real programs: the real Python, asked for its version or told what to do."""

    def test_returns_what_the_program_prints(self) -> None:
        printed = tools.ask_version(sys.executable)

        self.assertEqual(tools.read_version(printed), sys.version_info[:3])

    def test_returns_what_is_printed_as_an_error_too(self) -> None:
        printed = tools.ask_version(
            sys.executable, ("-c", "import sys; sys.stderr.write('tool 1.2.3')")
        )

        self.assertEqual(printed, "tool 1.2.3")

    def test_a_program_that_fails_is_broken(self) -> None:
        with self.assertRaises(tools.BrokenError) as raised:
            tools.ask_version(sys.executable, ("-c", "import sys; sys.exit(3)"))

        self.assertEqual(str(raised.exception), "it stopped with exit code 3")

    def test_a_program_that_gives_no_answer_is_broken(self) -> None:
        with self.assertRaises(tools.BrokenError) as raised:
            tools.ask_version(sys.executable, ("-c", "import time; time.sleep(60)"), 0.5)

        self.assertEqual(str(raised.exception), "it gave no answer within 0.5 seconds")

    def test_a_program_that_cannot_be_started_is_broken(self) -> None:
        with (
            tempfile.TemporaryDirectory() as folder,
            self.assertRaises(tools.BrokenError) as raised,
        ):

class ProgramTest(unittest.TestCase):
    """The script as a separate process, the way a person starts it."""

    def setUp(self) -> None:
        # Another folder than the repository: the script finds the project by
        # its own place, not by where it is started.
        self.folder = Path(tempfile.mkdtemp())
        self.addCleanup(shutil.rmtree, self.folder)

    def run_python(
        self, *arguments: str, path: str | None = None
    ) -> subprocess.CompletedProcess[str]:
        environment = None if path is None else {**os.environ, "PATH": path}
        # The arguments are the real Python, this repository's script and
        # values the test wrote.
        return subprocess.run(  # noqa: S603
            [sys.executable, *arguments],
            cwd=self.folder,
            env=environment,
            capture_output=True,
            text=True,
            check=False,
            timeout=120,
        )

    @staticmethod
    def states(lines: list[str]) -> list[str]:
        """The five lines about the tools, cut down to the state and the name."""
        return [" ".join(line.split()[:2]).rstrip(".") for line in lines[2:7]]

    def test_passes_on_this_computer_which_has_every_tool(self) -> None:
        finished = self.run_python(str(SCRIPT))

        self.assertEqual(finished.returncode, 0, finished.stdout + finished.stderr)
        lines = finished.stdout.splitlines()
        self.assertEqual(lines[0], "The tools MotoSphere needs on this computer:")
        self.assertEqual(
            self.states(lines),
            ["FOUND Python", "FOUND Git", "FOUND uv", "FOUND Node.js", "FOUND npm"],
        )
        python = ".".join(str(part) for part in sys.version_info[:3])
        self.assertIn(f"  FOUND    Python {python} (", lines[2])
        self.assertEqual(lines[-1], "5 of 5 tools are ready.")
        self.assertEqual(finished.stderr, "")

    def test_fails_where_only_python_can_be_found(self) -> None:
        # A PATH that holds one empty folder: no tool is found on it.
        finished = self.run_python(str(SCRIPT), path=str(self.folder))

        self.assertEqual(finished.returncode, 1, finished.stdout + finished.stderr)
        lines = finished.stdout.splitlines()
        self.assertEqual(
            self.states(lines),
            ["FOUND Python", "MISSING Git", "MISSING uv", "MISSING Node.js", "MISSING npm"],
        )
        self.assertEqual(lines[-1], "1 of 5 tools are ready.")
        self.assertEqual(finished.stderr, "")

    def test_tells_an_older_python_in_plain_words_that_it_is_too_old(self) -> None:
        # The real Python, told that it is Python 3.11 before it reads the script.
        pretend = (
            "import runpy, sys; "
            "sys.version_info = (3, 11, 9, 'final', 0); "
            "runpy.run_path(sys.argv[1], run_name='__main__')"
        )
        finished = self.run_python("-c", pretend, str(SCRIPT))

        self.assertEqual(finished.returncode, 1)
        self.assertEqual(finished.stdout, "")
        self.assertEqual(
            finished.stderr,
            "MotoSphere needs Python 3.12 or newer, and this is Python 3.11. "
            "Get a newer one from https://www.python.org/downloads/\n",
        )
```
