mode over both `backend/src` and `backend/tests`.

## Implementation detail

### 1. Dependency

Add to the `dev` group in `backend/pyproject.toml`, keeping the list sorted
alphabetically:

```toml
[dependency-groups]
dev = [
    "mypy>=1.13",
    "pytest>=8.3",
    "ruff>=0.9",
]
```

Then run `uv lock` in `backend/`.

### 2. Configuration

Append to `backend/pyproject.toml`:

```toml
[tool.mypy]
python_version = "3.12"
files = ["src", "tests"]
mypy_path = "src"
strict = true
warn_unreachable = true
warn_return_any = true
enable_error_code = ["ignore-without-code", "redundant-expr", "truthy-bool", "possibly-undefined"]
show_error_codes = true
pretty = true
```

Rules:

- Keep exactly these settings. `files` is what lets the gate run as plain
  `uv run mypy` with no arguments.
- No `[[tool.mypy.overrides]]` sections, no `ignore_missing_imports`, no
  `# type: ignore` comments anywhere. If mypy reports an error in existing
  code, fix the code. If you believe a setting is wrong for this project,
  stop and report it rather than relaxing it.

### 3. Documentation

- `README.md`, "Running the checks": add the type-check command to the
  backend lint and format block (or directly after it), run from `backend/`:

  ```
  uv run mypy
  ```

- `TESTING.md`, Gates table: add
  `Backend type check` → `cd backend && uv run mypy`.
- `CHANGELOG.md`: one bullet, for example "Backend static type checking with
  mypy in strict mode (FND-004)."

## Acceptance criteria

1. `uv run mypy` passes in `backend/` with the settings above and reports that
   it checked 2 source files (`src/motosphere/__init__.py` and
   `tests/unit/test_package.py`).
2. The gate fails on a deliberate type error and on an unannotated function
   (see "Verification").
3. No `# type: ignore`, no overrides, no relaxed settings.
4. `uv lock --check` passes; ruff check, ruff format check, backend tests (4)
   and repository checks (9) still pass.
5. README, TESTING.md and CHANGELOG.md describe the new gate.
6. No files outside "Scope" touched.

## Verification

From a clean state (delete `backend/.venv` first if it exists):

```
cd backend
uv lock --check
uv sync --locked
uv run mypy
uv run ruff check .
uv run ruff format --check .
uv run pytest -v
cd ..
python -m unittest discover -s tests/repo -v
git status --short
```

Expected: lock check passes; `Success: no issues found in 2 source files`;
`All checks passed!`; nothing to reformat; `4 passed`; `Ran 9 tests` / `OK`;
clean status once committed.

Then prove the gate can fail (do not commit these changes). Create a temporary
file `backend/src/motosphere/_type_probe.py` containing:

```python
def add(a: int, b: int) -> int:
    return a + b


def broken() -> int:
    return add("1", 2)


def untyped(x):
    return x
```

`uv run mypy` must exit non-zero and report two errors in that file: an
incompatible argument type (`arg-type`) and a missing annotation
(`no-untyped-def`). Record the error codes shown.

Delete the probe file and confirm `uv run mypy` passes again and `git status`
is clean.
