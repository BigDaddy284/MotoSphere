**Phase:** 2 – Data store and published data

## Objective

One function gives the row of the source of the countries in the store,
and stores that row first when the store does not have it: once, as
`DATA_SOURCES.md` describes the source, and switched off.

## Why

Every country in the store has to name the source it came from
(DAT-011), and that source is the project iso-codes (DAT-012). Before
the countries can be loaded, the store needs the row of that source,
and it needs it the same every time: "Every record must retain its
source and collection history." (CLAUDE.md §11). The source was found,
its licence read and its kind settled (DAT-012, DAT-058); what is left
is to say all that to the store.

DAT-059 was added as one task that registers the source and loads the
countries. Those are two objectives with two kinds of test, and a
command is a third (PLAN-049 in `PROGRESS.md`). This is the first of
the three: the source. Loading the countries is DAT-059, and the
command that does both is DAT-061.

## What this task is, and what it is not

- **It is** one new module,
  `backend/src/motosphere/reference/countries_source.py`: what the
  store is told of the source, and the function
  `source_of_the_countries(work)`.
- **It is** 38 new tests in two new files, 12 without a store and 26
  against a real SQLite file.
- **It is** the documents: `DATABASE.md`, `DATA_SOURCES.md`,
  `TESTING.md`, `ARCHITECTURE.md` and `CHANGELOG.md`.
- **It is not** a source in anybody's store. Nothing calls the function
  yet; DAT-059 will, when it loads the countries.
- **It is not** a command, a migration or a change to a model. The
  schema stays at version 15.
- **It is not** a decision that the source's terms were read by a
  person, or that the source is switched on. Both are left to the
  owner (see "What the trial settled").

## Design in short

`countries_source.py` has the description and one function.

The description: `NAME` (`iso-codes`), `WEBSITE`, `LICENCE`
(`LGPL-2.1-or-later`), `USAGE_RESTRICTIONS` (what the licence asks, in
three sentences), `DESCRIBED` (six columns of a source with what the
pipeline says of each, in the order of the table: the website, the
kind `reference list`, the way of collecting `public dataset`, no
address of terms, the licence and the restrictions) and `OFFERS` (the
one kind of information, `reference data`).

`source_of_the_countries(work)` looks for a source of that name.

- **There is none:** it stores one as described, writes it, stores its
  offer, writes that, and gives the source. The four columns that are
  for people keep what the table gives a new source: switched off, its
  terms read by nobody, no hours, no country.
- **There is one, as described:** it gives it as it is and writes
  nothing. What people have said of it is not looked at, and neither is
  what else it offers.
- **There is one that is described otherwise**, in one of the six
  columns or because it does not offer `reference data`: it raises
  `CountriesSourceError`, a `ValueError`, and changes nothing. The
  sentence names everything that differs, in the order of the table:

  `The store has a source called "iso-codes" that is not the source of
  the countries as the pipeline describes it. It differs in its website
  and licence. Nothing was changed.`

Everything is part of the unit of work it is handed.

## What the trial settled

- **Switched off, and its terms read by nobody.** The column
  `terms_read_at` says when a person last read a source's terms, and a
  source is switched on only after that (DAT-006). The planner read the
  licence of iso-codes and `DATA_SOURCES.md` says what it found; the
  planner is not a person, and the store is not told that a person read
  it. So a new row says what is so: nobody has yet. The source need not
  be switched on for its countries to be loaded, because nothing is
  fetched from it: its file is in the repository, which DAT-012
  decided. The owner switches it on, or leaves it, after reading the
  licence. `DATABASE.md` and `DATA_SOURCES.md` say so in those words.
- **No address of terms.** The source has no page of terms: its terms
  are its licence, whose text is in the repository beside the file. No
  address is made up for it, and none that the planner could not open
  is written down as one.
- **The pipeline describes, people decide.** The description is seven
  columns of a source with its name; four are for people
  (`terms_read_at`, `switched_on`, `scan_every_hours`, `country_id`).
  A test holds that every column of a source is on one side or the
  other, or is one of the store's own three, so a column that is added
  to the table later cannot be forgotten here.
- **A source of the name that is described otherwise is refused, not
  written over and not passed.** Writing over it would change a record
  without anybody deciding it. Passing it would load countries under a
  licence or a website the code does not know. A refusal with a
  sentence leaves it to a person. The case arises when a later release
  of iso-codes changes its licence, or when somebody changed the row by
  hand.
- **It may offer more.** A source that is as described and offers
  `reference data` among other things is the source. What else it
  offers is somebody's later decision and no contradiction.
- **Known by its name, letter for letter.** `ISO-codes` is another
  source. The table holds names apart the same way (`uq_source_name`).
- **Written before it returns.** The function writes the source and
  then its offer to the unit of work before it returns, so the offer
  can name its source, and so that what the store refuses is refused
  here and not at the end of the unit of work.
- **The texts are written twice.** The tests write the name, the
  website, the licence and the restrictions out a second time, so a
  change to what the store is told is made in two places and seen. A
  test holds the website and the licence to the note beside the file.

+    ("terms_address", None),
+    ("licence", LICENCE),
+    ("usage_restrictions", USAGE_RESTRICTIONS),

+    "category": "kind",
+    "collection_method": "way of collecting",
+    "terms_address": "address of its terms",
+    "licence": "licence",
+    "usage_restrictions": "restrictions of use",

+    """The store has a source of this name that is not the one the pipeline describes."""

+def source_of_the_countries(work: Session) -> Source:
+    """Give the source of the countries, and store it first when the store does not have it.
+
+    The source is known by its name. When the store has no source of that
+    name, one is stored as this module describes it, with what it offers.
+    It is switched off, and it says that nobody has read its terms: both
+    are for a person to say.
+
+    When the store has one, it is given as it is and nothing is written.
+    It must then be as described, and offer what is described; what else
+    it offers, and what people have said of it, is not looked at. A
+    source of this name that is described otherwise is refused with a
+    :class:`CountriesSourceError` that says in what it differs, and it is
+    left as it is: which of the two is right is for a person to decide.
+
+    Everything is part of the unit of work ``work``.
+    """
+    source = work.scalars(select(Source).where(Source.name == NAME)).one_or_none()
+    if source is None:
+        source = Source(name=NAME, **dict(DESCRIBED))
+        work.add(source)
+        work.flush()
+        work.add_all(SourceOffer(source_id=source.id, information_type=kind) for kind in OFFERS)
+        work.flush()
+        return source
+
+    different = [
+        _IN_WORDS[column] for column, value in DESCRIBED if getattr(source, column) != value
+    ]
+    offered = set(
+        work.scalars(select(SourceOffer.information_type).where(SourceOffer.source_id == source.id))
+    )
+    different += [f'offer of "{kind}"' for kind in OFFERS if kind not in offered]
+    if different:
+        raise CountriesSourceError(
+            f'The store has a source called "{NAME}" that is not the source of the countries '
+            f"as the pipeline describes it. It differs in its {_listed(different)}. "
+            "Nothing was changed."
+        )
+    return source
+

+def _listed(words: list[str]) -> str:
+    """Say several things in one breath: "a", "a and b", "a, b and c"."""
+    if len(words) == 1:
+        return words[0]
+    return f"{', '.join(words[:-1])} and {words[-1]}"
