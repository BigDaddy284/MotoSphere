## Objective

The store finds the runs of one source, newest first, without reading
the whole table of the runs.

## Why

`standing_of` (DAT-041) asks the table of the runs four times for the
newest run of one source. The table has no index beside the key's, so
SQLite reads every run of every source for each of those questions and
sorts what it found. The table grows with every run of every source, so
the reading grows with it, four times over for every source that is
asked about (CLAUDE.md §13: database query efficiency). The trial of
DAT-041 showed which index answers the questions; this task adds it. It
is the store's first index and its fourth migration.

## Design in short

- **One index, `ix_collection_run_source_id_started_at`**, over
  `source_id` and `started_at`, in that order. The model says it
  (`Index(None, "source_id", "started_at")`), the naming rule names it,
  and the fourth migration, `index_the_runs_of_a_source`, makes it.
- **One new test file** that asks SQLite itself how it will answer the
  statements `standing_of` really sends, and holds it to the index.
- No change to `standing_of` or to any other code, no new fixture, no
  new package from outside.

## What the task left open, and what the trial settled

- **Which columns.** The trial asked SQLite (3.53.1) for its plan for
  the four statements of `standing_of`, in a store the migrations built,
  with no index and with six:

  | Index over | What SQLite says |
  |---|---|
  | none | `SCAN collection_run`, `USE TEMP B-TREE FOR ORDER BY` |
  | `source_id`, `started_at` | `SEARCH collection_run USING INDEX … (source_id=?)` |
  | `source_id` | the same search, then `USE TEMP B-TREE FOR ORDER BY` |
  | `source_id`, `started_at`, `id` | the same search, nothing sorted |
  | `source_id`, `started_at`, `outcome` | the same search, then `USE TEMP B-TREE FOR LAST TERM OF ORDER BY` |
  | `source_id`, `started_at DESC` | the same search, then `USE TEMP B-TREE FOR LAST TERM OF ORDER BY` |
  | `source_id`, `outcome`, `started_at` | `SEARCH … (source_id=? AND outcome=?)`; sorted when more than one outcome is asked for |

  So the source and the start, rising, and no more. The key adds
  nothing: SQLite ends every entry of an index with the key by itself,
  which is why the order "newest start first, and of two that started
  together the one stored last" needs no sorting. The outcome would
  stand between the start and the key and break exactly that order.
- **It forbids nothing.** The index is not unique: two runs of one
  source can start at the same moment (DAT-007 has the test).
- **The name** is the one the naming rule gives (DAT-005):
  `ix_collection_run_source_id_started_at`. The model gives none by
  hand.
- **The migration** is one statement, `CREATE INDEX … ON collection_run
  (source_id, started_at)`, at the end of the history. It is named for
  what it does, `index_the_runs_of_a_source`. The runs a store has are
  kept; a test gives the migration to a store at version 3 with two
  runs. The statement is not softened with `IF NOT EXISTS`: where an
  index of that name is there already, over whatever columns, it would
  be taken for the right one ever after. The migration fails instead and
  the store stays at version 3, and a test holds it to that.
- **How the use of the index is proven.** A test catches the statements
  `standing_of` sends as they go to SQLite, with what they were given,
  and asks SQLite for its plan for each of the four that read the runs
  (`EXPLAIN QUERY PLAN`). Each must be the one step
  `SEARCH collection_run USING INDEX
  ix_collection_run_source_id_started_at (source_id=?)`. So the test
  follows the function: a statement changed later in a way the index
  does not serve fails it. A second test drops the index in the test's
  own store and reads the other plan, so that what the index is for is
  written down where it is tested. A third proves that the index changes
  no answer.
- **The words of SQLite's plan** are compared exactly. The trial read
  the same words from the SQLite of this machine (3.53.1) and from those
  of both of GitHub's machines, where the tests passed as they are here.
- **Deleting a source.** SQLite must look for the runs of a source
  before it lets the source go. In the trial its program for that
  statement (`EXPLAIN DELETE FROM source WHERE id = 1`) opened the table
  of the runs without the index, and the index with it. No test holds
  it to that: it is how SQLite works inside, and what it must do, refuse
  the delete, is tested already.

### 1. `backend/src/motosphere/db/models/collection_run.py` – the whole file, in place of the one there

New are the index at the end of `__table_args__`, with its comment, and
`Index` in the import. The rest is as it was.

```python
"""The collection runs: the record of every time a source was collected from.

A run is one attempt to collect from one source. This module has the
model of the table that records them, :class:`CollectionRun`, and the
list of how a run stands or ended, :class:`RunOutcome`.

A run is stored when it starts, and it is then running. When it ends it
says so itself: it succeeded, or it failed and says why. A run whose job
died says nothing more. It is still running in the table until the next
start finds it and marks it interrupted
(:func:`motosphere.db.runs.mark_interrupted`).
"""

from datetime import datetime
from enum import StrEnum

from sqlalchemy import CheckConstraint, ForeignKey, Index
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base
from motosphere.db.lists import OneOf
from motosphere.db.texts import NotEmpty

__all__ = ["CollectionRun", "RunOutcome"]


class RunOutcome(StrEnum):
    """How a collection run stands or ended."""

    # It has started and has not said how it ended.
    RUNNING = "running"
    # It ended, and collected what it set out to collect.
    SUCCEEDED = "succeeded"
    # It ended, and says what went wrong.
    FAILED = "failed"
    # It never said how it ended, because its job died. Nobody knows when.
    INTERRUPTED = "interrupted"


class CollectionRun(Base):
    """One run: which source it collected from, when, how it ended and what it changed.

    A run belongs to a source that exists, and a source that has runs
    cannot be deleted. The table itself refuses a run that ends before it
    started, a run whose end or whose error does not go with its outcome,
    and a count below nothing.
    """

    __tablename__ = "collection_run"
    __table_args__ = (
        CheckConstraint("ended_at >= started_at", name="ended_at_not_before_started_at"),
        # When it ended is known of a run that said so itself, and of no other.
        CheckConstraint(
            "(ended_at IS NULL) = (outcome IN ('running', 'interrupted'))",
            name="ended_at_when_succeeded_or_failed",
        ),
        # A run that failed says why, and no other run has an error.
        CheckConstraint("(error IS NULL) = (outcome != 'failed')", name="error_when_failed"),
        CheckConstraint("records_seen >= 0", name="records_seen_not_negative"),
        CheckConstraint("records_added >= 0", name="records_added_not_negative"),
        CheckConstraint("records_changed >= 0", name="records_changed_not_negative"),
        CheckConstraint("records_unchanged >= 0", name="records_unchanged_not_negative"),
        # The runs of one source, in the order they started: what asks for
        # the newest run of a source goes straight to it, and so does the
        # look for its runs when a source is to be deleted. SQLite ends
        # every entry of an index with the key, so two runs that started
        # together stand in the order they were stored.
        Index(None, "source_id", "started_at"),
    )

    # The source that was collected from.
    source_id: Mapped[int] = mapped_column(ForeignKey("source.id"))
    # When the run started. Whoever starts it says so.
    started_at: Mapped[datetime]
    # When it ended. No value: it is running, or it was interrupted and
    # nobody knows when.
    ended_at: Mapped[datetime | None]
    outcome: Mapped[RunOutcome] = mapped_column(OneOf(RunOutcome), default=RunOutcome.RUNNING)
    # How many records the run was given by its source, and how many of
    # them were new to the store, were different from what the store had,
    # and were what the store had already. A run counts as it goes or when
    # it ends; the table does not ask that the three add up to the first,
    # because a record that was refused is none of the three.
    records_seen: Mapped[int] = mapped_column(default=0)
    records_added: Mapped[int] = mapped_column(default=0)
    records_changed: Mapped[int] = mapped_column(default=0)
    records_unchanged: Mapped[int] = mapped_column(default=0)
    # What went wrong, in plain words, when the run failed.
    error: Mapped[NotEmpty | None]
```

```python
"""The history of the store's schema: every migration, oldest first.

A migration is a function that is given a connection and changes the
schema with it. ``MIGRATIONS`` is the list of them all, and the place of a
migration in that list is its number (:mod:`motosphere.db.migrations`
gives a store those it lacks).

- The list only ever grows at its end. A migration that has been merged is
  not changed, moved or taken out, because stores and snapshots at its
  version exist. A mistake in one is put right by a new one.
- A migration is plain SQL, written out here. It names no model, no list
  and no type of the store's code, and this module imports nothing of
  MotoSphere's: so a migration builds tomorrow what it builds today,
  whatever becomes of the code. What two migrations both need, each
  writes out for itself.
- A migration writes a table as its model makes it, and one test holds
  the two together (``DATABASE.md``, "The models and the migrations
  agree").
- A migration does not commit. ``migrate`` does, with the store's new
  version.
"""

from collections.abc import Callable

from sqlalchemy import Connection

__all__ = [
    "MIGRATIONS",
    "index_the_runs_of_a_source",
    "make_the_collection_runs",
    "make_the_source_offers",
    "make_the_sources",
]


def make_the_sources(connection: Connection) -> None:
    """1: the table of the information sources, ``source`` (DAT-006)."""
    white_space = (
        "char(9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, 8192, 8193, 8194, 8195, "
        "8196, 8197, 8198, 8199, 8200, 8201, 8202, 8232, 8233, 8239, 8287, 12288)"
    )

    def not_empty(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_not_empty CHECK (trim({column}, {white_space}) != '')"
        )

    def web_address(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_web_address CHECK ("
            f"(({column} GLOB '[Hh][Tt][Tt][Pp][Ss]://[^/?#]*')"
            f" OR ({column} GLOB '[Hh][Tt][Tt][Pp]://[^/?#]*'))"
            f" AND NOT ({column} GLOB '*[' || {white_space} || ']*')"
            f" AND instr({column}, char(0)) = 0)"
        )

    connection.exec_driver_sql(
        f"""
        CREATE TABLE source (
            id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            website TEXT NOT NULL,
            category TEXT NOT NULL,
            collection_method TEXT NOT NULL,
            scan_every_hours INTEGER,
            terms_address TEXT,
            licence TEXT,
            usage_restrictions TEXT,
            terms_read_at TEXT,
            switched_on INTEGER NOT NULL,
            created_at TEXT NOT NULL,
            updated_at TEXT NOT NULL,
            CONSTRAINT ck_source_scan_every_hours_positive CHECK (scan_every_hours > 0),
            CONSTRAINT ck_source_switched_on_terms_read
                CHECK (switched_on = 0 OR terms_read_at IS NOT NULL),
            CONSTRAINT uq_source_name UNIQUE (name),
            {not_empty("name")},
            {web_address("website")},
            CONSTRAINT ck_source_category_one_of CHECK (category IN (
                'governing body', 'championship', 'organiser', 'promoter', 'track', 'club',
                'regional organisation', 'results database', 'news publication',
                'community website', 'social media page', 'historical archive'
            )),
            CONSTRAINT ck_source_collection_method_one_of CHECK (collection_method IN (
                'official api', 'structured feed', 'rss feed', 'public dataset',
                'html extraction', 'structured document', 'json endpoint', 'sitemap discovery',
                'search engine discovery', 'human submission'
            )),
            {web_address("terms_address")},
            {not_empty("licence")},
            {not_empty("usage_restrictions")},
            CONSTRAINT ck_source_switched_on_yes_or_no CHECK (switched_on IN (0, 1))
        ) STRICT
        """
    )

def make_the_collection_runs(connection: Connection) -> None:
    """3: the table of the collection runs, ``collection_run`` (DAT-007)."""
    connection.exec_driver_sql(
        """
        CREATE TABLE collection_run (
            id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
            source_id INTEGER NOT NULL,
            started_at TEXT NOT NULL,

            records_added INTEGER NOT NULL,

            CONSTRAINT fk_collection_run_source_id_source
                FOREIGN KEY(source_id) REFERENCES source (id),
            CONSTRAINT ck_collection_run_outcome_one_of

            CONSTRAINT ck_collection_run_error_not_empty CHECK (trim(error, char(
                9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, 8192, 8193, 8194, 8195,

def index_the_runs_of_a_source(connection: Connection) -> None:
```

### 3. `backend/tests/integration/test_collection_run_index.py` – new, the whole file, 4 tests

```python
"""Tests of the index of the runs of one source, against a real SQLite file.

An index is there to be used. These tests ask SQLite itself how it will
answer the statements the store's code really sends, in a store that the
migrations built, and hold it to the index.
"""

from collections.abc import Sequence
from datetime import UTC, datetime, timedelta

from sqlalchemy import Connection, Engine, event

from motosphere.db.models import CollectionRun, Source
from motosphere.db.models.collection_run import RunOutcome
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.source_health import SourceHealth, standing_of
from motosphere.db.work import unit_of_work

INDEX = "ix_collection_run_source_id_started_at"
STARTED = datetime(2026, 11, 24, 6, 0, tzinfo=UTC)
# What SQLite says when it goes straight to the runs of one source.
BY_THE_INDEX = f"SEARCH collection_run USING INDEX {INDEX} (source_id=?)"


def some_runs(store: Engine) -> None:
    """Store three sources, each with a run of every outcome, an hour apart."""
    with unit_of_work(store) as work:
        for name in ("Example Federation", "Example Club", "Example Track"):
            source = Source(
                name=name,
                website="https://federation.example",
                category=SourceCategory.GOVERNING_BODY,
                collection_method=CollectionMethod.RSS,
            )
            work.add(source)
            work.flush()
            for hours, outcome in enumerate(RunOutcome):
                started = STARTED + timedelta(hours=hours)
                over = outcome in (RunOutcome.SUCCEEDED, RunOutcome.FAILED)
                work.add(
                    CollectionRun(
                        source_id=source.id,
                        started_at=started,
                        ended_at=started + timedelta(minutes=4) if over else None,
                        outcome=outcome,
                        error="The feed did not answer." if outcome is RunOutcome.FAILED else None,
                    )
                )


def statements_of_standing_of(store: Engine, source: int) -> list[tuple[str, Sequence[object]]]:
    """Every statement ``standing_of`` sends for this source, with what it is given."""
    sent: list[tuple[str, Sequence[object]]] = []

    def remember(
        _connection: Connection,
        _cursor: object,
        statement: str,
        given: Sequence[object],
        _context: object,
        _many: bool,
    ) -> None:
        sent.append((statement, given))

    event.listen(store, "before_cursor_execute", remember)
    try:
        with unit_of_work(store) as work:
            standing_of(work, source)
    finally:
        event.remove(store, "before_cursor_execute", remember)
    return sent


def plan_of(store: Engine, statement: str, given: Sequence[object]) -> list[str]:
    """SQLite's own account of how it will answer a statement, step by step."""
    with store.connect() as connection:
        steps = connection.exec_driver_sql("EXPLAIN QUERY PLAN " + statement, tuple(given))
        return [str(step[3]) for step in steps]


def test_the_newest_schema_has_the_index_over_the_source_and_the_start(newest: Engine) -> None:
    with newest.connect() as connection:
        columns = connection.exec_driver_sql(f"PRAGMA index_info({INDEX})").all()
        listed = connection.exec_driver_sql("PRAGMA index_list(collection_run)").all()

    assert [name for _, _, name in columns] == ["source_id", "started_at"]
    # Its name, that two rows can be alike in it, that a statement made it,
    # and that it is over all rows.
    assert [(name, unique, origin, partial) for _, name, unique, origin, partial in listed] == [
        (INDEX, 0, "c", 0)
    ]


def test_every_question_about_the_runs_of_a_source_is_answered_by_the_index(
    newest: Engine,
) -> None:
    some_runs(newest)

    about_the_runs = [
        (statement, given)
        for statement, given in statements_of_standing_of(newest, 2)
        if "FROM collection_run" in statement
    ]

    assert len(about_the_runs) == 4
    for statement, given in about_the_runs:
        # One step: the runs of the source are found by the index, and
        # nothing is sorted afterwards.
        assert plan_of(newest, statement, given) == [BY_THE_INDEX]


def test_without_the_index_the_whole_table_is_read_and_sorted(newest: Engine) -> None:
    # What the index is for: the same statements, in the same store without it.
    some_runs(newest)
    statements = [
        (statement, given)
        for statement, given in statements_of_standing_of(newest, 2)
        if "FROM collection_run" in statement
    ]
    with newest.begin() as connection:
        connection.exec_driver_sql(f"DROP INDEX {INDEX}")

    for statement, given in statements:
        assert plan_of(newest, statement, given) == [
            "SCAN collection_run",
            "USE TEMP B-TREE FOR ORDER BY",
        ]


def test_the_index_changes_no_answer(newest: Engine) -> None:
    some_runs(newest)
    with unit_of_work(newest) as work:
        with_it = [standing_of(work, source) for source in (1, 2, 3)]
    with newest.begin() as connection:
        connection.exec_driver_sql(f"DROP INDEX {INDEX}")

    with unit_of_work(newest) as work:
        without_it = [standing_of(work, source) for source in (1, 2, 3)]
```
