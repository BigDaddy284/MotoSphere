## Objective

The code knows the three levels of confidence and the four verification
statuses of a collected record, each with the text that is stored.

## Why

Every record MotoSphere collects is to say where it came from and how far
it can be trusted (DESIGN §8, CLAUDE.md §11). Two of the things it says
are one of a list: its confidence and its verification status. The texts
of a list are stored in rows and named in the table's check, so once a
table has them a text is changed only by a migration. What the texts are
and what each one means decides how every collector will mark what it
collects, so they are settled with care, in a task of their own, before
the columns that carry them (DAT-008). It was done the same way for the
lists of the sources (DAT-039). PLAN-025 in `PROGRESS.md` has the cut.

## Design in short

- **One new module, `motosphere.db.models.provenance`**, with two lists,
  each a `StrEnum` as a column of a list takes one (DAT-036):
  `Confidence` and `VerificationStatus`.
- **The texts are words in small letters, with one space between two**,
  as the texts of every list of the store are.
- **Both lists go from what can be trusted most to what can be trusted
  least.**
- No table, no model, no migration, no change to any existing code file,
  no new package from outside.

## What the task left open, and what the trial settled

- **Two questions, two lists.** Confidence is about the reading: how
  sure it is that the record says what its source says. Verification
  status is about the publishing: what standing the source's word has.
  Neither answers the other. A result read without doubt from a fan's
  website is of high confidence and independent; a date worked out from
  an official notice is official and of low confidence.
- **The levels of confidence.** The design asks for a "confidence level"
  and names none (DESIGN §8). Three, each said in one sentence that a
  collector can be held to:

  | `Confidence` | Text | When |
  |---|---|---|
  | `HIGH` | `high` | The source gives the value in a place made for it, such as a field of a feed or a cell under its heading, and it was taken as it stands |
  | `MEDIUM` | `medium` | The value was read out of a page or a document made for people, by a rule written for that source. It is wrong where the page is not as the rule expects it |
  | `LOW` | `low` | The value was worked out from what stands around it, or the source is unclear about it or says two things |

  No number: a number between 0 and 1 would look more exact than
  anything behind it, because nothing measures how sure a reading is.
- **The verification statuses.** The four kinds of record the design
  tells apart (DESIGN §6: "Clearly distinguish between"), in its order.
  They hold CLAUDE.md §11 as well: official information is told from
  independently published information.

  | `VerificationStatus` | Text | In the design | What it is |
  |---|---|---|---|
  | `OFFICIAL` | `official` | Officially published records | Published by whoever is answerable for what the record says: the body that ran the race or the championship, or the track about itself |
  | `INDEPENDENT` | `independent` | Independently published records | Published by somebody else, such as a news publication, a results database or a community website |
  | `RECONSTRUCTED` | `reconstructed` | Reconstructed historical records | Put together afterwards from what is left, where nothing published at the time is at hand. It is never shown as an official record |
  | `UNVERIFIED` | `unverified` | Unverified historical references | A mention that has not been checked against anything |

- **The status is said of the record, not of its source.** A governing
  body is official about its own championship and independent about a
  race somebody else ran. So the kind of a source (`SourceCategory`)
  does not give the status of what is collected from it, and no code
  here works one out from the other.
- **Where the lists stand.** In a module of the package of the models,
  `motosphere.db.models.provenance`, in which the columns every
  collected record has will stand too (DAT-008): a list and the column
  that is of it change together. The package's `__init__.py` names the
  models, and a list is none, so it does not change.
- **What a test of a list can hold.** The texts are written out in the
  test a second time, so a text changed by mistake fails there. Further:
  the two numbers, three and four; no text with two names; the form of
  every text; and that `OneOf` takes each list and gives a check that
  names its texts in their order, as SQLite is given it. That SQLite
  refuses a text that is not on a list is proven for every list by the
  tests of DAT-036, and for these two again with the columns (DAT-008).
- **A value has the name its text spells.** The tests above pass when
  two values of a list have each other's names (`LOW = "high"` first and
  `HIGH = "low"` last): the texts are all there, in their order. Code
  that says `Confidence.HIGH` would then store `low`. So one more test
  holds every value to the name its text spells, in capitals. The trial
  planted that defect, and only this test fails on it.
- **No text is on both lists**, so that a text read from a row says by
  itself which of the two questions it answers. A test holds it. While
  the texts are as they are written out in the test it cannot fail by
  itself; it is there for the day somebody changes a list and the test's
  texts together.
- **What is left to the columns (DAT-008).** Whether a record may be
  without one of the two; and how a record says the way it was got, the
  design's "extraction method", for which the store has the list of the
  ways of collecting already (`CollectionMethod`).

### 1. `backend/src/motosphere/db/models/provenance.py` – new, the whole file

```python
"""How far a collected record can be trusted: the two lists that say it.

Everything MotoSphere collects keeps with it where it came from and how
far it can be trusted (DESIGN.md 8). Two different questions are asked of
a record, and each has a list of its own:

- how sure it is that the record says what its source says. That is its
  confidence, :class:`Confidence`, and it is about the reading: a value
  taken from a field made for it is surer than one worked out from a
  sentence;
- what standing the source's word has. That is its verification status,
  :class:`VerificationStatus`, and it is about the publishing: what the
  organiser of a race published about it is official, whoever read it
  and however surely.

Neither answers the other. A result read without doubt from a fan's
website is of high confidence and independent; a date worked out from an
official notice is official and of low confidence.

Each list is said once, here. Its values are the texts that are stored,
and a column of the list (:class:`motosphere.db.lists.OneOf`) refuses
every other text. The texts are in small letters, with one space between
two words. Both lists go from what can be trusted most to what can be
trusted least. No table has a column of them yet: they come with the
columns every collected record has (DAT-008). Once a table has one, a
text of that list is changed or taken away only by a migration, because
the table's check names the texts and rows hold them.
"""

from enum import StrEnum

__all__ = ["Confidence", "VerificationStatus"]


class Confidence(StrEnum):
    """How sure it is that a record says what its source says (DESIGN.md 8)."""

    # The source gives the value in a place made for it, such as a field of
    # a feed or a cell under its heading, and it was taken as it stands.
    HIGH = "high"
    # The value was read out of a page or a document made for people, by a
    # rule written for that source. It is wrong where the page is not as
    # the rule expects it.
    MEDIUM = "medium"
    # The value was worked out from what stands around it, or the source is
    # unclear about it or says two things.
    LOW = "low"


class VerificationStatus(StrEnum):
    """What standing the word of a record's source has (DESIGN.md 6, in its order)."""

    # Published by whoever is answerable for what the record says: the body
    # that ran the race or the championship, or the track about itself.
    OFFICIAL = "official"
    # Published by somebody else, such as a news publication, a results
    # database or a community website.
    INDEPENDENT = "independent"
    # Put together afterwards from what is left, where nothing published at
    # the time is at hand. It is never shown as an official record.
    RECONSTRUCTED = "reconstructed"
    # A mention that has not been checked against anything.
    UNVERIFIED = "unverified"
```

### 2. `backend/tests/unit/test_db_models_provenance.py` – new, the whole file, 22 tests

```python
"""Tests of the lists that say how far a collected record can be trusted.

They need no store. One list says how sure it is that a record says what
its source says, the other what standing the source's word has.
"""

import re
from enum import StrEnum

import pytest
from sqlalchemy.dialects import sqlite

from motosphere.db.lists import OneOf
from motosphere.db.models.provenance import Confidence, VerificationStatus

# The texts that are stored, written out: a text changed by mistake fails here.
LEVELS = ["high", "medium", "low"]
STATUSES = ["official", "independent", "reconstructed", "unverified"]
EACH = pytest.mark.parametrize(
    ("the_list", "texts"),
    [(Confidence, LEVELS), (VerificationStatus, STATUSES)],
    ids=["how sure", "what standing"],
)
EVERY_VALUE = pytest.mark.parametrize(
    "value", [*Confidence, *VerificationStatus], ids=lambda value: value
)


def test_there_are_the_three_levels_of_confidence_and_the_four_statuses() -> None:
    assert (len(LEVELS), len(STATUSES)) == (3, 4)
    assert (len(Confidence), len(VerificationStatus)) == (3, 4)


@EACH
def test_a_list_has_exactly_its_texts_in_their_order(
    the_list: type[StrEnum], texts: list[str]
) -> None:
    assert [value.value for value in the_list] == texts


@EACH
def test_no_text_of_a_list_has_two_names(the_list: type[StrEnum], texts: list[str]) -> None:
    assert len(the_list.__members__) == len(texts)
    assert len(set(texts)) == len(texts)


@EVERY_VALUE
def test_a_text_is_words_in_small_letters_with_one_space_between_two(value: StrEnum) -> None:
    assert re.fullmatch(r"[a-z]+( [a-z]+)*", value.value)


@EVERY_VALUE
def test_a_value_has_the_name_its_text_spells(value: StrEnum) -> None:
    # Where the code says Confidence.HIGH, the store holds "high" and not
    # another text of the list.
    assert value.name == value.value.upper().replace(" ", "_")


def test_no_text_is_on_both_lists() -> None:
    # A text read from a row says by itself which of the two it speaks of.
    levels = {value.value for value in Confidence}
    statuses = {value.value for value in VerificationStatus}

    assert levels & statuses == set()


@EACH
def test_a_column_can_be_of_the_list_and_its_check_names_the_texts(
    the_list: type[StrEnum], texts: list[str]
) -> None:
    check = OneOf(the_list).check_for("trusted")
    written = check.sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )

    assert check.name == "trusted_one_of"
    assert str(written) == "trusted IN (" + ", ".join(f"'{text}'" for text in texts) + ")"
```
