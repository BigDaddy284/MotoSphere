## Objective

A model can say that a column holds a web address, and the store refuses
text that is not one.

## Why

The first real table is next (the information sources, DAT-006), and a
source has a website. Every collected record will say at which address it
was found (DAT-008), and a page makes a link of such an address. Text
that is not a web address must not get that far: a name without a scheme
is a link that leads nowhere, and a `javascript:` address is a link a
page must never show (CLAUDE.md §14).

Today such a column could only be plain text. This task gives the store a
column type for it, the fourth that brings its check (DAT-034) and the
last of the four small tasks before the first table (PLAN-021, in
`PROGRESS.md`).

## Design in short

- **One new module, `motosphere.db.web`**, with the column type
  `WebAddressText`, the name a model says it by, `WebAddress`, and the
  function `web_address(name)` that gives the check. It is built like
  `motosphere.db.texts`.
- **A model says the column's Python type**: `website: Mapped[WebAddress]`,
  and `Mapped[WebAddress | None]` for a column that may be without a
  value. To Python and to the type check a `WebAddress` is a `str`.
- **`Base` gets one entry** in the list by which a Python type becomes a
  column type, as for text that must not be empty. Nothing else in
  `base.py` changes but its description.
- **In the table the column is TEXT with a check**, named
  `ck_<table>_<column>_web_address`, by which SQLite refuses text that
  - does not begin with `https://` or `http://`, in small or in large
    letters;
  - does not go on with the name of a site: with at least one character,
    which is not `/`, `?` or `#`;
  - has white space anywhere, by the store's own list (`WHITE_SPACE` in
    `motosphere.db.texts`);
  - has a character with the number 0.
- **An address is stored as it was given.** The store does not tidy it
  and does not ask the network whether it leads anywhere.
- No new package, no model, no table, no migration.

## What the task left open, and what the trial settled

- **Exactly what the check refuses.** The four rules above. Each is one a
  table can keep with what SQLite has, and each refuses text that could
  not be a web address whatever comes after it.
- **Small and large letters.** An address may be written `HTTP://`: the
  standard for addresses says the scheme is the same in either. The check
  takes both, so that an address that is one is never refused, and the
  store keeps it as it was given.
- **`GLOB`, not `LIKE`.** `GLOB` tells small letters from large ones on
  every machine. What `LIKE` does about them can be changed for a
  connection (`PRAGMA case_sensitive_like`), and a check must refuse the
  same text wherever the file is opened. So the two cases of each letter
  are written out: `[Hh][Tt][Tt][Pp][Ss]://[^/?#]*`.
- **"And go on after it."** With one character that is not `/`, `?` or
  `#`: those three end the name of a site, so an address that has one of
  them straight after the scheme has no name. `https://`, `https:///tracks`
  and `https://?country=NL` are refused.
- **White space anywhere, not only around it.** A space before the scheme
  is refused by the first rule already. A line end after an address, a
  space in it and two addresses in one text are what a collector gets
  wrong most easily, and none of them is an address. The list of white
  space is the one the store already has, so "white space" means one
  thing in the store. Where an address has a space, whoever collects it
  writes the space as `%20` before it is stored.
- **The character with the number 0.** The trial found that SQLite's
  `GLOB` reads text up to such a character and no further:
  `https://example.org/` followed by that character and a space passed
  the rule against white space. The check refuses the character itself,
  with `instr(<column>, char(0)) = 0`, which does see it.
- **How far a check in a table goes.** It holds the beginning of an
  address to the rules, and not the rest. `https://.` passes, and so does
  an address of a site there is not. Whether a site answers is found out
  by whoever collects from it. `DATABASE.md` says where the check ends,
  and four tests hold it there.
- **Nothing is checked in Python.** The type is plain text with a check,
  as text that must not be empty is: SQLite refuses the row and names the
  check. There is one rule, in one place.
- **Two spellings of one address are two addresses to the store.** That
  follows from storing an address as it was given. One test says so, and
  `DATABASE.md` says that code which must find an address again brings it
  to one spelling first. Which spelling is decided with the first table
  that needs it.
- **The entry in the list of `Base` is what makes the type work.**
  Without it a model's `WebAddress` is plain text without a check, and
  nothing is refused. That is prove-it step 1.

### 1. `backend/src/motosphere/db/web.py` – new, the whole file

```python
"""A web address.

A source has a website, and every record says at which address it was
found. A model says of such a column that it holds a web address:

    website: Mapped[WebAddress]

The column is then TEXT with a check in its table, and SQLite itself
refuses text that is not a web address, whoever writes the row. To the
check, a web address is text that

- begins with ``https://`` or ``http://``, in small or in large letters;
- goes on after that with the name of a site: with at least one character,
  which is not ``/``, ``?`` or ``#``, the three that end such a name;
- has no white space anywhere, by the store's own list of white space
  (:data:`motosphere.db.texts.WHITE_SPACE`);
- has no character with the number 0, after which SQLite would not look.

That is as far as a check in a table goes. It does not know whether there
is such a site, and it does not hold the rest of the address to the rules
an address has. An address is stored as it was given: nothing is put in
small letters and nothing is taken off.

A column that may be without a value says ``Mapped[WebAddress | None]``: it
holds no value or a web address, and never empty text.
"""

from typing import Annotated

from sqlalchemy import CheckConstraint, ColumnClause, Text, and_, column, func, literal, not_, or_

from motosphere.db.checks import WithItsCheck
from motosphere.db.texts import WHITE_SPACE

__all__ = ["WebAddress", "WebAddressText", "web_address"]

# How a web address begins, as SQLite's GLOB is told it: the letters of
# "https" or "http", each small or large, then "://", then one character
# that is none of the three in the brackets, then anything. GLOB tells
# small letters from large ones on every machine, whatever a connection
# has been told about LIKE.
_BEGINS_WITH_HTTPS = "[Hh][Tt][Tt][Pp][Ss]://[^/?#]*"
_BEGINS_WITH_HTTP = "[Hh][Tt][Tt][Pp]://[^/?#]*"


class WebAddressText(WithItsCheck, Text):
    """The column type of a web address. In the table it is TEXT."""

    refuses = "text that is not a web address"
    given_by = "web_address"

    def check_for(self, name: str) -> CheckConstraint:
        """Give the check of :func:`web_address` for the column called ``name``."""
        return web_address(name)


# What a model says a column is: ``Mapped[WebAddress]``. To Python and to
# the type check it is a ``str``.
WebAddress = Annotated[str, WebAddressText]


def web_address(name: str) -> CheckConstraint:
    """Give the check that refuses text that is not a web address in the column ``name``.

    The check is called ``<name>_web_address``, which the naming rule makes
    ``ck_<table>_<name>_web_address`` once the check is given to a table. It
    belongs to no table until then. A column without a value passes it, as
    it passes every check.
    """
    text: ColumnClause[str] = column(name)
    begins_as_one = or_(
        text.bool_op("GLOB")(_BEGINS_WITH_HTTPS),
        text.bool_op("GLOB")(_BEGINS_WITH_HTTP),
    )
    # The white space is written by its numbers, as in the check for empty
    # text, so that the check is the same text on every machine.
    has_white_space = text.bool_op("GLOB")(literal("*[") + func.char(*WHITE_SPACE) + literal("]*"))
    # GLOB reads text up to a character with the number 0 and no further,
    # so white space after one would go unseen.
    has_no_nought = func.instr(text, func.char(0)) == 0
    return CheckConstraint(
        and_(begins_as_one, not_(has_white_space), has_no_nought),
        name=f"{name}_web_address",
    )
```

### 2. `backend/tests/unit/test_db_web.py` – new, the whole file, 8 tests

```python
"""Tests of a web address, without a store.

``tests/integration/test_web.py`` asks a real SQLite file what it refuses.
"""

from sqlalchemy import Column, Integer, MetaData, Table
from sqlalchemy.dialects import sqlite
from sqlalchemy.schema import conv

from motosphere.db import times
from motosphere.db.base import NAMING, Base, broken_rules
from motosphere.db.checks import WithItsCheck
from motosphere.db.texts import WHITE_SPACE
from motosphere.db.times import UtcDateTime
from motosphere.db.web import WebAddress, WebAddressText, web_address

THE_CHECK = (
    "(({0} GLOB '[Hh][Tt][Tt][Pp][Ss]://[^/?#]*') OR ({0} GLOB '[Hh][Tt][Tt][Pp]://[^/?#]*')) "
    "AND NOT ({0} GLOB '*[' || char(9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, "
    "8192, 8193, 8194, 8195, 8196, 8197, 8198, 8199, 8200, 8201, 8202, 8232, 8233, 8239, 8287, "
    "12288) || ']*') AND instr({0}, char(0)) = 0"
)


def said(name: str) -> str:
    """The check of a column of this name, as SQLite is given it."""
    written = web_address(name).sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )
    return str(written)


def a_table(schema: MetaData) -> Table:
    """A table made by hand that keeps every rule but one: two of its columns have no check."""
    return Table(
        "source",
        schema,
        Column("id", Integer, primary_key=True),
        Column("website", WebAddressText, nullable=False),
        Column("feed", WebAddressText),
        Column("created_at", UtcDateTime, nullable=False, default=times.now),
        Column("updated_at", UtcDateTime, nullable=False, default=times.now, onupdate=times.now),
        sqlite_strict=True,
        sqlite_autoincrement=True,
    )


def test_the_check_says_how_an_address_begins_and_what_it_must_not_have() -> None:
    assert said("website") == THE_CHECK.format("website")


def test_the_check_of_a_column_named_with_a_word_of_sql_names_it_in_quotes() -> None:
    assert said("group") == THE_CHECK.format('"group"')


def test_the_white_space_of_the_check_is_the_stores_own_list() -> None:
    the_list = "char(" + ", ".join(str(number) for number in WHITE_SPACE) + ")"

    assert f"GLOB '*[' || {the_list} || ']*'" in said("website")


def test_the_check_is_named_after_its_column_and_by_the_naming_rule() -> None:
    check = web_address("website")

    assert check.name == "website_web_address"

    owner = Table(
        "owner",
        MetaData(naming_convention=NAMING),
        Column("id", Integer),
        Column("website", WebAddressText),
    )

    assert check not in owner.constraints

    owner.append_constraint(check)

    assert check.name == "ck_owner_website_web_address"
    assert isinstance(check.name, conv)


def test_the_type_brings_the_check_that_web_address_gives() -> None:
    its_type = WebAddressText()
    brought = its_type.check_for("website")

    assert isinstance(its_type, WithItsCheck)
    assert brought.name == "website_web_address"
    assert str(
        brought.sqltext.compile(dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True})
    ) == said("website")
    assert its_type.refuses == "text that is not a web address"
    assert its_type.given_by == web_address.__name__


def test_in_the_table_the_type_is_text() -> None:
    assert WebAddressText().compile(dialect=sqlite.dialect()) == "TEXT"


def test_a_model_says_a_web_address_by_the_columns_python_type() -> None:
    assert Base.type_annotation_map[WebAddress] is WebAddressText


def test_such_a_column_is_named_until_its_table_has_the_check() -> None:
    sentence = (
        "The table source does not refuse text that is not a web address in its column {}: it "
        "must have the check that web_address gives for the column, named by the naming rule."
    )
    schema = MetaData(naming_convention=NAMING)
    source = a_table(schema)

    assert broken_rules(schema) == [sentence.format("website"), sentence.format("feed")]

    source.append_constraint(web_address("website"))

    assert broken_rules(schema) == [sentence.format("feed")]

    source.append_constraint(web_address("feed"))

    assert broken_rules(schema) == []
```
