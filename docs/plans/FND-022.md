# FND-022 – The application served from the site's path

**Phase:** 1 – Foundation
**Depends on:** FND-027, FND-029, FND-033 (all merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §8, `docs/WORKFLOW.md`, `TESTING.md`,
`ARCHITECTURE.md` (hosting), `frontend/playwright.config.ts`,
`frontend/e2e/fixtures.ts`

## Objective

The application works when it is served from `/MotoSphere/`, the path it
will have on GitHub Pages, and the tests prove it there. Today everything
is built and tested at the root of a server (`/`), where the published site
will never live.

## Design in short

- GitHub Pages serves a project's site under the name of its repository:
  `https://<owner>.github.io/MotoSphere/`. Every address the application
  uses for its own files must start with `/MotoSphere/`.
- The path is written once, in a new file `frontend/site.ts`
  (`SITE_PATH = '/MotoSphere/'`). The build (`vite.config.ts`) and the
  browser tests (`playwright.config.ts`) both read it there.
- Development, the unit tests, the browser tests and the published site
  all use this one path, so none of them can work by accident at another.
  The development address becomes `http://localhost:5173/MotoSphere/`.
- The browser tests reach the site through a base address that ends with
  the path, and write every address relative to it: `page.goto('./')`,
  `request.get('favicon.svg')`. An address that starts with `/` would leave
  the site, so none is left.
- New browser tests (`e2e/site.spec.ts`) check that the application is
  served under the path, that everything the page loads comes from under
  it, and that its files are not at the root of the server.
- The application code does not change: it already takes its base path from
  the build (`import.meta.env.BASE_URL`). The unit test that covers this is
  made stricter: it gives the build another path, so that neither `/` nor
  `/MotoSphere/` written into the code could pass.

Deployment itself, the workflow that publishes the site, is the next task
(FND-034) and is not part of this one.

## Implementation detail

### 1. `frontend/site.ts` – the whole file

```ts
/**
 * The path the application is served from. On GitHub Pages the site of a
 * project lives under the name of its repository, so every address the
 * application uses for its own files starts with this path.
 *
 * Development, the unit tests, the browser tests and the published site all
 * use this one path, so that none of them can work by accident at another.
 * If the site moves, to another repository name or to a domain of its own,
 * this is the one place to change.
 */
export const SITE_PATH = '/MotoSphere/'
```

### 2. `frontend/e2e/site.spec.ts` – the whole file, 7 tests

```ts
import { SITE_PATH } from '../site.ts'
import { manifestUrl } from '../src/data/manifest.ts'
import { expect, test } from './fixtures'

/**
 * The published site does not live at the root of its server: GitHub Pages
 * serves it under the name of the repository. The site under test is served
 * the same way, and these tests show that the application needs nothing from
 * outside its own path.
 */

test.describe("the site's path", () => {
  test('is the name of the repository, between slashes', () => {
    expect(SITE_PATH).toBe('/MotoSphere/')
  })

  test('is where the application is served', async ({ page, baseURL }) => {
    expect(baseURL?.endsWith(SITE_PATH)).toBe(true)

    const response = await page.goto('./')

    expect(response?.status()).toBe(200)
    expect(new URL(page.url()).pathname).toBe(SITE_PATH)
    await expect(page).toHaveTitle('MotoSphere')
    await expect(page.getByRole('banner')).toBeVisible()
  })

  test('holds everything the page loads', async ({ page }) => {
    const loaded: string[] = []
    page.on('request', (request) => {
      loaded.push(new URL(request.url()).pathname)
    })

    await page.goto('./')
    await expect(page.getByRole('banner').getByRole('status')).toHaveText(/^Data updated /)

    expect(loaded.filter((pathname) => !pathname.startsWith(SITE_PATH))).toEqual([])
    expect(loaded).toContain(SITE_PATH)
    expect(loaded).toContain(manifestUrl(SITE_PATH))
    expect(loaded.some((pathname) => pathname.endsWith('.js'))).toBe(true)
    expect(loaded.some((pathname) => pathname.endsWith('.css'))).toBe(true)
  })

  for (const file of ['favicon.svg', 'favicon.ico', 'apple-touch-icon.png', 'data/manifest.json']) {
    test(`${file} is under the path and not at the root of the server`, async ({ request }) => {
      const underThePath = await request.get(file)
      const atTheRoot = await request.get(`/${file}`, { maxRedirects: 0 })

      expect(underThePath.status()).toBe(200)
      expect(new URL(underThePath.url()).pathname).toBe(`${SITE_PATH}${file}`)
      expect(atTheRoot.status()).toBe(404)
    })
  }
})
```
