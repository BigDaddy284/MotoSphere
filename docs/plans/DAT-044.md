## Objective

A model can say that a column is a calendar day, and the store refuses
anything else in it.

## Why

Every collected record is to say when its source published it, where
that is known (DESIGN §8, DAT-008). Most sources say a day and no time:
"12 March 2024" under a report, a date on a results sheet. The store
has one type for a time, and a time always has its time of day and its
offset. A day kept in it would have to be given a midnight somewhere,
which the source never said (CLAUDE.md §11: never fabricate dates).
`DATABASE.md` has said since DAT-028 that a day without a time of day
needs a type of its own, to come with the first table that has such a
column. The columns of DAT-008 are the first, so the type comes now, as
a task of its own before them (PLAN-026 in `PROGRESS.md`). The days
races are held on and riders were born on will be of it too.

## Design in short

- **One new module, `motosphere.db.days`**, with the column type
  `CalendarDay`, the two functions that say and read the text,
  `to_text` and `from_text`, and the function `calendar_day(name)` that
  gives the check. It is built like `motosphere.db.times` and
  `motosphere.db.yes_no` together.
- **In the table a day is text in one form**, `2026-11-24`: four digits,
  two and two. Every text has the same length, and the order of the
  texts is the order of the days.
- **A model says the column's Python type**: `held_on: Mapped[date]`,
  and `Mapped[date | None]` for a column that may be without a value.
- **`Base` gets one entry** in the list by which a Python type becomes a
  column type, `date: CalendarDay`. Nothing else in `base.py` changes
  but its description and two imports.
- **The table has a check**, named `ck_<table>_<column>_calendar_day`,
  by which SQLite itself refuses text that is not a day of the calendar
  in that form.
- **Only a `date` is stored, and a time is refused**, although Python
  counts a `datetime` as a `date`.
- No new package, no model, no table, no migration.

## What the task left open, and what the trial settled

- **The form.** The one SQLite's own date functions write and read, and
  Python's `date.isoformat()`: `YYYY-MM-DD`. So a stored day can be read
  by both without this code, and compared and sorted as text.
- **The check**, as the file says it:

  ```
  CHECK ((held_on GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]') AND date(held_on) IS held_on AND held_on >= '0001-01-01')
  ```

  Three things are asked of the text.
  1. *It has the form.*
  2. *It is a day SQLite's calendar has*: SQLite reads it as a day and
     says the same text back. For `2026-02-30` it says `2026-03-02`; for
     what it cannot read it says nothing; neither is the text that was
     given. The comparison is `IS`, not `=`: with `=`, "nothing" would
     compare as not known, and a check lets what is not known pass. The
     trial planted `=` and text of the right form that SQLite cannot
     read (`2026-13-01`) was stored.
  3. *It is not before the first day there is*, `0001-01-01`. SQLite
     knows a year 0 and Python does not: `0000-01-01` would be stored
     and could never be read.
- **Why the form is asked, and asked first.** The second question alone
  refuses nearly everything the first does: whatever SQLite says back
  has the form. The exception the trial found is the word `now`. SQLite
  will not ask its calendar about it inside a check at all, and fails
  with words of its own (`non-deterministic use of date() in a CHECK
  constraint`), which is not a refusal that names the check. With the
  form asked first SQLite never gets to the calendar for such text, and
  `now` is refused like any other. A test stores `now` and holds SQLite
  to the name of the check, word for word, on every machine the gates
  run on; the trial planted the other order and that test fails.
- **What SQLite refuses**, each tried in the trial against the real
  file: the 30th of February, the 29th in a year that has none (also
  1900), the 31st of November, a 13th month, the day 0, the year 0, a
  day with a time, with a space before or after it, with one digit for
  month and day, without hyphens, day first, by week and weekday, with
  five digits for the year, with a character of the number 0 after it,
  with the digits of another script, the number astronomers give a day,
  the word `now` and empty text. A whole number and a number with a
  fraction, written with plain SQL, become text in a strict table and
  are refused by the check; bytes are refused because the table is
  strict.
- **A time is not a day.** Python counts a `datetime` as a `date`, so
  code that hands a time to a column of a day would be taken at its
  word by an ordinary check of the type. The time of day would be
  dropped in silence, and which day a moment falls on depends on the
  offset it is read in. So a time is refused with a sentence of its own,
  with an offset or without, also at midnight. `Base` is held to the
  same from the other side: a test proves that a model's `date` is a
  day and its `datetime` still a time, and a model with both proves it
  against the file.
- **What is read.** Only text in the one form is read as a day. Python
  itself reads more as a day (`20261124`, `2026-W48-2`), so what was
  read is said again and must be the text that was there, as
  `motosphere.db.times` does it. The table never holds another form, so
  this only meets what was written past the check or made by a function
  of SQLite.
- **The years.** From 1 to 9999, which is what a Python `date` can say.
  Both ends are stored and read back in the tests.
- **A day of which only the year or the month is known** is not a day,
  and this type does not hold it. Nothing is made up to fill it out.
  The table that first has such a thing settles how it is kept.
  `DATABASE.md` says so.
- **Whether SQLite's date functions belong in the list of what the
  store relies on** (`motosphere.db.sqlite`). They are not added: that
  list is of what a build of SQLite may be without, and the tests of
  this type ask the real SQLite of every machine the gates run on
  whether it refuses what is not a day.
- **SQLAlchemy's own type for a day cannot be used**: SQLite refuses to
  make a strict table with it (`unknown datatype … "DATE"`). A test
  holds that, as there is one for a list (DAT-036).

### 1. `backend/src/motosphere/db/days.py` – new, the whole file

```python
"""Calendar days in the data store.

Much of what the store holds is said by the day and not by the moment: the
day a race is held, the day a rider was born, the day a page says it was
published. A day has no time of day and no offset, and none is made up for
it: a day stored as the moment its midnight struck somewhere would say
more than its source did.

A strict table has no type for a day, so the store keeps a day as text, in
one form:

    2026-11-24

It always has the four digits of its year, the two of its month and the
two of its day. So every such text has the same length, the order of the
texts is the order of the days, and the text can be read without this
code: by a person, and by SQLite's own date functions.

A model says of such a column that it is a ``date``:

    held_on: Mapped[date]

The column is then TEXT with a check in its table, and SQLite itself
refuses text that is not a day in that form, whoever writes the row: also
a day that no calendar has, such as the 30th of February. To Python the
column is a ``date``, and only a ``date`` is stored. A time is refused,
although Python counts a ``datetime`` as a ``date``: its time of day would
be dropped without a word, and which day a moment falls on depends on
where one stands.

A column that may be without a value says ``Mapped[date | None]``: it holds
no value or a day. No value means that the day is not known.
"""

from contextlib import suppress
from datetime import date, datetime
from typing import override

from sqlalchemy import CheckConstraint, ColumnClause, Dialect, Text, and_, column, func
from sqlalchemy.types import TypeDecorator

from motosphere.db.checks import WithItsCheck

__all__ = ["CalendarDay", "calendar_day", "from_text", "to_text"]

# The form of a day, as SQLite's GLOB is told it: four digits, two and two,
# with a hyphen between them.
_FORM = "[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]"
# The first day there is. SQLite knows a year 0, and Python does not.
_FIRST = "0001-01-01"


def to_text(day: date) -> str:
    """Say a day in the store's form. What is not a day is refused, a time among it."""
    if not isinstance(day, date):
        raise TypeError(
            f"Only a day (a date) is stored as a day, not {type(day).__name__}: {day!r}."
        )
    if isinstance(day, datetime):
        raise TypeError(
            f"A time is not stored as a day: {day!r}. Say the day itself: which day a moment "
            "falls on depends on where one stands."
        )
    return day.isoformat()


def from_text(text: str) -> date:
    """Read a day that is in the store's form.

    Text in any other form is refused, also when it could be read as a day:
    the store holds one form only.
    """
    with suppress(TypeError, ValueError):
        day = date.fromisoformat(text)
        if to_text(day) == text:
            return day
    raise ValueError(f"The store holds a day that is not in the store's form: {text!r}.")


class CalendarDay(WithItsCheck, TypeDecorator[date]):
    """The type of a column that holds a calendar day. In the table it is TEXT."""

    impl = Text
    cache_ok = True
    refuses = "text that is not a calendar day"
    given_by = "calendar_day"

    def check_for(self, name: str) -> CheckConstraint:
        """Give the check of :func:`calendar_day` for the column called ``name``."""
        return calendar_day(name)

    @override
    def process_bind_param(self, value: date | None, dialect: Dialect) -> str | None:
        """Turn a day into the text that is stored."""
        return None if value is None else to_text(value)

    @override
    def process_result_value(self, value: str | None, dialect: Dialect) -> date | None:
        """Turn the text that is stored into a day."""
        return None if value is None else from_text(value)


def calendar_day(name: str) -> CheckConstraint:
    """Give the check that refuses text that is not a calendar day in the column ``name``.

    The check asks three things of the text. It has the form of a day. It
    is a day SQLite's own calendar has: SQLite reads it as a day and says
    the same text back, which it does not for the 30th of February. And it
    is not before the first day there is, the first of January of the year
    1.

    The check is called ``<name>_calendar_day``, which the naming rule makes
    ``ck_<table>_<name>_calendar_day`` once the check is given to a table.
    It belongs to no table until then. A column without a value passes it,
    as it passes every check.
    """
    day: ColumnClause[str] = column(name)
    has_the_form = day.bool_op("GLOB")(_FORM)
    is_on_the_calendar = func.date(day).is_(day)
    return CheckConstraint(
        and_(has_the_form, is_on_the_calendar, day >= _FIRST),
        name=f"{name}_calendar_day",
    )
```

```python
"""Tests of calendar days in the store, without a store.

``tests/integration/test_days.py`` asks a real SQLite file what it refuses.
"""

from datetime import UTC, date, datetime
from typing import Any

import pytest
from sqlalchemy import Column, Integer, MetaData, Table
from sqlalchemy.dialects import sqlite
from sqlalchemy.schema import conv

from motosphere.db import times
from motosphere.db.base import NAMING, Base, broken_rules
from motosphere.db.checks import WithItsCheck
from motosphere.db.days import CalendarDay, calendar_day, from_text, to_text
from motosphere.db.times import UtcDateTime

# A day and its text, from the first day there is to the last.
DAYS = [
    (date(1, 1, 1), "0001-01-01"),
    (date(987, 6, 5), "0987-06-05"),
    (date(1957, 8, 4), "1957-08-04"),
    (date(2024, 2, 29), "2024-02-29"),
    (date(2026, 1, 5), "2026-01-05"),
    (date(2026, 11, 24), "2026-11-24"),
    (date(9999, 12, 31), "9999-12-31"),
]
EACH_DAY = pytest.mark.parametrize(("day", "text"), DAYS, ids=[text for _, text in DAYS])
# The moment a day begins in UTC: the time that looks most like a day.
MIDNIGHT = datetime(2026, 11, 24, tzinfo=UTC)


def said(name: str) -> str:
    """The check of a column of this name, as SQLite is given it."""
    written = calendar_day(name).sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )
    return str(written)


@EACH_DAY
def test_a_day_is_said_as_its_year_its_month_and_its_day(day: date, text: str) -> None:
    assert to_text(day) == text


@pytest.mark.parametrize(
    ("value", "sentence"),
    [
        ("2026-11-24", "Only a day (a date) is stored as a day, not str: '2026-11-24'."),
        (20261124, "Only a day (a date) is stored as a day, not int: 20261124."),
        (None, "Only a day (a date) is stored as a day, not NoneType: None."),
    ],
    ids=["text", "a number", "no value"],
)
def test_what_is_not_a_day_is_refused(value: Any, sentence: str) -> None:
    with pytest.raises(TypeError, match="Only a day") as refused:
        to_text(value)

    assert str(refused.value) == sentence


@pytest.mark.parametrize(
    ("moment", "written"),
    [
        (
            datetime(2026, 11, 24, 8, 0, tzinfo=UTC),
            "datetime.datetime(2026, 11, 24, 8, 0, tzinfo=datetime.timezone.utc)",
        ),
        (MIDNIGHT, "datetime.datetime(2026, 11, 24, 0, 0, tzinfo=datetime.timezone.utc)"),
        (MIDNIGHT.replace(tzinfo=None), "datetime.datetime(2026, 11, 24, 0, 0)"),
    ],
    ids=["a time", "midnight in UTC", "midnight without an offset"],
)
def test_a_time_is_refused_although_python_counts_it_as_a_day(
    moment: datetime, written: str
) -> None:
    assert isinstance(moment, date)

    with pytest.raises(TypeError, match="A time is not stored as a day") as refused:
        to_text(moment)

    assert str(refused.value) == (
        f"A time is not stored as a day: {written}. Say the day itself: which day a moment "
        "falls on depends on where one stands."
    )


@EACH_DAY
def test_a_day_in_the_stores_form_is_read(day: date, text: str) -> None:
    read = from_text(text)

    assert read == day
    # A day and nothing more: not a time at its midnight.
    assert type(read) is date


@pytest.mark.parametrize(
    "text",
    [
        "20261124",
        "2026-W48-2",
        "2026-11-24T00:00:00",
        "2026-11-24 ",
        " 2026-11-24",
        "2026-11-24\n",
        "2026-1-5",
        "24/11/2026",
        "2026-02-30",
        "0000-01-01",
        "",
        "now",
        20261124,
        None,
        date(2026, 11, 24),
    ],
    ids=[
        "without hyphens",
        "by week and weekday",
        "with a time",
        "with a space after it",
        "with a space before it",
        "with a new line after it",
        "with one digit for month and day",
        "day first",
        "a day no calendar has",
        "the year 0",
        "empty text",
        "a word",
        "a number",
        "no value",
        "a day that is not text",
    ],
)
def test_what_is_not_in_the_stores_form_is_refused_also_when_it_could_be_read(text: Any) -> None:
    with pytest.raises(ValueError, match="not in the store's form") as refused:
        from_text(text)

    assert str(refused.value) == (
        f"The store holds a day that is not in the store's form: {text!r}."
    )


def test_every_text_has_the_same_length_and_their_order_is_the_order_of_the_days() -> None:
    texts = [to_text(day) for day, _ in DAYS]

    assert {len(text) for text in texts} == {10}
    assert sorted(texts, reverse=True) == [to_text(day) for day, _ in sorted(DAYS, reverse=True)]


def test_the_column_type_stores_the_text_and_reads_the_day() -> None:
    column_type = CalendarDay()
    dialect = sqlite.dialect()

    assert column_type.process_bind_param(date(2026, 11, 24), dialect) == "2026-11-24"
    assert column_type.process_result_value("2026-11-24", dialect) == date(2026, 11, 24)


def test_the_column_type_leaves_no_value_as_no_value() -> None:
    column_type = CalendarDay()
    dialect = sqlite.dialect()

    assert column_type.process_bind_param(None, dialect) is None
    assert column_type.process_result_value(None, dialect) is None


def test_in_the_table_the_type_is_text() -> None:
    assert str(CalendarDay().compile(dialect=sqlite.dialect())) == "TEXT"


def test_the_check_asks_for_the_form_for_a_day_of_the_calendar_and_for_the_year_1_or_later() -> (
    None
):
    assert said("held_on") == (
        "(held_on GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]') "
        "AND date(held_on) IS held_on AND held_on >= '0001-01-01'"
    )


def test_the_check_of_a_column_named_with_a_word_of_sql_names_it_in_quotes() -> None:
    assert said("group") == (
        "(\"group\" GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]') "
        'AND date("group") IS "group" AND "group" >= \'0001-01-01\''
    )


def test_the_check_is_named_after_its_column_and_by_the_naming_rule() -> None:
    check = calendar_day("held_on")

    assert check.name == "held_on_calendar_day"

    owner = Table(
        "owner",
        MetaData(naming_convention=NAMING),
        Column("id", Integer),
        Column("held_on", CalendarDay),
    )

    assert check not in owner.constraints

    owner.append_constraint(check)

    assert check.name == "ck_owner_held_on_calendar_day"
    assert isinstance(check.name, conv)


def test_the_type_brings_the_check_that_calendar_day_gives() -> None:
    its_type = CalendarDay()
    brought = its_type.check_for("held_on")

    assert isinstance(its_type, WithItsCheck)
    assert brought.name == "held_on_calendar_day"
    assert str(
        brought.sqltext.compile(dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True})
    ) == said("held_on")
    assert its_type.refuses == "text that is not a calendar day"
    assert its_type.given_by == calendar_day.__name__


def test_a_column_that_is_a_day_is_named_until_its_table_has_the_check() -> None:
    schema = MetaData(naming_convention=NAMING)
    owner = Table(
        "owner",
        schema,
        Column("id", Integer, primary_key=True),
        Column("held_on", CalendarDay, nullable=False),
        Column("created_at", UtcDateTime, nullable=False, default=times.now),
        Column("updated_at", UtcDateTime, nullable=False, default=times.now, onupdate=times.now),
        sqlite_strict=True,
        sqlite_autoincrement=True,
    )

    assert broken_rules(schema) == [
        "The table owner does not refuse text that is not a calendar day in its column held_on: "
        "it must have the check that calendar_day gives for the column, named by the naming rule."
    ]

    owner.append_constraint(calendar_day("held_on"))

    assert broken_rules(schema) == []


def test_to_the_base_a_date_is_a_day_and_a_datetime_is_still_a_time() -> None:
    # Python counts a datetime as a date. The base does not take one for the other.
    assert Base.type_annotation_map[date] is CalendarDay
    assert Base.type_annotation_map[datetime] is UtcDateTime
```

```python
"""Tests of calendar days in the store, with a table made in a real SQLite file.

The model here is made for the tests. It is a subclass of the real
``Base``, so it proves what a model gets when it says that a column is a
``date``, but it is kept in a schema of its own (``Proof.metadata``), so
the real schema never sees it.
"""

from datetime import UTC, date, datetime
from typing import Any

import pytest
from sqlalchemy import Date, Engine, MetaData, func, select
from sqlalchemy.exc import IntegrityError, OperationalError, StatementError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.days import CalendarDay
from motosphere.db.times import UtcDateTime
from motosphere.db.work import unit_of_work

A_TIME = "2026-11-19T08:00:00.000000+00:00"
A_DAY = date(2026, 11, 24)
THE_FIRST = date(1957, 8, 4)
REFUSED = "CHECK constraint failed: ck_proof_race_{}_calendar_day"
NOT_A_DAY = "Only a day \\(a date\\) is stored as a day"
A_TIME_IS_NO_DAY = "A time is not stored as a day"
# A row written with plain SQL. Its first three "?" are held_on, announced_on
# and first_held_on; the last two are its two times, which only the store's
# code sets.
PAST_THE_MODEL = (
    "INSERT INTO proof_race (held_on, announced_on, first_held_on, created_at, updated_at) "
    "VALUES (?, ?, ?, ?, ?)"
)
# The day 2026-11-24 with the digits of its year as they are written full width.
IN_ANOTHER_SCRIPT = "".join(chr(0xFF10 + digit) for digit in (2, 0, 2, 6)) + "-11-24"
# Text that is not a day in the store's form, each with what it is.
NOT_DAYS = {
    "the 30th of February": "2026-02-30",
    "the 29th of February of a year that has none": "2025-02-29",
    "the 29th of February 1900": "1900-02-29",
    "the 31st of November": "2026-11-31",
    "a 13th month": "2026-13-01",
    "the day 0": "2026-11-00",
    "the year 0": "0000-01-01",
    "with a time": "2026-11-24T08:00:00",
    "with a space after it": "2026-11-24 ",
    "with a space before it": " 2026-11-24",
    "with one digit for month and day": "2026-1-5",
    "without hyphens": "20261124",
    "day first": "24/11/2026",
    "by week and weekday": "2026-W48-2",
    "with five digits for the year": "10000-01-01",
    "with a character of the number 0 after it": "2026-11-24\x00",
    "with digits of another script": IN_ANOTHER_SCRIPT,
    "the number of a day as astronomers count them": "2460000",
    "the word now": "now",
    "empty text": "",
}


class Proof(Base):
    """A model of the tests' own, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofRace(Proof):
    __tablename__ = "proof_race"

    held_on: Mapped[date]
    # No value or a day.
    announced_on: Mapped[date | None]
    # A model that says more of the column: the value it has when none is given.
    first_held_on: Mapped[date] = mapped_column(default=THE_FIRST)
    # A time, as before: Python counts a datetime as a date, and the base does not.
    started_at: Mapped[datetime | None]


class Named(Base):
    """A schema for a model that names SQLAlchemy's own type for a day."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofHeat(Named):
    __tablename__ = "proof_heat"

    held_on: Mapped[date] = mapped_column(Date)


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the table of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def stored(made: Engine) -> list[tuple[Any, ...]]:
    """What the file holds of every race, with what kind of value it is, read without the model."""
    with made.connect() as connection:
        rows = connection.exec_driver_sql(
            "SELECT held_on, typeof(held_on), announced_on, typeof(announced_on), "
            "first_held_on, typeof(first_held_on) FROM proof_race ORDER BY id"
        ).all()
    return [tuple(row) for row in rows]


def test_a_day_is_text_in_a_strict_table_and_a_time_is_still_a_time(made: Engine) -> None:
    columns = ProofRace.__table__.c

    assert [column.name for column in columns if isinstance(column.type, CalendarDay)] == [
        "held_on",
        "announced_on",
        "first_held_on",
    ]
    assert [column.name for column in columns if isinstance(column.type, UtcDateTime)] == [
        "started_at",
        "created_at",
        "updated_at",
    ]
    assert broken_rules(Proof.metadata) == []

    with made.connect() as connection:
        in_the_file = {
            name: (declared, bool(required))
            for _, name, declared, required, _, _ in connection.exec_driver_sql(
                "PRAGMA table_info(proof_race)"
            )
        }

    assert in_the_file == {
        "id": ("INTEGER", True),
        "held_on": ("TEXT", True),
        "announced_on": ("TEXT", False),
        "first_held_on": ("TEXT", True),
        "started_at": ("TEXT", False),
        "created_at": ("TEXT", True),
        "updated_at": ("TEXT", True),
    }


def test_the_file_has_a_check_named_by_the_rule_for_each_such_column_and_for_no_other(
    made: Engine,
) -> None:
    with made.connect() as connection:
        written = str(
            connection.exec_driver_sql(
                "SELECT sql FROM sqlite_master WHERE name = 'proof_race'"
            ).scalar_one()
        )

    def check(name: str) -> str:
        return (
            f"CONSTRAINT ck_proof_race_{name}_calendar_day CHECK "
            f"(({name} GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]') "
            f"AND date({name}) IS {name} AND {name} >= '0001-01-01')"
        )

    assert [line.strip().rstrip(",") for line in written.splitlines() if "CHECK" in line] == [
        check("held_on"),
        check("announced_on"),
        check("first_held_on"),
    ]


@pytest.mark.parametrize(
    ("day", "text"),
    [
        (date(2026, 11, 24), "2026-11-24"),
        (date(2026, 1, 5), "2026-01-05"),
        (date(2024, 2, 29), "2024-02-29"),
        (date(2000, 2, 29), "2000-02-29"),
        (date(987, 6, 5), "0987-06-05"),
        (date(1, 1, 1), "0001-01-01"),
        (date(9999, 12, 31), "9999-12-31"),
    ],
    ids=[
        "a day",
        "a day of one digit in a month of one",
        "the 29th of February",
        "the 29th of February 2000",
        "a year of three digits",
        "the first day there is",
        "the last day there is",
    ],
)
def test_a_day_is_stored_as_text_in_one_form_and_comes_back_as_the_day(
    made: Engine, day: date, text: str
) -> None:
    with unit_of_work(made) as work:
        work.add(ProofRace(held_on=day, announced_on=day, first_held_on=day))

    assert stored(made) == [(text, "text", text, "text", text, "text")]
    with unit_of_work(made) as work:
        race = work.scalars(select(ProofRace)).one()
        assert (race.held_on, race.announced_on, race.first_held_on) == (day, day, day)
        # A day and nothing more: not a time at its midnight.
        assert type(race.held_on) is date


def test_a_column_that_may_be_without_a_value_holds_none_or_a_day(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add_all([ProofRace(held_on=A_DAY, announced_on=day) for day in (None, THE_FIRST)])

    assert [(announced, kind) for _, _, announced, kind, _, _ in stored(made)] == [
        (None, "null"),
        ("1957-08-04", "text"),
    ]
    with unit_of_work(made) as work:
        races = work.scalars(select(ProofRace).order_by(ProofRace.id)).all()
        assert [race.announced_on for race in races] == [None, THE_FIRST]


def test_a_column_given_no_value_gets_the_one_its_model_says(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add(ProofRace(held_on=A_DAY))

    assert stored(made) == [("2026-11-24", "text", None, "null", "1957-08-04", "text")]
    with unit_of_work(made) as work:
        assert work.scalars(select(ProofRace)).one().first_held_on == THE_FIRST


def test_a_change_of_the_day_is_stored(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add(ProofRace(held_on=A_DAY, announced_on=THE_FIRST))
    with unit_of_work(made) as work:
        race = work.scalars(select(ProofRace)).one()
        race.held_on = date(2026, 11, 25)

@pytest.mark.parametrize(

@pytest.mark.parametrize("text", list(NOT_DAYS.values()), ids=list(NOT_DAYS))

def test_rows_are_found_by_a_day_by_the_days_before_and_after_and_in_their_order(
    made: Engine,
) -> None:
    days = [date(2026, 11, 24), date(987, 6, 5), date(2026, 1, 5), date(9999, 12, 31)]
    with unit_of_work(made) as work:
        work.add_all([ProofRace(held_on=day) for day in days])
        work.add(ProofRace(held_on=A_DAY, announced_on=THE_FIRST))

    def found(*asked: Any) -> list[int]:
        with unit_of_work(made) as work:
            return list(work.scalars(select(ProofRace.id).where(*asked).order_by(ProofRace.id)))

    assert found(ProofRace.held_on == A_DAY) == [1, 5]
    assert found(ProofRace.held_on < A_DAY) == [2, 3]
    assert found(ProofRace.held_on > A_DAY) == [4]
    assert found(ProofRace.held_on.between(date(2026, 1, 1), date(2026, 12, 31))) == [1, 3, 5]
    assert found(ProofRace.held_on.in_([date(987, 6, 5), date(9999, 12, 31)])) == [2, 4]
    assert found(ProofRace.announced_on.is_(None)) == [1, 2, 3, 4]
    with unit_of_work(made) as work:
        in_order = work.scalars(select(ProofRace.held_on).order_by(ProofRace.held_on, ProofRace.id))
        assert list(in_order) == sorted([*days, A_DAY])
        assert work.scalar(select(func.min(ProofRace.held_on))) == date(987, 6, 5)
        assert work.scalar(select(func.max(ProofRace.held_on))) == date(9999, 12, 31)
```
