## Objective

The store knows which kinds of information each source offers (DESIGN
§7.3, "Available information types").

## Why

The registry of the design says of each source which kinds of
information it has. The collection that follows needs it to know where
to look for what: which sources to ask for events, and which for
results. A source can offer several kinds, so they cannot be a column of
the source: they are rows of a table of their own. It is the second
table and the second migration, and the first table that points to
another.

## Design in short

- **One list, `InformationType`**, in `motosphere.db.models.source`: the
  nine kinds of information, each with the text that is stored.
- **One table, `source_offer`**, with its model `SourceOffer` in the same
  module: one row for one kind that one source offers. Two columns
  between the key and the two times, `source_id` and `information_type`.
- **Three rules in the table**: a source offers a kind once; an offer
  belongs to a source that exists; a source that has offers cannot be
  deleted.
- **The second migration, `make_the_source_offers`**, at the end of the
  history.
- No new module, no new fixture, no new package from outside.

## What the task left open, and what the trial settled

- **The kinds.** The design names no list of them. The task proposed
  eight; the trial settled nine, from what the design says MotoSphere is
  a place to explore (DESIGN §1), in that order, as words in small
  letters in the plural:

  | `InformationType` | Text | What it is |
  |---|---|---|
  | `TRACKS` | `tracks` | Where tracks are and what they are like |
  | `EVENTS` | `events` | Races and other events with their dates: calendars and the rounds of a championship |
  | `CHAMPIONSHIPS` | `championships` | Championships and series: their seasons, their classes and who won them |
  | `RESULTS` | `results` | How races ended, single motos included |
  | `STANDINGS` | `standings` | The standings of a championship, with their points |
  | `RIDERS` | `riders` | Riders: who they are and what they have ridden |
  | `TEAMS` | `teams` | Teams: who they are and who rides for them |
  | `NEWS` | `news` | News and announcements |
  | `REFERENCE` | `reference data` | What other records are described by, such as the countries of the world |

  The ninth is there because the first source the plan registers offers
  none of the other eight: the reference file of the countries
  (DAT-012). A text added later costs a migration that builds the table
  anew, because the table's check names the texts.
- **The names.** The table is `source_offer` and the column is
  `information_type`, the design's own word ("Available information
  types"). "Kind" alone would be taken for the kind of source, which is
  `category`.
- **A source offers a kind once**: a unique constraint over the two
  columns, the source first, so that it also serves whoever asks what
  one source offers. Two sources can offer the same kind.
- **An offer belongs to a source that exists**: a foreign key to
  `source.id`, which SQLite enforces on every connection the store opens
  (DAT-021). It holds when an offer is stored and when it is changed.
- **A source that has offers cannot be deleted.** The foreign key does
  nothing by itself when its source is deleted, so SQLite refuses the
  delete. The other way, to take the offers away with their source in
  silence (`ON DELETE CASCADE`), was not taken: the task asks that a
  source "is not deleted unnoticed", and with the runs and the records
  that will point to a source later, a source that vanishes with all
  that hangs on it is the greater harm. Whoever deletes a source takes
  its offers away first, in the same unit of work; a test does exactly
  that.
- **A source may be without offers.** Nothing asks for one: a source is
  registered first and described after.
- **No way from the model of a source to its offers.** The model of an
  offer has the key of its source and no more (no `relationship`): what
  reads the offers of a source comes with the code that needs them.
- **The tests of the list go into the file of the two other lists**,
  `test_db_models_source.py`: the same five questions are asked of
  three lists where they were asked of two.

```python
"""The information sources: where everything the store holds comes from.

A source is a website or a dataset that MotoSphere may collect from. This
module has the model of the table that knows them all, :class:`Source`,
and the two lists a source is described by: what kind of source it is,
and how it is collected from. It also has what each source offers: the
list of the kinds of information there are, and the model of the table
that says which of them a source has, :class:`SourceOffer`.

Each list is said once, here. Its values are the texts that are stored,
and a column of the list (:class:`motosphere.db.lists.OneOf`) refuses
every other text. The texts are in small letters, with one space between
two words. Once a table has a column of a list, a text of that list is
changed or taken away only by a migration, because the table's check names
the texts and rows hold them.
"""

from datetime import datetime
from enum import StrEnum

from sqlalchemy import CheckConstraint, ForeignKey, UniqueConstraint
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base
from motosphere.db.lists import OneOf
from motosphere.db.texts import NotEmpty
from motosphere.db.web import WebAddress

__all__ = ["CollectionMethod", "InformationType", "Source", "SourceCategory", "SourceOffer"]


class SourceCategory(StrEnum):
    """What kind of source this is: who publishes it (DESIGN.md 7.1, in its order)."""

    # A body that makes the rules of the sport, for the world or for a country.
    GOVERNING_BODY = "governing body"
    # The website of one championship or series.
    CHAMPIONSHIP = "championship"
    # Whoever runs a championship from year to year.
    ORGANISER = "organiser"
    # Whoever puts on single races and sells them.
    PROMOTER = "promoter"
    # One track, about itself.
    TRACK = "track"
    # A local motorcycle club.
    CLUB = "club"
    # An organisation for the racing of one region of a country.
    REGIONAL_ORGANISATION = "regional organisation"
    # A public collection of race results or of timing.
    RESULTS_DATABASE = "results database"
    # A magazine or a news site about the sport.
    NEWS = "news publication"
    # A website the riders and followers of the sport write themselves.
    COMMUNITY = "community website"
    # A public page on a social network, only where that network permits collecting.
    SOCIAL_MEDIA = "social media page"
    # A public archive of how the sport was.
    ARCHIVE = "historical archive"


class CollectionMethod(StrEnum):
    """How a source is collected from (DESIGN.md 7.2, in its order)."""

    # An interface the source itself offers to programs.
    API = "official api"
    # A feed of records in a form made for programs, such as a calendar file.
    STRUCTURED_FEED = "structured feed"
    # A feed of what is new, as RSS or Atom.
    RSS = "rss feed"
    # A whole set of records published for reuse, under a licence.
    DATASET = "public dataset"
    # Pages made for people, only where the site's terms and its robots.txt permit.
    HTML = "html extraction"
    # A public document with a fixed layout, such as a results sheet.
    DOCUMENT = "structured document"
    # The data behind a public page, only where the source authorises its use.
    JSON = "json endpoint"
    # The list of its pages that a site publishes for programs.
    SITEMAP = "sitemap discovery"
    # What a search engine finds, only where the engine permits it.
    SEARCH = "search engine discovery"
    # A reference a person has sent in.
    SUBMITTED = "human submission"


class InformationType(StrEnum):
    """A kind of information a source can offer (DESIGN.md 1 and 7.3)."""

    # Where tracks are and what they are like.
    TRACKS = "tracks"
    # Races and other events with their dates: calendars and the rounds of a championship.
    EVENTS = "events"
    # Championships and series: their seasons, their classes and who won them.
    CHAMPIONSHIPS = "championships"
    # How races ended, single motos included.
    RESULTS = "results"
    # The standings of a championship, with their points.
    STANDINGS = "standings"
    # Riders: who they are and what they have ridden.
    RIDERS = "riders"
    # Teams: who they are and who rides for them.
    TEAMS = "teams"
    # News and announcements.
    NEWS = "news"
    # What other records are described by, such as the countries of the world.
    REFERENCE = "reference data"


class Source(Base):
    """One source of information: who it is, how it is collected from and how it may be used.

    A new source is switched off. It is switched on only after a person
    has read its terms, and the table itself refuses a row that is
    switched on and does not say when they were read.
    """

    __tablename__ = "source"
    __table_args__ = (
        CheckConstraint("scan_every_hours > 0", name="scan_every_hours_positive"),
        CheckConstraint(
            "switched_on = 0 OR terms_read_at IS NOT NULL", name="switched_on_terms_read"
        ),
    )

    # What the source is called. No two sources have one name.
    name: Mapped[NotEmpty] = mapped_column(unique=True)
    # The address of the site it is: its front page, not the page or feed
    # that is read. Two sources can have one website: a site that is
    # collected from in two ways is two sources.
    website: Mapped[WebAddress]
    category: Mapped[SourceCategory] = mapped_column(OneOf(SourceCategory))
    collection_method: Mapped[CollectionMethod] = mapped_column(OneOf(CollectionMethod))
    # After how many hours it is to be looked at again. No value: it is
    # not looked at by the clock, only when somebody loads it.
    scan_every_hours: Mapped[int | None]
    # Where its terms of use are, if it has any.
    terms_address: Mapped[WebAddress | None]
    # The licence under which what it publishes may be used, as the source names it.
    licence: Mapped[NotEmpty | None]
    # What its terms ask for or forbid, in plain words.
    usage_restrictions: Mapped[NotEmpty | None]
    # When a person last read its terms. No value: nobody has yet.
    terms_read_at: Mapped[datetime | None]
    # Whether MotoSphere collects from it.
    switched_on: Mapped[bool] = mapped_column(default=False)


class SourceOffer(Base):
    """One kind of information that one source offers.

    A source can offer several kinds, and each of them once. An offer
    belongs to a source that exists, and a source that has offers cannot
    be deleted: its offers are taken away first.
    """

    __tablename__ = "source_offer"
    __table_args__ = (UniqueConstraint("source_id", "information_type"),)

    source_id: Mapped[int] = mapped_column(ForeignKey("source.id"))
    information_type: Mapped[InformationType] = mapped_column(OneOf(InformationType))
```

### 2. `backend/src/motosphere/db/history.py` – the whole file, in place of the one there

New are the second migration and its name in `__all__` and in

```python
"""The history of the store's schema: every migration, oldest first.

A migration is a function that is given a connection and changes the
schema with it. ``MIGRATIONS`` is the list of them all, and the place of a
migration in that list is its number (:mod:`motosphere.db.migrations`
gives a store those it lacks).

- The list only ever grows at its end. A migration that has been merged is
  not changed, moved or taken out, because stores and snapshots at its
  version exist. A mistake in one is put right by a new one.
- A migration is plain SQL, written out here. It names no model, no list
  and no type of the store's code, and this module imports nothing of
  MotoSphere's: so a migration builds tomorrow what it builds today,
  whatever becomes of the code. What two migrations both need, each
  writes out for itself.
- A migration writes a table as its model makes it, and one test holds
  the two together (``DATABASE.md``, "The models and the migrations
  agree").
- A migration does not commit. ``migrate`` does, with the store's new
  version.
"""

from collections.abc import Callable

from sqlalchemy import Connection

__all__ = ["MIGRATIONS", "make_the_source_offers", "make_the_sources"]


def make_the_sources(connection: Connection) -> None:
    """1: the table of the information sources, ``source`` (DAT-006)."""
    white_space = (
        "char(9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, 8192, 8193, 8194, 8195, "
        "8196, 8197, 8198, 8199, 8200, 8201, 8202, 8232, 8233, 8239, 8287, 12288)"
    )

    def not_empty(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_not_empty CHECK (trim({column}, {white_space}) != '')"
        )

    def web_address(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_web_address CHECK ("
            f"(({column} GLOB '[Hh][Tt][Tt][Pp][Ss]://[^/?#]*')"
            f" OR ({column} GLOB '[Hh][Tt][Tt][Pp]://[^/?#]*'))"
            f" AND NOT ({column} GLOB '*[' || {white_space} || ']*')"
            f" AND instr({column}, char(0)) = 0)"
        )

    connection.exec_driver_sql(
        f"""
        CREATE TABLE source (
            id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            website TEXT NOT NULL,
            category TEXT NOT NULL,
            collection_method TEXT NOT NULL,
            scan_every_hours INTEGER,
            terms_address TEXT,
            licence TEXT,
            usage_restrictions TEXT,
            terms_read_at TEXT,
            switched_on INTEGER NOT NULL,
            created_at TEXT NOT NULL,
            updated_at TEXT NOT NULL,
            CONSTRAINT ck_source_scan_every_hours_positive CHECK (scan_every_hours > 0),
            CONSTRAINT ck_source_switched_on_terms_read
                CHECK (switched_on = 0 OR terms_read_at IS NOT NULL),
            CONSTRAINT uq_source_name UNIQUE (name),
            {not_empty("name")},
            {web_address("website")},
            CONSTRAINT ck_source_category_one_of CHECK (category IN (
                'governing body', 'championship', 'organiser', 'promoter', 'track', 'club',
                'regional organisation', 'results database', 'news publication',
                'community website', 'social media page', 'historical archive'
            )),
            CONSTRAINT ck_source_collection_method_one_of CHECK (collection_method IN (
                'official api', 'structured feed', 'rss feed', 'public dataset',
                'html extraction', 'structured document', 'json endpoint', 'sitemap discovery',
                'search engine discovery', 'human submission'
            )),
            {web_address("terms_address")},
            {not_empty("licence")},
            {not_empty("usage_restrictions")},
            CONSTRAINT ck_source_switched_on_yes_or_no CHECK (switched_on IN (0, 1))
        ) STRICT
        """
    )


def make_the_source_offers(connection: Connection) -> None:
    """2: the table of what the sources offer, ``source_offer`` (DAT-040)."""
    connection.exec_driver_sql(
        """
        CREATE TABLE source_offer (
            id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
            source_id INTEGER NOT NULL,
            information_type TEXT NOT NULL,
            created_at TEXT NOT NULL,
            updated_at TEXT NOT NULL,
            CONSTRAINT uq_source_offer_source_id_information_type
                UNIQUE (source_id, information_type),
            CONSTRAINT fk_source_offer_source_id_source
                FOREIGN KEY(source_id) REFERENCES source (id),
            CONSTRAINT ck_source_offer_information_type_one_of CHECK (information_type IN (
                'tracks', 'events', 'championships', 'results', 'standings', 'riders', 'teams',
                'news', 'reference data'
            ))
        ) STRICT
        """
    )


MIGRATIONS: tuple[Callable[[Connection], None], ...] = (make_the_sources, make_the_source_offers)
```

### 3. `backend/tests/integration/test_source_offer.py` – new, the whole file, 25 tests

```python
"""Tests of the table of what the sources offer, against a real SQLite file.

The store of every test is built by the migrations, as a real store is.
What the table must refuse is also written past the model.
"""

from collections.abc import Iterator
from contextlib import contextmanager

import pytest
from sqlalchemy import Engine, delete, select
from sqlalchemy.exc import IntegrityError

from motosphere.db.models import Source, SourceOffer
from motosphere.db.models.source import CollectionMethod, InformationType, SourceCategory
from motosphere.db.work import unit_of_work

MOMENT = "2026-11-19T08:00:00.000000+00:00"
BROKEN_KEY = "FOREIGN KEY constraint failed"
TWICE = "UNIQUE constraint failed: source_offer.source_id, source_offer.information_type"


@contextmanager
def refused(why: str) -> Iterator[None]:
    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:
        yield
    assert str(refusal.value.orig) == why


def a_source(store: Engine, name: str = "Example Federation") -> int:
    """Store a source, and give its key."""
    source = Source(
        name=name,
        website="https://federation.example",
        category=SourceCategory.GOVERNING_BODY,
        collection_method=CollectionMethod.RSS,
    )
    with unit_of_work(store) as work:
        work.add(source)
    return source.id


def offer(store: Engine, source: int, *types: InformationType) -> None:
    """Store that the source offers these kinds of information, in one unit of work."""
    with unit_of_work(store) as work:
        work.add_all(SourceOffer(source_id=source, information_type=one) for one in types)


def write(store: Engine, source: object, information_type: object) -> None:
    """Write an offer past the model, as plain SQL."""
    with store.begin() as connection:
        connection.exec_driver_sql(
            "INSERT INTO source_offer (source_id, information_type, created_at, updated_at) "
            "VALUES (?, ?, ?, ?)",
            (source, information_type, MOMENT, MOMENT),
        )


def held(store: Engine) -> list[tuple[object, ...]]:
    """What the table holds, as SQLite holds it: the source and the kind, by their key."""
    with store.connect() as connection:
        found = connection.exec_driver_sql(
            "SELECT source_id, information_type FROM source_offer ORDER BY id"
        )
        return [tuple(row) for row in found]


def sources(store: Engine) -> list[str]:
    with store.connect() as connection:
        found = connection.exec_driver_sql("SELECT name FROM source ORDER BY id")
        return [str(name) for (name,) in found]


def test_an_offer_is_stored_and_read_back(newest: Engine) -> None:
    source = a_source(newest)
    offer(newest, source, InformationType.EVENTS)

    with unit_of_work(newest) as work:
        found = work.execute(select(SourceOffer)).scalar_one()

    assert found.id == 1
    assert found.source_id == source
    assert found.information_type is InformationType.EVENTS
    assert found.created_at == found.updated_at
    assert held(newest) == [(source, "events")]


def test_a_source_can_offer_several_kinds_of_information(newest: Engine) -> None:
    source = a_source(newest)

    offer(newest, source, InformationType.EVENTS, InformationType.RESULTS, InformationType.NEWS)

    assert held(newest) == [(source, "events"), (source, "results"), (source, "news")]


@pytest.mark.parametrize("information_type", list(InformationType))
def test_a_source_can_offer_every_kind_on_the_list(
    newest: Engine, information_type: InformationType
) -> None:
    source = a_source(newest)

    offer(newest, source, information_type)

    with unit_of_work(newest) as work:
        assert work.execute(select(SourceOffer.information_type)).scalar_one() is information_type


def test_a_source_does_not_offer_one_kind_twice(newest: Engine) -> None:
    source = a_source(newest)
    offer(newest, source, InformationType.EVENTS)

    with refused(TWICE):
        offer(newest, source, InformationType.EVENTS)

    assert held(newest) == [(source, "events")]


def test_offers_stored_together_are_kept_together_or_not_at_all(newest: Engine) -> None:
    source = a_source(newest)

    with refused(TWICE):
        offer(newest, source, InformationType.TRACKS, InformationType.NEWS, InformationType.TRACKS)

    assert held(newest) == []


def test_two_sources_can_offer_the_same_kind(newest: Engine) -> None:
    first = a_source(newest)
    second = a_source(newest, "Example Club")

    offer(newest, first, InformationType.EVENTS)
    offer(newest, second, InformationType.EVENTS)

    assert held(newest) == [(first, "events"), (second, "events")]


@pytest.mark.parametrize("text", ["weather", "Events", "event", "rss feed", ""])
```
