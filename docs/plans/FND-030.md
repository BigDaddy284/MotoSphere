# FND-030 – Test counts and skipped tests in the check runner

**Phase:** 1 – Foundation
**Depends on:** FND-017 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §5, `docs/WORKFLOW.md`, `TESTING.md`,
`docs/plans/FND-017.md` ("Read this before touching the tests")

## Objective

The check runner says how many tests each gate ran, and a test gate fails
when a test was skipped. A skipped browser test is invisible to every other
gate today: the run is green and nobody is told that a test proved nothing.

## Design in short

- Five gates run tests: the repository checks and the script tests
  (`unittest`), the backend tests (pytest), the frontend unit tests (Vitest)
  and the browser tests (Playwright). Each names its tool in the gate table.
- The runner now reads every gate's output while passing it on to the
  terminal line by line, error output included, and keeps a copy. The bytes
  are passed on exactly as written, so a console that cannot show a check
  mark does not make the runner stumble (this matters on Windows).
- For a test gate, the counts are read from the tool's own closing lines,
  after any colour codes are removed: passed, failed (errors included) and
  skipped. "Skipped" is every test that neither passed nor failed: skipped,
  expected to fail, still to do, left out of the run or not run.
- A test gate fails when its command fails (as before), when a test was
  skipped, when no test ran, or when the counts cannot be found. The last
  rule means a change in a tool's output can never turn the check off
  silently.
- The summary shows the counts on each test gate's line, and a total for the
  run on a last line: `Tests: 473 passed, 0 failed, 0 skipped.`
- The rule about the runner's tests still holds: they never run the real
  script in the real repository, only a copy in a stand-in repository.

### 1. `scripts/check.py` – the whole file

```python
"""Run every check of the project, in order, and say which passed.

Standard library only, so it runs with a plain Python 3.12+ on Windows 11 and
Linux, from any folder:

    python scripts/check.py                     every gate
    python scripts/check.py --list              the gates, without running them
    python scripts/check.py --only repo         one gate
    python scripts/check.py --only frontend-lint frontend-tests

Every gate runs even when an earlier one failed, so one run shows everything
that is wrong. The exit code is 0 when every gate that ran passed, and 1
otherwise.

For the gates that run tests, the number of tests passed, failed and skipped
is read from the tool's own closing lines. Such a gate also fails when a test
was skipped, when no test ran, or when the numbers cannot be found: a test
that did not run has proved nothing.
"""

import argparse
import re
import shutil
import subprocess
import sys
import time
from collections.abc import Callable, Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import TextIO

ROOT = Path(__file__).resolve().parent.parent


@dataclass(frozen=True)
class Gate:
    """One check: a command, and the folder under the repository it runs in."""

    key: str
    name: str
    command: tuple[str, ...]
    folder: str = "."
    # For a gate that runs tests: the tool whose closing lines hold the counts.
    tests: str = ""


@dataclass(frozen=True)
class Counts:
    """How many tests a gate ran, by outcome.

    "Failed" includes errors. "Skipped" is every test that neither passed nor
    failed: skipped, expected to fail, still to do, left out or not run.
    """

    passed: int
    failed: int
    skipped: int


@dataclass(frozen=True)
class Result:
    """What happened when a gate ran."""

    gate: Gate
    passed: bool
    seconds: float
    note: str = ""
    counts: Counts | None = None


# In the order they run. The two install gates come before the gates that need
# what they install, so the runner works from a clean checkout.
GATES: tuple[Gate, ...] = (
    Gate(
        "repo",
        "Repository checks",
        ("python", "-m", "unittest", "discover", "-s", "tests/repo", "-v"),
        tests="unittest",
    ),
    Gate(
        "scripts",
        "Script tests",
        ("python", "-m", "unittest", "discover", "-s", "tests/scripts", "-v"),
        tests="unittest",
    ),
    Gate("backend-lock", "Backend lock file", ("uv", "lock", "--check"), "backend"),
    Gate("backend-install", "Backend install", ("uv", "sync", "--locked"), "backend"),
    Gate("backend-types", "Backend type check", ("uv", "run", "mypy"), "backend"),
    Gate("backend-lint", "Backend lint", ("uv", "run", "ruff", "check", "."), "backend"),
    Gate(
        "backend-format",
        "Backend format",
        ("uv", "run", "ruff", "format", "--check", "."),

    ),
    Gate("backend-tests", "Backend tests", ("uv", "run", "pytest"), "backend", "pytest"),
    Gate("frontend-install", "Frontend install", ("npm", "ci"), "frontend"),
    Gate("frontend-lint", "Frontend lint", ("npm", "run", "lint"), "frontend"),
    Gate("frontend-format", "Frontend format", ("npm", "run", "format:check"), "frontend"),
    Gate("frontend-types", "Frontend type check", ("npm", "run", "typecheck"), "frontend"),

    Gate("frontend-build", "Frontend build", ("npm", "run", "build"), "frontend"),

def find_program(name: str) -> str | None:
    """The full path of a program, or None when it is not installed.

    "python" is the Python that runs this script. Everything else is looked
    up on the PATH, which on Windows also finds `npm.cmd` for "npm".
    """
    if name == "python":
        return sys.executable
    return shutil.which(name)


def numbers(text: str, pattern: str) -> dict[str, int]:
    """Every "<number> <word>" pair in the text, as word to number."""
    return {word: int(number) for number, word in re.findall(pattern, text)}


def count_unittest(output: str) -> Counts | None:
    """Read `Ran 9 tests in 0.1s` and `OK (skipped=1)` or `FAILED (failures=1)`."""
    ran = list(re.finditer(r"^Ran (\d+) tests? in ", output, flags=re.MULTILINE))
    if not ran:
        return None
    verdict = re.search(
        r"^(?:OK|FAILED|NO TESTS RAN)(?: \((.*)\))?\s*$",
        output[ran[-1].end() :],
        flags=re.MULTILINE,
    )
    if verdict is None:
        return None
    detail = {
        words: int(number)
        for words, number in re.findall(r"([a-z]+(?: [a-z]+)*)=(\d+)", verdict[1] or "")
    }
    failed = sum(detail.get(word, 0) for word in ("failures", "errors", "unexpected successes"))
    skipped = sum(detail.get(word, 0) for word in ("skipped", "expected failures"))
    return Counts(int(ran[-1][1]) - failed - skipped, failed, skipped)


def count_pytest(output: str) -> Counts | None:
    """Read `==== 1 failed, 114 passed, 2 skipped in 2.51s ====`."""
    closing = re.findall(
        r"^=* ?(\d+ [a-z]+(?:, \d+ [a-z]+)*) in [\d.]+s", output, flags=re.MULTILINE
    )
    if not closing:
        return None
    found = numbers(closing[-1], r"(\d+) ([a-z]+)")
    failed = sum(found.get(word, 0) for word in ("failed", "error", "errors"))
    skipped = sum(found.get(word, 0) for word in ("skipped", "xfailed", "xpassed", "deselected"))
    return Counts(found.get("passed", 0), failed, skipped)


def count_vitest(output: str) -> Counts | None:
    """Read `Tests  1 failed | 198 passed | 1 skipped (200)`."""
    closing = re.findall(
        r"^\s*Tests\s+(\d+ [a-z]+(?: \| \d+ [a-z]+)*) \(\d+\)\s*$", output, flags=re.MULTILINE
    )
    if not closing:
        return None
    found = numbers(closing[-1], r"(\d+) ([a-z]+)")
    skipped = found.get("skipped", 0) + found.get("todo", 0)
    return Counts(found.get("passed", 0), found.get("failed", 0), skipped)


def count_playwright(output: str) -> Counts | None:
    """Read the closing lines `1 failed`, `2 skipped` and `80 passed (10.0s)`."""
    outcomes = "passed|failed|flaky|interrupted|skipped|did not run"
    found = numbers(output, rf"(?m)^\s+(\d+) ({outcomes})(?: \([\d.]+(?:ms|s|m|h)\))?\s*$")
    if not found:
        return None
    failed = sum(found.get(word, 0) for word in ("failed", "flaky", "interrupted"))
    skipped = found.get("skipped", 0) + found.get("did not run", 0)
    return Counts(found.get("passed", 0), failed, skipped)


COUNTERS: dict[str, Callable[[str], Counts | None]] = {
    "unittest": count_unittest,
    "pytest": count_pytest,
    "vitest": count_vitest,
    "playwright": count_playwright,
}


def without_colours(text: str) -> str:
    """The text without the escape codes that terminals read as colours."""
    return re.sub(r"\x1b\[[0-9;]*[A-Za-z]", "", text)


def judge(gate: Gate, exit_code: int, output: str) -> tuple[str, Counts | None]:
    """Why the gate failed ("" when it passed), and its test counts if it has any."""
    counts = COUNTERS[gate.tests](without_colours(output)) if gate.tests else None
    if exit_code != 0:
        return f"exit code {exit_code}", counts
    if not gate.tests:
        return "", None
    if counts is None:
        return "the test counts could not be read", None
    if counts.skipped:
        return "tests were skipped", counts
    if counts.passed == 0:
        return "no test ran", counts
    return "", counts


def run_gate(gate: Gate, root: Path, echo: Callable[[bytes], None]) -> Result:
    """Run one gate and wait for it. Its output is passed on line by line, and kept."""
    program = find_program(gate.command[0])
    if program is None:
        return Result(gate, False, 0.0, f"{gate.command[0]} is not installed")
    started = time.monotonic()
    kept: list[bytes] = []
    try:
        # The commands are the fixed ones listed above, never outside input.
        with (
            subprocess.Popen(  # noqa: S603
                [program, *gate.command[1:]],
                cwd=root / gate.folder,
                stdout=subprocess.PIPE,
                stderr=subprocess.STDOUT,
            ) as process
        ):
            if process.stdout is not None:
                for line in process.stdout:
                    echo(line)
                    kept.append(line)
        exit_code = process.returncode
    except OSError as error:
        return Result(gate, False, time.monotonic() - started, f"could not start: {error}")
    seconds = time.monotonic() - started
    note, counts = judge(gate, exit_code, b"".join(kept).decode("utf-8", errors="replace"))
    return Result(gate, note == "", seconds, note, counts)


def echo_to(out: TextIO) -> Callable[[bytes], None]:
    """A function that passes a gate's output on to where the runner writes.

    A real terminal or pipe gets the bytes exactly as the gate wrote them, so
    nothing depends on the terminal's character set. Anything else, such as
    the text buffer a test hands in, gets them as text.
    """
    binary = getattr(out, "buffer", None)

    def echo(data: bytes) -> None:
        if binary is None:
            out.write(data.decode("utf-8", errors="replace"))
        else:
            binary.write(data)
            binary.flush()

    return echo


def tally(counts: Counts) -> str:
    """Counts as a person reads them: `198 passed, 1 failed`."""
    parts = [f"{counts.passed} passed"]
    if counts.failed:
        parts.append(f"{counts.failed} failed")
    if counts.skipped:
        parts.append(f"{counts.skipped} skipped")
    return ", ".join(parts)


def describe(gate: Gate) -> str:
    """The command of a gate as a person would type it."""
    command = " ".join(gate.command)
    return command if gate.folder == "." else f"{command}  (in {gate.folder}/)"


def summary(results: Sequence[Result]) -> str:
    """The closing report: one line for each gate, then the verdict."""
    width = max(len(result.gate.name) for result in results)
    lines = ["", "Summary", ""]
    for result in results:
        line = (
            f"  {'PASSED' if result.passed else 'FAILED'}  "
            f"{result.gate.name:<{width}}  {result.seconds:7.1f} s"
        )
        if result.counts is not None:
            line += f"  {tally(result.counts)}"
        lines.append(f"{line}  {result.note}" if result.note else line)
    failed = [result.gate.name for result in results if not result.passed]
    verdict = f"{len(results) - len(failed)} of {len(results)} gates passed."
    if failed:
        verdict += f" FAILED: {', '.join(failed)}."
    lines += ["", verdict]
    counted = [result.counts for result in results if result.counts is not None]
    if counted:
        lines.append(
            f"Tests: {sum(counts.passed for counts in counted)} passed, "
            f"{sum(counts.failed for counts in counted)} failed, "
            f"{sum(counts.skipped for counts in counted)} skipped."
        )
    return "\n".join([*lines, ""])


def main(
    arguments: Sequence[str] | None = None,
    gates: Sequence[Gate] = GATES,
    root: Path = ROOT,
    out: TextIO = sys.stdout,
) -> int:
    parser = argparse.ArgumentParser(
        prog="check.py", description="Run the project's checks and say which passed."
    )
    choice = parser.add_mutually_exclusive_group()
    choice.add_argument(
        "--list", action="store_true", help="show the gates and their commands, and run nothing"
    )
    choice.add_argument(
        "--only",
        nargs="+",
        choices=[gate.key for gate in gates],
        metavar="GATE",
        help="run only these gates (see --list for their names)",
    )
    options = parser.parse_args(arguments)

    if options.list:
        width = max(len(gate.key) for gate in gates)
        for gate in gates:
            out.write(f"{gate.key:<{width}}  {describe(gate)}\n")
        return 0

    chosen = [gate for gate in gates if options.only is None or gate.key in options.only]
    results: list[Result] = []
    echo = echo_to(out)
    for number, gate in enumerate(chosen, start=1):
        out.write(f"\n=== [{number}/{len(chosen)}] {gate.name}: {describe(gate)}\n")
        out.flush()
        results.append(run_gate(gate, root, echo))
    out.write(summary(results))
    out.flush()
    return 0 if all(result.passed for result in results) else 1


if __name__ == "__main__":
    sys.exit(main())
```

def says(key: str, tool: str, *lines: str, exit_code: int = 0) -> check.Gate:
    """A test gate for the given tool that writes these lines, as that tool would."""
    code = f"import sys; sys.stderr.write({chr(10).join(lines) + chr(10)!r}); sys.exit({exit_code})"

def notes(key: str, folder: str = ".") -> check.Gate:

class TemporaryRootTest(unittest.TestCase):
    """Gives each test an empty folder to use as the repository."""

    def setUp(self) -> None:
        folder = tempfile.TemporaryDirectory()
        self.addCleanup(folder.cleanup)
        self.root = Path(folder.name)

    def log(self, folder: str = ".") -> list[str]:
        path = self.root / folder / "log.txt"
        return path.read_text(encoding="utf-8").split() if path.exists() else []

    def run_gate(self, gate: check.Gate) -> check.Result:
        self.echoed: list[bytes] = []
        return check.run_gate(gate, self.root, self.echoed.append)

    def run_main(self, arguments: list[str], gates: list[check.Gate]) -> tuple[int, str]:

        code = check.main(arguments, gates, self.root, out)

class CountTest(unittest.TestCase):
    """Reading test counts from the closing lines each tool really writes."""

    def test_unittest_all_passed(self) -> None:
        output = "test_a (test_s.S.test_a) ... ok\n\n-----\nRan 9 tests in 0.093s\n\nOK\n"

        self.assertEqual(check.count_unittest(output), check.Counts(9, 0, 0))

    def test_unittest_a_single_test(self) -> None:
        self.assertEqual(
            check.count_unittest("Ran 1 test in 0.001s\n\nOK\n"), check.Counts(1, 0, 0)
        )

    def test_unittest_every_kind_of_outcome(self) -> None:
        output = (
            "Ran 6 tests in 0.001s\n\n"
            "FAILED (failures=1, errors=1, skipped=1, expected failures=1, "
            "unexpected successes=1)\n"
        )

        self.assertEqual(check.count_unittest(output), check.Counts(1, 3, 2))

    def test_unittest_skipped_tests_do_not_stop_it_saying_ok(self) -> None:
        output = "Ran 3 tests in 0.001s\n\nOK (skipped=1, expected failures=1)\n"

        self.assertEqual(check.count_unittest(output), check.Counts(1, 0, 2))

    def test_unittest_no_tests(self) -> None:
        output = "Ran 0 tests in 0.000s\n\nNO TESTS RAN\n"

        self.assertEqual(check.count_unittest(output), check.Counts(0, 0, 0))

    def test_unittest_last_report_counts_when_the_output_quotes_another(self) -> None:
        # A failing test of the runner shows the output of the run it started.
        output = (
            "AssertionError: 1 != 0 : \n"
            "Ran 2 tests in 0.1s\n\nFAILED (failures=2)\n\n"
            "Ran 30 tests in 1.0s\n\nOK\n"

    def test_unittest_without_closing_lines(self) -> None:
        self.assertIsNone(check.count_unittest("Traceback (most recent call last):\n"))

    def test_pytest_all_passed(self) -> None:

    def test_pytest_every_kind_of_outcome(self) -> None:
        output = (
            "==== 1 failed, 1 passed, 1 skipped, 1 xfailed, 1 xpassed, 1 error in 0.42s =====\n"

    def test_pytest_without_counts(self) -> None:

class CommandLineTest(TemporaryRootTest):
    """The script itself, run as a separate process the way a person runs it.

    Every test here runs a copy of the script inside a small stand-in
    repository, never the script in the real one. One of the real gates runs
    these tests, so a defect in the runner could otherwise make it start
    itself again and again without end. In the stand-in repository the worst
    a defect can do is run gates that fail at once.
    """

    def setUp(self) -> None:
        super().setUp()
        (self.root / "scripts").mkdir()
        self.script = self.root / "scripts" / "check.py"
        shutil.copyfile(SCRIPT, self.script)
        elsewhere = tempfile.TemporaryDirectory()
        self.addCleanup(elsewhere.cleanup)
        self.elsewhere = Path(elsewhere.name)

    def add_repository_checks(self, body: str) -> None:
        folder = self.root / "tests" / "repo"
        folder.mkdir(parents=True)
        lines = [
            "import unittest",
            "",
            "",
            "class SampleTest(unittest.TestCase):",
            "    def test_sample(self):",
            f"        {body}",
            "",
        ]
        (folder / "test_sample.py").write_text("\n".join(lines), encoding="utf-8")

    def run_script(
        self, *arguments: str, console: str = "utf-8"
    ) -> subprocess.CompletedProcess[str]:
        # Started from another folder, to show that the script finds its repository itself.
        # `console` is the character set the runner believes its terminal has.
        return subprocess.run(  # noqa: S603
            [sys.executable, str(self.script), *arguments],
            cwd=self.elsewhere,
            env={**os.environ, "PYTHONIOENCODING": console},
            capture_output=True,
            text=True,
            encoding="utf-8",
            check=False,
        )

    def test_list_names_every_gate_and_runs_nothing(self) -> None:
        self.add_repository_checks("open('ran.txt', 'w').close()")

        finished = self.run_script("--list")

        self.assertEqual(finished.returncode, 0, finished.stderr)
        lines = finished.stdout.splitlines()
        self.assertEqual([line.split()[0] for line in lines], [gate.key for gate in check.GATES])
        self.assertEqual(lines[0], "repo              python -m unittest discover -s tests/repo -v")
        self.assertFalse((self.root / "ran.txt").exists())

    def test_exit_code_of_the_script_is_zero_when_the_gate_passes(self) -> None:
        self.add_repository_checks("open('ran.txt', 'w').close()")

        finished = self.run_script("--only", "repo")

        self.assertEqual(finished.returncode, 0, finished.stdout + finished.stderr)
        self.assertIn("=== [1/1] Repository checks: python -m unittest", finished.stdout)
        self.assertIn(
            "1 of 1 gates passed.\nTests: 1 passed, 0 failed, 0 skipped.\n", finished.stdout
        )
        self.assertRegex(finished.stdout, r"(?m)^  PASSED  Repository checks +\d+\.\d s  1 passed$")
        # The gate's own output is shown, under its announcement.
        self.assertLess(finished.stdout.index("=== [1/1]"), finished.stdout.index("Ran 1 test in"))
        self.assertLess(finished.stdout.index("Ran 1 test in"), finished.stdout.index("Summary"))
        # The gate ran in the repository the script is in, not where it was started.
        self.assertTrue((self.root / "ran.txt").exists())
        self.assertFalse((self.elsewhere / "ran.txt").exists())

    def test_exit_code_of_the_script_is_one_when_the_gate_fails(self) -> None:
        self.add_repository_checks("self.fail('planted')")

        finished = self.run_script("--only", "repo")

        self.assertEqual(finished.returncode, 1, finished.stdout + finished.stderr)
        self.assertIn("0 of 1 gates passed. FAILED: Repository checks.\n", finished.stdout)
        self.assertRegex(
            finished.stdout,
            r"(?m)^  FAILED  Repository checks +\d+\.\d s  0 passed, 1 failed  exit code 1$",
        )
        self.assertIn("Tests: 0 passed, 1 failed, 0 skipped.\n", finished.stdout)

    def test_exit_code_of_the_script_is_one_when_a_test_is_skipped(self) -> None:
        self.add_repository_checks("self.skipTest('planted')")

        finished = self.run_script("--only", "repo")

        self.assertEqual(finished.returncode, 1, finished.stdout + finished.stderr)
        line = r"  FAILED  Repository checks +\d+\.\d s  0 passed, 1 skipped  tests were skipped"
        self.assertRegex(finished.stdout, rf"(?m)^{line}$")
        self.assertIn("Tests: 0 passed, 0 failed, 1 skipped.\n", finished.stdout)

    def test_output_outside_ascii_passes_through_unchanged(self) -> None:
        # Written as bytes, the way the Node.js tools write their check marks.
        self.add_repository_checks(
            "import sys; sys.stderr.flush(); "
            "sys.stderr.buffer.write('\\u2713 na\\u00efve\\n'.encode('utf-8')); sys.stderr.flush()"
        )

        # A terminal that can only show ASCII, like an old Windows console,
        # must not make the runner stumble over what a gate writes.
        finished = self.run_script("--only", "repo", console="ascii")

        self.assertEqual(finished.returncode, 0, finished.stdout + finished.stderr)
        self.assertIn("\u2713 na\u00efve\n", finished.stdout)
        self.assertIn("1 of 1 gates passed.\n", finished.stdout)

    def test_help_explains_the_options(self) -> None:
        finished = self.run_script("--help")

        self.assertEqual(finished.returncode, 0)
        self.assertIn("--list", finished.stdout)
        self.assertIn("--only", finished.stdout)
