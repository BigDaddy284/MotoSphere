# FND-023 – Apply the owner's Graphite theme

**Phase:** 1 – Foundation
**Depends on:** FND-013 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §8, `docs/WORKFLOW.md`, `ARCHITECTURE.md` §3 ("Visual identity"), `docs/design/graphite-theme/README.md` and `graphite-theme.css`

## Objective

The application uses the colours and font the owner chose. FND-013 built the
token and contrast-test machinery with provisional colours; this task
replaces those colours with the owner's **Graphite** theme (soft charcoal
greys with a sky-blue accent), using Graphite's own role names so the tokens
map one-to-one onto the owner's reference file.

### 1. `frontend/src/styles/tokens.css`

Exactly this content. Every value marked Graphite is copied from
`docs/design/graphite-theme/graphite-theme.css`.

```css
/*
 * MotoSphere design tokens: the single source of truth for colour, type,
 * spacing, shape and motion. Components use these names and never their own
 * raw values. The colours are the owner's Graphite theme
 * (docs/design/graphite-theme/): soft charcoal greys with a sky-blue accent.
 * Colours are six-digit hex so the contrast tests can read them.
 */
:root {
  /* Surfaces (Graphite) */
  --color-bar: #1b1c1f; /* top bar */
  --color-canvas: #1d1e21; /* page background, behind panels */
  --color-panel: #222327; /* navigation and details panels, menus, cards */
  --color-window: #2a2b2f; /* main content background */
  --color-control: #35373c; /* inputs, hover */
  --color-pressed: #3d4046; /* pressed state */

  /* Lines (Graphite) */
  --color-border: #383a40;
  --color-control-border: #4a4d54;

  /* Text (Graphite) */
  --color-text: #ececee;
  --color-subtext: #a9acb3; /* secondary text and icons */
  --color-disabled: #75787f;

  /* Accent blues (Graphite) */
  --color-accent: #2580ee; /* buttons, selection fill */
  --color-on-accent: #ffffff; /* bold labels on the accent only: 3.89:1 */
  --color-accent-sky: #5ea8ff; /* links, focus ring, active underline */
  --color-accent-light: #8cc4ff; /* gradient end */
  --color-selection: #2f4a6e; /* selected row or tile */
  --gradient-accent: linear-gradient(90deg, var(--color-accent), var(--color-accent-light));

  /* Status (MotoSphere's own: Graphite has none) */
  --color-success: #3ecf8e;
  --color-warning: #f5b83d;
  --color-danger: #ff6b6b;
  --color-info: #5ab0ff;

  /* Type */
  --font-sans:
    'Segoe UI Variable Text', 'Segoe UI', system-ui, -apple-system, Roboto, 'Helvetica Neue', Arial,
    sans-serif;
  --font-mono: ui-monospace, 'Cascadia Mono', Consolas, 'Liberation Mono', monospace;
  --font-size-sm: 0.875rem;
  --font-size-md: 1rem;
  --font-size-lg: 1.25rem;
  --font-size-xl: 1.5rem;
  --font-size-2xl: 2rem;
  --font-weight-regular: 400;
  --font-weight-medium: 500;
  --font-weight-bold: 700;
  --line-height-tight: 1.2;
  --line-height-normal: 1.5;

  /* Spacing */
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 0.75rem;
  --space-4: 1rem;
  --space-5: 1.5rem;
  --space-6: 2rem;
  --space-7: 3rem;

  /* Shape */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;

  /* Motion */
  --duration-fast: 120ms;
  --duration-normal: 200ms;
  --easing-standard: cubic-bezier(0.2, 0, 0, 1);
}
```

Changes against FND-013, for orientation: the three provisional surfaces
become Graphite's six (`bar`, `canvas`, `panel`, `window`, `control`,
`pressed`); `--color-text-muted` becomes `--color-subtext`; `--color-focus`
is removed (the focus ring uses `--color-accent-sky`, as in Graphite); the
accent family, `--color-selection`, `--color-control-border`,
`--color-disabled` and `--gradient-accent` are new; the font stack starts
with the owner's fonts. Type sizes, spacing, radii and motion are unchanged.

### 2. `frontend/src/styles/base.css`

Three changes, nothing else:

1. `body`: `background-color: var(--color-canvas);` (the page background is

2. Links use the sky blue, and selected text uses the selection colour.

### 3. `frontend/src/styles/tokens.test.ts`

Keep the structure and the three "style sheets" tests as they are. Change
the "design tokens" block as follows.

- A constant with the owner's 16 Graphite colours, written out in the test:

  | Token | Value | Token | Value |
  |---|---|---|---|
  | `--color-bar` | `#1b1c1f` | `--color-text` | `#ececee` |
  | `--color-canvas` | `#1d1e21` | `--color-subtext` | `#a9acb3` |
  | `--color-panel` | `#222327` | `--color-disabled` | `#75787f` |
  | `--color-window` | `#2a2b2f` | `--color-accent` | `#2580ee` |
  | `--color-control` | `#35373c` | `--color-on-accent` | `#ffffff` |
  | `--color-pressed` | `#3d4046` | `--color-accent-sky` | `#5ea8ff` |
  | `--color-border` | `#383a40` | `--color-accent-light` | `#8cc4ff` |
  | `--color-control-border` | `#4a4d54` | `--color-selection` | `#2f4a6e` |

- `defines exactly the agreed set of tokens`: the 46 names in the file above
  (20 colours, `--gradient-accent`, and the 25 type, spacing, shape and
  motion tokens).
- `defines each token only once`: unchanged.
- New test `uses exactly the owner's Graphite colours`: each of the 16 tokens
  has exactly the value in the table.
- `writes every colour as a six-digit hex value`: now 20 `--color-*` tokens.
- `%s on %s has a contrast of at least %d`: 47 cases, from these rules. "Page
  surfaces" are bar, canvas, panel and window; "all surfaces" adds control
  and pressed.

  | Foreground | Backgrounds | Minimum | Cases |
  |---|---|---|---|
  | `--color-text` | all surfaces and `--color-selection` | 7 | 7 |
  | `--color-subtext` | all surfaces | 4.5 | 6 |
  | `--color-accent-sky` | page surfaces and control | 4.5 | 5 |
  | `--color-accent-sky` | pressed, `--color-selection` | 3 | 2 |
  | `--color-accent-light` | all surfaces | 4.5 | 6 |
  | `--color-success`, `--color-warning`, `--color-danger`, `--color-info` | page surfaces | 4.5 | 16 |
  | `--color-disabled` | page surfaces | 3 | 4 |
  | `--color-on-accent` | `--color-accent` | 3 | 1 |

  The last row is deliberate and must carry a comment in the test: white on
  the owner's accent blue measures 3.89:1, which meets 3:1 (large or bold
  text) but not 4.5:1. The owner has been told; the colour is used for bold
  button labels only. Do not raise the threshold and do not change the
  colour.

That makes 4 + 47 = 51 cases in "design tokens" and 3 in "style sheets": 54
in this file, and 69 in the whole unit suite (5 for `App` and the entry
point, 10 for the contrast maths, 54 here).
