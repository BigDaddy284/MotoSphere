## Objective

Every collection run is recorded: which source, when, how it ended and
what it changed.

## Why

The design counts the collection runs among the things the store knows
(DESIGN §5.1). Without a record of them nobody can say when a source was
last looked at, whether that worked, or what it changed, and a job that
died leaves no trace of what it was doing. How a source is doing
(DAT-041) is read from this table, and recovery after an interrupted
job (CLAUDE.md §13) starts from it. It is the third table and the third
migration, and the first function that changes rows of the store.

## Design in short

- **One list, `RunOutcome`**, and **one table, `collection_run`**, with
  its model `CollectionRun`, in a new module,
  `motosphere.db.models.collection_run`. Nine columns between the key
  and the two times: the source, the start, the end, the outcome, four
  counts and the error.
- **Eight rules in the table**: a run belongs to a source that exists,
  and a source that has runs cannot be deleted (one foreign key); a run
  cannot end before it started; its end goes with its outcome; its error
  goes with its outcome; and none of the four counts is below 0.
- **The third migration, `make_the_collection_runs`**, at the end of the
  history.
- **One function, `mark_interrupted(work)`**, in a new module,
  `motosphere.db.runs`: it marks every run that is still running as
  interrupted and touches nothing else.
- No new fixture, no new package from outside.

## What the task left open, and what the trial settled

- **The names.** The table is `collection_run` and its model
  `CollectionRun`, the design's own words ("Data collection runs"). A
  run alone could be a run of the tests or of a race. The list is
  `RunOutcome`, with the four texts the task names:

  | `RunOutcome` | Text | What it is | Its end | Its error |
  |---|---|---|---|---|
  | `RUNNING` | `running` | It has started and has not said how it ended | None | None |
  | `SUCCEEDED` | `succeeded` | It ended, and collected what it set out to collect | Said | None |
  | `FAILED` | `failed` | It ended, and says what went wrong | Said | Said |
  | `INTERRUPTED` | `interrupted` | It never said how it ended, because its job died | None | None |

- **A module of its own.** `motosphere.db.models.source` is about the
  sources. The runs get `motosphere.db.models.collection_run`, and the
  package names the new model, so that `SCHEMA` has its table.
- **A run is stored when it starts.** A new run is `running` and has
  counted nothing: the model gives the outcome and the four counts
  their first values. `started_at` has none: whoever starts the run says
  when, by asking the store's clock.
- **An interrupted run has no end.** Nobody knows when its job died, and
  the store does not hold a time that somebody made up (CLAUDE.md §11).
  `updated_at` says when the run was marked, which is another thing.
- **The end goes with the outcome**: a run that succeeded or failed says
  when it ended, and no other run does. One check says both ways,
  `(ended_at IS NULL) = (outcome IN ('running', 'interrupted'))`.
- **The error goes with the outcome**: a run that failed says what went
  wrong, and no other run has an error:
  `(error IS NULL) = (outcome != 'failed')`. The error is text that is
  not empty (`NotEmpty`), which brings its own check.
- **A run cannot end before it started**: `ended_at >= started_at`. The
  store's times are text of one form whose order is the order of the
  times (DAT-028), so SQLite compares them as they are. A run can end
  at the moment it started.
- **The counts.** Four whole numbers that cannot be without a value and
  cannot be below 0, each with a check of its own, so that what SQLite
  says names the count. The table does not ask that added, changed and
  unchanged add up to seen: a record that was refused was seen and is
  none of the three, and what a collector counts as one record is the
  collectors' to settle.
- **A source that has runs cannot be deleted**, as with its offers
  (DAT-040): the foreign key does nothing by itself, so SQLite refuses
  the delete. A record of a run does not vanish in silence with its
  source.
- **No index beside the key's, and no rule against two running runs of
  one source.** The first task that reads the runs of one source
  (DAT-041) has the question an index must answer; the first task that
  starts runs knows whether two may run at once. Neither is guessed
  here.
- **Marking the runs that were left running** is one statement,
  `UPDATE … SET outcome = 'interrupted' WHERE outcome = 'running'`, in
  `motosphere.db.runs.mark_interrupted(work)`:
  - It takes the session of a unit of work and is part of it: it is
    kept or taken back with whatever else the caller does there, and a
    new run can be stored in the same unit.
  - It gives the keys of the runs it marked, smallest first, so that
    the caller can say which they were. They come from the statement
    itself (`RETURNING`), which the store's SQLite has. That also keeps
    the type check clean: a count of changed rows (`rowcount`) is not on
    what a session's `execute` is typed to give.
  - `updated_at` of the marked runs is set by `Base`, as for every
    change (DAT-031). Nothing else of them changes.
  - A run that the unit of work had read already says `interrupted`
    afterwards: SQLAlchemy brings loaded rows in line with such a
    statement by itself, and a test holds it to that.
  - Nothing calls it yet. The first task that collects does, at its
    start, before it stores a new run.
- **The tests of the list get a file of their own**,
  `test_db_models_collection_run.py`: the list is in a module of its
  own, and it has one word for each text where the lists of the sources
  have several.

### 1. `backend/src/motosphere/db/models/collection_run.py` – new, the whole file

```python
"""The collection runs: the record of every time a source was collected from.

A run is one attempt to collect from one source. This module has the
model of the table that records them, :class:`CollectionRun`, and the
list of how a run stands or ended, :class:`RunOutcome`.

A run is stored when it starts, and it is then running. When it ends it
says so itself: it succeeded, or it failed and says why. A run whose job
died says nothing more. It is still running in the table until the next
start finds it and marks it interrupted
(:func:`motosphere.db.runs.mark_interrupted`).
"""

from datetime import datetime
from enum import StrEnum

from sqlalchemy import CheckConstraint, ForeignKey
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base
from motosphere.db.lists import OneOf
from motosphere.db.texts import NotEmpty

__all__ = ["CollectionRun", "RunOutcome"]


class RunOutcome(StrEnum):
    """How a collection run stands or ended."""

    # It has started and has not said how it ended.
    RUNNING = "running"
    # It ended, and collected what it set out to collect.
    SUCCEEDED = "succeeded"
    # It ended, and says what went wrong.
    FAILED = "failed"
    # It never said how it ended, because its job died. Nobody knows when.
    INTERRUPTED = "interrupted"


class CollectionRun(Base):
    """One run: which source it collected from, when, how it ended and what it changed.

    A run belongs to a source that exists, and a source that has runs
    cannot be deleted. The table itself refuses a run that ends before it
    started, a run whose end or whose error does not go with its outcome,
    and a count below nothing.
    """

    __tablename__ = "collection_run"
    __table_args__ = (
        CheckConstraint("ended_at >= started_at", name="ended_at_not_before_started_at"),
        # When it ended is known of a run that said so itself, and of no other.
        CheckConstraint(
            "(ended_at IS NULL) = (outcome IN ('running', 'interrupted'))",
            name="ended_at_when_succeeded_or_failed",
        ),
        # A run that failed says why, and no other run has an error.
        CheckConstraint("(error IS NULL) = (outcome != 'failed')", name="error_when_failed"),
        CheckConstraint("records_seen >= 0", name="records_seen_not_negative"),
        CheckConstraint("records_added >= 0", name="records_added_not_negative"),
        CheckConstraint("records_changed >= 0", name="records_changed_not_negative"),
        CheckConstraint("records_unchanged >= 0", name="records_unchanged_not_negative"),
    )

    # The source that was collected from.
    source_id: Mapped[int] = mapped_column(ForeignKey("source.id"))
    # When the run started. Whoever starts it says so.
    started_at: Mapped[datetime]
    # When it ended. No value: it is running, or it was interrupted and
    # nobody knows when.
    ended_at: Mapped[datetime | None]
    outcome: Mapped[RunOutcome] = mapped_column(OneOf(RunOutcome), default=RunOutcome.RUNNING)
    # How many records the run was given by its source, and how many of
    # them were new to the store, were different from what the store had,
    # and were what the store had already. A run counts as it goes or when
    # it ends; the table does not ask that the three add up to the first,
    # because a record that was refused is none of the three.
    records_seen: Mapped[int] = mapped_column(default=0)
    records_added: Mapped[int] = mapped_column(default=0)
    records_changed: Mapped[int] = mapped_column(default=0)
    records_unchanged: Mapped[int] = mapped_column(default=0)
    # What went wrong, in plain words, when the run failed.
    error: Mapped[NotEmpty | None]
```

### 2. `backend/src/motosphere/db/runs.py` – new, the whole file

```python
"""What the store does with its collection runs.

A run is stored as running when it starts, and says itself how it ended.
A run whose job died cannot: it would be running in the table for ever.
:func:`mark_interrupted` is what the next start of collecting calls
before anything else, so that the table says of every run what is true
of it, and whoever takes up the work has a record of what was cut off.
"""

from sqlalchemy import update
from sqlalchemy.orm import Session

from motosphere.db.models.collection_run import CollectionRun, RunOutcome

__all__ = ["mark_interrupted"]


def mark_interrupted(work: Session) -> list[int]:
    """Mark every run that is still running as interrupted, and give their keys in order.

    It is for the moment nothing can be running: the start of collecting,
    before the first new run is stored. A run that is running then was
    left so by a job that died.

    Only the outcome of those runs is changed, and with it when they were
    last changed. They get no end, because nobody knows when they ended,
    and they keep what they had counted. No other run and no other table
    is touched. The marking is part of the unit of work ``work``: it is
    kept or taken back with it.
    """
    marked = work.scalars(
        update(CollectionRun)
        .where(CollectionRun.outcome == RunOutcome.RUNNING)
        .values(outcome=RunOutcome.INTERRUPTED)
        .returning(CollectionRun.id)
    )
    return sorted(marked)
```

"""The history of the store's schema: every migration, oldest first.

A migration is a function that is given a connection and changes the
schema with it. ``MIGRATIONS`` is the list of them all, and the place of a
migration in that list is its number (:mod:`motosphere.db.migrations`
gives a store those it lacks).

- The list only ever grows at its end. A migration that has been merged is
  not changed, moved or taken out, because stores and snapshots at its
  version exist. A mistake in one is put right by a new one.
- A migration is plain SQL, written out here. It names no model, no list
  and no type of the store's code, and this module imports nothing of
  MotoSphere's: so a migration builds tomorrow what it builds today,
  whatever becomes of the code. What two migrations both need, each
  writes out for itself.
- A migration writes a table as its model makes it, and one test holds
  the two together (``DATABASE.md``, "The models and the migrations
  agree").
- A migration does not commit. ``migrate`` does, with the store's new
  version.
"""

from collections.abc import Callable

from sqlalchemy import Connection

__all__ = ["MIGRATIONS", "make_the_collection_runs", "make_the_source_offers", "make_the_sources"]


def make_the_sources(connection: Connection) -> None:
    """1: the table of the information sources, ``source`` (DAT-006)."""
    white_space = (
        "char(9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, 8192, 8193, 8194, 8195, "
        "8196, 8197, 8198, 8199, 8200, 8201, 8202, 8232, 8233, 8239, 8287, 12288)"
    )

    def not_empty(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_not_empty CHECK (trim({column}, {white_space}) != '')"
        )

    def web_address(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_web_address CHECK ("
            f"(({column} GLOB '[Hh][Tt][Tt][Pp][Ss]://[^/?#]*')"
            f" OR ({column} GLOB '[Hh][Tt][Tt][Pp]://[^/?#]*'))"
            f" AND NOT ({column} GLOB '*[' || {white_space} || ']*')"
            f" AND instr({column}, char(0)) = 0)"
        )

    connection.exec_driver_sql(
        f"""
        CREATE TABLE source (
            id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            website TEXT NOT NULL,
            category TEXT NOT NULL,
            collection_method TEXT NOT NULL,
            scan_every_hours INTEGER,
            terms_address TEXT,
            licence TEXT,
            usage_restrictions TEXT,

            switched_on INTEGER NOT NULL,

            updated_at TEXT NOT NULL,

            CONSTRAINT ck_source_switched_on_terms_read
                CHECK (switched_on = 0 OR terms_read_at IS NOT NULL),
            CONSTRAINT uq_source_name UNIQUE (name),
            {not_empty("name")},
            {web_address("website")},
            CONSTRAINT ck_source_category_one_of CHECK (category IN (
                'governing body', 'championship', 'organiser', 'promoter', 'track', 'club',
                'regional organisation', 'results database', 'news publication',
                'community website', 'social media page', 'historical archive'
            )),
            CONSTRAINT ck_source_collection_method_one_of CHECK (collection_method IN (
                'official api', 'structured feed', 'rss feed', 'public dataset',

"""Tests of the table of the collection runs, against a real SQLite file.

The store of every test is built by the migrations, as a real store is.
What the table must refuse is also written past the model.
"""

from collections.abc import Iterator
from contextlib import contextmanager
from datetime import UTC, datetime, timedelta

import pytest
from sqlalchemy import Engine, delete, select
from sqlalchemy.exc import IntegrityError

from motosphere.db.models import CollectionRun, Source
from motosphere.db.models.collection_run import RunOutcome
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.work import unit_of_work

STARTED = datetime(2026, 11, 23, 6, 0, tzinfo=UTC)
ENDED = STARTED + timedelta(minutes=4)
START = "2026-11-23T06:00:00.000000+00:00"
END = "2026-11-23T06:04:00.000000+00:00"
BEFORE = "2026-11-23T05:59:59.999999+00:00"
MOMENT = "2026-11-23T06:05:00.000000+00:00"
BROKEN_KEY = "FOREIGN KEY constraint failed"
COUNTS = ["records_seen", "records_added", "records_changed", "records_unchanged"]
# A run of each outcome that the table takes: its end and its error.
TAKEN = {
    "running": (None, None),
    "succeeded": (END, None),
    "failed": (END, "The feed did not answer."),
    "interrupted": (None, None),
}


@contextmanager
def refused(why: str) -> Iterator[None]:
    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:
        yield
    assert str(refusal.value.orig) == why


def a_source(store: Engine, name: str = "Example Federation") -> int:
    """Store a source, and give its key."""
    source = Source(
        name=name,
        website="https://federation.example",
        category=SourceCategory.GOVERNING_BODY,
        collection_method=CollectionMethod.RSS,
    )
    with unit_of_work(store) as work:
        work.add(source)
    return source.id


def write(store: Engine, **given: object) -> None:
    """Write a run past the model, as plain SQL: a running run, but for what is given."""
    row: dict[str, object] = {
        "source_id": 1,
        "started_at": START,
        "ended_at": None,
        "outcome": "running",
        "records_seen": 0,
        "records_added": 0,
        "records_changed": 0,
        "records_unchanged": 0,
        "error": None,
        "created_at": MOMENT,
        "updated_at": MOMENT,
    }
    assert set(given) <= set(row)
    row.update(given)
    with store.begin() as connection:
        connection.exec_driver_sql(
            f"INSERT INTO collection_run ({', '.join(row)}) "  # noqa: S608
            f"VALUES ({', '.join('?' * len(row))})",
            tuple(row.values()),
        )


def held(store: Engine) -> list[tuple[object, ...]]:
    """What the table holds, as SQLite holds it, by the key, without the two times."""
    with store.connect() as connection:
        found = connection.exec_driver_sql(
            "SELECT source_id, started_at, ended_at, outcome, records_seen, records_added, "
