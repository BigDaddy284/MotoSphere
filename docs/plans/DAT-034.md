## Objective

Any column type can bring the check for its column: `Base` gives that
check to the table and `broken_rules` names a column whose table is
without it, for every such type, so that a new type of this kind needs no
change to either.

## Why

The first real table is next (the information sources, DAT-006), and it
needs kinds of column the store does not have yet: one that is yes or no,
one whose value is one of a fixed list, one that is a web address. Each is
narrower than any type of a strict table, so each is kept by a check, as
text that must not be empty is (DAT-030).

Today `Base` and `broken_rules` know that one type by its name: `Base`
gives a table the check `not_empty` gives, for every column of the type
`NotEmptyText`, and `broken_rules` asks for exactly that check. A second
such type would need both changed again, and a third again. This task
turns the two places into one rule that asks the column's type, and so
the three types that follow are each one small module and its tests
(PLAN-021, in `PROGRESS.md`).

## Design in short

- **One new module, `motosphere.db.checks`, with one class.** A column
  type that brings a check is a subclass of `WithItsCheck`, beside its
  SQLAlchemy type, and says three things:
  - `check_for(name)` gives the check for the column called `name`: with
    the last part of its name, and belonging to no table yet;
  - `refuses`, what the check refuses, as the words of a sentence
    (`"empty text"`);
  - `given_by`, the name of the function that gives the check
    (`"not_empty"`), for whoever has to give it to a table by hand.
- **`NotEmptyText` becomes such a type.** Its `check_for` gives the
  check of `not_empty`, which stays as it is. Nothing else in
  `motosphere.db.texts` changes.
- **`Base` asks the type.** Where it gave the check of `not_empty` to
  every column of the type `NotEmptyText`, it gives
  `column.type.check_for(column.name)` to every column whose type is a
  `WithItsCheck`.
- **`broken_rules` asks the type**, in the same way, and writes its
  sentence with the type's two words. For text that must not be empty the
  sentence is letter for letter what it was.
- **A type that says it brings a check and gives none is an error**
  (`NotImplementedError`, from `WithItsCheck.check_for`), when a model
  with a column of it is defined and when `broken_rules` is asked.
- No new package, no model, no table, no migration. Nothing a model says
  changes: `Mapped[NotEmpty]` is as before.

## What the trial settled

- **No existing test changes.** With the three files of code changed and
  no test touched, all 492 backend tests passed: for text that must not
  be empty, nothing that could be observed is different. That is the
  proof that the change keeps what was there, and the reason the sentence
  of `broken_rules` keeps its words.
- **Why the type says `given_by`.** The sentence of `broken_rules` tells
  whoever reads it which function gives the missing check. To keep that
  sentence as it was, the type has to say the function's name. One test
  holds the word to the real name of the function.
- **How the new rule is proven without a second real type.** With a
  column type of the tests' own, `ShoutedText` (text in large letters
  only): a table made by hand in the unit tests, and a model with a real
  SQLite file in the integration tests. The next three tasks each bring a
  real type; none of them changes `Base` or `broken_rules`.
- **What the pair `_without_their_check` returns.** The column's name and
  its type, so that `broken_rules` can write the sentence in the type's
  words without asking again whether the type brings a check.

### 1. `backend/src/motosphere/db/checks.py` – new, the whole file

```python
"""Column types that bring a check.

A strict table knows a handful of types, and much of what the store must
promise of a column is narrower than any of them: text that is not empty
is narrower than TEXT. Such a promise is kept by a check in the table, so
that SQLite itself refuses the row, whoever writes it.

A column type that is a subclass of :class:`WithItsCheck`, beside its
SQLAlchemy type, brings the check for its column. ``Base`` gives that
check to the table of every model that has a column of such a type, and
``broken_rules`` names a column of such a type whose table is without it.
A new type of this kind therefore needs no change to either.
"""

from typing import ClassVar

from sqlalchemy import CheckConstraint

__all__ = ["WithItsCheck"]


class WithItsCheck:
    """What a column type is a subclass of, beside its SQLAlchemy type, when it brings a check."""

    # What the check refuses, as the words of a sentence: "empty text".
    refuses: ClassVar[str]
    # The name of the function that gives the check, for whoever must give
    # it to a table by hand: "not_empty".
    given_by: ClassVar[str]

    def check_for(self, name: str) -> CheckConstraint:
        """Give the check for the column called ``name``.

        The check has the last part of its name, which the naming rule
        completes once the check is given to a table, and belongs to no
        table until then.
        """
        raise NotImplementedError
```

### 2. `backend/tests/integration/test_checks.py` – new, the whole file, 4 tests

```python
"""Tests of a column type that brings a check, with a table made in a real SQLite file.

The type and the model here are made for the tests. The model is a
subclass of the real ``Base``, so it proves what ``Base`` gives a column
of any type that brings a check, but it is kept in a schema of its own
(``Proof.metadata``), so the real schema never sees it.
"""

import pytest
from sqlalchemy import CheckConstraint, Engine, MetaData, Text, column, func
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.checks import WithItsCheck
from motosphere.db.texts import NotEmpty
from motosphere.db.work import unit_of_work


class ShoutedText(WithItsCheck, Text):
    """A column type of the tests' own that brings a check: text in large letters only."""

    refuses = "small letters"
    given_by = "shouted"

    def check_for(self, name: str) -> CheckConstraint:
        return CheckConstraint(column(name) == func.upper(column(name)), name=f"{name}_shouted")


class Proof(Base):
    """A model of the tests' own, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofSign(Proof):
    __tablename__ = "proof_sign"

    code: Mapped[str] = mapped_column(ShoutedText)
    # A column of the type the store has had so far, between two of the new one.
    name: Mapped[NotEmpty]
    # No value, or text in large letters.
    tag: Mapped[str | None] = mapped_column(ShoutedText)


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the table of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def codes(made: Engine) -> list[tuple[str, str | None]]:
    """The code and the tag of every sign the file holds, read without the model."""
    with made.connect() as connection:
        rows = connection.exec_driver_sql("SELECT code, tag FROM proof_sign ORDER BY id").all()
    return [(str(code), None if tag is None else str(tag)) for code, tag in rows]


def test_base_gives_the_table_the_check_of_every_column_whose_type_brings_one(
    made: Engine,
) -> None:
    assert broken_rules(Proof.metadata) == []

    with made.connect() as connection:
        written = str(
            connection.exec_driver_sql(
                "SELECT sql FROM sqlite_master WHERE name = 'proof_sign'"
            ).scalar_one()
        )

    checks = [line.strip().rstrip(",") for line in written.splitlines() if "CHECK" in line]
    assert [check.split(" CHECK ")[0] for check in checks] == [
        "CONSTRAINT ck_proof_sign_code_shouted",
        "CONSTRAINT ck_proof_sign_name_not_empty",
        "CONSTRAINT ck_proof_sign_tag_shouted",
    ]
    assert checks[0] == "CONSTRAINT ck_proof_sign_code_shouted CHECK (code = upper(code))"
    assert checks[2] == "CONSTRAINT ck_proof_sign_tag_shouted CHECK (tag = upper(tag))"


def test_sqlite_takes_what_the_check_of_the_type_allows(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add(ProofSign(code="STOP", name="Stop", tag=None))
        work.add(ProofSign(code="GO", name="Go", tag="GREEN"))

    assert codes(made) == [("STOP", None), ("GO", "GREEN")]


@pytest.mark.parametrize(
    ("code", "tag", "refused_by"),
    [("Stop", None, "code"), ("STOP", "red", "tag")],
    ids=["in a column that must have a value", "in a column that may be without one"],
)
def test_sqlite_refuses_what_the_check_of_the_type_refuses(
    made: Engine, code: str, tag: str | None, refused_by: str
) -> None:
    refusal = f"CHECK constraint failed: ck_proof_sign_{refused_by}_shouted"
    signs = [
        ProofSign(code="GO", name="Go", tag=None),
        ProofSign(code=code, name="Stop", tag=tag),
    ]

    with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
        work.add_all(signs)

    assert codes(made) == []
```
