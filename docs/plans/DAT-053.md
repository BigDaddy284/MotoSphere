## Objective

One function puts what a source says of a field of a stored record
into the review queue, and a doubt that is there already stays one
item.

## Why

"Use review queues when information conflicts." (CLAUDE.md §11). The
queue can be given a possible duplicate (DAT-051), but not yet the
other two kinds of doubt the table knows: that the sources disagree
about a field, and that a source says something the rules of the
field refuse. The code that collects needs one call for "this source
says this of that field, and I cannot settle it": a call that takes
the record as it is, cannot name a field the table does not have,
keeps what the source said letter for letter, and can be made again
by the next run without asking a person twice.

## What this task is, and what it is not

- **It is** one function, `open_field_doubt`, added to
  `motosphere.db.review`, and its tests.
- **It is** two rules that `open_possible_duplicate` already has in
  its own lines, which records and which tables are taken, said once
  in two small functions of the module that both functions ask. The
  sentences and the behaviour of `open_possible_duplicate` are what
  they were; its 54 tests are unchanged and pass.
- **It is** one name made public: the list of the three columns that
  are the store's own in every table, `_THE_STORES_OWN` in
  `motosphere.db.changes`, becomes `THE_STORES_OWN`, so that the
  second module that needs it does not keep a copy.
- **It is not** anything that decides an item or keeps a decision
  (DAT-052), nor anything that applies what a source says to a record.
- No table, column, check, index or migration changes. The schema
  stays at version 9.

## Design in short

    def open_field_doubt(
        work: Session, record: Base, field: str, *,
        kind: ReviewKind, source: int, address: str, says: str, reason: str,
    ) -> ReviewItem:

- **Given the record itself.** The name of its table and its key are
  taken from it, as in `open_possible_duplicate` and `change`.
- **The source is given by its key**, as `change` is given the key of
  a run. The code that collects has the key of its source at hand and
  need not read the row.
- **What the source says is text, exactly**, and kept letter for
  letter.
- **The doubt that is there is given back as it is.** One statement
  looks for an item of this table, this key, this field, this source
  and this text. If there is one, it is returned and nothing is
  written, whatever its state, its kind, its address and its reason.
  If not, one open item is added, written to the unit of work, and
  returned.
- **Six refusals before anything is written**, each with one
  sentence: a record that is not stored or not of this unit of work;
  a row of a table that holds no collected records; the kind of a
  possible duplicate; a column that is the store's own; a field the
  table does not have (each a `ValueError`); and something said that
  is not text (a `TypeError`).
- **Part of the unit of work.** It is written (`work.flush()`) before
  the function returns, and kept or taken back with the unit.

## What the task left open, and what the trial settled

- **Must the field be a column of the record's table?** Yes, by its
  name as the model says it, letter for letter. A doubt about a field
  the table does not have could never be applied, and a misspelled
  name would wait in the queue for a person to find. The function
  asks the model of the record (`inspect(record).mapper.columns`), so
  it names no table and no column itself.
- **Are the three columns that are the store's own refused?** Yes:
  `id`, `created_at` and `updated_at`, which `change` refuses to
  change. No source says what they hold. The list is the one `change`
  uses, which is why its name becomes public; a copy in the second
  module could come to differ.
- **How is the source given, and what is said of one that is not
  there?** By its key. A key that is no source is refused by the
  store at the call, by the reference the table has
  (`FOREIGN KEY constraint failed`), and the unit of work fails as a
  whole. The function does not read the source first to say so in its
  own words: that would be one statement more at every call for a
  mistake that only code can make, and the store refuses it anyway.
- **In which form is what the source says given and kept?** As text,
  as the source said it (DAT-010). Only exactly text is taken
  (`type(says) is not str`): a number, yes or no, bytes, nothing at
  all and a class of its own that derives from `str` are each
  refused with a `TypeError`. The function does not make text of a
  number, because there are several ways to and the code that
  collects knows which one the source used. Empty text is taken: it
  is what a source says when it says nothing of the field.
- **Is a doubt of the kind "sources disagree" refused where the record
  already holds what the source says?** No. The function does not
  look at what the record holds at all. A source says a thing in its
  own words (`1750 m`, `1.75 km`) and the record holds it in the
  store's (`1750`), so the function cannot tell whether they agree,
  and a comparison of the two texts would be right only by accident.
  The code that collects has read the source and knows. A test stores
  such a doubt for both kinds, so that this is on record.
- **Which kinds are taken?** The two that are about a field. The kind
  of a possible duplicate is refused in a sentence that names the
  function to call; the table's own check would refuse it too, later
  and in SQLite's words.
- **What is the same doubt?** What the index of DAT-050 says: the
  table, the key, the field, the source and what it says. The kind,
  the address and the reason given the second time are not read, so
  one the store would refuse in a new item is not refused there; five
  tests hold that. A decided item counts and is given back as it was
  decided.
- **What does the function share with `open_possible_duplicate`?** The
  two rules that are true of both: only records that are stored and
  that this unit of work read or stored, and no row of a table on the
  list `NOT_COLLECTED`. They are now `_must_be_stored(work, *records)`
  and `_must_hold_collected_records(table)`, with the sentences they
  had. Nothing else is shared: the look and the new item differ in
  every column but the table.
- **In which order are the refusals said?** Stored first, then the
  table, then the kind, then the field, then what is said. A row of a
  table without collected records is refused for its table before
  its field is looked at: the test gives such a row with the field
  `created_at`, which every table has and which is the store's own,
  and holds that the sentence is the one about the table.
- **What refuses a bad address and an empty reason?** The store, by
  the checks the table has, at the call. The function does not say
  those rules a second time.
- **Can another connection store the same doubt between the look and
  the write?** No, for the reason found in DAT-051: SQLite says
  "database is locked" to it. A test tries it for this function too,
  on both machines.
- **Is the look answered by the index of DAT-050?** Yes. The test
  takes the statement the function really sends and reads SQLite's
  plan for it: one search of
  `ix_review_item_record_table_record_id_field_source_id_source_value`.
  It also holds that the function sends one statement where the doubt
  is there, and two where it is new.

def a_doubt(**given: object) -> tuple[object, ...]:
    """A doubt about a field that nobody has decided, as the table holds it without its times."""
    row: dict[str, object] = {
        "kind": "sources disagree",
        "record_table": "proof_venue",
        "record_id": 1,
        "other_record_id": None,
        "field": "length_in_metres",
        "source_id": 1,
        "source_address": ADDRESS,
        "source_value": SAYS,
        "reason": REASON,
        "state": "open",
        "decided_by": None,
        "decided_at": None,
        "note": None,
    }
    assert set(given) <= set(row)
    row.update(given)
    return tuple(row.values())


def held(store: Engine) -> list[tuple[object, ...]]:
    """What the queue holds, as SQLite holds it, by the key, without the key and the times."""
    with store.connect() as connection:
        return [tuple(row) for row in connection.exec_driver_sql(WHAT_IT_HOLDS)]


def everything(store: Engine) -> list[tuple[object, ...]]:
    """Every column of every item, as SQLite holds it, by the key."""
    with store.connect() as connection:
        return [tuple(row) for row in connection.exec_driver_sql(EVERYTHING_IT_HOLDS)]


def rows_of(store: Engine, statement: str) -> list[tuple[object, ...]]:
    """What a plain statement finds in the file."""
    with store.connect() as connection:
        return [tuple(row) for row in connection.exec_driver_sql(statement)]


def asked(work: Session, record: Base, **given: Any) -> ReviewItem:
    """Open the doubt of the tests about a record, but for what is given."""
    said: dict[str, Any] = {
        "field": "length_in_metres",
        "kind": ReviewKind.SOURCES_DISAGREE,
        "source": 1,
        "address": ADDRESS,
        "says": SAYS,
        "reason": REASON,
    }
    assert set(given) <= set(said)
    said.update(given)
    return open_field_doubt(work, record, said.pop("field"), **said)


def opened(store: Engine, venue: int = 1, **given: Any) -> ReviewItem:
    """Open the doubt of the tests about a venue in a unit of work of its own."""
    with unit_of_work(store) as work:
        return asked(work, work.get_one(ProofVenue, venue), **given)

@pytest.mark.parametrize("kind", OF_A_FIELD)
def test_a_doubt_about_a_field_is_one_open_item_that_names_what_the_source_says(
    made: Engine, clock: list[datetime], kind: ReviewKind

    item = opened(made, kind=kind)

    # open, and nothing else is said of it.

    # One reading of the clock: the item was stored at that moment.
    assert len(clock) == before + 1
    moment = times.to_text(clock[-1])
    assert rows_of(made, "SELECT id, created_at, updated_at FROM review_item") == [
        (1, moment, moment)

    assert (item.id, item.kind, item.record_table, item.record_id, item.other_record_id) == (
        1,
        kind,
        "proof_venue",
        1,
        None,
    )
    assert (item.field, item.source_id, item.source_address, item.source_value) == (
        "length_in_metres",
        1,
        ADDRESS,
        SAYS,
    )
    assert (item.reason, item.state, item.decided_by, item.decided_at, item.note) == (
        REASON,
        ReviewState.OPEN,
        None,
        None,
        None,
    )
    assert item.created_at == item.updated_at == clock[-1]

@pytest.mark.parametrize("state", ["accepted", "rejected"])
def test_a_doubt_that_was_decided_is_given_back_as_it_was_decided(
    made: Engine, clock: list[datetime], state: str
) -> None:
    opened(made)
    with made.begin() as connection:
        connection.exec_driver_sql(
            "UPDATE review_item SET state = ?, decided_by = 'Jo Example', decided_at = ?, "
            "note = 'Measured on the map.'",

    before = everything(made)
    read = len(clock)

    again = opened(made, reason="Found again by the next run.")

    # A question a person has answered is not put to them again: no new

    assert (again.id, again.state, again.decided_by, again.note) == (
        1,
        ReviewState(state),
        "Jo Example",
        "Measured on the map.",

    assert again.decided_at == datetime(2026, 11, 26, 9, 0, tzinfo=UTC)
    assert again.reason == REASON
    assert everything(made) == before
    assert len(before) == 1
    assert len(clock) == read

def test_the_same_thing_said_of_another_record_is_another_doubt(made: Engine) -> None:

def sent_by(store: Engine, call: Callable[[], object]) -> list[tuple[str, Sequence[object]]]:
    """Every statement a call sends to the store, with what it is given."""
    sent: list[tuple[str, Sequence[object]]] = []

    def remember(
        _connection: Connection,
        _cursor: object,
        statement: str,
        given: Sequence[object],
        _context: object,
        _many: bool,
    ) -> None:
        sent.append((statement, given))

    event.listen(store, "before_cursor_execute", remember)
    try:
        call()
    finally:
        event.remove(store, "before_cursor_execute", remember)
    return sent


def plan_of(store: Engine, statement: str, given: Sequence[object]) -> list[str]:
    """SQLite's own account of how it will answer a statement, step by step."""
    with store.connect() as connection:
        steps = connection.exec_driver_sql("EXPLAIN QUERY PLAN " + statement, tuple(given))
        return [str(step[3]) for step in steps]

    made: Engine,

    # store the same doubt in between, the write would be refused. SQLite

        _context: object,
        _many: bool,
    ) -> None:
