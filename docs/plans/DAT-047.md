## Objective

One function changes a field of a stored record and writes what the
field held before to the table of the changes, in the same unit of
work, so that neither exists without the other.

## Why

DAT-009 made the place where an old value is kept. Nothing writes into
it yet, and a table of history that code may or may not fill is no
history. The function is the one way a record is changed: it decides
whether a field changed at all, which text the old and the new value
have, and it writes the change and its history together. It comes
before the first table of records (DAT-011), so that the first code
that changes a record already has it.

## Design in short

- **One new module, `motosphere.db.changes`, with one function:**

  ```python
  change(work, record, {"name": "Example Raceway"}, run=run)
  change(work, record, {"name": "Example Raceway"}, decided_by="Jo Example")
  ```

  It gives back the rows of `record_change` it wrote, in the order the
  fields were given; an empty list when nothing changed.
- **A field that holds the value already is left alone**: no row, and
  when no field differs the record is not touched at all.
- **Values are compared, and written to the history, as the text of
  what the store keeps.** The type of the column is asked, as it is
  asked when a row is written.
- **One reading of the clock for one call**: every row of the call has
  it as `created_at`, and the record as `updated_at`.
- **Everything the function can tell is refused before anything is
  changed**; what only SQLite can tell is refused when the function
  writes, which it does before it returns, and the unit of work then
  fails as a whole.
- No table, no migration, no new package, and no existing file of code
  or tests changes.

## What the task left open, and what the trial settled

- **Which text a value has.** The text of what the store keeps for
  it, which the column's own type says: a time, a day and a word of a
  list as the store's types write them, yes or no as `1` or `0`, a
  whole number as its digits, text as it is. The trial asks SQLite for
  `CAST(<field> AS TEXT)` before and after a change, for a column of
  every kind with and without a value (17 cases), and the history
  holds exactly those two texts. So nobody has to say the forms a
  second time in this module, and a new type of the store gets its
  text by itself, as long as it keeps text or a whole number.
- **How strict it is about kinds.** A column of text takes text and a
  column of whole numbers a whole number. SQLite makes `1750` of the
  text `"1750"` in a strict INTEGER column, `1` of yes, and `'7'` of
  the number 7 in a TEXT column; the function refuses all three, in
  one sentence, because the record in the code and the history would
  otherwise say what the store does not hold. The store's own types
  already refuse what is not theirs (a number for yes or no, plain
  text for a word of a list), and their sentences are left as they
  are.
- **A number with a fraction and bytes.** No text yet, and a change to
  a column that keeps either is refused in one sentence. A number with
  a fraction has more than one text, and the choice matters for
  coordinates; no real table has such a column, so there is nothing to
  try it on. The task that brings the first decides. A record that has
  such columns can have its other fields changed, which a test holds.
- **Whether the rows of one call carry the same moment.** They do, and
  the record's `updated_at` is that moment too: the clock is read
  once. The rows of one change are then found together, and a record's
  last change is the moment of its newest history. When nothing
  changes the clock is not read.
- **Which fields never go through the function.** `id`, `created_at`
  and `updated_at`: the store's own in every table.
- **The columns that say where a collected record came from** go
  through the function like any other field. A test changes a result
  with its address, day, moments and confidence in one call, as a
  collector will, and the history holds what belonged to the old
  value: "Historical information must retain its original date". The
  function does not decide whether a record that was merely seen again
  gets a row for `last_verified_at`: the code that collects decides,
  by what it gives.
- **A record that is stored for the first time has no history.** A
  record that was only added to the unit of work is refused, and taken
  once the unit of work has written it.
- **Whether the function writes at once.** It does (`flush`), so that
  what SQLite refuses is refused at the call and the rows it gives
  back have their keys. A refusal fails the unit of work as a whole,
  and a test holds that a unit which caught one cannot go on.
- **No first write before the comparing.** A field set by hand before
  the call is compared as the unit of work holds it, and written with
  everything else. The trial had a `flush` at the start and found that
  nothing could tell whether it was there, so it is not.
- **Nothing stops a change past the function**, and a test stores one
  so that this is on record. Holding every change to the function
  would need the session to refuse writes it did not see; no task asks
  for it, and DAT-048 is about the rows of the history, not about the
  records.
- **A row of the history is not a record to change.** Refused here in
  one sentence, so that the function never writes history about
  history; that nothing else edits or deletes a row is DAT-048.

- `motosphere.db.work`, `motosphere.db.base`, the models, the

- The real schema: unchanged, at version 5. Nothing calls the function

### 1. `backend/src/motosphere/db/changes.py` – new, the whole file

```python
"""Changing a record, with its history.

Nothing the store holds of a record is written over without a trace
(DESIGN.md 8, CLAUDE.md 11). :func:`change` is how a record that is
stored is changed. It gives the record its new values and adds one row
to the table of the changes for every field that then holds another
value, in the same unit of work. So a change and its history are kept
together or taken back together, and neither is there without the other.

A value is compared, and written to the history, as the text of what the
store keeps for it: a whole number as its digits, a time, a day and a
word of a list as the text the store's own types make of them, and yes
or no as 1 or 0.
"""

from collections.abc import Mapping
from typing import Any

from sqlalchemy import Column, Dialect, Integer, String, inspect
from sqlalchemy.orm import Session
from sqlalchemy.types import TypeDecorator

from motosphere.db import times
from motosphere.db.base import Base
from motosphere.db.models.record_change import RecordChange

__all__ = ["change"]

# The columns of every table that only the store's code sets.
_THE_STORES_OWN = ("id", "created_at", "updated_at")


def _as_the_store_keeps_it(
    table: str, column: Column[Any], value: object, dialect: Dialect
) -> str | None:
    """Give the text of what the store keeps for ``value`` in this column, or none for no value.

    The type of the column says what is kept: it is asked as it is asked
    when a row is written, so the text is the one the row holds. A column
    of text takes text and a column of whole numbers a whole number, and
    nothing that is merely like one. A column of numbers with a fraction
    or of bytes has no text here yet: no real table has one, and the
    task that brings the first says which text its values have.
    """
    kind = column.type.impl_instance if isinstance(column.type, TypeDecorator) else column.type
    wanted: type[int] | type[str]
    if isinstance(kind, Integer):
        wanted, what = int, "a whole number"
    elif isinstance(kind, String):
        wanted, what = str, "text"
    else:
        raise TypeError(
            f"The history has no text for what the column {table}.{column.name} keeps: it "
            "has one for text and for whole numbers, and for what the store's own types "
            "make of a time, a day, a word of a list and yes or no."
        )
    to_the_store = column.type.bind_processor(dialect)
    kept = value if to_the_store is None else to_the_store(value)
    if kept is None:
        return None
    # Exactly that, and not a subclass: yes is a whole number to Python,
    # and its text would be "True".
    if type(kept) is not wanted:
        raise TypeError(f"The column {table}.{column.name} keeps {what}, which {value!r} is not.")
    return str(kept)


def change(
    work: Session,
    record: Base,
    to: Mapping[str, object],
    *,
    run: int | None = None,
    decided_by: str | None = None,
) -> list[RecordChange]:
    """Give a stored record new values, and write what it held before to its history.

    ``to`` names the fields and what each shall hold now. A field that
    holds that already is left alone and gets no row. For every other
    field the record is changed and one row is added to the table of the
    changes, in the order the fields are given. The rows are given back,
    and there are none when nothing changed.

    What caused the change is said with it, and it is one of two: the key
    of the collection run that found the record changed at its source
    (``run``), or the name of the person who decided it (``decided_by``).

    The rows of one call are stored at one moment, and the record says
    it was last changed at that same moment. When nothing changed the
    record is not touched at all.

    Everything is part of the unit of work ``work`` and is written to it
    before the function returns, so what the store refuses is refused
    here. Whatever is refused, the unit of work fails as a whole, and
    neither the change nor its history is kept.

    Refused before anything is changed: a call that names no cause or
    both; a record that this unit of work did not read or store, or
    that is not stored yet, since a record that is stored for the first
    time has no history; a row of the history itself; a field its table
    does not have; and the three columns that are the store's own in
    every table.
    """
    if (run is None) == (decided_by is None):
        raise ValueError(
            "A change is caused by a collection run or decided by a person: "
            "say one of the two, and not both."
        )
    if isinstance(record, RecordChange):
        raise ValueError("The history is added to and never changed: its rows are not records.")
    state = inspect(record)
    if not state.persistent or state.session is not work:
        raise ValueError(
            "Only a record that is stored, and that this unit of work read or stored, is "
            "changed with its history. A record that is stored for the first time has none yet."
        )
    table = str(type(record).__tablename__)
    columns = state.mapper.columns
    for field in to:
        if field in _THE_STORES_OWN:
            raise ValueError(
                f"The column {field} is the store's own in every table: only the store's "
                "code sets it."
            )
        if field not in columns:
            raise ValueError(f"The table {table} has no column {field}.")

    dialect = work.get_bind().dialect
    different: list[tuple[str, object, str | None, str | None]] = []
    for field, value in to.items():
        before = _as_the_store_keeps_it(table, columns[field], getattr(record, field), dialect)
        after = _as_the_store_keeps_it(table, columns[field], value, dialect)
        if before != after:
            different.append((field, value, before, after))
    if not different:
        return []

    # One reading of the clock for the whole change.
    moment = times.now()
    written: list[RecordChange] = []
    for field, value, before, after in different:
        setattr(record, field, value)
        written.append(
            RecordChange(
                record_table=table,
                record_id=record.id,
                field=field,
                old_value=before,
                new_value=after,
                collection_run_id=run,
                decided_by=decided_by,
                created_at=moment,
            )
        )
    record.updated_at = moment
    work.add_all(written)
    work.flush()
    return written
```

def a_track(store: Engine, **given: Any) -> int:
    """Store a track through the model, and give its key."""
    said: dict[str, Any] = {
        "name": "Example Park",
        "length_in_metres": 1600,
        "opened_on": date(1998, 5, 1),
        "inspected_at": INSPECTED,
        "floodlit": False,
        "surface": Surface.SAND,
    }
    said.update(given)
    with unit_of_work(store) as work:
        track = ProofTrack(**said)
        work.add(track)
    return track.id


def a_run(store: Engine) -> int:
    """Store a source and a run of it, and give the key of the run. The source has the key 1."""
    with unit_of_work(store) as work:
        source = Source(
            name="Example Federation",
            website="https://federation.example",
            category=SourceCategory.GOVERNING_BODY,
            collection_method=CollectionMethod.HTML,
        )
        work.add(source)
        work.flush()
        run = CollectionRun(source_id=source.id, started_at=COLLECTED_AGAIN)
        work.add(run)
    return run.id


def in_the_file(store: Engine, table: str, key: int) -> dict[str, object]:
    """One row as SQLite holds it, by the names of its columns."""
    with store.connect() as connection:
        found = connection.exec_driver_sql(THE_ROW[table], (key,))
        return dict(found.mappings().one())


def history(store: Engine) -> list[tuple[object, ...]]:
    """The table of the changes as SQLite holds it, by the key, without the key."""
    with store.connect() as connection:
        return [tuple(row) for row in connection.exec_driver_sql(THE_HISTORY)]


def test_a_changed_field_is_in_the_record_and_its_old_value_in_the_history(
    made: Engine, clock: list[datetime]
) -> None:
    key = a_track(made)
    before = in_the_file(made, "proof_track", key)
    asked = len(clock)

    with unit_of_work(made) as work:
        track = work.get_one(ProofTrack, key)
        written = change(work, track, {"name": "Example Raceway"}, decided_by="Jo Example")

    # One reading of the clock: the row of the history was stored at that
    # moment, and the record says it was last changed at that moment.
    assert len(clock) == asked + 1
    moment = times.to_text(clock[-1])
    assert in_the_file(made, "proof_track", key) == {
        **before,
        "name": "Example Raceway",
        "updated_at": moment,
    }
    assert [row[:7] for row in history(made)] == [
        ("proof_track", key, "name", "Example Park", "Example Raceway", None, "Jo Example")
    ]
    assert [row[7:] for row in history(made)] == [(moment, moment)]
    assert [(row.id, row.field, row.old_value, row.new_value) for row in written] == [
        (1, "name", "Example Park", "Example Raceway")
    ]
    assert track.name == "Example Raceway"
    assert track.updated_at == written[0].created_at == clock[-1]


def test_a_change_to_three_fields_is_three_rows_of_one_moment_in_the_order_given(
    made: Engine, clock: list[datetime]
) -> None:
    key = a_track(made)
    asked = len(clock)

    with unit_of_work(made) as work:
        track = work.get_one(ProofTrack, key)
        written = change(
            work,
            track,
            {"surface": Surface.HARD_PACK, "name": "Example Raceway", "length_in_metres": 1750},

        )

    assert len(clock) == asked + 1
    moment = times.to_text(clock[-1])
    assert [row[:7] for row in history(made)] == [

        ("proof_track", key, "name", "Example Park", "Example Raceway", None, "Jo Example"),
        ("proof_track", key, "length_in_metres", "1600", "1750", None, "Jo Example"),

    assert [row[7:] for row in history(made)] == [(moment, moment)] * 3
    assert [row.id for row in written] == [1, 2, 3]

        "Example Raceway",

    assert row["updated_at"] == moment

+  two, as the table asks; a call that names neither or both is refused

+  row, and when no field differs the record is not touched at all: not

+  were given, and an empty list when there were none.

+  type of the column is asked for what it keeps, as it is asked when a
+  row is written, and the history holds the text of that:

+  |---|---|---|
+  | Text, also text that must not be empty and a web address | The text itself, letter for letter | `Example Park` |
