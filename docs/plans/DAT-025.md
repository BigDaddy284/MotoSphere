## Objective

One command says which schema the store has and whether it is the newest
the code knows, and changes nothing.

## Why

`migrate` (DAT-024) brings a store to the newest schema, and that is a
change. Whoever looks after the pipeline also needs to ask without
changing anything: is there a store where the settings point, is it up to
date, how far behind is it, would `migrate` take it at all? Until now the
only way to find out was to run `migrate` and see what it did.

This is the fourth fifth of the old "DAT-004 – Schema migrations"
(PLAN-014, in `PROGRESS.md`). The function it asks, `pending`, was made
for it in DAT-027 (PLAN-016).

## Design in short

- **The command is `python -m motosphere schema`.** It takes no argument:
  the store is the file `MOTOSPHERE_STORE_PATH` names. (The name is
  shorter than `version` and `migrate`, so the list of commands in the
  help keeps its columns and no existing test of the help changes.)
- One new module, `motosphere.cli.schema`, built like
  `motosphere.cli.migrate`: `add_parser` registers the command, `run` does
  the work, `report` makes the sentence. `motosphere.cli.app` registers it
  between `migrate` and `version`.
- **It never writes.** `open_store` makes a file that is not there, so
  the command looks first: where the path names nothing, it says so and
  does not call `open_store`. Otherwise it opens the store and asks
  `pending` (DAT-027), which only reads.
- **What it says**, in one sentence on standard output, with the file's
  whole path, and the exit code 0:
  - there is no file: "There is no data store: <file> does not exist."
  - the store lacks nothing: "The data store is up to date: <file> is at
    schema version N." (the sentence `migrate` has for the same state)
  - the store lacks migrations: "The data store lacks 2 migrations: <file>
    is at schema version 3, and the newest is version 5." (and "1
    migration" for one)
- **A store that cannot be opened (`StoreError`) or that `migrate` would
  refuse (`SchemaError`)** gives that same sentence on standard error,
  with nothing before or after it, and the exit code 1
  (`EXIT_STORE_REFUSED`, which the command takes from
  `motosphere.cli.migrate`: it is the same refusal). Nothing is written
  to standard output. So "would `migrate` take this file?" is answered by
  the exit code, and the two commands cannot come to disagree, because
  both ask `pending`.
- **The exit codes:** 0 when the command could say which schema the store
  has, or that there is none; 1 when the file there is refused; 2 stays
  what it is everywhere: wrong arguments or wrong settings.
- **No log line**, as with `migrate`.
- The pipeline's list of migrations is still empty. So today the command
  says "There is no data store: …" or "… is up to date: … is at schema
  version 0." That is right, and the tests that run the command in a
  process of its own check exactly that, written so that they stay right
  when the first migration is added (`len(MIGRATIONS)`).
- No new package.

### 1. `backend/src/motosphere/cli/schema.py` – new, the whole file

```python
"""The ``schema`` command: say which schema the data store has, and change nothing."""

import argparse
import sys

from motosphere.cli.migrate import EXIT_STORE_REFUSED
from motosphere.core.settings import Settings
from motosphere.db.migrations import SchemaError, pending, schema_version
from motosphere.db.store import StoreError, open_store

__all__ = ["add_parser", "report", "run"]


def add_parser(commands: "argparse._SubParsersAction[argparse.ArgumentParser]") -> None:
    """Register the ``schema`` command."""
    parser = commands.add_parser(
        "schema",
        help="say which schema the data store has",
        description=(
            "Say which schema the data store has, and whether it is the newest. Nothing is "
            "changed, and no file is made. The store is the file the setting "
            "MOTOSPHERE_STORE_PATH names."
        ),
        allow_abbrev=False,
    )
    parser.set_defaults(handler=run)


def report(path: str, version: int | None, lacking: int) -> str:
    """Say in one sentence which schema the store at ``path`` has.

    ``version`` is the store's schema version, or ``None`` where there is
    no file, and ``lacking`` is the number of migrations the store lacks.
    """
    if version is None:
        return f"There is no data store: {path} does not exist."
    if lacking == 0:
        return f"The data store is up to date: {path} is at schema version {version}."
    migrations = "1 migration" if lacking == 1 else f"{lacking} migrations"
    return (
        f"The data store lacks {migrations}: {path} is at schema version {version}, "
        f"and the newest is version {version + lacking}."
    )


def run(_arguments: argparse.Namespace, settings: Settings) -> int:
    """Write which schema the store has to standard output, and write nothing else anywhere.

    Where there is no file, the command says so and makes none. A store
    that ``migrate`` would refuse, or that cannot be opened, gives the same
    sentence on standard error and the same exit code 1 as there.
    """
    path = settings.store_path.resolve()
    if not path.exists():
        # open_store would make the file.
        sys.stdout.write(report(str(path), None, 0) + "\n")
        return 0
    try:
        store = open_store(path)
        lacking = pending(store)
    except (StoreError, SchemaError) as error:
        sys.stderr.write(f"{error}\n")
        return EXIT_STORE_REFUSED

    sys.stdout.write(report(str(path), schema_version(store), len(lacking)) + "\n")
    return 0
```

```python
"""Tests of what the ``schema`` command says, and of its place in the command line."""

import pytest

from motosphere.cli import main
from motosphere.cli.schema import report

STORE = "/data/store.sqlite3"


@pytest.mark.parametrize(
    ("version", "lacking", "sentence"),
    [
        (None, 0, f"There is no data store: {STORE} does not exist."),
        (0, 0, f"The data store is up to date: {STORE} is at schema version 0."),
        (5, 0, f"The data store is up to date: {STORE} is at schema version 5."),
        (
            0,
            1,
            f"The data store lacks 1 migration: {STORE} is at schema version 0, "
            "and the newest is version 1.",
        ),
        (
            1,
            2,
            f"The data store lacks 2 migrations: {STORE} is at schema version 1, "
            "and the newest is version 3.",
        ),
        (
            2,
            3,
            f"The data store lacks 3 migrations: {STORE} is at schema version 2, "
            "and the newest is version 5.",
        ),
    ],
    ids=[
        "no file",
        "up to date, no migration yet",
        "up to date",
        "lacks one",
        "lacks two",
        "lacks three",
    ],
)
def test_the_report_says_which_schema_the_store_has(
    version: int | None, lacking: int, sentence: str
) -> None:
    assert report(STORE, version, lacking) == sentence


def test_schema_is_in_the_help(capsys: pytest.CaptureFixture[str]) -> None:
    with pytest.raises(SystemExit) as exit_info:
        main(["--help"])

    assert exit_info.value.code == 0
    assert "schema    say which schema the data store has" in capsys.readouterr().out


def test_schema_has_its_own_help(capsys: pytest.CaptureFixture[str]) -> None:
    with pytest.raises(SystemExit) as exit_info:
        main(["schema", "--help"])

    assert exit_info.value.code == 0
    captured = capsys.readouterr()
    assert captured.out.startswith("usage: python -m motosphere schema")
    assert "Say which schema the data store has" in captured.out
    assert "MOTOSPHERE_STORE_PATH" in captured.out
    assert captured.err == ""


def test_schema_takes_no_argument(capsys: pytest.CaptureFixture[str]) -> None:
    with pytest.raises(SystemExit) as exit_info:
        main(["schema", "now"])

    assert exit_info.value.code == 2
    captured = capsys.readouterr()
    assert captured.out == ""
    assert captured.err.startswith("usage: python -m motosphere ")
    assert "now" in captured.err
```

### 3. `backend/tests/integration/test_schema_command.py` – new, the whole file, 12 tests

```python
"""Tests of the ``schema`` command with a history of migrations, against a real SQLite file.

Like the tests of ``migrate`` in ``test_migrate_command.py``, these call
:func:`motosphere.cli.main` in the test's process, with a list of
migrations of their own in the place of the pipeline's, which is still
empty. The store is a real file, and nothing else is replaced.
``test_command_line.py`` runs the command in a process of its own, with the
pipeline's list.

The command must never write. So every test that gives it a file compares
the file byte for byte, and the test without a file looks for one
afterwards.
"""

import logging
import sqlite3
from collections.abc import Iterator
from contextlib import closing
from pathlib import Path

import pytest
from sqlalchemy import Connection

from motosphere.cli import main
from motosphere.core.logging_config import HANDLER_NAME
from motosphere.db import migrations
from motosphere.db.migrations import APPLICATION_ID, Migration


@pytest.fixture(autouse=True)
def _restore_root_logger() -> Iterator[None]:
    """Undo every change main() makes to the root logger."""
    root = logging.getLogger()
    original_level = root.level
    yield
    for handler in [handler for handler in root.handlers if handler.name == HANDLER_NAME]:
        root.removeHandler(handler)
    root.setLevel(original_level)


def make(table: str) -> Migration:
    def migration(connection: Connection) -> None:
        connection.exec_driver_sql(f"CREATE TABLE {table} (id INTEGER PRIMARY KEY)")

    return migration


THREE = (make("first"), make("second"), make("third"))


@pytest.fixture
def place(tmp_path: Path, monkeypatch: pytest.MonkeyPatch) -> Path:
    """Where the settings say the store is: a file and a folder that are not there yet."""
    path = tmp_path / "data" / "store.sqlite3"
    monkeypatch.setenv("MOTOSPHERE_STORE_PATH", str(path))
    return path.resolve()


def history(monkeypatch: pytest.MonkeyPatch, *the_migrations: Migration) -> None:
    monkeypatch.setattr(migrations, "MIGRATIONS", the_migrations)


def with_sqlite_alone(path: Path, *statements: str) -> None:
    """Make the file at ``path`` as another program would: with SQLite and nothing else."""
    path.parent.mkdir(parents=True)
    with closing(sqlite3.connect(path, autocommit=True)) as connection:
        for statement in statements:
            connection.execute(statement)


def test_where_there_is_no_store_the_command_says_so_and_makes_none(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE)

    assert main(["schema"]) == 0

    captured = capsys.readouterr()
    assert captured.out == f"There is no data store: {place} does not exist.\n"
    assert captured.err == ""
    assert not place.exists()
    assert not place.parent.exists()


def test_a_store_at_the_newest_schema_is_up_to_date(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE)
    main(["migrate"])
    capsys.readouterr()
    before = place.read_bytes()

    assert main(["schema"]) == 0

    captured = capsys.readouterr()
    assert captured.out == f"The data store is up to date: {place} is at schema version 3.\n"
    assert captured.err == ""
    assert place.read_bytes() == before
    assert list(place.parent.iterdir()) == [place]


@pytest.mark.parametrize(
    ("had", "sentence"),
    [
        (0, "lacks 3 migrations: {place} is at schema version 0, and the newest is version 3."),
        (1, "lacks 2 migrations: {place} is at schema version 1, and the newest is version 3."),
        (2, "lacks 1 migration: {place} is at schema version 2, and the newest is version 3."),
    ],
    ids=["a new, empty file", "one of three", "two of three"],
)
def test_a_store_that_lacks_migrations_is_told_how_many_and_is_not_given_them(
    had: int,
    sentence: str,
    place: Path,
    monkeypatch: pytest.MonkeyPatch,
    capsys: pytest.CaptureFixture[str],
) -> None:
    history(monkeypatch, *THREE[:had])
    main(["migrate"])
    capsys.readouterr()
    before = place.read_bytes()
    history(monkeypatch, *THREE)

    assert main(["schema"]) == 0

    captured = capsys.readouterr()
    assert captured.out == "The data store " + sentence.format(place=place) + "\n"
    assert captured.err == ""
    assert place.read_bytes() == before
    assert list(place.parent.iterdir()) == [place]


@pytest.mark.parametrize(
    "statements",
    [
        ["CREATE TABLE theirs (id INTEGER PRIMARY KEY)"],
        ["PRAGMA application_id = 1196444487"],
        [f"PRAGMA application_id = {APPLICATION_ID}", "PRAGMA user_version = 4"],
        [f"PRAGMA application_id = {APPLICATION_ID}", "PRAGMA user_version = -1"],
    ],
    ids=[
        "the database of another program",
        "the mark of another application",
        "a store newer than the code",
        "a version below zero",
    ],
)
def test_a_store_migrate_would_refuse_is_refused_in_the_same_words_and_left_as_it_is(
    statements: list[str],
    place: Path,
    monkeypatch: pytest.MonkeyPatch,
    capsys: pytest.CaptureFixture[str],
) -> None:
    history(monkeypatch, *THREE)
    with_sqlite_alone(place, *statements)
    before = place.read_bytes()

    code = main(["schema"])

    said = capsys.readouterr()
    assert place.read_bytes() == before
    assert main(["migrate"]) == 1
    refusal = capsys.readouterr()
    assert code == 1
    assert said.out == ""
    assert said.err == refusal.err


def test_a_file_that_is_no_database_is_refused_in_one_line_and_left_as_it_is(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE)
    place.parent.mkdir()
    place.write_bytes(b"These are notes, not a database.\n" * 40)

    assert main(["schema"]) == 1

    captured = capsys.readouterr()
    assert captured.out == ""
    assert captured.err.startswith(
        f"The data store cannot be opened: {place} cannot be read as an SQLite database ("
    )
    assert captured.err.count("\n") == 1
    assert place.read_bytes() == b"These are notes, not a database.\n" * 40


def test_a_folder_where_the_store_should_be_is_refused_in_one_line(
    place: Path, capsys: pytest.CaptureFixture[str]
) -> None:
    place.mkdir(parents=True)

    assert main(["schema"]) == 1

    captured = capsys.readouterr()
    assert captured.out == ""
    assert captured.err == f"The data store cannot be opened: {place} is a folder, not a file.\n"
    assert list(place.iterdir()) == []


def test_a_relative_store_path_is_taken_from_the_current_folder(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    # The shared fixture has made tmp_path the current folder.
    monkeypatch.setenv("MOTOSPHERE_STORE_PATH", "data/store.sqlite3")
    history(monkeypatch, *THREE)
    place = (tmp_path / "data" / "store.sqlite3").resolve()

    assert main(["schema"]) == 0
    assert capsys.readouterr().out == f"There is no data store: {place} does not exist.\n"

    main(["migrate"])
    capsys.readouterr()

    assert main(["schema"]) == 0
    assert capsys.readouterr().out == (
        f"The data store is up to date: {place} is at schema version 3.\n"
    )
```

## Acceptance criteria

1. `python -m motosphere schema` is in the command line's help, has a
   help of its own that names `MOTOSPHERE_STORE_PATH`, and takes no
   argument.
2. Where there is no file, the command says "There is no data store:
   <file> does not exist." on standard output, with the exit code 0 and
   nothing on standard error, and afterwards there is no file and no
   folder for it either.
3. A store at the newest schema gives "The data store is up to date:
   <file> is at schema version N."; exit code 0.
4. A store that lacks migrations gives "The data store lacks K
   migrations: <file> is at schema version A, and the newest is version
   B." ("1 migration" for one); exit code 0. It is not given them.
5. The file is named with its whole path, also when the setting is a
   relative path, which is taken from the current folder.
6. A store that `migrate` would refuse gives, on standard error, exactly
   what `migrate` gives for it, nothing on standard output, and the exit
   code 1. A file that is no database, and a folder where the file should
   be, each give their one line and the exit code 1.
7. In every case with a file, the file is byte for byte as before, and
   nothing is made beside it.
8. The type check passes with no `ignore`, and no new `noqa` is added.
9. No existing test changed, and all pass. The full run reports 19 of 19
   gates and 911 tests (backend tests 281).
10. On the pull request, "All gates (Linux)" and "All gates (Windows)" are
    green with those numbers, and the three jobs after the gates are
    skipped.
11. Only the files under "Scope" changed.
