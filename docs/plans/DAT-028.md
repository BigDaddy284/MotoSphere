## Objective

A time is stored in one way in every table: in UTC and with its offset; it
comes back as an aware UTC time, and a time without an offset is refused.

## Why

Nearly every table to come says when something happened: when a source
was last scanned, when a record was collected, when a row was changed. A
strict table has no type for a time (DAT-005: SQLite refuses SQLAlchemy's
DATETIME there), so the store needs a way of its own, and it has to be
decided once, before the first table. A time that does not say which
offset it has is the usual way for wrong times to get into a database, so
the store refuses one.

This is the second quarter of the old "DAT-005 – Model conventions: keys,
times and names" (PLAN-017, in `PROGRESS.md`).

## Design in short

- One new module, `motosphere.db.times`, with three names: `to_text`,
  `from_text` and `UtcDateTime`.
- **The form.** A time is stored as text, always like this:

  ```
  2026-11-19T08:26:04.123456+00:00
  ```

  in UTC, with the offset written out, and with all six digits of the
  fraction of the second, also when they are zeros. Every text is 32
  characters long, so the order of the texts is the order of the times,
  and sorting or comparing rows by a time needs nothing but the text.
  Python's `datetime` keeps a time to the microsecond, so nothing is lost
  and what comes back is equal to what was stored.
- **`to_text(moment)`** says a time in that form. It turns a time with
  another offset to UTC. It refuses, each with one plain sentence: what is
  not a `datetime` (`TypeError`), a time without an offset, also one whose
  zone gives none (`ValueError`), and a time that UTC cannot say within
  the years 1 to 9999 (`ValueError`).
- **`from_text(text)`** reads text that is in the form and gives an aware
  UTC time. Text in any other form is refused (`ValueError`, with the text
  in the sentence), also when Python could read it as a time: the store
  holds one form only. It reads the text with Python and then asks
  `to_text` whether the time, said again, is the same text; so there is
  one description of the form, not two.
- **`UtcDateTime`** is the column type (a SQLAlchemy `TypeDecorator` on
  `Text`): it stores with `to_text`, reads with `from_text`, and leaves
  no time (`None`) as it is. In the table the column is TEXT.
- **`Base` gives the type to a model's `datetime`**: one more line in its
  `type_annotation_map`. A model says `Mapped[datetime]` or
  `Mapped[datetime | None]` and nothing more.
- **Not in this task: a check in the table itself.** Text in another form
  can only get into such a column past the models, with plain SQL, and is
  then refused when a model reads it, with the text shown. Whether the
  table should also refuse it when it is written is settled with the
  checks of DAT-030, which builds the way a column gets a check.
- No new package, no table, no migration.

## Implementation detail

### 1. `backend/src/motosphere/db/times.py` – new, the whole file

```python
"""Times in the data store.

A strict table has no type for a time, so the store keeps a time as text,
in one form:

    2026-11-19T08:26:04.123456+00:00

It is always in UTC, always has its offset written out, and always has the
six digits of the fraction of its second. So every such text has the same
length, the order of the texts is the order of the times, and the text can
be read without this code: by a person, and by SQLite's own date functions.

A time that does not say which offset it has is refused: nothing can tell
which moment it means.
"""

from contextlib import suppress
from datetime import UTC, datetime
from typing import override

from sqlalchemy import Dialect, Text
from sqlalchemy.types import TypeDecorator

__all__ = ["UtcDateTime", "from_text", "to_text"]


def to_text(moment: datetime) -> str:
    """Say a time in the store's form. A time without an offset is refused."""
    if not isinstance(moment, datetime):
        raise TypeError(
            f"Only a time (a datetime) is stored as a time, not {type(moment).__name__}: "
            f"{moment!r}."
        )
    if moment.utcoffset() is None:
        raise ValueError(
            f"A time without an offset is not stored: {moment.isoformat()}. "
            "Say which offset it has, for example with tzinfo=UTC."
        )
    try:
        in_utc = moment.astimezone(UTC)
    except OverflowError:
        raise ValueError(
            f"A time outside the years 1 to 9999 in UTC is not stored: {moment.isoformat()}."
        ) from None
    return in_utc.isoformat(timespec="microseconds")


def from_text(text: str) -> datetime:
    """Read a time that is in the store's form. It comes back as an aware UTC time.

    Text in any other form is refused, also when it could be read as a time:
    the store holds one form only.
    """
    with suppress(TypeError, ValueError):
        moment = datetime.fromisoformat(text)
        if to_text(moment) == text:
            return moment
    raise ValueError(f"The store holds a time that is not in the store's form: {text!r}.")


class UtcDateTime(TypeDecorator[datetime]):
    """The type of a column that holds a time. In the table it is TEXT."""

    impl = Text
    cache_ok = True

    @override
    def process_bind_param(self, value: datetime | None, dialect: Dialect) -> str | None:
        """Turn a time into the text that is stored."""
        return None if value is None else to_text(value)

    @override
    def process_result_value(self, value: str | None, dialect: Dialect) -> datetime | None:
        """Turn the text that is stored into a time."""
        return None if value is None else from_text(value)
```

```python
"""Tests of the form a time has in the data store, without a store.

``tests/integration/test_times.py`` stores times in a real SQLite file.
"""

from datetime import UTC, date, datetime, timedelta, timezone, tzinfo
from typing import Any

import pytest
from sqlalchemy.dialects import sqlite

from motosphere.db.times import UtcDateTime, from_text, to_text

A_TIME = datetime(2026, 11, 19, 8, 26, 4, 123456, tzinfo=UTC)
ITS_TEXT = "2026-11-19T08:26:04.123456+00:00"


def offset(hours: int, minutes: int = 0) -> timezone:
    """A zone that is always this far from UTC."""
    return timezone(timedelta(hours=hours, minutes=minutes))


class NoOffset(tzinfo):
    """A zone that does not say how far it is from UTC."""

    def utcoffset(self, _moment: datetime | None) -> timedelta | None:
        return None

    def dst(self, _moment: datetime | None) -> timedelta | None:
        return None

    def tzname(self, _moment: datetime | None) -> str | None:
        return None


def test_a_utc_time_is_said_with_its_offset_and_the_whole_fraction() -> None:
    assert to_text(A_TIME) == ITS_TEXT


@pytest.mark.parametrize(
    "moment",
    [
        datetime(2026, 11, 19, 10, 26, 4, 123456, tzinfo=offset(2)),
        datetime(2026, 11, 19, 2, 56, 4, 123456, tzinfo=offset(-5, -30)),
        datetime(2026, 11, 20, 1, 26, 4, 123456, tzinfo=offset(17)),
        datetime(2026, 11, 18, 22, 26, 4, 123456, tzinfo=offset(-10)),
    ],
    ids=["east of UTC", "west of UTC by hours and minutes", "the day after", "the day before"],
)
def test_a_time_with_another_offset_is_said_as_the_same_moment_in_utc(moment: datetime) -> None:
    assert moment == A_TIME

    assert to_text(moment) == ITS_TEXT


def test_every_text_has_the_same_length() -> None:
    texts = [
        to_text(datetime(2026, 11, 19, 8, 26, 4, tzinfo=UTC)),
        to_text(datetime(2026, 11, 19, 8, 26, tzinfo=UTC)),
        to_text(datetime(2026, 1, 2, 3, 4, 5, 6, tzinfo=UTC)),
        to_text(datetime(987, 6, 5, tzinfo=UTC)),
    ]

    assert texts == [
        "2026-11-19T08:26:04.000000+00:00",
        "2026-11-19T08:26:00.000000+00:00",
        "2026-01-02T03:04:05.000006+00:00",
        "0987-06-05T00:00:00.000000+00:00",
    ]
    assert {len(text) for text in texts} == {len(ITS_TEXT)}


def test_the_order_of_the_texts_is_the_order_of_the_times() -> None:
    in_order = [
        datetime(987, 6, 5, tzinfo=UTC),
        datetime(2026, 11, 19, 23, 0, tzinfo=offset(9)),
        datetime(2026, 11, 19, 8, 26, 4, tzinfo=offset(-8)),
        datetime(2026, 11, 19, 8, 26, 4, 1, tzinfo=offset(-8)),
        datetime(2026, 11, 20, 0, 30, tzinfo=offset(5, 30)),
        datetime(2026, 11, 19, 23, 59, 59, 999999, tzinfo=UTC),
        datetime(2026, 11, 20, tzinfo=UTC),
    ]
    assert sorted(in_order) == in_order

    texts = [to_text(moment) for moment in in_order]

    assert sorted(texts) == texts
    assert len(set(texts)) == len(texts)


def test_a_time_without_an_offset_is_refused() -> None:
    naive = A_TIME.replace(tzinfo=None)

    with pytest.raises(ValueError, match="without an offset") as refused:
        to_text(naive)

    assert str(refused.value) == (
        "A time without an offset is not stored: 2026-11-19T08:26:04.123456. "
        "Say which offset it has, for example with tzinfo=UTC."
    )


def test_a_time_whose_zone_gives_no_offset_is_refused() -> None:
    with pytest.raises(ValueError, match="A time without an offset is not stored"):
        to_text(A_TIME.replace(tzinfo=NoOffset()))
```

### 3. `backend/tests/integration/test_times.py` – new, the whole file, 15 tests

```python
"""Tests of times in the data store, with a table made in a real SQLite file.

The model here is made for the tests. It is a subclass of the real ``Base``,
so it proves what a model gets for a time, but it is kept in a schema of its
own (``Proof.metadata``), so the real schema never sees it.
"""

from datetime import UTC, datetime, timedelta, timezone

import pytest
from sqlalchemy import Engine, MetaData, func, select
from sqlalchemy.exc import StatementError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.times import UtcDateTime
from motosphere.db.work import unit_of_work

A_TIME = datetime(2026, 11, 19, 8, 26, 4, 123456, tzinfo=UTC)
ITS_TEXT = "2026-11-19T08:26:04.123456+00:00"
NO_OFFSET = "A time without an offset is not stored"


def offset(hours: int, minutes: int = 0) -> timezone:
    """A zone that is always this far from UTC."""
    return timezone(timedelta(hours=hours, minutes=minutes))


class Proof(Base):
    """Models of the tests' own: what ``Base`` gives a time, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofVisit(Proof):
    __tablename__ = "proof_visit"

    id: Mapped[int] = mapped_column(primary_key=True)
    seen_at: Mapped[datetime]
    checked_at: Mapped[datetime | None]


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the table of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def stored_texts(made: Engine) -> list[tuple[str, str | None]]:
    """What the file itself holds, read without the model."""
    with made.connect() as connection:
        rows = connection.exec_driver_sql(
            "SELECT seen_at, checked_at FROM proof_visit ORDER BY id"
        ).all()
    return [(seen_at, checked_at) for seen_at, checked_at in rows]


def test_a_models_time_is_the_stores_own_type_and_text_in_a_strict_table(made: Engine) -> None:
    assert isinstance(ProofVisit.__table__.c.seen_at.type, UtcDateTime)
    assert isinstance(ProofVisit.__table__.c.checked_at.type, UtcDateTime)
    assert broken_rules(Proof.metadata) == []

    with made.connect() as connection:
        columns = {
            name: (declared, bool(required))
            for _, name, declared, required, _, _ in connection.exec_driver_sql(
                "PRAGMA table_info(proof_visit)"
            )
        }

    assert columns == {
        "id": ("INTEGER", True),
        "seen_at": ("TEXT", True),
        "checked_at": ("TEXT", False),
    }


@pytest.mark.parametrize(
    "zone",
    [UTC, offset(2), offset(-5, -30), offset(14), offset(-12)],
    ids=["UTC", "two hours east", "five and a half hours west", "the day after", "the day before"],
)
def test_a_time_is_stored_as_text_in_utc_and_comes_back_as_an_aware_utc_time(
    made: Engine, zone: timezone
) -> None:
    with unit_of_work(made) as work:
        work.add(ProofVisit(seen_at=A_TIME.astimezone(zone), checked_at=A_TIME.astimezone(zone)))

    assert stored_texts(made) == [(ITS_TEXT, ITS_TEXT)]
    with unit_of_work(made) as work:
        visit = work.scalars(select(ProofVisit)).one()
    assert (visit.seen_at, visit.checked_at) == (A_TIME, A_TIME)
    assert visit.seen_at.utcoffset() == timedelta(0)
    assert visit.seen_at.tzinfo == UTC


def test_no_time_is_stored_as_nothing_and_comes_back_as_nothing(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add(ProofVisit(seen_at=A_TIME))

    assert stored_texts(made) == [(ITS_TEXT, None)]
    with unit_of_work(made) as work:
        assert work.scalars(select(ProofVisit)).one().checked_at is None


def test_a_time_without_an_offset_is_refused_and_nothing_is_stored(made: Engine) -> None:
    naive = A_TIME.replace(tzinfo=None)

    with pytest.raises(StatementError, match=NO_OFFSET) as refused, unit_of_work(made) as work:
        work.add_all([ProofVisit(seen_at=A_TIME), ProofVisit(seen_at=naive)])

    assert isinstance(refused.value.orig, ValueError)
    assert stored_texts(made) == []


def test_rows_sorted_by_a_time_come_in_the_order_of_the_times(made: Engine) -> None:
    in_order = [
        datetime(2026, 11, 19, 23, 0, tzinfo=offset(9)),
        datetime(2026, 11, 19, 8, 26, 4, tzinfo=offset(-8)),
        datetime(2026, 11, 19, 8, 26, 4, 1, tzinfo=offset(-8)),
        datetime(2026, 11, 20, 0, 30, tzinfo=offset(5, 30)),
        datetime(2026, 11, 20, tzinfo=UTC),
    ]
    assert sorted(in_order) == in_order
    with unit_of_work(made) as work:
        work.add_all(ProofVisit(seen_at=moment) for moment in reversed(in_order))

    with unit_of_work(made) as work:
        found = work.scalars(select(ProofVisit.seen_at).order_by(ProofVisit.seen_at)).all()

    assert found == in_order


def test_rows_are_found_by_a_time_whatever_offset_the_question_has(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add_all(ProofVisit(seen_at=A_TIME + timedelta(hours=hours)) for hours in (-1, 0, 1))
    asked = A_TIME.astimezone(offset(9))

    with unit_of_work(made) as work:
        at = work.scalars(select(ProofVisit.seen_at).where(ProofVisit.seen_at == asked)).all()
        after = work.scalars(select(ProofVisit.seen_at).where(ProofVisit.seen_at > asked)).all()
        number_before = work.scalar(
            select(func.count()).select_from(ProofVisit).where(ProofVisit.seen_at < asked)
        )

    assert at == [A_TIME]
    assert after == [A_TIME + timedelta(hours=1)]
    assert number_before == 1


def test_a_question_with_a_time_without_an_offset_is_refused(made: Engine) -> None:
    naive = A_TIME.replace(tzinfo=None)

    with pytest.raises(StatementError, match=NO_OFFSET), unit_of_work(made) as work:
```
