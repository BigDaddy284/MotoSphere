## Objective

A model can say that a column is yes or no, and the store refuses
anything else in it.

## Why

The first real table is close (the information sources, DAT-006), and it
has to say whether a source is switched on. Much of what follows is yes
or no as well: whether a result is official, whether a track is open.

A strict table has no type for yes and no, and SQLite refuses to make a
strict table with SQLAlchemy's own type for it (`DATABASE.md`). So today
a model that says `Mapped[bool]` gets a table that cannot be made. This
task gives the store its own type for it, the second column type that
brings its check (DAT-034) and the second of the four small tasks before
the first table (PLAN-021, in `PROGRESS.md`).

## Design in short

- **One new module, `motosphere.db.yes_no`.** It has the column type
  `YesOrNo`, the function `yes_or_no(name)` that gives the check, and the
  two functions the type uses, `to_number` and `from_number`.
- **A model says `Mapped[bool]`**, or `Mapped[bool | None]` for a column
  that may be without a value. `Base` gets one more entry in the list by
  which a model's Python type becomes a column type
  (`type_annotation_map`): `bool: YesOrNo`.
- **In the table the column is INTEGER with a check**:
  `CONSTRAINT ck_<table>_<column>_yes_or_no CHECK (<column> IN (0, 1))`.
  1 is yes and 0 is no. `Base` gives the check to the table, because
  `YesOrNo` is a `WithItsCheck` (DAT-034).
- **Only `True` and `False` are stored.** Whatever else a model or a
  question is given, the number 1 and the word "no" among it, is refused
  before anything is written, with a `TypeError` that says what it was
  given. Nothing is taken for true or false the way Python takes it.
- **Only the whole numbers 1 and 0 are read.** Anything else that comes
  back through the type is refused with a `ValueError`, not read as yes.
- **A column without a value stays without one**, on the way in and on
  the way out: no value means "not known", which is not no.
- No new package, no model, no table, no migration. The rule by which
  `Base` gives checks, and `broken_rules`, do not change.

## What the task left open, and what the trial settled

- **How a model says it.** With the plain Python type, `Mapped[bool]`,
  and not with a name of the store's own as for text that must not be
  empty. There, `str` has to stay what it was, text that may be empty.
  Here there is nothing to keep: a `bool` column could not be made at
  all. And so no model can get SQLAlchemy's own type by leaving a word
  out.
- **What a column that may be without a value holds.** No value, yes or
  no: three things, and the first is "not known". A source that was never
  looked at is not a source that was looked at and found wanting, and the
  store must be able to say which (CLAUDE.md §11).
- **Why a number is not taken for yes or no.** Python takes much for
  true: every text that is not empty, the word "no" and the text "0"
  among it. A collector that hands over what it read from a page would
  store "no" as yes without anyone noticing. So the type takes `True` and
  `False` and nothing else, and says what it was given instead.
- **Why what is read is held to the same.** The table can hold nothing
  but 1 and 0 in such a column, so the refusal on reading never happens
  for a row. It happens for what SQLAlchemy reads through the column's
  type without it being a row's value: a sum over the column
  (`func.sum`) comes back through the type. Refusing 2 there is right;
  reading it as yes would be a wrong answer that looks like a good one.
  `DATABASE.md` says how to count the rows that are yes instead, and one
  test holds what it says.
- **What SQLite takes for one of the two numbers.** A strict table stores
  what can be a whole number without loss as that number: the text `'1'`
  and the number `1.0`, written with plain SQL, are stored as the whole
  number 1. That is the strict table's doing, not the check's, and it is
  why the file never holds anything but the two whole numbers. The word
  `'yes'` and the number 1.5 are refused by the strict table itself.
  Tests say all of it.
- **`base.py` changes in two lines of code**: the import of `YesOrNo`
  and its entry in the list. The description at the top of the file is
  brought in line. Nothing that gives or asks for a check changes, which
  is what DAT-034 was for.

### 1. `backend/src/motosphere/db/yes_no.py` – new, the whole file

```python
"""Yes or no in the data store.

A strict table has no type for yes and no, so the store keeps them as a
whole number: 1 for yes and 0 for no. A model says of such a column that it
is a ``bool``:

    active: Mapped[bool]

The column is then INTEGER with a check in its table, and SQLite itself
refuses a row with any other number in it, whoever writes it. To Python the
column is ``True`` or ``False``, and only these two are stored: a number, a
word and every other value is refused, also one that Python would take for
true or false, because "no" is a word Python takes for true.

A column that may be without a value says ``Mapped[bool | None]``: it holds
no value, yes or no. No value means that it is not known, which is not no.
"""

from typing import override

from sqlalchemy import CheckConstraint, Dialect, Integer, column
from sqlalchemy.types import TypeDecorator

from motosphere.db.checks import WithItsCheck

__all__ = ["YesOrNo", "from_number", "to_number", "yes_or_no"]


def to_number(value: bool) -> int:
    """Say yes or no as the number that is stored. What is neither is refused."""
    if not isinstance(value, bool):
        raise TypeError(
            f"Only yes or no (True or False) is stored as yes or no, not "
            f"{type(value).__name__}: {value!r}."
        )
    return int(value)


def from_number(number: int) -> bool:
    """Read the number that is stored for yes or no. Any other is refused, not taken for yes."""
    # Not Python's True, and not 1.0: both are equal to 1 and neither is the number.
    if type(number) is int and number in (0, 1):
        return number == 1
    raise ValueError(f"The store holds what is neither yes (1) nor no (0): {number!r}.")


class YesOrNo(WithItsCheck, TypeDecorator[bool]):
    """The type of a column that is yes or no. In the table it is INTEGER."""

    impl = Integer
    cache_ok = True
    refuses = "a number other than 0 and 1"
    given_by = "yes_or_no"

    def check_for(self, name: str) -> CheckConstraint:
        """Give the check of :func:`yes_or_no` for the column called ``name``."""
        return yes_or_no(name)

    @override
    def process_bind_param(self, value: bool | None, dialect: Dialect) -> int | None:
        """Turn yes or no into the number that is stored."""
        return None if value is None else to_number(value)

    @override
    def process_result_value(self, value: int | None, dialect: Dialect) -> bool | None:
        """Turn the number that is stored into yes or no."""
        return None if value is None else from_number(value)


def yes_or_no(name: str) -> CheckConstraint:
    """Give the check that refuses every number but 0 and 1 in the column called ``name``.

    The check is called ``<name>_yes_or_no``, which the naming rule makes
    ``ck_<table>_<name>_yes_or_no`` once the check is given to a table. It
    belongs to no table until then. A column without a value passes it, as
    it passes every check.
    """
    return CheckConstraint(column(name).in_((0, 1)), name=f"{name}_yes_or_no")
```

### 2. `backend/tests/unit/test_db_yes_no.py` – new, the whole file, 20 tests

```python
"""Tests of yes or no in the store, without a store.

``tests/integration/test_yes_no.py`` asks a real SQLite file what it refuses.
"""

from typing import Any

import pytest
from sqlalchemy import Column, Integer, MetaData, Table
from sqlalchemy.dialects import sqlite
from sqlalchemy.schema import conv

from motosphere.db import times
from motosphere.db.base import NAMING, broken_rules
from motosphere.db.checks import WithItsCheck
from motosphere.db.times import UtcDateTime
from motosphere.db.yes_no import YesOrNo, from_number, to_number, yes_or_no


def said(name: str) -> str:
    """The check of a column of this name, as SQLite is given it."""
    written = yes_or_no(name).sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )
    return str(written)


def test_yes_is_said_as_1_and_no_as_0() -> None:
    assert to_number(True) == 1
    assert to_number(False) == 0
    # A whole number, not Python's True and False under another name.
    assert [type(to_number(value)) for value in (True, False)] == [int, int]


@pytest.mark.parametrize(
    ("value", "sentence"),
    [
        (1, "Only yes or no (True or False) is stored as yes or no, not int: 1."),
        (0, "Only yes or no (True or False) is stored as yes or no, not int: 0."),
        ("no", "Only yes or no (True or False) is stored as yes or no, not str: 'no'."),
        ("", "Only yes or no (True or False) is stored as yes or no, not str: ''."),
        (1.0, "Only yes or no (True or False) is stored as yes or no, not float: 1.0."),
    ],
    ids=["the number 1", "the number 0", "the word no", "empty text", "a number with a fraction"],
)
def test_what_is_neither_true_nor_false_is_refused(value: Any, sentence: str) -> None:
    with pytest.raises(TypeError, match="Only yes or no") as refused:
        to_number(value)

    assert str(refused.value) == sentence


def test_1_is_read_as_yes_and_0_as_no() -> None:
    assert from_number(1) is True
    assert from_number(0) is False


@pytest.mark.parametrize(
    "number",
    [2, -1, 1.0, "1", True],
    ids=["two", "less than nothing", "a number with a fraction", "text", "Python's True"],
)
def test_what_is_neither_1_nor_0_is_refused_and_not_read_as_yes(number: Any) -> None:
    with pytest.raises(ValueError, match="neither yes") as refused:
        from_number(number)

    assert str(refused.value) == (
        f"The store holds what is neither yes (1) nor no (0): {number!r}."
    )


def test_the_column_type_stores_the_number_and_reads_yes_or_no() -> None:
    column_type = YesOrNo()
    dialect = sqlite.dialect()

    assert column_type.process_bind_param(True, dialect) == 1
    assert column_type.process_bind_param(False, dialect) == 0
    assert column_type.process_result_value(1, dialect) is True
    assert column_type.process_result_value(0, dialect) is False


def test_the_column_type_leaves_no_value_as_no_value() -> None:
    column_type = YesOrNo()
    dialect = sqlite.dialect()

    assert column_type.process_bind_param(None, dialect) is None
    assert column_type.process_result_value(None, dialect) is None


def test_in_the_table_the_type_is_a_whole_number() -> None:
    assert str(YesOrNo().compile(dialect=sqlite.dialect())) == "INTEGER"


def test_the_check_allows_the_two_numbers_and_no_other() -> None:
    assert said("active") == "active IN (0, 1)"


def test_the_check_of_a_column_named_with_a_word_of_sql_names_it_in_quotes() -> None:
    assert said("group") == '"group" IN (0, 1)'


def test_the_check_is_named_after_its_column_and_by_the_naming_rule() -> None:
    check = yes_or_no("active")

    assert check.name == "active_yes_or_no"

    owner = Table(
        "owner",
        MetaData(naming_convention=NAMING),
        Column("id", Integer),
        Column("active", YesOrNo),
    )

    assert check not in owner.constraints

    owner.append_constraint(check)

    assert check.name == "ck_owner_active_yes_or_no"
    assert isinstance(check.name, conv)


def test_the_type_brings_the_check_that_yes_or_no_gives() -> None:
    its_type = YesOrNo()
    brought = its_type.check_for("active")

    assert isinstance(its_type, WithItsCheck)
    assert brought.name == "active_yes_or_no"
    assert str(
        brought.sqltext.compile(dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True})
    ) == said("active")
    assert its_type.refuses == "a number other than 0 and 1"
    assert its_type.given_by == yes_or_no.__name__


def test_a_column_that_is_yes_or_no_is_named_until_its_table_has_the_check() -> None:
    schema = MetaData(naming_convention=NAMING)
    owner = Table(
        "owner",
        schema,
        Column("id", Integer, primary_key=True),
        Column("active", YesOrNo, nullable=False),
        Column("created_at", UtcDateTime, nullable=False, default=times.now),
        Column("updated_at", UtcDateTime, nullable=False, default=times.now, onupdate=times.now),
        sqlite_strict=True,
        sqlite_autoincrement=True,
    )

    assert broken_rules(schema) == [
        "The table owner does not refuse a number other than 0 and 1 in its column active: "
        "it must have the check that yes_or_no gives for the column, named by the naming rule."
    ]

    owner.append_constraint(yes_or_no("active"))

    assert broken_rules(schema) == []
```

### 3. `backend/tests/integration/test_yes_no.py` – new, the whole file, 27 tests

```python
"""Tests of yes or no in the store, with a table made in a real SQLite file.

The model here is made for the tests. It is a subclass of the real
``Base``, so it proves what a model gets when it says that a column is yes
or no, but it is kept in a schema of its own (``Proof.metadata``), so the
real schema never sees it.
"""

from typing import Any

import pytest
from sqlalchemy import Engine, MetaData, func, select
from sqlalchemy.exc import IntegrityError, StatementError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.work import unit_of_work
from motosphere.db.yes_no import YesOrNo

A_TIME = "2026-11-19T08:00:00.000000+00:00"
REFUSED = "CHECK constraint failed: ck_proof_gate_{}_yes_or_no"
NOT_YES_OR_NO = "Only yes or no \\(True or False\\) is stored as yes or no"
# A row written with plain SQL. Its first three "?" are open, lit and locked;
# the last two are its two times, which only the store's code sets.
PAST_THE_MODEL = (
    "INSERT INTO proof_gate (open, lit, locked, created_at, updated_at) VALUES (?, ?, ?, ?, ?)"
)


class Proof(Base):
    """A model of the tests' own, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofGate(Proof):
    __tablename__ = "proof_gate"

    open: Mapped[bool]
    # No value, yes or no.
    lit: Mapped[bool | None]
    # A model that says more of the column: the value it has when none is given.
    locked: Mapped[bool] = mapped_column(default=False)
    # A whole number that is not yes or no, as before.
    width: Mapped[int | None]


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the table of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def stored(made: Engine) -> list[tuple[Any, ...]]:
    """What the file holds of every gate, with what kind of value it is, read without the model."""
    with made.connect() as connection:
        rows = connection.exec_driver_sql(
            "SELECT open, typeof(open), lit, typeof(lit), locked, typeof(locked) "
            "FROM proof_gate ORDER BY id"
        ).all()
    return [tuple(row) for row in rows]


def test_yes_or_no_is_a_whole_number_in_a_strict_table(made: Engine) -> None:
    columns = ProofGate.__table__.c

    assert [column.name for column in columns if isinstance(column.type, YesOrNo)] == [
        "open",
        "lit",
        "locked",
    ]
    assert broken_rules(Proof.metadata) == []

    with made.connect() as connection:
        in_the_file = {
            name: (declared, bool(required))
            for _, name, declared, required, _, _ in connection.exec_driver_sql(
                "PRAGMA table_info(proof_gate)"
            )
        }

    assert in_the_file == {
        "id": ("INTEGER", True),
        "open": ("INTEGER", True),
        "lit": ("INTEGER", False),
        "locked": ("INTEGER", True),
        "width": ("INTEGER", False),
        "created_at": ("TEXT", True),
        "updated_at": ("TEXT", True),
    }


def test_the_file_has_a_check_named_by_the_rule_for_each_such_column_and_for_no_other(
    made: Engine,
) -> None:
    with made.connect() as connection:
        written = str(

        "CONSTRAINT ck_proof_gate_open_yes_or_no CHECK (open IN (0, 1))",
        "CONSTRAINT ck_proof_gate_lit_yes_or_no CHECK (lit IN (0, 1))",
        "CONSTRAINT ck_proof_gate_locked_yes_or_no CHECK (locked IN (0, 1))",

def test_yes_and_no_are_stored_as_1_and_0_and_come_back_as_true_and_false(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add(ProofGate(open=True, lit=False, locked=True))

    assert stored(made) == [

        assert (second.open, second.lit, second.locked) == (False, True, False)
        assert first.open is True
```
