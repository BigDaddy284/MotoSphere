# DAT-039 – The lists a source is described by

**Phase:** 2 – Data store and published data
**Depends on:** DAT-038 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §10, §11, `docs/WORKFLOW.md`, `DESIGN.md`

`backend/tests/unit/test_db_lists.py`

## Objective

The code knows the twelve kinds of source and the ten ways of collecting
from one, each with the text that is stored.

## Why

The first table of the store is the table of the information sources
(DAT-006). Two of its columns are one of a list: what kind of source it
is, and how it is collected from. The texts of a list are stored in rows
and named in the table's check, so once a table has them a text is
changed only by a migration. They are worth a task of their own before
the table: small, with no store, and settled with care (PLAN-023 in
`PROGRESS.md`).

## Design in short

- **One new package, `motosphere.db.models`**, for the models of the
  store, with one new module, `motosphere.db.models.source`. The package
  has no model yet; its `__init__.py` is a description and nothing else.
- **Two lists in that module**, each a `StrEnum` as a column of a list
  takes one (DAT-036): `SourceCategory`, the twelve kinds of source of
  DESIGN §7.1, and `CollectionMethod`, the ten ways of collecting of
  DESIGN §7.2, both in the design's order.
- **The texts are words in small letters, with one space between two.**
- No table, no model, no migration, no new package from outside.

  | `SOCIAL_MEDIA` | `social media page` | | | |
  | `ARCHIVE` | `historical archive` | | | |

- **The conditions of the design are not in the texts.** The design says
  "Permitted HTML extraction", "Public JSON endpoints where authorised",
  "Search-engine discovery where permitted" and "Public social media
  pages where permitted". A text names the way, not the condition:
  `html extraction` in a row cannot say that somebody checked the site's
  terms. The condition is checked when a source is registered and written
  down with it; `DATABASE.md` and `DATA_SOURCES.md` say so, and the table
  of DAT-006 is to hold a source to it (PLAN-023).
- **Where the lists stand.** In the module in which the model of the
  sources will stand, because a list and the column that is of it change
  together. `ARCHITECTURE.md` §2 has the models under `db/`.
- **What a test of a list can hold.** The texts are written out in the
  test a second time, so a text changed by mistake fails there. Further:
  the two numbers, twelve and ten; no text with two names; the form of
  every text; and that `OneOf` takes each list and gives a check that
  names its texts in their order, as SQLite is given it. That SQLite
  refuses a text that is not on a list is proven for every list by the
  tests of DAT-036, and for these two again with the table (DAT-006).
- **Whether a source has one kind and one way.** Not settled here. The
  lists do not say, and the table decides (DAT-006).

### 2. `backend/src/motosphere/db/models/source.py` – new, the whole file

```python
"""The information sources: where everything the store holds comes from.

A source is a website or a dataset that MotoSphere may collect from. This
module has the two lists a source is described by: what kind of source it
is, and how it is collected from. The table of the sources is not here
yet.

Each list is said once, here. Its values are the texts that are stored,
and a column of the list (:class:`motosphere.db.lists.OneOf`) refuses
every other text. The texts are in small letters, with one space between
two words. Once a table has a column of a list, a text of that list is
changed or taken away only by a migration, because the table's check names
the texts and rows hold them.
"""

from enum import StrEnum

__all__ = ["CollectionMethod", "SourceCategory"]


class SourceCategory(StrEnum):
    """What kind of source this is: who publishes it (DESIGN.md 7.1, in its order)."""

    # A body that makes the rules of the sport, for the world or for a country.
    GOVERNING_BODY = "governing body"
    # The website of one championship or series.
    CHAMPIONSHIP = "championship"
    # Whoever runs a championship from year to year.
    ORGANISER = "organiser"
    # Whoever puts on single races and sells them.
    PROMOTER = "promoter"
    # One track, about itself.
    TRACK = "track"
    # A local motorcycle club.
    CLUB = "club"
    # An organisation for the racing of one region of a country.
    REGIONAL_ORGANISATION = "regional organisation"
    # A public collection of race results or of timing.
    RESULTS_DATABASE = "results database"
    # A magazine or a news site about the sport.
    NEWS = "news publication"
    # A website the riders and followers of the sport write themselves.
    COMMUNITY = "community website"
    # A public page on a social network, only where that network permits collecting.
    SOCIAL_MEDIA = "social media page"
    # A public archive of how the sport was.
    ARCHIVE = "historical archive"


class CollectionMethod(StrEnum):
    """How a source is collected from (DESIGN.md 7.2, in its order)."""

    # An interface the source itself offers to programs.
    API = "official api"
    # A feed of records in a form made for programs, such as a calendar file.
    STRUCTURED_FEED = "structured feed"
    # A feed of what is new, as RSS or Atom.
    RSS = "rss feed"
    # A whole set of records published for reuse, under a licence.
    DATASET = "public dataset"
    # Pages made for people, only where the site's terms and its robots.txt permit.
    HTML = "html extraction"
    # A public document with a fixed layout, such as a results sheet.
    DOCUMENT = "structured document"
    # The data behind a public page, only where the source authorises its use.
    JSON = "json endpoint"
    # The list of its pages that a site publishes for programs.
    SITEMAP = "sitemap discovery"
    # What a search engine finds, only where the engine permits it.
    SEARCH = "search engine discovery"
    # A reference a person has sent in.
    SUBMITTED = "human submission"
```

### 3. `backend/tests/unit/test_db_models_source.py` – new, the whole file, 29 tests

```python
"""Tests of the two lists an information source is described by. They need no store."""

import re
from enum import StrEnum

import pytest
from sqlalchemy.dialects import sqlite

from motosphere.db.lists import OneOf
from motosphere.db.models.source import CollectionMethod, SourceCategory

# The texts that are stored, written out: a text changed by mistake fails here.
CATEGORIES = [
    "governing body",
    "championship",
    "organiser",
    "promoter",
    "track",
    "club",
    "regional organisation",
    "results database",
    "news publication",
    "community website",
    "social media page",
    "historical archive",
]
METHODS = [
    "official api",
    "structured feed",
    "rss feed",
    "public dataset",
    "html extraction",
    "structured document",
    "json endpoint",
    "sitemap discovery",
    "search engine discovery",
    "human submission",
]
BOTH = pytest.mark.parametrize(
    ("the_list", "texts"),
    [(SourceCategory, CATEGORIES), (CollectionMethod, METHODS)],
    ids=["the kinds of source", "the ways of collecting"],
)


def test_there_are_the_twelve_kinds_of_source_and_the_ten_ways_of_collecting() -> None:
    assert (len(CATEGORIES), len(METHODS)) == (12, 10)
    assert (len(SourceCategory), len(CollectionMethod)) == (12, 10)


@BOTH
def test_a_list_has_exactly_its_texts_in_the_order_of_the_design(
    the_list: type[StrEnum], texts: list[str]
) -> None:
    assert [value.value for value in the_list] == texts


@BOTH
def test_no_text_of_a_list_has_two_names(the_list: type[StrEnum], texts: list[str]) -> None:
    assert len(the_list.__members__) == len(texts)
    assert len(set(texts)) == len(texts)


@pytest.mark.parametrize("value", [*SourceCategory, *CollectionMethod], ids=lambda value: value)
def test_a_text_is_words_in_small_letters_with_one_space_between_two(value: StrEnum) -> None:
    assert re.fullmatch(r"[a-z]+( [a-z]+)*", value.value)


@BOTH
def test_a_column_can_be_of_the_list_and_its_check_names_the_texts(
    the_list: type[StrEnum], texts: list[str]
) -> None:
    check = OneOf(the_list).check_for("described")
    written = check.sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )

    assert check.name == "described_one_of"
    assert str(written) == "described IN (" + ", ".join(f"'{text}'" for text in texts) + ")"
```
