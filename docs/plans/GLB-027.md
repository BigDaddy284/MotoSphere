## Objective

A `Globe` component starts one engine in its drawing surface when it is
shown and stops it when it goes, proven by unit tests with a stand-in
for the engine.

## Why

The engine of the globe is large and holds a 3D picture of the browser
for as long as it runs. A browser keeps only so many of those for a
page: in the trial of GLB-026 a page that kept forty got "WARNING: Too
many active WebGL contexts. Oldest context will be lost." 25 times. So
an engine that is started twice, or left running when the globe has
gone, is a defect a person would see as a globe that goes blank. React
shows every component twice in development, and a globe can go while
its engine is still on the way. This task holds the life of the globe
to one engine at a time, before the real engine is in the page
(GLB-002), where each of these cases would be slow and hard to bring
about in a browser test.

## What this task is, and what it is not

- **It is** the component `Globe`, a stand-in for the engine that the
  unit tests use, and their tests.
- **It is not** in the page. Nothing shows the component yet, so
  nothing a user sees changes, and the task has no browser tests.
- **It is not** the real engine. The component names nothing of it:
  how the engine is loaded and started is handed in. The real way is
  GLB-002.
- **It is not** what a person is told when the engine fails. The
  component tells whoever shows it; the words are GLB-004.
- **It is not** the size of the drawing surface. The element has no
  style of its own yet; that it fills the stage is GLB-002, and that
  it follows the stage is GLB-028.

## Design in short

    export type Stop = () => void
    export type Start = (surface: HTMLElement) => Stop
    export type Load = () => Promise<Start>

    export function Globe({ load, onFailed }: GlobeProps) {
      const surface = useRef<HTMLDivElement>(null)
      const loadTheEngine = useEffectEvent(load)
      const failed = useEffectEvent(onFailed)

      useEffect(() => {
        const element = surface.current
        let shown = true
        let stop: Stop | undefined

        async function begin(): Promise<void> {
          try {
            const start = await loadTheEngine()
            if (shown && element !== null) {
              stop = start(element)
            }
          } catch (why) {
            if (shown) {
              failed(why)
            }
          }
        }
        void begin()

        return () => {
          shown = false
          stop?.()
        }
      }, [])

      return <div ref={surface} />
    }

Loading gives the way to start an engine in an element; starting gives
the way to stop it. The stand-in of the tests,
`frontend/src/test/engine.ts`, gives such a `load`, lets each loading
end when the test says so, and remembers what was started where and
how often it was stopped.

## What the trial settled

- **The engine is handed in.** The component brings in `react` and
  nothing else. A test reads the component as it is written and holds
  that; a planted defect that names the engine there is found. So no
  unit test loads the engine by way of the component.
- **The engine is asked for when the globe is shown, not when it is
  drawn.** React can draw a component and not show it, for one because
  something beside it is not ready. A test draws a globe beside
  something that is never ready and finds that the engine was not
  asked for; a planted defect that asks while the globe is drawn is
  found by it.
- **One showing, one loading.** The way of loading and the listener
  are read through `useEffectEvent`, which React has for exactly this
  (React 19.2 and later; 19.3.1 is installed): what is done when the
  globe is shown does not depend on them, so another listener or
  another way of loading handed in later starts nothing anew, and the
  listener that is told is the one the globe has at that moment. The
  lint passes with the empty list of what the effect depends on.
- **A globe that has gone starts nothing and tells nothing.** The
  effect notes that the globe has gone. An engine that arrives after
  that is never started, and a loading that fails after that is told
  to nobody: nobody is waiting for it.
- **Everything that goes wrong on the way is told once**: a loading
  that fails, a way of loading that breaks before it gives anything,
  and an engine that has arrived and cannot be started. What is handed
  on is the very thing that went wrong, an error or not.
- **In development one engine runs.** Under `StrictMode` React shows
  the globe, takes it away and shows it again, so the engine is asked
  for twice. The first asking belongs to a globe that has gone: its
  engine is never started, in whichever order the two loadings end.
  The real way of loading (GLB-002) is an import, which the browser
  does once however often it is asked.
- **The component asks React for nothing after it is shown.** It keeps
  no state, so its tests need no waiting on React's work, and the
  set-up of the unit tests (FND-056) holds every one of them to ending
  with none waiting, as it does every test.
- **The stand-in comes back when what waited has run.** `arrives()`
  and `fails()` end the loading and then wait a moment
  (`setTimeout`), so a test can look at once at what the component did
  with it. A test hangs a chain of twenty links on a loading and finds
  its end reached when the stand-in comes back; without the moment the
  planted defect is found by that test and by no other, because the
  component as it is waits on the loading in one step only.
- **A way to stop that fails is not caught.** It is a defect of
  whatever started the engine and is to be seen, not hidden.

+import { useEffect, useEffectEvent, useRef } from 'react'
+
+/** Stops an engine that was started, and gives back what it held. */
+export type Stop = () => void
+
+/** Starts an engine in an element of the page, and gives the way to stop it. */
+export type Start = (surface: HTMLElement) => Stop
+
+/** Loads the engine, and gives the way to start one. */
+export type Load = () => Promise<Start>
+
+type GlobeProps = {
+  /**
+   * How the engine is loaded. It is asked when the globe is shown and not
+   * before, and the way that was handed in then is the one that is used.
+   */
+  load: Load
+  /**
+   * Told once, with what went wrong, when the engine cannot be loaded or
+   * started for a globe that is still shown.
+   */
+  onFailed: (why: unknown) => void
+}
+
+/**
+ * The globe: one element of the page, and one engine that draws in it for
+ * as long as the globe is shown.
+ *
+ * The engine is loaded when the globe is shown and started in the element
+ * when it has arrived. When the globe goes, the engine is stopped. A globe
+ * can go before its engine has arrived: that engine is then never started,
+ * and if it cannot be loaded nobody is told, because nobody is waiting for
+ * it any more. React shows a component, takes it away and shows it again
+ * in development; then two loadings are asked for, and only the engine of
+ * the globe that stayed is started.
+ */
+export function Globe({ load, onFailed }: GlobeProps) {
+  const surface = useRef<HTMLDivElement>(null)
+  const loadTheEngine = useEffectEvent(load)
+  const failed = useEffectEvent(onFailed)
+
+  useEffect(() => {
+    const element = surface.current
+    let shown = true
+    let stop: Stop | undefined
+
+    async function begin(): Promise<void> {
+      try {
+        const start = await loadTheEngine()
+        if (shown && element !== null) {
+          stop = start(element)
+        }
+      } catch (why) {
+        if (shown) {
+          failed(why)
+        }
+      }
+    }
+    void begin()
+
+    return () => {
+      shown = false
+      stop?.()
+    }
+  }, [])
+
+  return <div ref={surface} />
+}

+import type { Load, Start } from '../globe/Globe.tsx'
+
+/** An engine the stand-in started. */
+export type Engine = {
+  /** The element it was started in. */
+  surface: HTMLElement
+  /** Whether that element was in the page when the engine was started. */
+  inThePage: boolean
+  /** How many times it was stopped. */
+  stops: number
+}
+
+export type StandIn = {
+  /** The way to load the engine that a test hands to a globe. */
+  load: Load
+  /** How many times the engine was asked for. */
+  loadings: () => number
+  /** Lets a loading end well: the one asked for first, or the one named. */
+  arrives: (which?: number) => Promise<void>
+  /** Lets a loading end badly, with what went wrong. */
+  fails: (why: unknown, which?: number) => Promise<void>
+  /** From now on the engine cannot be started, and says this. */
+  breaksAtTheStart: (why: unknown) => void
+  /** Every engine that was started, in the order they were started. */
+  engines: () => readonly Engine[]
+  /** The elements in which an engine is running now. */
+  running: () => readonly HTMLElement[]
+}
+
+type Loading = { give: (start: Start) => void; refuse: (why: unknown) => void }
+
+/** What a test is told that names a loading the engine was not asked for. */
+export function noSuchLoading(asked: number, which: number): string {
+  return `The engine was asked for ${asked} times, so there is no loading number ${which}.`
+}
+
+/** A moment in which what waits on a loading can run. */
+function aMoment(): Promise<void> {
+  return new Promise<void>((resolve) => {
+    setTimeout(resolve, 0)
+  })
+}
+
+/**
+ * A stand-in for the engine of the globe. The real engine draws, which the
+ * test environment cannot, and takes its time to load. The stand-in is
+ * loaded when the test says so, well or badly, and remembers where it was
+ * started and how often it was stopped. Nothing of the real engine is in
+ * it.
+ */
+export function standInEngine(): StandIn {
+  const asked: Loading[] = []
+  const started: Engine[] = []
+  let broken: { why: unknown } | undefined
+
+  const start: Start = (surface) => {
+    if (broken !== undefined) {
+      throw broken.why
+    }
+    const engine = { surface, inThePage: surface.isConnected, stops: 0 }
+    started.push(engine)
+    return () => {
+      engine.stops += 1
+    }
+  }
+
+  function loading(which: number): Loading {
+    const found = asked[which]
+    if (found === undefined) {
+      throw new Error(noSuchLoading(asked.length, which))
+    }
+    return found
+  }
+
+  return {
+    load: () =>
+      new Promise<Start>((give, refuse) => {
+        asked.push({ give, refuse })
+      }),
+    loadings: () => asked.length,
+    arrives: async (which = 0) => {
+      loading(which).give(start)
+      await aMoment()
+    },
+    fails: async (why, which = 0) => {
+      loading(which).refuse(why)
+      await aMoment()
+    },
+    breaksAtTheStart: (why) => {
+      broken = { why }
+    },
+    engines: () => started.map((engine) => ({ ...engine })),
+    running: () => started.filter((engine) => engine.stops === 0).map((engine) => engine.surface),
+  }
+}
