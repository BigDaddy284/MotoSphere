**Phase:** 2 – Data store and published data
**Depends on:** DAT-039 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §10, §11, `docs/WORKFLOW.md`, `DESIGN.md`
§7.3, `PROGRESS.md` (PLAN-023), `DATABASE.md` ("How the schema changes",

`backend/src/motosphere/db/base.py`,

`backend/tests/integration/test_compare.py`

## Objective

The store knows every source of information: who it is, how it is
collected from and how it may be used (DESIGN §7.3).

## Why

Everything the store will hold comes from a source, and every record
will say from which. So the sources are the first table. It is also the
first model and the first migration, and with them three things have to
be settled once for all the tables that follow: where the migrations are
written, how a test of a model gets a store with the tables in it, and
how the two tests that hold the whole schema (the rules every table
keeps, and the models against the migrations) come to see every model.

## Design in short

- **One table, `source`**, with its model `Source` in
  `motosphere.db.models.source`, beside the two lists of DAT-039.
- **The first migration, `make_the_sources`**, in one new module,
  `motosphere.db.history`, which has every migration and the list of
  them. `motosphere.db.migrations` takes `MIGRATIONS` from there and is
  otherwise as it was.
- **A migration is plain SQL that names nothing of the store's code.**
  The module imports nothing of MotoSphere's, and a test holds it to
  that.
- **`SCHEMA` in `motosphere.db.models` is the whole schema.** The package
  names every model, so loading it, or any one model, loads them all.
  The two tests that hold the whole schema take it from there, and a
  new test proves that it is whole.
- **One new fixture, `newest`**: the test's own store, brought to the
  newest schema by `migrate`, as every real store is.
- No new package from outside.

## What the task left open, and what the trial settled

- **The columns.** After the key, and before the two times:

  | Column | In the model | In the table |
  |---|---|---|
  | `name` | `Mapped[NotEmpty]`, unique | `TEXT NOT NULL`, unique, not empty |
  | `website` | `Mapped[WebAddress]` | `TEXT NOT NULL`, a web address |
  | `category` | `OneOf(SourceCategory)` | `TEXT NOT NULL`, one of the twelve |
  | `collection_method` | `OneOf(CollectionMethod)` | `TEXT NOT NULL`, one of the ten |
  | `scan_every_hours` | `Mapped[int \| None]` | `INTEGER`, more than nought |
  | `terms_address` | `Mapped[WebAddress \| None]` | `TEXT`, a web address |
  | `licence` | `Mapped[NotEmpty \| None]` | `TEXT`, not empty |
  | `usage_restrictions` | `Mapped[NotEmpty \| None]` | `TEXT`, not empty |
  | `terms_read_at` | `Mapped[datetime \| None]` | `TEXT` |
  | `switched_on` | `Mapped[bool]`, `default=False` | `INTEGER NOT NULL`, 1 or 0 |

- **A new source is switched off, and it is switched on only after its
  terms were read** (CLAUDE.md §10). The model gives a new source "no".
  The table gives the column no value of its own: a row written past the
  model that does not say is refused, not switched on in silence. One
  check, `ck_source_switched_on_terms_read`, says
  `switched_on = 0 OR terms_read_at IS NOT NULL`. It refuses a source
  that is stored switched on without the time, one that is switched on
  later without it, and one that is switched on and loses it. A source
  can be switched off again and keeps the time. The table cannot know
  that somebody read the terms; it makes sure that whoever switches a
  source on has written down when.
- **Two sources may share a website** (the question PLAN-023 left to
  this trial). A source has one kind and one way of collecting, and its
  runs and its health will be its own (DAT-007, DAT-041). A site that is
  collected from in two ways is therefore two sources of two names with
  the same website. `website` is the address of the site, not of the
  page or feed that is read. Only the name is unique.
- **Names are told apart letter for letter.** `Example` and `EXAMPLE` are
  two names, and so are a name and the same name with a space after it:
  SQLite compares text that way unless a table says otherwise, and the
  table does not. A test pins it, and `DATABASE.md` says it.
- **A source may be without a scanning interval.** The task said "how
  often it is to be scanned". A source that is loaded once by a command,
  as the reference file of the countries will be (DAT-012), is not
  scanned by the clock at all, and a number invented for it would be a
  false statement in the store. So the column may be without a value,
  which means exactly that. Where there is a number, it is whole hours
  and more than nought: 24 is daily, 168 weekly.
- **The website is not optional.** Every record keeps the address it was
  found at (DESIGN §8), so every source is on the web.
- **Where the migrations are written.** In a module of their own,
  `motosphere.db.history`, apart from the runner: the runner seldom
  changes, and the history grows with every table. `MIGRATIONS` is defined there and imported by
  `motosphere.db.migrations`, so `migrations.MIGRATIONS` is still the
  name the runner reads and the tests replace.
- **A migration depends on nothing that can change.** It names no model,
  no list and no type of the store's code: the texts of the two lists
  and the white space of the checks are written out in the SQL. Inside
  `make_the_sources` two small functions write the check for empty text
  and the check for a web address once for each column that has it;
  they are inside the function so that no later migration can come to
  share them. The statement is otherwise what SQLAlchemy writes for the
  model, word for word, which the test of the models and the migrations
  holds it to.
- **How the tests of the whole schema see every model.**
  `motosphere/db/models/__init__.py` imports every model by name and
  gives the whole schema a name, `SCHEMA` (it is `Base.metadata`). Python
  runs a package's `__init__.py` before any module of the package, so
  whoever loads one model has loaded them all. The two tests take
  `SCHEMA` where they took `Base.metadata`. That `SCHEMA` is whole cannot
  be asked in the Python that runs the tests, where other tests have
  loaded models already (the test of the models and the migrations
  passes there today even without this change, and fails when it is run
  by itself: the trial saw both). So a new test asks a new Python, three
  times: which tables the models say after every module MotoSphere has
  was loaded, which tables `SCHEMA` has, and which there are after one
  model was loaded by its own module. All three must be the same.
- **The tests run on a store the migrations built**, not on one made
  from the models: that is how every real store comes to be. The
  fixture `newest` is in `conftest.py` because every table that follows
  needs it. It has no tests of its own: it is two lines, and 67 of the
  new tests fail if it does not migrate (the trial took the line out
  and put it back).
- **What SQLite says when it refuses is matched word for word**
  (`str(error.orig)`), so a test names the one constraint that refused
  the row, and not another whose name begins the same.
- **What is not decided here.** Whether a category for a publisher of
  reference data is needed (the twelve of the design name none) is for
  the trial of DAT-012. That a name is stored without white space
  around it is for whoever registers a source.

### 1. `backend/src/motosphere/db/history.py` – new, the whole file

```python
"""The history of the store's schema: every migration, oldest first.

A migration is a function that is given a connection and changes the
schema with it. ``MIGRATIONS`` is the list of them all, and the place of a
migration in that list is its number (:mod:`motosphere.db.migrations`
gives a store those it lacks).

- The list only ever grows at its end. A migration that has been merged is
  not changed, moved or taken out, because stores and snapshots at its
  version exist. A mistake in one is put right by a new one.
- A migration is plain SQL, written out here. It names no model, no list
  and no type of the store's code, and this module imports nothing of
  MotoSphere's: so a migration builds tomorrow what it builds today,
  whatever becomes of the code. What two migrations both need, each
  writes out for itself.
- A migration writes a table as its model makes it, and one test holds
  the two together (``DATABASE.md``, "The models and the migrations
  agree").
- A migration does not commit. ``migrate`` does, with the store's new
  version.
"""

from collections.abc import Callable

from sqlalchemy import Connection

__all__ = ["MIGRATIONS", "make_the_sources"]


def make_the_sources(connection: Connection) -> None:
    """1: the table of the information sources, ``source`` (DAT-006)."""
    white_space = (
        "char(9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, 8192, 8193, 8194, 8195, "
        "8196, 8197, 8198, 8199, 8200, 8201, 8202, 8232, 8233, 8239, 8287, 12288)"
    )

    def not_empty(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_not_empty CHECK (trim({column}, {white_space}) != '')"
        )

    def web_address(column: str) -> str:
        return (
            f"CONSTRAINT ck_source_{column}_web_address CHECK ("
            f"(({column} GLOB '[Hh][Tt][Tt][Pp][Ss]://[^/?#]*')"
            f" OR ({column} GLOB '[Hh][Tt][Tt][Pp]://[^/?#]*'))"
            f" AND NOT ({column} GLOB '*[' || {white_space} || ']*')"
            f" AND instr({column}, char(0)) = 0)"
        )

    connection.exec_driver_sql(
        f"""
        CREATE TABLE source (
            id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            website TEXT NOT NULL,
            category TEXT NOT NULL,
            collection_method TEXT NOT NULL,
            scan_every_hours INTEGER,
            terms_address TEXT,
            licence TEXT,
            usage_restrictions TEXT,
            terms_read_at TEXT,
            switched_on INTEGER NOT NULL,
            created_at TEXT NOT NULL,
            updated_at TEXT NOT NULL,
            CONSTRAINT ck_source_scan_every_hours_positive CHECK (scan_every_hours > 0),
            CONSTRAINT ck_source_switched_on_terms_read
                CHECK (switched_on = 0 OR terms_read_at IS NOT NULL),
            CONSTRAINT uq_source_name UNIQUE (name),
            {not_empty("name")},
            {web_address("website")},
            CONSTRAINT ck_source_category_one_of CHECK (category IN (
                'governing body', 'championship', 'organiser', 'promoter', 'track', 'club',
                'regional organisation', 'results database', 'news publication',
                'community website', 'social media page', 'historical archive'
            )),
            CONSTRAINT ck_source_collection_method_one_of CHECK (collection_method IN (
                'official api', 'structured feed', 'rss feed', 'public dataset',
                'html extraction', 'structured document', 'json endpoint', 'sitemap discovery',
                'search engine discovery', 'human submission'
            )),
            {web_address("terms_address")},
            {not_empty("licence")},
            {not_empty("usage_restrictions")},
            CONSTRAINT ck_source_switched_on_yes_or_no CHECK (switched_on IN (0, 1))
        ) STRICT
        """
    )


MIGRATIONS: tuple[Callable[[Connection], None], ...] = (make_the_sources,)
```

### 3. `backend/src/motosphere/db/models/source.py` – the whole file, in place of the one there

The two lists are as they were. New are the model at the end, the
imports it needs, and the first paragraph of the description.

```python
"""The information sources: where everything the store holds comes from.

A source is a website or a dataset that MotoSphere may collect from. This
module has the model of the table that knows them all, :class:`Source`,
and the two lists a source is described by: what kind of source it is,
and how it is collected from.

Each list is said once, here. Its values are the texts that are stored,
and a column of the list (:class:`motosphere.db.lists.OneOf`) refuses
every other text. The texts are in small letters, with one space between
two words. Once a table has a column of a list, a text of that list is
changed or taken away only by a migration, because the table's check names
the texts and rows hold them.
"""

from datetime import datetime
from enum import StrEnum

from sqlalchemy import CheckConstraint
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base
from motosphere.db.lists import OneOf
from motosphere.db.texts import NotEmpty
from motosphere.db.web import WebAddress

__all__ = ["CollectionMethod", "Source", "SourceCategory"]


class SourceCategory(StrEnum):
    """What kind of source this is: who publishes it (DESIGN.md 7.1, in its order)."""

    # A body that makes the rules of the sport, for the world or for a country.
    GOVERNING_BODY = "governing body"
    # The website of one championship or series.
    CHAMPIONSHIP = "championship"
    # Whoever runs a championship from year to year.
    ORGANISER = "organiser"
    # Whoever puts on single races and sells them.
    PROMOTER = "promoter"
    # One track, about itself.
    TRACK = "track"
    # A local motorcycle club.
    CLUB = "club"
    # An organisation for the racing of one region of a country.
    REGIONAL_ORGANISATION = "regional organisation"
    # A public collection of race results or of timing.
    RESULTS_DATABASE = "results database"
    # A magazine or a news site about the sport.
    NEWS = "news publication"
    # A website the riders and followers of the sport write themselves.
    COMMUNITY = "community website"
    # A public page on a social network, only where that network permits collecting.
    SOCIAL_MEDIA = "social media page"
    # A public archive of how the sport was.
    ARCHIVE = "historical archive"


class CollectionMethod(StrEnum):
    """How a source is collected from (DESIGN.md 7.2, in its order)."""

    # An interface the source itself offers to programs.
    API = "official api"
    # A feed of records in a form made for programs, such as a calendar file.
    STRUCTURED_FEED = "structured feed"
    # A feed of what is new, as RSS or Atom.
    RSS = "rss feed"
    # A whole set of records published for reuse, under a licence.
    DATASET = "public dataset"
    # Pages made for people, only where the site's terms and its robots.txt permit.
    HTML = "html extraction"
    # A public document with a fixed layout, such as a results sheet.
    DOCUMENT = "structured document"
    # The data behind a public page, only where the source authorises its use.
    JSON = "json endpoint"
    # The list of its pages that a site publishes for programs.
    SITEMAP = "sitemap discovery"
    # What a search engine finds, only where the engine permits it.
    SEARCH = "search engine discovery"
    # A reference a person has sent in.
    SUBMITTED = "human submission"


class Source(Base):
    """One source of information: who it is, how it is collected from and how it may be used.

    A new source is switched off. It is switched on only after a person
    has read its terms, and the table itself refuses a row that is
    switched on and does not say when they were read.
    """

    __tablename__ = "source"
    __table_args__ = (
        CheckConstraint("scan_every_hours > 0", name="scan_every_hours_positive"),
        CheckConstraint(
            "switched_on = 0 OR terms_read_at IS NOT NULL", name="switched_on_terms_read"
        ),
    )

    # What the source is called. No two sources have one name.
    name: Mapped[NotEmpty] = mapped_column(unique=True)
    # The address of the site it is: its front page, not the page or feed
    # that is read. Two sources can have one website: a site that is
    # collected from in two ways is two sources.
    website: Mapped[WebAddress]
    category: Mapped[SourceCategory] = mapped_column(OneOf(SourceCategory))
    collection_method: Mapped[CollectionMethod] = mapped_column(OneOf(CollectionMethod))
    # After how many hours it is to be looked at again. No value: it is
    # not looked at by the clock, only when somebody loads it.
    scan_every_hours: Mapped[int | None]
    # Where its terms of use are, if it has any.
    terms_address: Mapped[WebAddress | None]
    # The licence under which what it publishes may be used, as the source names it.
    licence: Mapped[NotEmpty | None]
    # What its terms ask for or forbid, in plain words.
    usage_restrictions: Mapped[NotEmpty | None]
    # When a person last read its terms. No value: nobody has yet.
    terms_read_at: Mapped[datetime | None]
    # Whether MotoSphere collects from it.
    switched_on: Mapped[bool] = mapped_column(default=False)
```

### 4. `backend/tests/integration/test_history.py` – new, the whole file, 6 tests

```python
"""Tests of the store's own history: the real migrations, against real SQLite files."""

import ast
from pathlib import Path

import pytest
from sqlalchemy import Engine

from motosphere.db import history, migrations
from motosphere.db.history import MIGRATIONS
from motosphere.db.migrations import APPLICATION_ID, migrate, pending, schema_version


def tables(store: Engine) -> list[str]:
    """The tables of the store, without those SQLite keeps for itself."""
    with store.connect() as connection:
        found = connection.exec_driver_sql(
            "SELECT name FROM sqlite_master "
            "WHERE type = 'table' AND name NOT LIKE 'sqlite~_%' ESCAPE '~' ORDER BY name"
        )
        return [str(name) for (name,) in found]


def test_the_history_is_these_migrations_in_this_order() -> None:
    # The list only grows at its end: a new migration adds its name here, last.
    assert [migration.__name__ for migration in MIGRATIONS] == ["make_the_sources"]


def test_the_history_is_the_one_the_store_is_migrated_with() -> None:
    assert migrations.MIGRATIONS is MIGRATIONS


@pytest.mark.parametrize("number", range(1, len(MIGRATIONS) + 1))
def test_each_migration_is_taken_by_a_store_at_the_version_before_it(
    store: Engine, number: int
) -> None:
    migrate(store, MIGRATIONS[: number - 1])
    assert schema_version(store) == number - 1

    applied = migrate(store, MIGRATIONS[:number])

    assert applied == [number]
    assert schema_version(store) == number


def test_the_first_migration_makes_the_table_of_the_sources(store: Engine) -> None:
    assert tables(store) == []

    migrate(store, MIGRATIONS[:1])

    assert tables(store) == ["source"]
    with store.connect() as connection:
        assert connection.exec_driver_sql("PRAGMA application_id").scalar_one() == APPLICATION_ID
        assert connection.exec_driver_sql("SELECT count(*) FROM source").scalar_one() == 0


def test_a_store_with_the_newest_schema_lacks_no_migration(newest: Engine) -> None:
    assert schema_version(newest) == len(MIGRATIONS)
    assert pending(newest) == []


def test_the_history_names_nothing_of_the_stores_code() -> None:
    # A migration that named a model, a list or a type would build something
    # else once that was changed.
    written = ast.parse(Path(history.__file__).read_text(encoding="utf-8"))
    named: list[str] = []
    for part in ast.walk(written):
        if isinstance(part, ast.Import):
            named.extend(alias.name for alias in part.names)
        elif isinstance(part, ast.ImportFrom):
            named.append("." * part.level + (part.module or ""))

    assert "sqlalchemy" in named
    assert [name for name in named if name.startswith(("motosphere", "."))] == []
```

### 5. `backend/tests/integration/test_models.py` – new, the whole file, 2 tests

```python
"""Tests that the whole schema is whole: no model anywhere in the code is missing from it.

Each question is asked of a new Python, which has loaded nothing but what
it is told to: in the Python that runs the tests, other tests have loaded
models already.
"""

import subprocess
import sys

TIMEOUT_SECONDS = 60

# Load every module MotoSphere has, and say which tables the models then say.
EVERY_MODULE = """
import importlib
import pkgutil

import motosphere
from motosphere.db.base import Base

for module in pkgutil.walk_packages(motosphere.__path__, "motosphere."):
    if module.name != "motosphere.__main__":
        importlib.import_module(module.name)
print(*sorted(Base.metadata.tables))
"""
```
