## Objective

A model can say that a column's value is one of a fixed list, and the
store refuses any other.

## Why

The first real table is close (the information sources, DAT-006), and two
of its columns are each one of a short list the code knows: the category
of a source and the way it is collected (DESIGN §7.1, §7.2). The tables
after it have more: how a run ended, the state of a review item, how sure
a record is.

Today such a column could only be plain text, and a misspelled word or a
word nobody ever decided on would be stored like any other. This task
gives the store a column type for it, the third that brings its check
(DAT-034) and the third of the four small tasks before the first table
(PLAN-021, in `PROGRESS.md`).

## Design in short

- **One new module, `motosphere.db.lists`**, with the column type `OneOf`
  and the function `one_of(name, the_list)` that gives the check.
- **A list is a `StrEnum`.** Its values are the texts that are stored:
  `class Surface(StrEnum): SAND = "sand"`. It is said once, in the code.
- **A model names the type and the list**:
  `surface: Mapped[Surface] = mapped_column(OneOf(Surface))`, and
  `Mapped[Surface | None]` for a column that may be without a value.
- **In the table the column is TEXT with a check that names the texts**,
  in the order of the list:
  `CONSTRAINT ck_<table>_<column>_one_of CHECK (<column> IN ('sand', 'hard pack'))`.
  `Base` gives the check to the table, because `OneOf` is a
  `WithItsCheck` (DAT-034).
- **Only a value of the list is stored.** Text is refused before anything
  is written, also text that is spelled like a value, and so is a value
  of another list, with a `TypeError` that says what was given. What is
  read comes back as the value of the list itself.
- **What is not a list is refused when the type is made**: anything that
  is not a `StrEnum`, a list with nothing on it, and a list with an empty
  value.
- No new package, no model, no table, no migration. **No existing file of
  code changes**, `base.py` neither.

## What the task left open, and what the trial settled

- **How a list is said.** As a `StrEnum` (Python 3.11; the project needs
  3.12). The code then names a value, `Surface.SAND`, and cannot misspell
  it without the type check noticing; a value is text, so it goes into
  the published data as it is; and the list can be asked for its values,
  which is what the check is written from.
- **How a model says it.** By naming the type,
  `mapped_column(OneOf(Surface))`. For text that must not be empty and
  for yes or no a model says only the column's Python type, because
  `Base` has an entry for it. A list cannot have one: there is one type
  for each list. SQLAlchemy has a way to make `Mapped[Surface]` enough,
  but only through a method it keeps to itself
  (`_resolve_for_python_type`), and the store does not build on those.
- **What happens when a model forgets.** `surface: Mapped[Surface]` alone
  gives SQLAlchemy's own type for a list, which would store the names of
  the values in a column of a type no strict table takes: SQLite refuses
  to make the table (`unknown datatype for proof_stall.kind:
  "VARCHAR(5)"`). So the slip cannot go unnoticed, and one test holds
  that.
- **What the values look like in the file.** The text of the value, not
  its name: `'hard pack'`, not `HARD_PACK`. So the file can be read
  without the code, and a value can be given another name in the code
  without a migration.
- **Why text is not taken for a value.** A model's column is declared as
  the list, so the type check already asks for a value of it. Taking
  text at run time as well would let through what the type check cannot
  see, and a value of another list that happens to be spelled the same
  (both of the tests' lists have a `track`). The type takes values of its
  own list and nothing else, as the type for yes or no takes `True` and
  `False` only (DAT-035).
- **What a change to a list means for a migration.** The check names the
  texts, so a value more, a value less, another spelling and another
  order are each a change to the schema: the test that holds the models
  and the migrations together (DAT-026) fails until a migration builds
  the table anew. `DATABASE.md` says so, and that a new value goes at the
  end.
- **A list with an empty value is refused.** "Not known" is said with no
  value, in one way only, as for text that must not be empty (DAT-030).
- **A gap the planted defects found, and closed.** With the first tests,
  a check that named the texts in small letters went unnoticed, because
  every text of the tests' lists was in small letters. One list now has
  a text with large letters (`MXoN`), in the unit and in the integration
  tests.
- **Two such types must not be taken for one.** SQLAlchemy keeps a
  statement it has seen and uses it again for one that is the same but
  for its values. It tells two `OneOf` types apart by the list they were
  made with, because the type keeps the list under the name its maker
  takes it by (`the_list`). One test proves it with two statements that
  differ in the list only.

### 1. `backend/src/motosphere/db/lists.py` – new, the whole file

```python
"""A column whose value is one of a list.

Much of what the store holds is one of a few values the code knows: what
kind of source this is, how a run ended, how sure a record is. Such a list
is said once, as a ``StrEnum``, whose values are the texts that are stored:

    class Surface(StrEnum):
        SAND = "sand"
        HARD_PACK = "hard pack"

A model says of a column that its value is one of the list:

    surface: Mapped[Surface] = mapped_column(OneOf(Surface))

The column is then TEXT with a check in its table that names the values,
and SQLite itself refuses a row with any other text in it, whoever writes
it. To Python the column is a value of the list, and only such a value is
stored: text is refused, also text that is spelled like a value, and so is
a value of another list.

A column that may be without a value says ``Mapped[Surface | None]``: it
holds no value or a value of the list.
"""

from enum import StrEnum
from inspect import isclass
from typing import override

from sqlalchemy import CheckConstraint, Dialect, Text, column
from sqlalchemy.types import TypeDecorator

from motosphere.db.checks import WithItsCheck

__all__ = ["OneOf", "one_of"]


def _is_a_list(what: object) -> bool:
    """Say whether this is a list as the store means one: a ``StrEnum``, the class itself."""
    return isclass(what) and issubclass(what, StrEnum)


class OneOf(WithItsCheck, TypeDecorator[StrEnum]):
    """The type of a column whose value is one of a list. In the table it is TEXT."""

    impl = Text
    cache_ok = True
    refuses = "text that is not on its list"
    given_by = "one_of"

    def __init__(self, the_list: type[StrEnum]) -> None:
        """Take the list the column's values are of. What is not a list is refused.

        A list is a ``StrEnum`` with at least one value, none of them empty:
        a column says "not known" with no value, not with a value that is
        empty text.
        """
        if not _is_a_list(the_list):
            raise TypeError(f"A list is a StrEnum, with the texts that are stored: {the_list!r}.")
        if not list(the_list):
            raise ValueError(f"The list {the_list.__name__} has nothing on it.")
        for value in the_list:
            if not value.value.strip():
                raise ValueError(f"The list {the_list.__name__} has an empty value: {value!r}.")
        super().__init__()
        # SQLAlchemy tells two such types apart by this, which is why it has
        # the name it has above: a statement is kept for one list only.
        self.the_list = the_list

    def check_for(self, name: str) -> CheckConstraint:
        """Give the check of :func:`one_of` for the column called ``name`` and this list."""
        return one_of(name, self.the_list)

    @override
    def process_bind_param(self, value: StrEnum | None, dialect: Dialect) -> str | None:
        """Turn a value of the list into the text that is stored."""
        if value is None:
            return None
        if not isinstance(value, self.the_list):
            raise TypeError(
                f"Only a value of the list {self.the_list.__name__} is stored in this column, "
                f"not {type(value).__name__}: {value!r}."
            )
        return value.value

    @override
    def process_result_value(self, value: str | None, dialect: Dialect) -> StrEnum | None:
        """Turn the text that is stored into the value of the list."""
        if value is None:
            return None
        try:
            return self.the_list(value)
        except ValueError:
            raise ValueError(
                f"The store holds what is not on the list {self.the_list.__name__}: {value!r}."
            ) from None


def one_of(name: str, the_list: type[StrEnum]) -> CheckConstraint:
    """Give the check that refuses every text but the list's in the column called ``name``.

    The check names the texts in the order of the list. It is called
    ``<name>_one_of``, which the naming rule makes
    ``ck_<table>_<name>_one_of`` once the check is given to a table. It
    belongs to no table until then. A column without a value passes it, as
    it passes every check.
    """
    texts = [value.value for value in the_list]
    return CheckConstraint(column(name).in_(texts), name=f"{name}_one_of")
```

### 2. `backend/tests/unit/test_db_lists.py` – new, the whole file, 32 tests

```python
"""Tests of a column whose value is one of a list, without a store.

``tests/integration/test_lists.py`` asks a real SQLite file what it refuses.
"""

from enum import Enum, StrEnum
from typing import Any

import pytest
from sqlalchemy import Column, Integer, MetaData, Table
from sqlalchemy.dialects import sqlite
from sqlalchemy.schema import conv

from motosphere.db import times
from motosphere.db.base import NAMING, broken_rules
from motosphere.db.checks import WithItsCheck
from motosphere.db.lists import OneOf, one_of
from motosphere.db.times import UtcDateTime


class Kind(StrEnum):
    TRACK = "track"
    CLUB = "club"


class Surface(StrEnum):
    """A second list. One of its texts is a text of the first list too."""

    SAND = "sand"
    HARD_PACK = "hard pack"
    TRACK = "track"


class Odd(StrEnum):
    """Texts with the characters a statement of SQL has a use for, and one in large letters."""

    QUOTE = "o'brien"
    TWO_QUOTES = 'say "go"'
    PERCENT = "50%"
    COLON = "a:b"
    QUESTION = "what?"
    BACKSLASH = "a\\b"
    LARGE = "MXoN"


class Twice(StrEnum):
    """A list with two names for one value."""

    DIRT = "dirt"
    SOIL = "dirt"
    GRASS = "grass"


class Colour(Enum):
    """Not a list of the store's kind: its values are not texts."""

    RED = 1


NOT_ON_IT = "The store holds what is not on the list Kind: {!r}."
NO_CHECK = (
    "The table owner does not refuse text that is not on its list in its column kind: "
    "it must have the check that one_of gives for the column, named by the naming rule."
)


def said(name: str, the_list: type[StrEnum]) -> str:
    """The check of a column of this name and list, as SQLite is given it."""
    written = one_of(name, the_list).sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )
    return str(written)


def test_a_value_of_the_list_is_stored_as_its_text() -> None:
    stored = OneOf(Kind).process_bind_param(Kind.CLUB, sqlite.dialect())

    assert stored == "club"
    # Plain text, not the value of the list under another name.
    assert type(stored) is str


@pytest.mark.parametrize(
    ("value", "sentence"),
    [
        ("track", "not str: 'track'."),
        ("shop", "not str: 'shop'."),
        (Surface.TRACK, "not Surface: <Surface.TRACK: 'track'>."),
        (1, "not int: 1."),
    ],
    ids=[
        "text that is spelled like a value",
        "text that is not on the list",
        "a value of another list with the same text",
        "a number",
    ],
)
def test_what_is_not_a_value_of_the_list_is_refused(value: Any, sentence: str) -> None:
    with pytest.raises(TypeError, match="Only a value of the list") as refused:
        OneOf(Kind).process_bind_param(value, sqlite.dialect())

    assert str(refused.value) == (
        f"Only a value of the list Kind is stored in this column, {sentence}"
    )


def test_the_text_is_read_as_the_value_of_the_list() -> None:
    column_type = OneOf(Kind)
    dialect = sqlite.dialect()

    assert column_type.process_result_value("track", dialect) is Kind.TRACK
    assert column_type.process_result_value("club", dialect) is Kind.CLUB
    assert OneOf(Surface).process_result_value("track", dialect) is Surface.TRACK


@pytest.mark.parametrize(
    "text",
    ["shop", "TRACK", "track ", "", "sand", 1],
    ids=[
        "another word",
        "in large letters",
        "with a space after it",
        "nothing",
        "a text of another list",
        "a number",
    ],
)
def test_text_that_is_not_on_the_list_is_refused_when_it_is_read(text: Any) -> None:
    with pytest.raises(ValueError, match="not on the list") as refused:
        OneOf(Kind).process_result_value(text, sqlite.dialect())

    assert str(refused.value) == NOT_ON_IT.format(text)
    # The sentence is the whole of it: Python's own refusal is not shown behind it.
    assert refused.value.__suppress_context__


def test_the_column_type_leaves_no_value_as_no_value() -> None:
    column_type = OneOf(Kind)
    dialect = sqlite.dialect()

    assert column_type.process_bind_param(None, dialect) is None
    assert column_type.process_result_value(None, dialect) is None


def test_in_the_table_the_type_is_text() -> None:
    assert str(OneOf(Kind).compile(dialect=sqlite.dialect())) == "TEXT"


def test_the_check_names_the_texts_in_the_order_of_the_list() -> None:
    assert said("kind", Kind) == "kind IN ('track', 'club')"
    assert said("surface", Surface) == "surface IN ('sand', 'hard pack', 'track')"


def test_the_check_of_a_column_named_with_a_word_of_sql_names_it_in_quotes() -> None:
    assert said("group", Kind) == "\"group\" IN ('track', 'club')"


def test_a_text_is_written_into_the_check_as_text_whatever_characters_it_has() -> None:
    assert said("mark", Odd) == (
        "mark IN ('o''brien', 'say \"go\"', '50%', 'a:b', 'what?', 'a\\b', 'MXoN')"
    )


def test_a_value_with_two_names_is_named_once() -> None:
    assert said("ground", Twice) == "ground IN ('dirt', 'grass')"
    assert OneOf(Twice).process_bind_param(Twice.SOIL, sqlite.dialect()) == "dirt"
    assert OneOf(Twice).process_result_value("dirt", sqlite.dialect()) is Twice.DIRT


def test_the_check_is_named_after_its_column_and_by_the_naming_rule() -> None:
    check = one_of("kind", Kind)

    assert check.name == "kind_one_of"

    owner = Table(
        "owner",
        MetaData(naming_convention=NAMING),
        Column("id", Integer),
        Column("kind", OneOf(Kind)),
    )

    assert check not in owner.constraints

    owner.append_constraint(check)

    assert check.name == "ck_owner_kind_one_of"
    assert isinstance(check.name, conv)


def test_the_type_brings_the_check_that_one_of_gives_for_its_list() -> None:
    its_type = OneOf(Surface)
    brought = its_type.check_for("surface")

    assert isinstance(its_type, WithItsCheck)
    assert brought.name == "surface_one_of"
    assert str(
        brought.sqltext.compile(dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True})
    ) == said("surface", Surface)
    assert its_type.refuses == "text that is not on its list"
    assert its_type.given_by == one_of.__name__


@pytest.mark.parametrize(
    ("not_a_list", "shown"),
    [
        (str, "<class 'str'>"),
        (Colour, "<enum 'Colour'>"),
        (["track", "club"], "['track', 'club']"),
        (Kind.TRACK, "<Kind.TRACK: 'track'>"),
        ("Kind", "'Kind'"),
    ],
    ids=[
        "text itself",
        "an enum whose values are not texts",
        "texts in square brackets",
        "a value of a list",
        "the name of a list",
    ],
)
def test_what_is_not_a_list_is_refused(not_a_list: Any, shown: str) -> None:
    with pytest.raises(TypeError, match="A list is a StrEnum") as refused:
        OneOf(not_a_list)

    assert str(refused.value) == f"A list is a StrEnum, with the texts that are stored: {shown}."


def test_a_list_with_nothing_on_it_is_refused() -> None:
    class Nothing(StrEnum):
        pass

    with pytest.raises(ValueError, match="nothing on it") as refused:
        OneOf(Nothing)

    assert str(refused.value) == "The list Nothing has nothing on it."


@pytest.mark.parametrize(
    "empty",
    ["", " ", "\t\n", chr(160)],
    ids=["no characters", "a space", "a tab and a line end", "the space that cannot be broken"],
)
def test_a_list_with_an_empty_value_is_refused(empty: str) -> None:
    class Holed(StrEnum):
        FULL = "full"
        EMPTY = empty

    with pytest.raises(ValueError, match="an empty value") as refused:
        OneOf(Holed)

    assert str(refused.value) == f"The list Holed has an empty value: <Holed.EMPTY: {empty!r}>."


def a_table(schema: MetaData) -> Table:
    """A table made by hand that keeps every rule but one: its column kind has no check."""
    return Table(
        "owner",
        schema,
        Column("id", Integer, primary_key=True),
        Column("kind", OneOf(Kind), nullable=False),
        Column("created_at", UtcDateTime, nullable=False, default=times.now),
        Column("updated_at", UtcDateTime, nullable=False, default=times.now, onupdate=times.now),
        sqlite_strict=True,
        sqlite_autoincrement=True,
    )


def test_such_a_column_is_named_until_its_table_has_the_check() -> None:
    schema = MetaData(naming_convention=NAMING)
    owner = a_table(schema)

    assert broken_rules(schema) == [NO_CHECK]

    owner.append_constraint(one_of("kind", Kind))

    assert broken_rules(schema) == []


def test_the_check_for_another_list_does_not_count() -> None:
    schema = MetaData(naming_convention=NAMING)
    owner = a_table(schema)
    owner.append_constraint(one_of("kind", Surface))

    assert broken_rules(schema) == [NO_CHECK]
```

```python
"""Tests of a column whose value is one of a list, with tables made in a real SQLite file.

The lists and the models here are made for the tests. The models are
subclasses of the real ``Base``, so they prove what a model gets when it
says that a column's value is one of a list, but they are kept in schemas
of their own, so the real schema never sees them.
"""

from typing import Any

import pytest
from sqlalchemy import Engine, MetaData, literal, select
from sqlalchemy.exc import IntegrityError, OperationalError, StatementError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.lists import OneOf
from motosphere.db.work import unit_of_work

A_TIME = "2026-11-19T08:00:00.000000+00:00"

NOT_OF_THE_LIST = "Only a value of the list Kind is stored in this column"
# A row written with plain SQL. Its first two "?" are kind and surface; the
# last two are its two times, which only the store's code sets.
PAST_THE_MODEL = (

class Kind(StrEnum):

    SHOP = "shop"


class Surface(StrEnum):
    """A second list. One of its texts is a text of the first list too."""

    SAND = "sand"
    HARD_PACK = "hard pack"
    TRACK = "track"


class Odd(StrEnum):
    """Texts with the characters SQL has a use for, in large letters, and beyond ASCII."""

    QUOTE = "o'brien"
    TWO_QUOTES = 'say "go"'
    PERCENT = "50%"
    COLON = "a:b"
    QUESTION = "what?"
    BACKSLASH = "a\\b"
    LARGE = "MXoN"
    ACCENT = "caf" + chr(233)


class Proof(Base):
```
