## Objective

One command of the pipeline's command line brings the store the settings
name to the newest schema and says what it did.

## Why

`migrate` (DAT-004) brings a store to the newest schema, and since DAT-023
it refuses a file that is not MotoSphere's. But nothing calls it: no
command uses the store yet, and nothing reads the setting
`MOTOSPHERE_STORE_PATH`. The scheduled run will need one step that says
"bring the store up to date" before anything is collected, and whoever
reads that run's log must see in one line what happened to the store.

This is the third fifth of the old "DAT-004 – Schema migrations"
(PLAN-014, in `PROGRESS.md`).

## Design in short

- **The command is `python -m motosphere migrate`.** It takes no argument:
  the store is the file `MOTOSPHERE_STORE_PATH` names. (The name has seven
  letters like `version`, so the list of commands in the help keeps its
  columns and no existing test of the help changes.)
- One new module, `motosphere.cli.migrate`, built like
  `motosphere.cli.export`: `add_parser` registers the command, `run` does
  the work. `motosphere.cli.app` registers it between `export` and
  `version`.
- **What it does:** it makes the path whole, notes whether a file is
  there, opens the store with `open_store` (which makes the file and its
  folder if they are not there), calls `migrate`, and writes one sentence
  to standard output. Exit code 0.
- **What it says** is one function by itself, `report`, so that the
  sentences can be tested without a store:
  - there was no file: "A new data store was made: <file> is at schema
    version N."
  - the store was given migrations: "The data store was brought up to
    date: <file> went from schema version A to B."
  - it lacked none: "The data store is up to date: <file> is at schema
    version N."

  The file is always named with its whole path, as `SchemaError` names it.
- **A store that cannot be opened (`StoreError`) or that is refused
  (`SchemaError`)** gives its own sentence on standard error, with nothing
  before or after it, and the exit code 1 (`EXIT_STORE_REFUSED`). Nothing
  is written to standard output, and the file is left as it is. The exit
  code 2 stays what it is: wrong arguments or wrong settings.
- **An error inside a migration is not caught.** It is a fault in the
  code, not a store that is refused: its traceback is what whoever mends
  it needs, the process ends with an exit code other than 0 by itself, and
  the store stays at the version before that migration (DAT-004). One test
  holds that the command does not swallow it.
- **No log line.** The sentence on standard output is what the command
  has to say; a second line that says it again would be noise.
- The pipeline's list of migrations is still empty. So today the command
  makes an empty file and says "is at schema version 0", and a second run
  says the store is up to date. That is right, and the tests that run the
  command in a process of its own check exactly that, written so that they
  stay right when the first migration is added (`len(MIGRATIONS)`).
- No new package.

### 1. `backend/src/motosphere/cli/migrate.py` – new, the whole file

```python
"""The ``migrate`` command: bring the data store to the newest schema."""

import argparse
import sys
from collections.abc import Sequence

from motosphere.core.settings import Settings
from motosphere.db.migrations import SchemaError, migrate, schema_version
from motosphere.db.store import StoreError, open_store

__all__ = ["EXIT_STORE_REFUSED", "add_parser", "report", "run"]

EXIT_STORE_REFUSED = 1


def add_parser(commands: "argparse._SubParsersAction[argparse.ArgumentParser]") -> None:
    """Register the ``migrate`` command."""
    parser = commands.add_parser(
        "migrate",
        help="bring the data store to the newest schema",
        description=(
            "Bring the data store to the newest schema. The store is the file the setting "
            "MOTOSPHERE_STORE_PATH names; it is made if it is not there."
        ),
        allow_abbrev=False,
    )
    parser.set_defaults(handler=run)


def report(path: str, made: bool, applied: Sequence[int], version: int) -> str:
    """Say in one sentence what the command did to the store at ``path``.

    ``made`` says that there was no file before, ``applied`` holds the
    numbers of the migrations the store was given, and ``version`` is the
    schema version the store has now.
    """
    if made:
        return f"A new data store was made: {path} is at schema version {version}."
    if applied:
        return (
            f"The data store was brought up to date: {path} went from schema version "
            f"{version - len(applied)} to {version}."
        )
    return f"The data store is up to date: {path} is at schema version {version}."


def run(_arguments: argparse.Namespace, settings: Settings) -> int:
    """Give the store the migrations it lacks and write what was done to standard output.

    A store that cannot be opened, or that is refused, gives its one
    sentence on standard error and the exit code 1, and is left as it is.
    An error inside a migration is not caught: it is a fault in the code,
    and the store stays at the version before that migration.
    """
    path = settings.store_path.resolve()
    made = not path.exists()
    try:
        store = open_store(path)
        applied = migrate(store)
    except (StoreError, SchemaError) as error:
        sys.stderr.write(f"{error}\n")
        return EXIT_STORE_REFUSED

    sys.stdout.write(report(str(path), made, applied, schema_version(store)) + "\n")
    return 0
```

"""Tests of what the ``migrate`` command says, and of its place in the command line."""

import pytest

from motosphere.cli import main
from motosphere.cli.migrate import report

STORE = "/data/store.sqlite3"


@pytest.mark.parametrize(
    ("made", "applied", "version", "sentence"),
    [
        (True, [], 0, f"A new data store was made: {STORE} is at schema version 0."),
        (True, [1, 2, 3], 3, f"A new data store was made: {STORE} is at schema version 3."),
        (
            False,
            [1],
            1,
            f"The data store was brought up to date: {STORE} went from schema version 0 to 1.",
        ),
        (
            False,
            [3, 4, 5],
            5,
            f"The data store was brought up to date: {STORE} went from schema version 2 to 5.",
        ),
        (False, [], 5, f"The data store is up to date: {STORE} is at schema version 5."),
    ],
    ids=[
        "a new store, nothing to apply",
        "a new store",
        "one migration",
        "three migrations",
        "up to date",
    ],

def test_the_report_says_what_was_done(
    made: bool, applied: list[int], version: int, sentence: str

        main(["--help"])

    assert exit_info.value.code == 0
    assert "migrate   bring the data store to the newest schema" in capsys.readouterr().out

### 3. `backend/tests/integration/test_migrate_command.py` – new, the whole file, 6 tests

```python
"""Tests of the ``migrate`` command with a history of migrations, against a real SQLite file.

    with open_store(path).connect() as connection:
        found = connection.exec_driver_sql("SELECT name FROM sqlite_master ORDER BY name")
        return [str(name) for (name,) in found]


def test_a_store_that_is_not_there_is_made_at_the_newest_schema(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE)

    assert main(["migrate"]) == 0

    captured = capsys.readouterr()
    assert captured.out == f"A new data store was made: {place} is at schema version 3.\n"
    assert captured.err == ""
    assert schema_version(open_store(place)) == 3
    assert tables(place) == ["first", "second", "third"]


def test_a_second_run_says_the_store_is_up_to_date_and_changes_nothing(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE)
    main(["migrate"])
    capsys.readouterr()
    before = place.read_bytes()

    assert main(["migrate"]) == 0

    captured = capsys.readouterr()
    assert captured.out == f"The data store is up to date: {place} is at schema version 3.\n"
    assert captured.err == ""
    assert place.read_bytes() == before


def test_a_store_is_given_the_migrations_it_lacks(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE[:1])
    main(["migrate"])
    capsys.readouterr()
    history(monkeypatch, *THREE)

    assert main(["migrate"]) == 0

    captured = capsys.readouterr()
    assert captured.out == (
        f"The data store was brought up to date: {place} went from schema version 1 to 3.\n"
    )
    assert captured.err == ""
    assert tables(place) == ["first", "second", "third"]


def test_a_store_newer_than_the_code_is_refused_in_one_line_and_left_as_it_is(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    history(monkeypatch, *THREE)
    main(["migrate"])
    capsys.readouterr()
    before = place.read_bytes()
    history(monkeypatch, *THREE[:2])

    assert main(["migrate"]) == 1

    captured = capsys.readouterr()
    assert captured.out == ""
    assert captured.err == (
        "The data store cannot be brought up to date: its schema is version 3, "
        "and this MotoSphere knows only the versions 0 to 2.\n"
    )
    assert place.read_bytes() == before


def test_an_error_inside_a_migration_is_not_caught(
    place: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    error = RuntimeError("the migration failed part-way")

    def fail(_connection: Connection) -> None:
        raise error

    history(monkeypatch, make("first"), fail, make("third"))

    with pytest.raises(RuntimeError) as caught:
        main(["migrate"])

    assert caught.value is error
    assert capsys.readouterr().out == ""
    assert schema_version(open_store(place)) == 1
    assert tables(place) == ["first"]


def test_a_relative_store_path_is_taken_from_the_current_folder(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch, capsys: pytest.CaptureFixture[str]
) -> None:
    # The shared fixture has made tmp_path the current folder.
    monkeypatch.setenv("MOTOSPHERE_STORE_PATH", "data/store.sqlite3")
    history(monkeypatch, *THREE)
    place = (tmp_path / "data" / "store.sqlite3").resolve()

    assert main(["migrate"]) == 0

    assert capsys.readouterr().out == (
        f"A new data store was made: {place} is at schema version 3.\n"
    )
    assert schema_version(open_store(place)) == 3

+    assert result.stderr == ""
+    assert store.is_file()
+
+
+def test_migrate_a_second_time_says_the_store_is_up_to_date_and_changes_nothing(
+    tmp_path: Path,
+) -> None:
+    store = (tmp_path / "elsewhere" / "data.sqlite3").resolve()
+    setting = {"MOTOSPHERE_STORE_PATH": str(Path("elsewhere", "data.sqlite3"))}
+    first = _run(tmp_path, "migrate", extra_env=setting)
+    before = store.read_bytes()
+
+    second = _run(tmp_path, "migrate", extra_env=setting)
+
+    assert first.returncode == 0, first.stderr
+    assert second.returncode == 0, second.stderr
+    assert second.stdout == (
+        f"The data store is up to date: {store} is at schema version {len(MIGRATIONS)}.\n"
+    )
+    assert second.stderr == ""
+    assert store.read_bytes() == before
+    assert not (tmp_path / "store").exists()
+
+
+def test_migrate_refuses_the_database_of_another_program_in_one_line(tmp_path: Path) -> None:
+    theirs = (tmp_path / "theirs.sqlite3").resolve()
+    with closing(sqlite3.connect(theirs, autocommit=True)) as connection:
+        connection.execute("CREATE TABLE theirs (id INTEGER PRIMARY KEY)")
+    before = theirs.read_bytes()
+
+    result = _run(tmp_path, "migrate", extra_env={"MOTOSPHERE_STORE_PATH": "theirs.sqlite3"})
+
+    assert result.returncode == 1
+    assert result.stdout == ""
+    assert result.stderr == (
+        f"The data store cannot be brought up to date: {theirs} is not a store of "
+        "MotoSphere's (it is not a new, empty file, and it does not carry MotoSphere's mark).\n"
+    )
+    assert theirs.read_bytes() == before
+
+
+def test_migrate_refuses_a_file_that_is_no_database_in_one_line(tmp_path: Path) -> None:
+    notes = (tmp_path / "notes.txt").resolve()
+    notes.write_bytes(b"These are notes, not a database.\n" * 40)
+
+    result = _run(tmp_path, "migrate", extra_env={"MOTOSPHERE_STORE_PATH": "notes.txt"})
+
+    assert result.returncode == 1
+    assert result.stdout == ""
+    lines = result.stderr.splitlines()
+    assert len(lines) == 1, result.stderr
+    assert lines[0].startswith(
+        f"The data store cannot be opened: {notes} cannot be read as an SQLite database ("
+    )
+    assert notes.read_bytes() == b"These are notes, not a database.\n" * 40
````

## Acceptance criteria

1. `python -m motosphere migrate` is in the command line's help, has a
   help of its own that names `MOTOSPHERE_STORE_PATH`, and takes no
   argument.
2. Where there is no file, the store is made, with its folder, at the
   newest schema, and the command says "A new data store was made: <file>
   is at schema version N." on standard output; exit code 0, nothing on
   standard error.
3. A second run says "The data store is up to date: <file> is at schema
   version N." and the file is byte for byte as before.
4. A store that lacks migrations is given them, and the command says "The
   data store was brought up to date: <file> went from schema version A
   to B."
5. The file is named with its whole path, also when the setting is a
   relative path, which is taken from the current folder.
6. A store that is refused (the database of another program, a store
   newer than the code) and a file that cannot be opened as a store (a
   file that is no database) each give exactly one line on standard error,
   their own sentence, nothing on standard output and the exit code 1,
   and the file is byte for byte as before.
7. An error inside a migration reaches the caller as it was raised; the
   store stays at the version before that migration.
8. The type check passes with no `ignore`, and no new `noqa` is added.
9. No existing test changed, and all pass. The full run reports 19 of 19
   gates and 876 tests (backend tests 246).
10. On the pull request, "All gates (Linux)" and "All gates (Windows)" are
    green with those numbers, and the three jobs after the gates are
    skipped.
11. Only the files under "Scope" changed.
