# DAT-046 – A table of collected records without its provenance is named

**Phase:** 2 – Data store and published data
**Depends on:** DAT-008 and DAT-045 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §11, `docs/WORKFLOW.md`, `PROGRESS.md`
(PLAN-027), `DATABASE.md` ("The rules every table keeps", "Where a
collected record came from"), `TESTING.md` ("The rules every table
keeps", "Where a collected record came from"),
`backend/src/motosphere/db/base.py`,
`backend/src/motosphere/db/models/provenance.py`,
`backend/tests/unit/test_db_base.py`,
`backend/tests/unit/test_db_models_collected.py`

## Objective

A table of collected records that was made without the set of DAT-008,
or with a part of it changed, is named in plain words, and a test holds
the real schema to it.

## Why

Every collected record must say where it came from (DESIGN.md §8,
CLAUDE.md §11: "Every record must retain its source and collection
history"). `Collected` gives a table the columns for that, with the
index over its source and the check of its two times. But nothing stops
a model from being a subclass of `Base` where it should be one of
`Collected`: its table is then a good table by every rule there is, and
its records say nothing of where they came from. Nor does anything stop
a model from saying a column of the set again in its own way, as plain
text or with a value the table gives by itself. The first real table of
collected records comes soon (DAT-011 on), and from then on there are
many. The rule is written before the first of them, so that no table is
ever made past it.

## Design in short

- **One new module**, `motosphere.db.models.provenance_rule`, with one
  function and one list.
- **`broken_provenance(schema, not_collected)`** says which tables of a
  schema do not say where their records came from: one plain sentence
  for each break, and an empty list for a schema that keeps the rule.
- **A table holds collected records unless the list names it.**
  `NOT_COLLECTED` is the list of the real schema: its three tables, each
  with the reason why it holds nothing collected.
- **A table of collected records must have** the eight columns, each as
  the set has it; an index over `source_id` alone; and the check of its
  two times.
- A test holds the real schema to the rule with that list.
- No table, no migration, no new package. No existing file of code or
  tests changes: not `base.py`, and not `provenance.py`.

## What the task left open, and what the trial settled

- **How the rule knows which tables hold collected records: all of
  them, unless a list says otherwise.** The task named this as the
  first thing to try, and it is the one that works. A rule cannot look
  for the tables that have the columns, because the table to be named
  is the one without them. It does not ask what a model is a subclass
  of either: like `broken_rules` it looks at tables, so it also holds a
  table made by hand and a schema made for a test. With a list of the
  tables that do *not* hold collected records, a new table that nobody
  thought about is named, and the list has each table with its reason,
  which is read with the change that puts it there.
- **The list is given to the function**, and is not built into it. The
  tests give their own schemas with their own lists; the real schema is
  asked with `NOT_COLLECTED`.
- **Beside `broken_rules`, not a part of it.** `Base` knows nothing of
  sources, and `broken_rules` is asked about many schemas that hold
  nothing collected (more than forty calls in the tests). So `base.py` does not
  change, and neither does any test of it.
- **In a module of its own**, not in `provenance.py`. That module says
  what a record keeps; this one says which tables must. `provenance.py`
  does not change.
- **The rule says the set a second time**, in its own words, and does
  not take it from `Collected`. The other way would be a model made
  from `Collected` inside the rule, to compare with: a mapped class in
  the code that is no table of the store, and a rule that could never
  disagree with `Collected`, whatever became of it. Said twice, a
  change to the set is made in two places, and the test that gives the
  tables of models of `Collected` to the rule fails until they agree.
  The trial planted the 83 defects of `Collected` that DAT-008 and
  DAT-045 planted, with only the new file of tests running: 70 of them
  fail it. The other 13 are in what this rule does not hold: the order
  of the columns, the key, a rule or an index of a table's own, a name
  given by hand and a check given twice. The tests of DAT-008 and
  DAT-045 detect all 83.
- **What "as the set has it" means for a column:** its type, and its
  list where it is of one (a list of the tests' own with the very texts
  of `Confidence` is not `Confidence`: what is read back would be a
  value of another list); that a row cannot be without it, unless it is
  `published_on`; that it is given no value, by the code or the table,
  when a row is stored or changed; that `source_id` refers to
  `source.id` and to nothing else, and says nothing of what happens
  when the source is deleted or changed, and that no other column of
  the set refers to anything.
- **What the rule does not hold:** the order of the columns, and
  anything else a table has. A model's own rule over the source and a
  name, or its own index that begins with the source, breaks nothing.
- **The index** is one over `source_id` alone, over all rows, in which
  two rows can be alike, whatever it is called: that a name was given
  by hand is for `broken_rules` to say.
- **The check** is looked for by the name the naming rule gives it and
  by its text, letter for letter. A check that means the same and is
  written otherwise is named: the table "must have the check that
  Collected gives".
- **One sentence for all missing columns of a table**, not one for
  each, and the index and the check are not asked for where a column
  they need is missing. A table that is simply not a table of
  collected records gets one sentence, which says both ways out.
- **The list is held to the schema as well:** a name on it that is no
  table is named, and so is a table on it that has all eight columns.
  A table on the list is not looked at otherwise, because the runs and
  the offers have a `source_id` of their own.
- **The test of the real schema would pass with a rule that names
  nothing**, because all three real tables are on the list today. So a
  second test takes each real table off the list in turn and holds the
  rule to the sentences it then has for it.

## What is left as it is

- Whether the rows of a table were collected is a person's judgement,
  written down in the list. The rule cannot tell a good reason from a
  bad one.
- The task that brings a table decides where it belongs: the countries
  (DAT-011) are the first, and its plan says whether they are collected
  records or a table for the list.

### 1. `backend/src/motosphere/db/models/provenance_rule.py` – new, the whole file

```python
"""The rule that every table of collected records says where its records came from.

A model whose records are collected is a subclass of ``Collected``
(:mod:`motosphere.db.models.provenance`) and its table then has the eight
columns of the set, the index over the source of its records and the
check of its two times. Nothing in that stops a model from being a
subclass of ``Base`` where it should be one of ``Collected``, or from
saying a column of the set again in its own way. :func:`broken_provenance`
says in plain words which tables of a schema do so, and a test holds the
real schema to it.

A table holds collected records unless it is on a list of those that do
not. So a new table that nobody thought about is named, and the list
says of each table on it why it is there. The list of the real schema
is :data:`NOT_COLLECTED`.

The rule says the set a second time, in its own words (``_THE_SET``),
and does not take it from ``Collected``. That is meant: a change to the
set must then be made in both places, and a test fails as long as the
two do not agree.

The rule stands beside :func:`motosphere.db.base.broken_rules` and is not
a part of it. ``Base`` knows nothing of sources, and most of the schemas
that function is asked about hold nothing that was collected.
"""

from collections.abc import Collection, Mapping
from typing import Any, Final

from sqlalchemy import CheckConstraint, Column, Integer, MetaData, Table
from sqlalchemy.types import TypeEngine

from motosphere.db.base import NAMING
from motosphere.db.days import CalendarDay
from motosphere.db.lists import OneOf
from motosphere.db.models.provenance import Confidence, VerificationStatus
from motosphere.db.models.source import CollectionMethod
from motosphere.db.times import UtcDateTime
from motosphere.db.web import WebAddressText

__all__ = ["NOT_COLLECTED", "broken_provenance"]

# The tables of the store that hold no collected records, each with why.
# A table is put here only with its reason: every other table must say
# where its records came from.
NOT_COLLECTED: Final[Mapping[str, str]] = {
    "collection_run": (
        "A run is the store's own record of its work: it is what collects, "
        "and not what is collected."
    ),
    "source": (
        "A source is where records come from. A person describes it and reads "
        "its terms: it is not collected from a source itself."
    ),
    "source_offer": (
        "What a source offers is part of the description of the source, which a person gives."
    ),
}

# The columns every table of collected records has, in their order, each
# with its type. They are said here a second time: see the top of the module.
_THE_SET: Final[Mapping[str, TypeEngine[Any]]] = {
    "source_id": Integer(),
    "source_address": WebAddressText(),
    "collected_at": UtcDateTime(),
    "published_on": CalendarDay(),
    "last_verified_at": UtcDateTime(),
    "extraction_method": OneOf(CollectionMethod),
    "confidence": OneOf(Confidence),
    "verification_status": OneOf(VerificationStatus),
}
# The one column of the set that may be without a value.
_MAY_BE_UNKNOWN: Final = "published_on"
# The one column of the set that refers to another table, and what it refers to.
_REFERS: Final = {"source_id": "source.id"}
# The check that holds the two times of a record together: the last part
# of its name, and what it says.
_THE_TWO_TIMES: Final = (
    "last_verified_at_not_before_collected_at",
    "last_verified_at >= collected_at",
)


def _of_the_same_type(found: TypeEngine[Any], wanted: TypeEngine[Any]) -> bool:
    """Say whether a column's type is the one the set has for it, and of the same list."""
    if type(found) is not type(wanted):
        return False
    if isinstance(found, OneOf) and isinstance(wanted, OneOf):
        return found.the_list is wanted.the_list
    return True


def _as_the_set_has_it(column: Column[Any]) -> bool:
    """Say whether a column of a table is as every table of collected records has it.

    It is of the type the set has for it. A row cannot be without it,
    unless it is the day the record was published. The table gives it no
    value, and neither does the store's code. It refers to the source if
    it is the source of the record, and to nothing otherwise, and says
    nothing of what happens when what it refers to is deleted or changed.
    """
    refers_to = {(key.target_fullname, key.ondelete, key.onupdate) for key in column.foreign_keys}
    wanted = {(_REFERS[column.name], None, None)} if column.name in _REFERS else set()
    return (
        _of_the_same_type(column.type, _THE_SET[column.name])
        and column.nullable == (column.name == _MAY_BE_UNKNOWN)
        and column.default is None
        and column.server_default is None
        and column.onupdate is None
        and column.server_onupdate is None
        and refers_to == wanted
    )


def _finds_the_records_of_a_source(table: Table) -> bool:
    """Say whether the table has an index over the source of its records alone.

    The index is over all rows, and two rows can be alike in it.
    """
    return any(
        [column.name for column in index.columns] == ["source_id"]
        and not index.unique
        and index.dialect_options["sqlite"]["where"] is None
        for index in table.indexes
    )


def _holds_its_two_times(table: Table) -> bool:
    """Say whether the table has the check of its two times, as ``Collected`` gives it.

    The check has the name the naming rule gives it and says what the
    check of ``Collected`` says, letter for letter.
    """
    last_part, says = _THE_TWO_TIMES
    name = NAMING["ck"] % {"table_name": table.name, "constraint_name": last_part}
    return any(
        isinstance(check, CheckConstraint)
        and str(check.name) == name
        and str(check.sqltext) == says
        for check in table.constraints
    )


def broken_provenance(schema: MetaData, not_collected: Collection[str]) -> list[str]:
    """Say which tables of ``schema`` do not say where their records came from.

    There is one plain sentence for each break, and a schema that keeps
    the rule gives an empty list. Every table holds collected records
    unless ``not_collected`` names it. Such a table must have the eight
    columns of the set, each as ``Collected`` gives it, an index over the
    source of its records alone, and the check that holds its two times
    together.

    The list is held to the schema as well: a name on it that is no
    table is named, and so is a table on it that has all eight columns.
    A table on the list is not looked at otherwise.
    """
    breaks = [
        f"The list of the tables that hold no collected records names {name}, "
        "which is no table of the schema."
        for name in sorted(set(not_collected) - set(schema.tables))
    ]
    for table in sorted(schema.tables.values(), key=lambda table: table.name):
        without = [name for name in _THE_SET if name not in table.columns]
        if table.name in not_collected:
            if not without:
                breaks.append(
                    f"The table {table.name} has the eight columns of collected records and is "
                    "on the list of the tables that hold none: it must come off the list."
                )
            continue
        if without:
            breaks.append(
                f"The table {table.name} is without {len(without)} of the eight columns every "
                f"table of collected records has ({', '.join(without)}): its model must be a "
                "subclass of Collected, or the table must be on the list of the tables that "
                "hold no collected records, with the reason."
            )
        breaks.extend(
            f"The table {table.name} does not have the column {name} as every table of "
            "collected records has it: a model takes the columns from Collected and does "
            "not say them itself."
            for name in _THE_SET
            if name in table.columns and not _as_the_set_has_it(table.columns[name])
        )
        if "source_id" in table.columns and not _finds_the_records_of_a_source(table):
            breaks.append(
                f"The table {table.name} has no index over source_id alone: every table of "
                "collected records has one, so that the records of one source are found "
                "without reading the whole table."
            )
        if not {"collected_at", "last_verified_at"} & set(without) and not _holds_its_two_times(
            table
        ):
            breaks.append(
                f"The table {table.name} does not refuse a record that was last seen at its "
                "source before it was collected: it must have the check that Collected gives, "
                "named by the naming rule."
            )
    return breaks
```

### 2. `backend/tests/unit/test_db_models_provenance_rule.py` – new, the whole file, 74 tests

```python
"""Tests of the rule that every table of collected records says where its records came from.

The tables here are made for the tests, by hand and each in a schema of
its own, so the real schema never sees them. Two models of the tests'
own, subclasses of the real ``Collected``, hold the rule to what a model
of collected records really gets.
"""

from datetime import UTC, datetime
from enum import StrEnum
from typing import Any

import pytest
from sqlalchemy import (
    BigInteger,
    CheckConstraint,
    Column,
    DateTime,
    ForeignKey,
    Index,
    Integer,
    MetaData,
    Table,
    Text,
    UniqueConstraint,
    text,
)
from sqlalchemy.orm import Mapped
from sqlalchemy.schema import SchemaItem

from motosphere.db import times
from motosphere.db.base import NAMING, broken_rules
from motosphere.db.checks import WithItsCheck
from motosphere.db.days import CalendarDay
from motosphere.db.lists import OneOf
from motosphere.db.models import SCHEMA
from motosphere.db.models.provenance import Collected, Confidence, VerificationStatus
from motosphere.db.models.provenance_rule import NOT_COLLECTED, broken_provenance
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.texts import NotEmpty
from motosphere.db.times import UtcDateTime
from motosphere.db.web import WebAddressText

KEPT: dict[str, Any] = {"sqlite_strict": True, "sqlite_autoincrement": True}
A_MOMENT = datetime(2026, 11, 25, 9, 30, tzinfo=UTC)
THE_EIGHT = (
    "source_id, source_address, collected_at, published_on, last_verified_at, "
    "extraction_method, confidence, verification_status"
)
WITHOUT = (
    "The table {} is without {} of the eight columns every table of collected records has "
    "({}): its model must be a subclass of Collected, or the table must be on the list of "
    "the tables that hold no collected records, with the reason."
)
NOT_AS_THE_SET = (
    "The table {} does not have the column {} as every table of collected records has it: "
    "a model takes the columns from Collected and does not say them itself."
)
NO_INDEX = (
    "The table {} has no index over source_id alone: every table of collected records has "
    "one, so that the records of one source are found without reading the whole table."
)
NO_CHECK = (
    "The table {} does not refuse a record that was last seen at its source before it was "
    "collected: it must have the check that Collected gives, named by the naming rule."
)
NO_TABLE = (
    "The list of the tables that hold no collected records names {}, which is no table of "
    "the schema."
)
LISTED_WITH_THE_SET = (
    "The table {} has the eight columns of collected records and is on the list of the "
    "tables that hold none: it must come off the list."
)
THE_TWO_TIMES = "last_verified_at >= collected_at"


class Standing(StrEnum):
    """A list of the tests' own, with the texts of the levels of confidence."""

    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"


class Proof(Collected):
    """A model of collected records of the tests' own, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=NAMING)


# A record refers to its source, so the schema of the tests knows that table too.
SCHEMA.tables["source"].to_metadata(Proof.metadata)


class ProofResult(Proof):
    """A model that says nothing of its own."""

    __tablename__ = "proof_result"


class ProofVenue(Proof):
    """A model that says more of its table, and has a second index that begins with the source."""

    __tablename__ = "proof_venue"
    __table_args__ = (
        UniqueConstraint("source_id", "name"),
        CheckConstraint("length_in_metres > 0", name="length_in_metres_positive"),
        Index(None, "source_id", "last_verified_at"),
    )

    name: Mapped[NotEmpty]
    length_in_metres: Mapped[int | None]


def a_schema() -> MetaData:
    """A schema with the naming rule of the real one, and a table of sources in it."""
    schema = MetaData(naming_convention=NAMING)
    Table("source", schema, the_key(), *the_times(), **KEPT)
    return schema


def the_key() -> Column[int]:
    return Column("id", Integer, primary_key=True)


def the_times() -> list[Column[datetime]]:
    return [
        Column("created_at", UtcDateTime, nullable=False, default=times.now),
        Column("updated_at", UtcDateTime, nullable=False, default=times.now, onupdate=times.now),
    ]


def the_set(**said: Column[Any] | None) -> list[Column[Any]]:
    """The eight columns as every table of collected records has them.

    ``said`` gives a column in another way, by its name, or leaves it
    out with ``None``.
    """
    as_it_is: dict[str, Column[Any] | None] = {
        "source_id": Column("source_id", Integer, ForeignKey("source.id"), nullable=False),
        "source_address": Column("source_address", WebAddressText, nullable=False),
        "collected_at": Column("collected_at", UtcDateTime, nullable=False),
        "published_on": Column("published_on", CalendarDay),
        "last_verified_at": Column("last_verified_at", UtcDateTime, nullable=False),
        "extraction_method": Column("extraction_method", OneOf(CollectionMethod), nullable=False),
        "confidence": Column("confidence", OneOf(Confidence), nullable=False),
        "verification_status": Column(
            "verification_status", OneOf(VerificationStatus), nullable=False
        ),
    }
    assert set(said) <= set(as_it_is)
    return [column for column in (as_it_is | said).values() if column is not None]


def the_index() -> Index:
    return Index(None, "source_id")


def the_check() -> CheckConstraint:
    return CheckConstraint(THE_TWO_TIMES, name="last_verified_at_not_before_collected_at")


def records(schema: MetaData, name: str, *more: SchemaItem, **said: Column[Any] | None) -> Table:
    """A table of collected records made by hand, with what ``more`` gives it besides.

    It has no index over its source and no check of its two times unless
    ``more`` gives them. As ``Base`` does for the table of a model, it is
    given the check of every column whose type brings one.
    """
    table = Table(name, schema, the_key(), *the_set(**said), *the_times(), *more, **KEPT)
    for column in table.columns:
        if isinstance(column.type, WithItsCheck):
            table.append_constraint(column.type.check_for(column.name))
    return table


def test_the_real_schema_breaks_no_rule_of_where_records_came_from() -> None:
    assert broken_provenance(SCHEMA, NOT_COLLECTED) == []


@pytest.mark.parametrize(
    ("name", "breaks"),
    [
        (
            "collection_run",
            [
                WITHOUT.format("collection_run", 7, THE_EIGHT.removeprefix("source_id, ")),
                NO_INDEX.format("collection_run"),
            ],
        ),
        ("source", [WITHOUT.format("source", 8, THE_EIGHT)]),
        (
            "source_offer",
            [
                WITHOUT.format("source_offer", 7, THE_EIGHT.removeprefix("source_id, ")),
                NO_INDEX.format("source_offer"),
            ],
        ),
    ],
    ids=["collection_run", "source", "source_offer"],
)
def test_every_table_of_the_real_schema_is_named_as_soon_as_it_is_off_the_list(
    name: str, breaks: list[str]
) -> None:
    # What makes the test above worth something: the rule looks at the real tables.
    assert name in NOT_COLLECTED
    the_others = [other for other in NOT_COLLECTED if other != name]

    assert broken_provenance(SCHEMA, the_others) == breaks


def test_every_table_on_the_list_of_the_real_schema_has_its_reason() -> None:
    assert list(NOT_COLLECTED) == sorted(NOT_COLLECTED)
    for reason in NOT_COLLECTED.values():
        assert reason == reason.strip()
        assert len(reason.split()) >= 8
        assert reason[0].isupper()
        assert reason.endswith(".")
    assert len(set(NOT_COLLECTED.values())) == len(NOT_COLLECTED)


def test_the_tables_of_models_of_collected_records_break_none() -> None:
```
