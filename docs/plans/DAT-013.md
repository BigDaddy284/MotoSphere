## Objective

The store holds the regions of a country, each of one country and by
its name, so that a track can say where in its country it is.

## Why

A country is too large a place for a track: a rider looks for the
tracks of a state, a province or a county (DESIGN.md). A track can
only say which region it is in when there is a table of them, and a
region has to belong to a country that is in the store. "Every record
must retain its source and collection history." (CLAUDE.md §11): a
region is read from a source, like a country.

## What this task is, and what it is not

- **It is** one table, `region`, its model `Region`, the sixteenth
  migration that makes it, and their tests.
- **It is not** the regions themselves. The table has no rows, and no
  reference rows are loaded: a region comes with the record that needs
  it, from the source that names it. The tests use a handful of real
  names as examples only.
- **It is not** the code the standard ISO 3166-2 gives a region.
  `TASKS.md` had that in this task; it is a second objective, with a
  form to hold and a rule of its own, and is now DAT-064 (PLAN-054).
- **It is not** a region inside a region. `TASKS.md` had the optional
  parent in this task too; it is a third objective, with a reference
  of the table to itself and a wider rule of the names, and is now
  DAT-065 (PLAN-054).
- **It is not** a change to any table that is there, to a command or
  to the published data.

## Design in short

    class Region(Collected):
        __tablename__ = "region"
        __table_args__ = (UniqueConstraint("country_id", "name"),)

        country_id: Mapped[int] = mapped_column(ForeignKey("country.id"))
        name: Mapped[NotEmpty]

The table then has thirteen columns: the key, the two above, the eight
of a collected record, and the two times. `Collected` gives the eight
with their checks, the reference to `source`, the index
`ix_region_source_id` and the check of the two times. The migration
writes all of it out as plain SQL, as every migration does, and the
test of the models and the migrations holds the two together.

## What the task left open, and what the trial settled

- **Three objectives, three tasks.** The entry asked for the country,
  the name, the code of ISO 3166-2, an optional parent and provenance
  in one table and one task. The code has a form of its own to hold
  and to test; the parent makes the table refer to itself, must be of
  the same country, and changes what "one name" means. Each is a
  migration and a set of tests of its own, so the task is the table
  with the country, the name and where the row came from, and the two
  others follow it (PLAN-054). "When uncertain, always choose smaller
  tasks." (CLAUDE.md §1).
- **A region is a part of exactly one country**, one that is in the
  store: `country_id` cannot be without a value and refers to
  `country` (`fk_region_country_id_country`).
- **A country that has regions cannot be deleted.** The reference says
  nothing of deleting, so SQLite refuses to delete a country while a
  region refers to it, and deletes nothing by itself. A test deletes a
  country without regions beside one that has them, and another takes
  the regions away first and then the country.
- **No two regions of one country have one name**:
  `uq_region_country_id_name`, over the country and then the name. It
  holds when a region is stored, when it is given another name and
  when it is moved to another country. Two countries can each have a
  region of a name. With DAT-065 the rule becomes one of the regions
  under the same parent; until then every region is a part of its
  country only.
- **Two names are one name only if they are the same text.** The
  table does not judge whether "Bayern" and "Bavaria" mean one region,
  nor does it take "Canterbury" and "canterbury" for one: that is a
  question for a person, and such a pair goes to the review queue.
  "Do not automatically merge uncertain rider or track identities."
  (CLAUDE.md §11) holds for places too. A name is stored as its source
  writes it.
- **The rule's own index finds the regions of a country.** SQLite
  keeps an index for a rule of this kind
  (`sqlite_autoindex_region_1`), and because the country stands first
  in it, SQLite uses it to find the regions of one country: for
  whoever asks for them, and for itself when a country is to be
  deleted and it looks whether the country has regions. The trial
  asked SQLite which index it uses for both, and a test holds the
  answer. So the table has no index of its own over `country_id`; one
  would be a second index over the same thing. A planted defect that
  puts the name first in the rule is found by that test.
- **A region is a collected record**, the second real table of them
  after the countries. So `region` is not on the list `NOT_COLLECTED`,
  the rule of DAT-046 holds it to the eight columns, and nothing in
  that rule or its tests had to change. The source of a region need
  not be the source of its country.
- **Nothing gives itself a value**, as `Collected` has it: the model
  gives no country, no name and none of the seven things that are
  known of every record.
- **Deleting.** A source that regions came from cannot be deleted. A
  region can be deleted while nothing refers to it, and nothing refers
  to a region yet; its key is not given again.
- **History.** `change` (DAT-047) works on a region as on a country: a
  new name and a new moment it was last seen give one row of history
  each, and a change the table refuses leaves neither. Two tests hold
  that, on the real table.
- **Nothing else names the tables of the store.** As with the
  countries, only the list of the migrations' names in the tests had
  to change. The commands, the loading of the countries and the rules
  take the tables as they find them.

### 1. `backend/src/motosphere/db/models/region.py` – new, the whole file

```python
"""The regions: the parts a country is divided into.

A country can be divided into parts: states, provinces, counties,
islands. A track says with one of them where in its country it lies.
This module has the model of the table that knows them,
:class:`Region`.

A region is a collected record. That it is there, the country it is a
part of and its name are read from a source, and every row says which
one and when (:class:`motosphere.db.models.provenance.Collected`). The
table has no rows of its own: a region comes with the record that needs
it.
"""

from sqlalchemy import ForeignKey, UniqueConstraint
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.models.provenance import Collected
from motosphere.db.texts import NotEmpty

__all__ = ["Region"]


class Region(Collected):
    """One part of a country, and what it is called.

    A region is a part of exactly one country, one that is in the store,
    and a country that has regions cannot be deleted: its regions are
    taken away first. No two regions of one country have one name; two
    countries can each have a region of a name.
    """

    __tablename__ = "region"
    # SQLite keeps an index for this rule, which begins with the country.
    # It is what finds the regions of one country: for whoever asks for
    # them, and for SQLite itself when a country is to be deleted and it
    # looks whether the country has regions.
    __table_args__ = (UniqueConstraint("country_id", "name"),)

    # The country it is a part of.
    country_id: Mapped[int] = mapped_column(ForeignKey("country.id"))
    # What it is called, as its source writes it. Two names are one name
    # only if they are the same text: the table does not judge whether
    # "Bayern" and "Bavaria" mean one region.
    name: Mapped[NotEmpty]
```

### 2. `backend/tests/integration/test_region.py` – new, the whole file, 104 tests

```python
"""Tests of the table of the regions, against a real SQLite file.

The store of every test is built the way a real store is built: by the
migrations. What is stored through the model is also read as SQLite holds
it, and what the table must refuse is also written past the model.

What every table of collected records has is proved on tables made for
the purpose (``test_collected.py``, ``test_collected_index.py``); here
the real table is held to it.
"""

from collections.abc import Iterator
from contextlib import contextmanager
from datetime import UTC, date, datetime, timedelta, timezone
from typing import Any

import pytest
from sqlalchemy import Engine, delete, select
from sqlalchemy.exc import IntegrityError

from motosphere.db.changes import change
from motosphere.db.models import Country, Region, Source
from motosphere.db.models.provenance import Confidence, VerificationStatus
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.work import unit_of_work

COLLECTED = datetime(2026, 11, 27, 9, 0, tzinfo=UTC)
SEEN_AGAIN = datetime(2026, 11, 28, 9, 0, tzinfo=UTC)
ADDRESS = "https://standards.example/regions.csv"
# What a region cannot be without: every column but the day its source
# says it was published.
NEEDED = [
    "country_id",
    "name",
    "source_id",
    "source_address",
    "collected_at",
    "last_verified_at",
    "extraction_method",
    "confidence",
    "verification_status",
]
# The two countries of the tests, by their keys.
NEW_ZEALAND = 1
AUSTRALIA = 2


@contextmanager
def refused(why: str) -> Iterator[None]:
    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:
        yield
    assert str(refusal.value.orig) == why


@pytest.fixture
def mapped(newest: Engine) -> Engine:
    """The test's own store with the newest schema, one source and two countries in it.

    The key of the source is 1, New Zealand's is 1 and Australia's is 2.
    """
    with unit_of_work(newest) as work:
        work.add(
            Source(
                name="Example Standards Body",
                website="https://standards.example",
                category=SourceCategory.GOVERNING_BODY,
                collection_method=CollectionMethod.DATASET,
            )
        )
    for two, three, name in [("NZ", "NZL", "New Zealand"), ("AU", "AUS", "Australia")]:
        with unit_of_work(newest) as work:
            work.add(
                Country(
                    alpha_2=two,
                    alpha_3=three,
                    name=name,
                    source_id=1,
                    source_address="https://standards.example/countries.csv",
                    collected_at=COLLECTED,
                    last_verified_at=COLLECTED,
                    extraction_method=CollectionMethod.DATASET,
                    confidence=Confidence.HIGH,
                    verification_status=VerificationStatus.OFFICIAL,
                )
            )
    return newest


def a_region(**said: Any) -> Region:
    """Canterbury in New Zealand as the one source of the tests says it, and what the test says."""
    described: dict[str, Any] = {
        "country_id": NEW_ZEALAND,
        "name": "Canterbury",
        "source_id": 1,
        "source_address": ADDRESS,
        "collected_at": COLLECTED,
        "last_verified_at": COLLECTED,
        "extraction_method": CollectionMethod.DATASET,
        "confidence": Confidence.HIGH,
        "verification_status": VerificationStatus.OFFICIAL,
    }
    return Region(**(described | said))


def keep(store: Engine, region: Region) -> int:
    """Store a region in a unit of work of its own, and give its key."""
    with unit_of_work(store) as work:
        work.add(region)
    return region.id


def the_region(store: Engine, key: int) -> Region:
    """Read a region anew from the store."""
    with unit_of_work(store) as work:
        return work.execute(select(Region).where(Region.id == key)).scalar_one()


# A row written past the model, as plain SQL: every column but the key.
A_ROW = (
    "INSERT INTO region (country_id, name, source_id, source_address, collected_at, "
    "published_on, last_verified_at, extraction_method, confidence, verification_status, "
    "created_at, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)"
)


def write(store: Engine, **said: object) -> None:
    """Write Canterbury past the model, with what the test says of it."""
    row: dict[str, object] = {
        "country_id": NEW_ZEALAND,
        "name": "Canterbury",
        "source_id": 1,
        "source_address": ADDRESS,
        "collected_at": "2026-11-27T09:00:00.000000+00:00",
        "published_on": None,
        "last_verified_at": "2026-11-27T09:00:00.000000+00:00",
        "extraction_method": "public dataset",
        "confidence": "high",
        "verification_status": "official",
        "created_at": "2026-11-27T09:00:05.000000+00:00",
        "updated_at": "2026-11-27T09:00:05.000000+00:00",
    } | said
    # A column the test names that the table does not have would be one value more.
    assert len(row) == 12
    with store.begin() as connection:
        connection.exec_driver_sql(A_ROW, tuple(row.values()))


def held(store: Engine) -> list[tuple[object, ...]]:
    """The rows of the table as SQLite holds them, by their key."""
    with store.connect() as connection:
        return [
            tuple(row) for row in connection.exec_driver_sql("SELECT * FROM region ORDER BY id")
        ]


def names(store: Engine) -> list[tuple[int, str]]:
    """The country and the name of every region, by their key."""
    with store.connect() as connection:
        found = connection.exec_driver_sql("SELECT country_id, name FROM region ORDER BY id")
        return [(int(country), str(name)) for country, name in found]


def test_a_region_is_stored_and_read_back_with_everything_said_of_it(
    mapped: Engine, clock: list[datetime]
) -> None:
    in_another_zone = SEEN_AGAIN.astimezone(timezone(timedelta(hours=13)))
    before = len(clock)
    key = keep(
        mapped,
        a_region(published_on=date(2026, 11, 2), last_verified_at=in_another_zone),
    )

    found = the_region(mapped, key)

    assert found.id == key == 1
    assert found.country_id == NEW_ZEALAND
    assert found.name == "Canterbury"
    assert found.source_id == 1
    assert found.source_address == ADDRESS
    assert found.collected_at == COLLECTED
    assert found.published_on == date(2026, 11, 2)
    assert found.last_verified_at == SEEN_AGAIN
    assert found.last_verified_at.utcoffset() == timedelta(0)
    assert found.extraction_method is CollectionMethod.DATASET
    assert found.confidence is Confidence.HIGH
    assert found.verification_status is VerificationStatus.OFFICIAL
    assert found.created_at == found.updated_at == clock[before]
    assert len(clock) == before + 1


def test_what_the_table_holds_is_plain_text_and_whole_numbers(
    mapped: Engine, clock: list[datetime]
) -> None:
    before = len(clock)
    keep(mapped, a_region(published_on=date(2026, 11, 2), last_verified_at=SEEN_AGAIN))

    stored_at = clock[before].isoformat(timespec="microseconds")
    assert held(mapped) == [
        (
            1,
            1,
            "Canterbury",
            1,
            ADDRESS,
            "2026-11-27T09:00:00.000000+00:00",
            "2026-11-02",
            "2026-11-28T09:00:00.000000+00:00",
            "public dataset",
            "high",
            "official",
            stored_at,
            stored_at,
        )
    ]
    assert stored_at.endswith("+00:00")
    assert len(clock) == before + 1


def test_a_region_whose_source_gives_no_day_has_no_day(mapped: Engine) -> None:
    key = keep(mapped, a_region())

    assert the_region(mapped, key).published_on is None
    assert held(mapped)[0][6] is None


def test_a_row_written_past_the_model_is_read_as_a_region(mapped: Engine) -> None:
    write(mapped, published_on="2026-11-02")

    found = the_region(mapped, 1)

    assert (found.country_id, found.name) == (NEW_ZEALAND, "Canterbury")
    assert found.collected_at == found.last_verified_at == COLLECTED
    assert found.published_on == date(2026, 11, 2)
    assert found.extraction_method is CollectionMethod.DATASET
    assert found.created_at == COLLECTED + timedelta(seconds=5)


@pytest.mark.parametrize("column", NEEDED)

    assert held(mapped) == []


@pytest.mark.parametrize("column", NEEDED)
def test_the_model_gives_no_value_to_what_a_region_cannot_be_without(

) -> None:
    with refused(f"NOT NULL constraint failed: region.{column}"):
        keep(mapped, a_region(**{column: None}))

    assert held(mapped) == []


def test_bytes_are_not_a_name(mapped: Engine) -> None:
    with refused("cannot store BLOB value in TEXT column region.name"):
        write(mapped, name=b"Canterbury")

    assert held(mapped) == []


@pytest.mark.parametrize("column", ["country_id", "source_id"])
def test_text_is_not_a_key(mapped: Engine, column: str) -> None:
    with refused(f"cannot store TEXT value in INTEGER column region.{column}"):
        write(mapped, **{column: "the first"})

    assert held(mapped) == []


def test_a_region_is_a_part_of_a_country_that_is_there(mapped: Engine) -> None:
    with refused("FOREIGN KEY constraint failed"):
        keep(mapped, a_region(country_id=3))
    with refused("FOREIGN KEY constraint failed"):
        write(mapped, country_id=3)

    assert held(mapped) == []


def test_a_region_cannot_be_moved_to_a_country_that_is_not_there(mapped: Engine) -> None:
    key = keep(mapped, a_region())

    with refused("FOREIGN KEY constraint failed"), unit_of_work(mapped) as work:
        work.get_one(Region, key).country_id = 3

    assert names(mapped) == [(NEW_ZEALAND, "Canterbury")]


def test_a_country_that_has_regions_cannot_be_deleted(mapped: Engine) -> None:
    keep(mapped, a_region())

    with refused("FOREIGN KEY constraint failed"), unit_of_work(mapped) as work:
        work.execute(delete(Country).where(Country.id == NEW_ZEALAND))

    with unit_of_work(mapped) as work:
        assert work.get_one(Country, NEW_ZEALAND).name == "New Zealand"
    assert names(mapped) == [(NEW_ZEALAND, "Canterbury")]


def test_a_country_without_regions_can_be_deleted_beside_one_that_has_them(
    mapped: Engine,
) -> None:
    keep(mapped, a_region())

    with unit_of_work(mapped) as work:
        work.execute(delete(Country).where(Country.id == AUSTRALIA))

    with unit_of_work(mapped) as work:
        assert [country.name for country in work.scalars(select(Country))] == ["New Zealand"]
```

````diff
+## The regions
+
+A country can be divided into parts: states, provinces, counties,
+islands. A track says with one of them where in its country it lies,
+and the table `region` knows them (DAT-013). Its model is `Region`, in
+`motosphere.db.models.region`, and the sixteenth migration,
+`make_the_regions`, makes the table and its index. The table has no
+rows, and no reference rows are loaded into it: a region comes with the
+record that needs it, from the source that names it.
+
+| Column | What it holds | May be without a value |
+|---|---|---|
+| `country_id` | The country it is a part of | No |
+| `name` | What it is called, as its source writes it. Text that is not empty (see "Text that must not be empty") | No |
+| the eight columns of a collected record | Where the row came from and how far it can be trusted (see "Where a collected record came from") | Only `published_on` |
+
+The key is before these columns and the two times are after them, as
+in every table.
+
+- **A region is a part of exactly one country**, one that is in the
+  store (`fk_region_country_id_country`). A row without a country is
+  refused, and so is one of a country that is not there, when the
+  region is stored and when it is moved. **A country that has regions
+  cannot be deleted**: its regions are taken away first. Nothing is
+  said of what is to happen to the regions then, so SQLite refuses the
+  deletion; it deletes nothing by itself.
+- **No two regions of one country have one name**
+  (`uq_region_country_id_name`), when a region is stored, when it is
+  given another name and when it is moved to another country. Two
+  countries can each have a region of a name.
+- **Two names are one name only if they are the same text.**
+  "Canterbury" and "canterbury" are two names, and so are "Canterbury"
+  and "Canterbury " with a space after it. The table does not judge
+  whether two names mean one region: whether "Bayern" and "Bavaria" do
+  is a question for a person, and such a pair goes to the review queue
+  (see "Opening a possible duplicate"). A name is stored as its source
+  writes it, with the white space, the capitals and the letters it has.
+- **A region is a collected record.** `Region` is a subclass of
+  `Collected` and names two columns; the eight, their checks, the
+  reference to `source`, the index over `source_id`
+  (`ix_region_source_id`) and the check that holds the two times
+  together come with that. A region comes from a source that is there,
+  and a source that regions came from cannot be deleted. The source of
+  a region need not be the source of its country.
+- **The regions of one country are found without reading the table.**
+  SQLite keeps an index for the rule of the names
+  (`sqlite_autoindex_region_1`, over the country and then the name).
+  Because the country stands first in it, it finds the regions of one
+  country, for whoever asks for them and for SQLite itself when a
+  country is to be deleted and it looks whether the country has
+  regions. So the table has no index of its own over `country_id`; a
+  test holds what SQLite says it uses.
+- **Nothing gives itself a value.** A row cannot be without a country,
+  a name or any of the seven things that are known of every collected
+  record, and neither the model nor the table makes one up.
+- **A region is changed with its history**, by `change` (see "Changing
+  a record"), like every record. A region can be deleted while nothing
+  refers to it; nothing refers to a region yet.
+- **What is not in the table yet.** The code the standard ISO 3166-2
+  gives a region, such as `NZ-CAN` (DAT-064). A region that is a part
+  of another region, as a county is of a state (DAT-065): until then
+  every region is a part of its country only, and the rule of the
+  names is for the whole country. Names in other languages, and the
+  other names a region is known by, are not in this table.
````
