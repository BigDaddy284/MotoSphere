# DAT-030 – Text that must not be empty

**Phase:** 2 – Data store and published data
**Depends on:** DAT-005, DAT-029 and DAT-032 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §11, §12, §14, `docs/WORKFLOW.md`,
`DATABASE.md` ("The rules every table keeps", "Times"), `TESTING.md` ("The
rules every table keeps", "A data store of its own for every test"),
`backend/src/motosphere/db/base.py`, `backend/src/motosphere/db/times.py`,
`backend/tests/integration/test_key.py`

## Objective

A column whose text must not be empty refuses empty text in the store
itself, and every model says so in the same way.

## Why

Much of what the store will hold is names: of a track, a rider, a team, a
source. A name that is empty means nothing, and a page shows it as a gap.
The text comes from web pages, which are full of fields that hold nothing
or nothing but white space. So before the first table is made (DAT-006), a
model gets one way to say that a column's text must not be empty, and the
table itself refuses such text, whoever writes the row: the collectors'
code, a migration, or a person with plain SQL.

This is the last quarter of the old "DAT-005 – Model conventions: keys,
times and names" (PLAN-017). The planner's trial settled what the task
left open, and found one more small task, DAT-033 (PLAN-020, in
`PROGRESS.md`).

## Design in short

- **A model says it with the column's type**: `name: Mapped[NotEmpty]`.
  `NotEmpty` is `Annotated[str, NotEmptyText]`; to Python and to the type
  check it is a `str`. `Base` maps it to the column type `NotEmptyText`,
  a subclass of SQLAlchemy's `Text` with nothing added, which is TEXT in
  the table and marks the column.
- **`Base` gives the table a check for every such column**, when the
  model is defined (`__init_subclass__`, where the table is made strict):
  the check that `not_empty(<the column's name>)` gives.
- **The check**:
  `trim(<column>, char(9, 10, …, 12288)) != ''`. What is left of the text
  when the white space is taken off both ends must not be empty text.
  SQLite's `trim` with one argument takes off spaces only, so the white
  space is named, as the numbers of its characters in Unicode
  (`WHITE_SPACE`).
- **White space is the 29 characters Python calls so**
  (`str.isspace`), which are the ones `str.strip` takes off. So text is
  empty to the table exactly when `text.strip()` is empty in Python. The
  space that cannot be broken (160) is among them; it is what an empty
  field of a web page usually holds.
- **The numbers are written out**, not asked of Python when the program
  runs, so that the text of the check is the same on every machine and
  with every version of Python. A test holds the list to Python's.
- **The name of the check**: `not_empty` names it `<column>_not_empty`,
  and the naming rule makes that `ck_<table>_<column>_not_empty`. SQLite's
  refusal names it: `CHECK constraint failed: ck_proof_rider_name_not_empty`.
- **Text that is not empty is stored as it was given**, with the white
  space it has around it. The store does not tidy text.
- **A column that may be without a value**, `Mapped[NotEmpty | None]`,
  gets the same check: it holds no value or text that is not empty. (A
  check passes a column without a value.)
- **`Mapped[str]` is as before**: TEXT without a check.
- No new package, no model, no table, no migration. `broken_rules` does
  not change (DAT-033).

## What the task left open, and what the trial settled

- **What counts as empty**: no characters, or nothing but white space, as
  above.
- **Whether text is stored without the white space around it**: no. A
  type that changed what it was given would make the store hold something
  other than what was collected; tidying is the collectors' work, before
  the text is stored. The check only refuses.
- **Whether a column of a time gets a check of its form**: no, and no
  task follows for it. A check in a table is for what the models cannot
  promise. Empty text can come through a model, from a web page; a time
  in another form cannot, because the store's type writes every time in
  the one form (DAT-028), and text put there past the models is refused
  when it is read. `DATABASE.md` says so.
- **Where `Base` cannot add the check**, each tried: a column that a
  subclass of a model adds to its parent's table (single-table
  inheritance) is added after the parent was defined and gets none; a
  table made without a model gets none. A column a model gets from a
  mixin gets its check. Naming a column without its check is one more
  rule of `broken_rules`, and a task of its own: DAT-033, which follows
  this one.

  `broken_rules` takes it as a name from the rule.

  its check, by SQLAlchemy.

  SQLAlchemy does that. Tried: with such a check, the line of `Base` that
  gives the check to the table could be taken out and no test could tell.

  name alone: the check belongs to no table until `Base` gives it to one,
  and tests fail if that line is left out.

  is refused, and each is kept around text; text of several kinds of
  white space is refused; a change to empty text is refused in three
  ways (through the model, by an `update` statement, with plain SQL); a
  row written with plain SQL is refused.
- **What is not white space**: a character that Python does not call
  white space is content to the check, also one that cannot be seen. The
  space without width (8203) is one; a test stores it and says so.
- **Odd characters in a test file.** The tests write the space that
  cannot be broken and its like as their numbers (a backslash, `u` and
  four digits), never as themselves: the lint refuses such a character in
  text (RUF001), and an editor can change one without showing it.

### 1. `backend/src/motosphere/db/texts.py` – new, the whole file

```python
"""Text that must not be empty.

Much of the store's text is names, and a name that is empty means nothing.
A model says of such a column that its text must not be empty:

    name: Mapped[NotEmpty]

The column is then TEXT with a check in its table, and SQLite itself
refuses a row whose text is empty, whoever writes it. Empty is text with no
characters, and text with nothing but white space: the characters Python's
``str.strip`` takes off, among them the space that cannot be broken, which
web pages are full of. Text that is not empty is stored as it was given,
with the white space it has around it.

A column that may be without a value says ``Mapped[NotEmpty | None]``: it
holds no value or text that is not empty, and never empty text.
"""

from typing import Annotated

from sqlalchemy import CheckConstraint, Text, column, func

__all__ = ["WHITE_SPACE", "NotEmpty", "NotEmptyText", "not_empty"]

# The characters that are white space, each by its number in Unicode: the
# ones Python's str.isspace and str.strip know. They are written out, and
# not asked of Python, so that the check is the same text on every machine
# and with every version of Python. A test holds the list to Python's.
WHITE_SPACE = (
    *(9, 10, 11, 12, 13),  # tab, line feed, vertical tab, form feed, carriage return
    *(28, 29, 30, 31),  # the four separators of ASCII
    32,  # the space
    133,  # next line
    160,  # the space that cannot be broken
    5760,  # the Ogham space mark
    *(8192, 8193, 8194, 8195, 8196, 8197, 8198, 8199, 8200, 8201, 8202),  # the spaces of print
    *(8232, 8233),  # the line and the paragraph separator
    8239,  # the narrow space that cannot be broken
    8287,  # the mathematical space
    12288,  # the wide space of Chinese, Japanese and Korean
)


class NotEmptyText(Text):
    """The column type of text that must not be empty. In the table it is TEXT."""


# What a model says a column is: ``Mapped[NotEmpty]``. To Python and to the
# type check it is a ``str``.
NotEmpty = Annotated[str, NotEmptyText]


def not_empty(name: str) -> CheckConstraint:
    """Give the check that refuses empty text in the column called ``name``.

    The check is called ``<name>_not_empty``, which the naming rule makes
    ``ck_<table>_<name>_not_empty`` once the check is given to a table. It
    belongs to no table until then. A column without a value passes it, as
    it passes every check.
    """
    without_white_space = func.trim(column(name), func.char(*WHITE_SPACE))
    return CheckConstraint(without_white_space != "", name=f"{name}_not_empty")
```

### 2. `backend/tests/unit/test_db_texts.py` – new, the whole file, 6 tests

```python
"""Tests of text that must not be empty, without a store.

``tests/integration/test_texts.py`` asks a real SQLite file what it refuses.
"""

import sys

from sqlalchemy import Column, Integer, MetaData, Table
from sqlalchemy.dialects import sqlite
from sqlalchemy.schema import conv

from motosphere.db.base import NAMING
from motosphere.db.texts import WHITE_SPACE, NotEmptyText, not_empty

THE_CHECK = (
    "trim({}, char(9, 10, 11, 12, 13, 28, 29, 30, 31, 32, 133, 160, 5760, 8192, 8193, 8194, "
    "8195, 8196, 8197, 8198, 8199, 8200, 8201, 8202, 8232, 8233, 8239, 8287, 12288)) != ''"
)


def said(name: str) -> str:
    """The check of a column of this name, as SQLite is given it."""
    written = not_empty(name).sqltext.compile(
        dialect=sqlite.dialect(), compile_kwargs={"literal_binds": True}
    )
    return str(written)


def test_the_white_space_is_what_python_calls_white_space() -> None:
    pythons = tuple(number for number in range(sys.maxunicode + 1) if chr(number).isspace())

    assert pythons == WHITE_SPACE
    assert len(WHITE_SPACE) == 29


def test_the_white_space_is_what_pythons_strip_takes_off() -> None:
    kept = [number for number in WHITE_SPACE if (chr(number) + "a" + chr(number)).strip() != "a"]

    assert kept == []
    assert "".join(chr(number) for number in WHITE_SPACE).strip() == ""


def test_the_check_takes_the_white_space_off_and_refuses_what_is_then_empty() -> None:
    assert said("name") == THE_CHECK.format("name")


def test_the_check_of_a_column_named_with_a_word_of_sql_names_it_in_quotes() -> None:
    assert said("group") == THE_CHECK.format('"group"')


def test_the_check_is_named_after_its_column_and_by_the_naming_rule() -> None:
    check = not_empty("name")

    assert check.name == "name_not_empty"

    owner = Table(
        "owner",
        MetaData(naming_convention=NAMING),
        Column("id", Integer),
        Column("name", NotEmptyText),
    )

    assert check not in owner.constraints

    owner.append_constraint(check)

    assert check.name == "ck_owner_name_not_empty"
    assert isinstance(check.name, conv)


def test_in_the_table_the_type_is_text() -> None:
    assert NotEmptyText().compile(dialect=sqlite.dialect()) == "TEXT"
```

### 3. `backend/tests/integration/test_texts.py` – new, the whole file, 26 tests

```python
"""Tests of text that must not be empty, with tables made in a real SQLite file.

The two models here are made for the tests. They are subclasses of the
real ``Base``, so they prove what a model gets when it says that a
column's text must not be empty, but they are kept in a schema of their
own (``Proof.metadata``), so the real schema never sees them.
"""

import re

import pytest
from sqlalchemy import Engine, MetaData, UniqueConstraint, select, update
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.texts import WHITE_SPACE, NotEmpty, NotEmptyText
from motosphere.db.work import unit_of_work

A_TIME = "2026-11-19T08:00:00.000000+00:00"
REFUSED = "CHECK constraint failed: ck_{}_not_empty"
THE_CHECK = (
    "CONSTRAINT ck_proof_rider_{}_not_empty CHECK (trim({}, char(9, 10, 11, 12, 13, 28, 29, 30, "
    "31, 32, 133, 160, 5760, 8192, 8193, 8194, 8195, 8196, 8197, 8198, 8199, 8200, 8201, 8202, "
    "8232, 8233, 8239, 8287, 12288)) != '')"
)


class Proof(Base):
    """Models of the tests' own: what ``Base`` gives such text, in a schema of their own."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofRider(Proof):
    __tablename__ = "proof_rider"

    name: Mapped[NotEmpty]
    # No value, or text that is not empty.
    nickname: Mapped[NotEmpty | None]
    # A model that says more of the column.
    number: Mapped[NotEmpty] = mapped_column(unique=True)
    # A name that is a word of SQL.
    group: Mapped[NotEmpty]
    # Text that may be empty, as before.
    note: Mapped[str]


class ProofTeam(Proof):
    __tablename__ = "proof_team"
    # A model that says something of its table itself.
    __table_args__ = (UniqueConstraint("name", "country"),)

    name: Mapped[NotEmpty]
    country: Mapped[str]


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the two tables of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def rider(**said: str | None) -> ProofRider:
    """A rider every column of whom is as it must be, unless ``said`` otherwise."""
    as_it_must_be = {"name": "Ada Example", "nickname": None, "number": "84", "group": "A"}
    return ProofRider(**(as_it_must_be | {"note": ""} | said))


def written(made: Engine, table: str) -> str:
    """How the file itself says the table is made."""
    with made.connect() as connection:
        text = connection.exec_driver_sql(
            "SELECT sql FROM sqlite_master WHERE name = ?", (table,)
        ).scalar_one()
    return str(text)


def names(made: Engine) -> list[str]:
    """The names of the riders the file holds, read without the model."""
    with made.connect() as connection:
        return list(
            connection.exec_driver_sql("SELECT name FROM proof_rider ORDER BY id").scalars()
        )


def test_text_that_must_not_be_empty_is_text_in_a_strict_table(made: Engine) -> None:
    columns = ProofRider.__table__.c

    assert [column.name for column in columns if isinstance(column.type, NotEmptyText)] == [
        "name",
        "nickname",
        "number",
        "group",
    ]
    assert broken_rules(Proof.metadata) == []

    with made.connect() as connection:
        in_the_file = {
            name: (declared, bool(required))
            for _, name, declared, required, _, _ in connection.exec_driver_sql(
                "PRAGMA table_info(proof_rider)"
            )
        }

    assert in_the_file == {
        "id": ("INTEGER", True),
        "name": ("TEXT", True),
        "nickname": ("TEXT", False),
        "number": ("TEXT", True),
        "group": ("TEXT", True),
        "note": ("TEXT", True),
        "created_at": ("TEXT", True),
        "updated_at": ("TEXT", True),
    }


def test_the_file_has_a_check_named_by_the_rule_for_each_such_column_and_for_no_other(
    made: Engine,
) -> None:
    riders = written(made, "proof_rider")

    assert sorted(re.findall(r"CONSTRAINT (\w+) CHECK", riders)) == [
        "ck_proof_rider_group_not_empty",
        "ck_proof_rider_name_not_empty",
        "ck_proof_rider_nickname_not_empty",
        "ck_proof_rider_number_not_empty",
    ]
    assert THE_CHECK.format("name", "name") in riders
    assert THE_CHECK.format("group", '"group"') in riders
    assert "CONSTRAINT uq_proof_rider_number UNIQUE (number)" in riders
    assert re.findall(r"CONSTRAINT (\w+) CHECK", written(made, "proof_team")) == [
        "ck_proof_team_name_not_empty"
    ]


@pytest.mark.parametrize(
    "name",
    ["Ada Example", "  Ada Example \n", "0", "\u00e9", "a\tb", "\u200b"],
    ids=[
        "a name",
        "white space around a name",
        "a nought",
        "a letter with an accent",
        "white space between letters",
        "a space without width, which Python does not call white space",
    ],
)
def test_text_that_is_not_empty_is_stored_as_it_was_given(made: Engine, name: str) -> None:
    with unit_of_work(made) as work:
        work.add(rider(name=name))

    assert names(made) == [name]
    with unit_of_work(made) as work:
        assert work.scalars(select(ProofRider.name)).one() == name


@pytest.mark.parametrize(
    "empty",
    ["", " ", "   ", "\t", "\n", "\r\n", "\u00a0", "\u3000", " \t\u00a0\n"],
    ids=[
        "no characters",
        "a space",
        "three spaces",
        "a tab",
        "a line feed",
        "the line end of Windows",
        "the space that cannot be broken",
        "the wide space",
        "white space of four kinds",
    ],
)
def test_empty_text_is_refused_by_the_store_and_the_refusal_names_the_check(
    made: Engine, empty: str
) -> None:
    refusal = REFUSED.format("proof_rider_name")

    with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
        work.add_all([rider(), rider(number="85", name=empty)])

    assert names(made) == []


def test_every_white_space_character_alone_is_empty_text(made: Engine) -> None:
    stored = []
    for number in WHITE_SPACE:
        try:
            with unit_of_work(made) as work:
                work.add(rider(number=str(number), name=chr(number)))
        except IntegrityError:
            continue
        stored.append(number)

    assert stored == []
    assert names(made) == []


def test_every_white_space_character_around_text_is_kept(made: Engine) -> None:
    given = [chr(number) + "Ada" + chr(number) for number in WHITE_SPACE]

    with unit_of_work(made) as work:
        work.add_all(rider(number=str(place), name=name) for place, name in enumerate(given))

    assert names(made) == given


def test_empty_text_written_past_the_model_is_refused(made: Engine) -> None:
    statement = (
        'INSERT INTO proof_rider (name, number, "group", note, created_at, updated_at) '
        "VALUES (?, '84', 'A', '', ?, ?)"
    )

    with made.begin() as connection:
        connection.exec_driver_sql(statement, ("Ada Example", A_TIME, A_TIME))
    for empty in ("", " \u00a0"):
        refusal = REFUSED.format("proof_rider_name")
        with pytest.raises(IntegrityError, match=refusal), made.begin() as connection:
            connection.exec_driver_sql(statement, (empty, A_TIME, A_TIME))

    assert names(made) == ["Ada Example"]


def test_a_change_to_empty_text_is_refused_and_the_row_stays_as_it_was(made: Engine) -> None:
    refusal = REFUSED.format("proof_rider_name")
    with unit_of_work(made) as work:
        work.add(rider())

    with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
        work.scalars(select(ProofRider)).one().name = " "
    with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
        work.execute(update(ProofRider).values(name=""))
    with pytest.raises(IntegrityError, match=refusal), made.begin() as connection:
        connection.exec_driver_sql("UPDATE proof_rider SET name = '\t'")

    assert names(made) == ["Ada Example"]


def test_a_column_that_may_be_without_a_value_holds_none_or_text_that_is_not_empty(
    made: Engine,
) -> None:
    refusal = REFUSED.format("proof_rider_nickname")

    with unit_of_work(made) as work:
        work.add_all([rider(), rider(number="85", nickname="The Example")])
    for empty in ("", " "):
        with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
            work.add(rider(number="86", nickname=empty))

    with made.connect() as connection:
        nicknames = connection.exec_driver_sql(
            "SELECT nickname FROM proof_rider ORDER BY id"
        ).scalars()
        assert list(nicknames) == [None, "The Example"]


@pytest.mark.parametrize("column", ["number", "group"])
def test_every_such_column_has_a_check_of_its_own(made: Engine, column: str) -> None:
    refusal = REFUSED.format(f"proof_rider_{column}")

    with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
        work.add(rider(**{column: ""}))

    assert names(made) == []


def test_a_model_that_says_something_of_its_table_gets_the_check_too(made: Engine) -> None:
    refusal = REFUSED.format("proof_team_name")

    with unit_of_work(made) as work:
        work.add(ProofTeam(name="Example Racing", country=""))
    with pytest.raises(IntegrityError, match=refusal), unit_of_work(made) as work:
        work.add(ProofTeam(name="", country="NL"))

    with made.connect() as connection:
        teams = connection.exec_driver_sql("SELECT name, country FROM proof_team").all()
    assert [tuple(team) for team in teams] == [("Example Racing", "")]


def test_text_that_may_be_empty_is_stored_empty_as_before(made: Engine) -> None:
    with unit_of_work(made) as work:
        work.add_all([rider(note=""), rider(number="85", note="  ")])

    with made.connect() as connection:
        notes = connection.exec_driver_sql("SELECT note FROM proof_rider ORDER BY id").scalars()
```
