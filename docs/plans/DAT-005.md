# DAT-005 – The base of all models: strict tables and one naming rule

**Phase:** 2 – Data store and published data
**Depends on:** DAT-021 and DAT-022 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §11, §12, `docs/WORKFLOW.md`, `DATABASE.md`
("Opening the store", "Units of work", "How the schema changes", "What the
store relies on in SQLite"), `TESTING.md` ("A data store of its own for

`backend/src/motosphere/db/work.py`, `backend/tests/conftest.py`,
`backend/tests/integration/test_work.py`

## Objective

Every table of the data store is strict, has columns of the types a strict
table takes, and has its constraints and indexes named by one rule; and a
test holds every table to that.

## Why

The first table comes with DAT-006, and more with most of the tasks after
it. What all of them share is decided once, before the first, so that no
table has to be changed later to fit the others.

This is the first quarter of the old "DAT-005 – Model conventions: keys,
times and names" (PLAN-017, in `PROGRESS.md`). Times (DAT-028), the key
and the timestamps of every table (DAT-029) and text that must not be
empty (DAT-030) follow, each as a task of its own.

## Design in short

- One new module, `motosphere.db.base`, with three names: `Base`,
  `NAMING` and `broken_rules`.
- **`Base` is the class every model is a subclass of** (SQLAlchemy's
  declarative base). A model is a class that describes one table. There
  is no model yet: the first comes with DAT-006.
- **Every table is strict.** In an ordinary table SQLite stores whatever
  it is given; in a strict one it refuses a value that is not of its
  column's type (DAT-001 named strict tables as one of the six things the
  store needs from SQLite). `Base` makes the table of each new model
  strict when the model is defined (`__init_subclass__`), so a model
  cannot leave it out, also not by saying something else of its table
  (`__table_args__`).
- **Column types.** A strict table takes INTEGER, REAL, TEXT and BLOB.
  SQLAlchemy's own types for a `str` (VARCHAR) and a `float` (FLOAT) are
  not among them, so `Base` says which type a model's column gets from its
  Python type alone: `str` is TEXT and `float` is REAL. `int` and `bytes`
  are INTEGER and BLOB without being named. Types for times and for yes
  and no are not part of this task.
- **One naming rule**, `NAMING`, given to the schema of `Base`:

  | What | Its name |
  |---|---|
  | The key | `pk_<table>` |
  | A foreign key | `fk_<table>_<columns>_<table it points to>` |
  | A unique constraint | `uq_<table>_<columns>` |
  | A check | `ck_<table>_<what the model calls it>` |
  | An index | `ix_<table>_<columns>` |

  A check has no columns to be named after, so its model gives the last
  part of the name, and a check without one is refused by SQLAlchemy when
  its table is defined.
- **`broken_rules(schema)`** says in plain sentences which tables of a
  schema break a rule: a table that is not strict (one made without a
  model can be), and a constraint or an index that was named by hand
  instead of by the rule. SQLAlchemy marks every name the rule gave
  (`sqlalchemy.schema.conv`), and that mark is what is looked at. The
  sentences come table by table and name by name, in alphabetical order,
  so the list is the same every time.
- **One test holds the real schema to the rules**:
  `broken_rules(Base.metadata) == []`. It passes today because there is
  no table, and it is the test that fails when a table is added that
  breaks a rule.
- **The tests' own models stay out of the real schema.** The tests need
  models to prove what `Base` does. They are subclasses of the real
  `Base`, through one class of the tests' own, `Proof`, which is abstract
  and has a schema of its own with the same naming rule. So
  `Base.metadata` never holds a table of the tests'.
- No new package.

  strict table with a column of SQLAlchemy's `String`, `Float`, `Boolean`

  there: SQLAlchemy already gives them INTEGER and BLOB, which the test of
  the column types reads from the file. A comment says so.

  written as `CONSTRAINT pk_<table> PRIMARY KEY (id)` after the columns.
  Tried: `id` is still the row's number (`rowid`), and SQLite still gives

  are DAT-029's.

  the table is defined, not only when it is made in a store. One test
  holds that, so a change of that behaviour in a later SQLAlchemy would
  be seen.
- **One case of the tests was taken out**: text given for the key. SQLite
  refuses that in an ordinary table too ("datatype mismatch"), so it
  proves nothing about strict tables.
- **One planted defect was replaced.** "The names given by hand are not
  sorted" was detected in the trial, but only by chance: the constraints
  of a table are kept in a set, whose order differs from run to run. The
  planted defect is now "sorted the other way round", which is detected

## Implementation detail

### 1. `backend/src/motosphere/db/base.py` – new, the whole file

```python
"""The base of every model: the rules all tables of the data store share.

A model is a class that describes one table. Every model is a subclass of
:class:`Base`, and so every table

- is a strict table: SQLite refuses a value that is not of its column's
  type, where an ordinary table would store whatever it is given;
- has columns of the few types a strict table takes: a Python ``int``
  becomes INTEGER, a ``str`` TEXT, a ``float`` REAL and ``bytes`` BLOB;
- has its constraints and indexes named by one rule, :data:`NAMING`, so
  that a migration can name what it changes and the names are the same on
  every machine.

:func:`broken_rules` says in plain words which tables of a schema break a
rule. A test holds the real schema to it.
"""

from typing import Any, ClassVar

from sqlalchemy import REAL, Constraint, Index, MetaData, Text
from sqlalchemy.orm import DeclarativeBase
from sqlalchemy.schema import conv
from sqlalchemy.types import TypeEngine

__all__ = ["NAMING", "Base", "broken_rules"]

# How constraints and indexes are named. A check has no columns to be named
# after, so it is given the last part of its name where it is written:
# CheckConstraint("laps > 0", name="laps_positive") is ck_<table>_laps_positive.
# A check without a name is refused when its table is defined.
NAMING = {
    "pk": "pk_%(table_name)s",
    "fk": "fk_%(table_name)s_%(column_0_N_name)s_%(referred_table_name)s",
    "uq": "uq_%(table_name)s_%(column_0_N_name)s",
    "ck": "ck_%(table_name)s_%(constraint_name)s",
    "ix": "ix_%(table_name)s_%(column_0_N_name)s",
}


class Base(DeclarativeBase):
    """The class every model is a subclass of."""

    metadata = MetaData(naming_convention=NAMING)
    # What a column is when its model gives only the Python type. An int and
    # bytes become INTEGER and BLOB without being named here.
    type_annotation_map: ClassVar[dict[type, type[TypeEngine[Any]]]] = {
        str: Text,
        float: REAL,
    }

    def __init_subclass__(cls, **kwargs: Any) -> None:
        """Make the table of a new model strict, whatever else the model says of it."""
        super().__init_subclass__(**kwargs)
        table = cls.__dict__.get("__table__")
        if table is not None:
            table.dialect_options["sqlite"]["strict"] = True


def broken_rules(schema: MetaData) -> list[str]:
    """Say which tables of ``schema`` break a rule, one plain sentence for each break.

    A table must be strict, and every constraint and index of it must have
    its name from the naming rule, not one given by hand. A schema that
    keeps the rules gives an empty list.
    """
    breaks: list[str] = []
    for table in sorted(schema.tables.values(), key=lambda table: table.name):
        if not table.dialect_options["sqlite"]["strict"]:
            breaks.append(f"The table {table.name} is not strict.")
        named: list[Constraint | Index] = [*table.constraints, *table.indexes]
        by_hand = sorted(str(one.name) for one in named if not isinstance(one.name, conv))
        breaks.extend(
            f"The table {table.name} has a name given by hand, {name}: "
            "constraints and indexes are named by the naming rule."
            for name in by_hand
        )
    return breaks
```

### 2. `backend/tests/unit/test_db_base.py` – new, the whole file, 9 tests

```python
"""Tests of the rules every table keeps, without a store.

The tables here are made for the tests, each in a schema of its own, so
the real schema never sees them. ``tests/integration/test_base.py`` makes
tables in a real SQLite file.
"""

import pytest
from sqlalchemy import (
    CheckConstraint,
    Column,
    ForeignKey,
    ForeignKeyConstraint,
    Index,
    Integer,
    MetaData,
    PrimaryKeyConstraint,
    Table,
    Text,
    UniqueConstraint,
)
from sqlalchemy.exc import InvalidRequestError
from sqlalchemy.schema import SchemaItem

from motosphere.db.base import NAMING, Base, broken_rules


def a_schema() -> MetaData:
    """An empty schema with the naming rule of the real one."""
    return MetaData(naming_convention=NAMING)


def test_the_real_schema_breaks_no_rule() -> None:
    assert broken_rules(Base.metadata) == []


def test_tables_that_keep_the_rules_break_none() -> None:
    schema = a_schema()
    Table(
        "owner",
        schema,
        Column("id", Integer, primary_key=True),
        Column("name", Text, unique=True),
        sqlite_strict=True,
    )
    Table(
        "item",
        schema,
        Column("id", Integer, primary_key=True),
        Column("owner_id", Integer, ForeignKey("owner.id")),
        Column("number", Integer),
        Column("place", Text, index=True),
        UniqueConstraint("owner_id", "number"),
        CheckConstraint("number > 0", name="number_positive"),
        Index(None, "place", "number"),
        sqlite_strict=True,
    )

    assert broken_rules(schema) == []


def test_a_table_that_is_not_strict_is_named() -> None:
    schema = a_schema()
    Table("strict_one", schema, Column("id", Integer, primary_key=True), sqlite_strict=True)
    Table("loose_one", schema, Column("id", Integer, primary_key=True))

    assert broken_rules(schema) == ["The table loose_one is not strict."]


@pytest.mark.parametrize(
    "by_hand",
    [
        PrimaryKeyConstraint("id", name="mine"),
        UniqueConstraint("number", name="mine"),
        ForeignKeyConstraint(["number"], ["other.id"], name="mine"),
        Index("mine", "number"),
    ],
    ids=["a key", "a unique constraint", "a foreign key", "an index"],
)
def test_a_name_given_by_hand_is_named(by_hand: SchemaItem) -> None:
    schema = a_schema()
    Table("other", schema, Column("id", Integer, primary_key=True), sqlite_strict=True)
    Table(
        "named",
        schema,
        Column("id", Integer),
        Column("number", Integer),
        by_hand,
        sqlite_strict=True,
    )

    assert broken_rules(schema) == [
        "The table named has a name given by hand, mine: "
        "constraints and indexes are named by the naming rule."
    ]


def test_the_breaks_are_listed_table_by_table_and_name_by_name() -> None:
    schema = a_schema()
    Table(
        "zebra",
        schema,
        Column("id", Integer, primary_key=True),
        Column("a", Integer),
        Column("b", Integer),
        UniqueConstraint("b", name="second"),
        UniqueConstraint("a", name="first"),
        sqlite_strict=True,
    )
    Table("aardvark", schema, Column("id", Integer, primary_key=True))

    assert broken_rules(schema) == [
        "The table aardvark is not strict.",
        "The table zebra has a name given by hand, first: "
        "constraints and indexes are named by the naming rule.",
        "The table zebra has a name given by hand, second: "
        "constraints and indexes are named by the naming rule.",
    ]


def test_a_check_without_a_name_is_refused_when_its_table_is_defined() -> None:
    schema = a_schema()

    with pytest.raises(InvalidRequestError, match="requires that constraint is explicitly named"):
        Table(
            "nameless",
            schema,
            Column("id", Integer, primary_key=True),
            Column("number", Integer),
            CheckConstraint("number > 0"),
        )
```

### 3. `backend/tests/integration/test_base.py` – new, the whole file, 9 tests

```python
"""Tests of the base of every model, with tables made in a real SQLite file.

The two models here are made for the tests. They are subclasses of the
real ``Base``, so they prove what it does, but they are kept in a schema of
their own (``Proof.metadata``), so the real schema never sees them.
"""

import sqlite3

import pytest
from sqlalchemy import (
    CheckConstraint,
    Engine,
    ForeignKey,
    Index,
    MetaData,
    UniqueConstraint,
    inspect,
    select,
)
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base, broken_rules
from motosphere.db.work import unit_of_work


class Proof(Base):
    """Models of the tests' own: the rules of ``Base``, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofOwner(Proof):
    __tablename__ = "proof_owner"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(unique=True)


class ProofItem(Proof):
    __tablename__ = "proof_item"
    # A model that says something of its table itself. The table is strict all the same.
    __table_args__ = (
        UniqueConstraint("owner_id", "number"),
        CheckConstraint("number > 0", name="number_positive"),
        Index(None, "place", "length"),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    owner_id: Mapped[int] = mapped_column(ForeignKey("proof_owner.id"))
    number: Mapped[int]
    place: Mapped[str] = mapped_column(index=True)
    length: Mapped[float | None]
    picture: Mapped[bytes | None]


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the two tables of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def test_the_tables_of_models_are_strict_in_the_store(made: Engine) -> None:
    with made.connect() as connection:
        strict = {
            name: bool(is_strict)
            for _, name, kind, _, _, is_strict in connection.exec_driver_sql("PRAGMA table_list")
            if kind == "table" and name.startswith("proof_")
        }

    assert strict == {"proof_owner": True, "proof_item": True}


@pytest.mark.parametrize(
    "statement",
    [
        "INSERT INTO proof_owner (name) VALUES (x'00ff')",
        "INSERT INTO proof_item (owner_id, number, place) VALUES (1, 'seven', 'a place')",
        "INSERT INTO proof_item (owner_id, number, place, length) VALUES (1, 7, 'a place', 'long')",
        "INSERT INTO proof_item (owner_id, number, place, picture) VALUES (1, 7, 'a place', 1.5)",
    ],
    ids=[
        "bytes as text",
        "text as a whole number",
        "text as a number",
        "a number as bytes",
    ],
)
def test_a_value_that_is_not_of_its_columns_type_is_refused(made: Engine, statement: str) -> None:
    with made.begin() as connection:
        connection.exec_driver_sql("INSERT INTO proof_owner (id, name) VALUES (1, 'the owner')")

    with pytest.raises(IntegrityError) as refused, made.begin() as connection:
        connection.exec_driver_sql(statement)

    assert isinstance(refused.value.orig, sqlite3.IntegrityError)
    assert "cannot store" in str(refused.value.orig)


def test_python_types_become_the_column_types_a_strict_table_takes(made: Engine) -> None:
    with made.connect() as connection:
        types = {
            name: declared
            for _, name, declared, _, _, _ in connection.exec_driver_sql(
                "PRAGMA table_info(proof_item)"
            )
        }

    assert types == {
        "id": "INTEGER",
        "owner_id": "INTEGER",
        "number": "INTEGER",
        "place": "TEXT",
        "length": "REAL",
        "picture": "BLOB",
    }


def test_values_come_back_as_they_were_stored(made: Engine) -> None:
    with unit_of_work(made) as work:
        owner = ProofOwner(name="the owner")
        work.add(owner)
        work.flush()
        work.add(
            ProofItem(
                owner_id=owner.id, number=7, place="a place", length=1.75, picture=b"\x00\xff"
            )
        )

    with unit_of_work(made) as work:
        item = work.scalars(select(ProofItem)).one()

    assert (item.number, item.place, item.length, item.picture) == (7, "a place", 1.75, b"\x00\xff")
    assert type(item.length) is float
    assert type(item.picture) is bytes


def test_constraints_and_indexes_are_named_by_the_rule_in_the_store(made: Engine) -> None:
    schema = inspect(made)

    assert schema.get_pk_constraint("proof_owner")["name"] == "pk_proof_owner"
    assert [found["name"] for found in schema.get_unique_constraints("proof_owner")] == [
        "uq_proof_owner_name"
    ]
    assert schema.get_pk_constraint("proof_item")["name"] == "pk_proof_item"
    assert [found["name"] for found in schema.get_foreign_keys("proof_item")] == [
        "fk_proof_item_owner_id_proof_owner"
    ]
    assert [found["name"] for found in schema.get_unique_constraints("proof_item")] == [
        "uq_proof_item_owner_id_number"
    ]
    assert [found["name"] for found in schema.get_check_constraints("proof_item")] == [
        "ck_proof_item_number_positive"
    ]
    assert sorted(str(found["name"]) for found in schema.get_indexes("proof_item")) == [
        "ix_proof_item_place",
        "ix_proof_item_place_length",
    ]


def test_the_models_of_these_tests_break_no_rule() -> None:
    assert broken_rules(Proof.metadata) == []
```

## Acceptance criteria

1. The table of a model is strict in the store, also when the model says
   something of its table itself; a value that is not of its column's type
   is refused by SQLite.
2. A model's `int`, `str`, `float` and `bytes` columns are INTEGER, TEXT,
   REAL and BLOB in the store, and values come back as they were stored.
3. In the store, the key, a foreign key, a unique constraint, a check and
   two indexes of the tests' models have exactly the names the rule gives,
   on Linux and on Windows.

5. `broken_rules` gives an empty list for a schema that keeps the rules,
   and otherwise one sentence for each table that is not strict and for
   each key, unique constraint, foreign key or index named by hand, table
   by table and name by name.

   table of the tests'.
