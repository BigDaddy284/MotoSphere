## Objective

A source can say which country it is of, so that sources can be found
by country.

## Why

A federation, a club and a track are each of a country, and the
sources of one country are what a visitor of that country's part of
the globe is shown, and what a collector for that country goes
through. DAT-006 made the table of the sources before there were
countries and left the column out; DAT-011 made the countries. This
task joins the two.

It is also the first migration that changes a table that is there and
holds rows. Every migration so far made a table, an index or a
trigger. "Preserve original records and update history wherever
practical." (CLAUDE.md §11): a source that is in a store keeps
everything it had, and every row that points to it still points to
it.

## What this task is, and what it is not

- **It is** one column of `source`, `country_id`, in the model and in
  the store, the fourteenth migration that puts it there, the index
  over it, and their tests.
- **It is not** a country for any source. No source is given a
  country here: every source that is in a store has none after the
  migration, and nothing in the code names a country.
- **It is not** a way to tell "of no one country" from "nobody has
  said yet". The table has no value for both. If that difference is
  needed one day it is a column of its own.
- **It is not** the countries themselves (DAT-012) or regions
  (DAT-013).

## Design in short

In the model, after `switched_on`:

    country_id: Mapped[int | None] = mapped_column(ForeignKey("country.id"), index=True)

In the store, the table `source` as the first migration writes it,
with one column more, after `switched_on` and before the two times,
and one constraint more, after `uq_source_name`:

    country_id INTEGER,
    …
    CONSTRAINT fk_source_country_id_country
        FOREIGN KEY(country_id) REFERENCES country (id),

and the index `ix_source_country_id` over that column.

The fourteenth migration, `let_a_source_say_its_country`, builds the
table anew, in this order:

1. `PRAGMA defer_foreign_keys = ON`: the foreign keys stay on, and
   are checked when the migration's transaction ends.
2. The rows of `source` are copied aside, into `source_before`.
3. The highest key `source` has given is copied aside, into
   `source_key_before` (from SQLite's own table `sqlite_sequence`).
4. `source` is dropped, made again with the column, and filled from
   the copy: every source with its key and everything it had, and no
   country.
5. The highest key is put back.
6. The two copies are dropped, and the index is made.

## What the task left open, and what the trial settled

- **A column added, or the table built anew?** Built anew. `ALTER
  TABLE … ADD COLUMN` puts the column after all the others, and SQLite
  cannot give a column that is added a foreign key with a name. The
  table would then not be as its model makes it, and the test of the
  models and the migrations compares the two statement by statement
  (`DATABASE.md`, "The models and the migrations agree"). The other
  way round, the model following what `ADD COLUMN` gives, would put
  `country_id` after `updated_at` in every store and leave its
  foreign key without the name every other one has. The runner of the
  migrations allows a table to be built anew since DAT-004, and its
  tests do it with a table made for them; this is the first real one.
- **Where the column stands.** After `switched_on`, as the last thing
  a source says of itself, before the two times that every table ends
  with. The trial first had it after `website`; three existing tests
  of `test_source.py` read rows by position and would have changed.
  Where it stands now one existing test changes, by one value.
- **The foreign keys stay on.** Four tables point to a source
  (`source_offer`, `collection_run`, `review_item`, `country`).
  While `source` is dropped their rows point to nothing. With
  `defer_foreign_keys` SQLite counts that and checks at the end of the
  transaction, when every source is there again under its key. If a
  source were lost on the way the migration would be refused as a
  whole. Switching the foreign keys off instead is not possible
  inside a transaction, and would check nothing.
- **The highest key.** `source` gives its keys with `AUTOINCREMENT`,
  so the key of a deleted source is never given again (DAT-006).
  SQLite keeps the highest key given in `sqlite_sequence`, and
  forgets it when the table is dropped; filling the new table sets it
  to the highest key that is *there*. A store whose last source was
  deleted would then give that key a second time, and rows of history
  that name it would speak of another source. So the migration keeps
  the number and puts it back. A table that never gave a key has no
  row there before and none after. Three tests hold this, one of them
  for a table that has no sources left.
- **The statement that fills the table is written out**, column by
  column, twice. The project's lint refuses SQL that is put together
  from parts, and the list is thirteen names.
- **Nothing is done for a source when its country would go.** The
  foreign key says nothing of deleting, like every other in the
  store: SQLite refuses to delete a country that a source is of.
  Neither "the sources go too" nor "the sources lose their country"
  is something the store should decide in silence.
- **An index.** `ix_source_country_id`, over the column alone. It
  finds the sources of one country, and it is what SQLite uses for
  the question it asks itself before a country is deleted: is a
  source of it? Without the index that reads every source. The test
  holds both query plans.
- **What the column holds.** A whole number or nothing. The table is
  strict (DAT-006), so a text, part of a number and bytes are refused,
  each with SQLite's own sentence. A whole number written as text
  (`'2'`) or with a point (`2.0`) is not refused: SQLite reads it as
  the number it is, stores the whole number, and holds it to the
  foreign key. The trial expected `'1'` to be refused, and was wrong;
  a test puts on record what SQLite does.
- **The two tables point to each other.** A country says which source
  it came from, and now a source says which country it is of. A body
  that publishes the list of the countries is itself of one of them.
  That works in one order: the source first, of no country; then its
  countries; then the source is said to be of one of them. To take
  them away: the source is first of no country again, then the
  countries go, then the source. Two tests walk both ways. While the
  two point to each other neither can be deleted.
- **Does anything need the tables in an order?** SQLAlchemy cannot
  sort two tables that point to each other (`SCHEMA.sorted_tables`
  warns, and a warning fails a test in this project). Nothing in
  `backend/src` or in the tests asks for that order or drops the
  schema, and making the tables from the models (`create_all`) needs
  no order in SQLite, where a table can name one that is not there
  yet: the trial ran every test of the pipeline with the column in
  place before writing a test of its own, and only the list of the
  migrations' names and one row read by position had to change. A
  unit test holds that these two tables are the only ones that point
  to each other and that nothing else goes round.
- **The schemas made for tests.** Some tests copy the table `source`
  into a schema of their own (`to_metadata`) beside tables made for
  the test. They build their tables in a store the migrations made,
  so `country` is there for the copy to point to. None had to change.
- **`source` stays off the list of collected records**
  (`NOT_COLLECTED`): a source is registered by a person, not
  collected, and a unit test holds that the schema with the column
  breaks no rule.
- **It is all or nothing.** A table of the name of either copy, or an
  index of the name of the index, that is there already makes the
  migration fail, and the store is as it was: at version 13, the
  table without the column, every row and the highest key as before.
  The test of the index makes it fail at its very last statement,
  after the table was dropped, made anew and filled.

### 1. `backend/tests/integration/test_source_country.py` – new, the whole file, 25 tests

```python
"""Tests of the country a source is of, against a real SQLite file.

The store of every test is built the way a real store is built: by the
migrations. What is stored through the model is also read as SQLite holds
it, and what the table must refuse is also written past the model.

A source can say which country it is of, and a country says which source
it came from. So the two tables point to each other, and the tests hold
what follows from that: which of the two can be deleted, and when.
"""

from collections.abc import Iterator
from contextlib import contextmanager
from datetime import UTC, datetime
from typing import Any

import pytest
from sqlalchemy import Engine, delete, select, update
from sqlalchemy.exc import IntegrityError

from motosphere.db.models import Country, Source
from motosphere.db.models.provenance import Confidence, VerificationStatus
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.work import unit_of_work

COLLECTED = datetime(2026, 11, 27, 9, 0, tzinfo=UTC)
# The keys the fixture gives: its one source, and its two countries.
STANDARDS = 1
NEW_ZEALAND = 1
BRITAIN = 2
# A key no country has.
NO_COUNTRY = 99


@contextmanager
def refused(why: str) -> Iterator[None]:
    """SQLite refuses what the block writes, and says exactly this."""
    with pytest.raises(IntegrityError) as refusal:
        yield
    assert str(refusal.value.orig) == why


def a_country(alpha_2: str, alpha_3: str, name: str) -> Country:
    """A country as the one source of the fixture says it."""
    return Country(
        alpha_2=alpha_2,
        alpha_3=alpha_3,
        name=name,
        source_id=STANDARDS,
        source_address="https://standards.example/countries.csv",
        collected_at=COLLECTED,
        last_verified_at=COLLECTED,
        extraction_method=CollectionMethod.DATASET,
        confidence=Confidence.HIGH,
        verification_status=VerificationStatus.OFFICIAL,
    )


@pytest.fixture
def listed(newest: Engine) -> Engine:
    """The newest store with one source, of no country, and the two countries that came from it."""
    with unit_of_work(newest) as work:
        work.add(
            Source(
                name="Example Standards Body",
                website="https://standards.example",
                category=SourceCategory.GOVERNING_BODY,
                collection_method=CollectionMethod.DATASET,
            )
        )
    with unit_of_work(newest) as work:
        work.add(a_country("NZ", "NZL", "New Zealand"))
    with unit_of_work(newest) as work:
        work.add(a_country("GB", "GBR", "United Kingdom of Great Britain and Northern Ireland"))
    return newest


def a_source(**said: Any) -> Source:
    """A federation with what a source cannot be without, and what the test says of it."""
    described: dict[str, Any] = {
        "name": "Example Federation",
        "website": "https://federation.example",
        "category": SourceCategory.GOVERNING_BODY,
        "collection_method": CollectionMethod.RSS,
    }
    return Source(**(described | said))


def keep(store: Engine, source: Source) -> int:
    """Store a source in a unit of work of its own, and give its key."""
    with unit_of_work(store) as work:
        work.add(source)
    return source.id


def write(store: Engine, country_id: object, name: str = "Example Federation") -> None:
    """Write a source past the model, as plain SQL, with this in the column of its country."""
    with store.begin() as connection:
        connection.exec_driver_sql(
            "INSERT INTO source (name, website, category, collection_method, switched_on, "
            "country_id, created_at, updated_at) VALUES (?, 'https://federation.example', "
            "'governing body', 'rss feed', 0, ?, '2026-11-27T10:00:00.000000+00:00', "
            "'2026-11-27T10:00:00.000000+00:00')",
            (name, country_id),
        )


def countries_of_the_sources(store: Engine) -> list[tuple[str, object]]:
    """The name of every source and the country SQLite holds for it, by the source's key."""
    with store.connect() as connection:
        found = connection.exec_driver_sql("SELECT name, country_id FROM source ORDER BY id")
        return [(str(name), country) for name, country in found]


def codes(store: Engine) -> list[str]:
    """The code of two letters of every country, by its key."""
    with store.connect() as connection:
        return [
            str(code)
            for (code,) in connection.exec_driver_sql("SELECT alpha_2 FROM country ORDER BY id")
        ]


THE_SOURCE_OF_THE_FIXTURE = ("Example Standards Body", None)


def test_a_source_says_its_country_and_is_read_back_with_it(listed: Engine) -> None:
    key = keep(listed, a_source(country_id=NEW_ZEALAND))

    with unit_of_work(listed) as work:
        found = work.execute(select(Source).where(Source.id == key)).scalar_one()
        country = work.get_one(Country, found.country_id)

        assert found.country_id == NEW_ZEALAND
        assert (country.alpha_2, country.name) == ("NZ", "New Zealand")
    assert countries_of_the_sources(listed) == [
        THE_SOURCE_OF_THE_FIXTURE,
        ("Example Federation", NEW_ZEALAND),
    ]


def test_a_source_of_which_no_country_is_said_has_none(listed: Engine) -> None:
    key = keep(listed, a_source())

    with unit_of_work(listed) as work:
        assert work.get_one(Source, key).country_id is None
    assert countries_of_the_sources(listed) == [
        THE_SOURCE_OF_THE_FIXTURE,
        ("Example Federation", None),
    ]


def test_a_row_written_past_the_model_is_read_with_its_country(listed: Engine) -> None:
    write(listed, BRITAIN)
    write(listed, None, name="Example World Body")

    with unit_of_work(listed) as work:
        found = work.scalars(select(Source).order_by(Source.id)).all()

        assert [(source.name, source.country_id) for source in found] == [
            THE_SOURCE_OF_THE_FIXTURE,
            ("Example Federation", BRITAIN),
            ("Example World Body", None),
        ]


def test_the_country_of_a_source_is_one_that_is_there(listed: Engine) -> None:
    with refused("FOREIGN KEY constraint failed"):
        keep(listed, a_source(country_id=NO_COUNTRY))
    with refused("FOREIGN KEY constraint failed"):
        write(listed, NO_COUNTRY)
    with refused("FOREIGN KEY constraint failed"):
        write(listed, 0)

    assert countries_of_the_sources(listed) == [THE_SOURCE_OF_THE_FIXTURE]


def test_a_source_cannot_be_moved_to_a_country_that_is_not_there(listed: Engine) -> None:
    key = keep(listed, a_source(country_id=NEW_ZEALAND))

    with refused("FOREIGN KEY constraint failed"), unit_of_work(listed) as work:
        work.execute(update(Source).where(Source.id == key).values(country_id=NO_COUNTRY))

    assert countries_of_the_sources(listed)[1] == ("Example Federation", NEW_ZEALAND)


@pytest.mark.parametrize(
    ("value", "kind"),
    [("NZ", "TEXT"), ("1.5", "REAL"), (1.5, "REAL"), (b"\x01", "BLOB")],
    ids=["a code", "part of a number as text", "part of a number", "bytes"],
)
def test_the_country_of_a_source_is_a_key_and_nothing_else(
    listed: Engine, value: object, kind: str
) -> None:
    with refused(f"cannot store {kind} value in INTEGER column source.country_id"):
        write(listed, value)

    assert countries_of_the_sources(listed) == [THE_SOURCE_OF_THE_FIXTURE]


def test_a_source_is_given_a_country_later_and_another_and_none(listed: Engine) -> None:
    key = keep(listed, a_source())
    said: list[object] = []

    for country in (NEW_ZEALAND, BRITAIN, None):
        with unit_of_work(listed) as work:
            work.get_one(Source, key).country_id = country
        said.append(countries_of_the_sources(listed)[1][1])

    assert said == [NEW_ZEALAND, BRITAIN, None]


def test_two_sources_can_be_of_one_country(listed: Engine) -> None:
    keep(listed, a_source(country_id=NEW_ZEALAND))
    keep(listed, a_source(name="Example Club", country_id=NEW_ZEALAND))

    assert countries_of_the_sources(listed) == [
        THE_SOURCE_OF_THE_FIXTURE,
        ("Example Federation", NEW_ZEALAND),
        ("Example Club", NEW_ZEALAND),
    ]


def test_a_country_that_a_source_is_of_cannot_be_deleted(listed: Engine) -> None:
    keep(listed, a_source(country_id=BRITAIN))

    with refused("FOREIGN KEY constraint failed"), unit_of_work(listed) as work:
        work.execute(delete(Country).where(Country.id == BRITAIN))
    with refused("FOREIGN KEY constraint failed"), listed.begin() as connection:
        connection.exec_driver_sql("DELETE FROM country WHERE alpha_2 = 'GB'")

    assert codes(listed) == ["NZ", "GB"]
    assert countries_of_the_sources(listed)[1] == ("Example Federation", BRITAIN)


def test_a_country_that_no_source_is_of_can_be_deleted(listed: Engine) -> None:
    keep(listed, a_source(country_id=BRITAIN))

    with unit_of_work(listed) as work:
        work.execute(delete(Country).where(Country.id == NEW_ZEALAND))

    assert codes(listed) == ["GB"]
    assert countries_of_the_sources(listed)[1] == ("Example Federation", BRITAIN)


@pytest.mark.parametrize("then", ["of no country", "of another country", "deleted"])
def test_a_country_can_be_deleted_once_no_source_is_of_it_any_more(
    listed: Engine, then: str
) -> None:
    key = keep(listed, a_source(country_id=BRITAIN))
```
