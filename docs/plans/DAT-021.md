# DAT-021 – Opening the store

**Phase:** 2 – Data store and published data
**Depends on:** DAT-001 and DAT-002 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §12, §14, `docs/WORKFLOW.md`, `DATABASE.md`,
`ARCHITECTURE.md` §5, `TESTING.md` ("The data store's SQLite"),
`backend/src/motosphere/db/sqlite.py`,
`backend/tests/integration/test_sqlite_on_this_machine.py`,
`backend/tests/conftest.py`

## Objective

The pipeline opens its store through one function. Every connection
enforces foreign keys, work that fails is taken back as a whole, and an
SQLite that lacks what the store relies on is refused before anything is
written.

## Why

DAT-001 named what the store needs from SQLite, and DAT-002 says where the
store's file is. Nothing opens it yet. Every later task of Phase 2 (the
test fixture, migrations, every table) goes through the function this task
adds, so three things must be true of every connection from the start, and
SQLite gives none of them by itself:

1. **Foreign keys are off** unless each new connection switches them on.
   One connection that forgets can store a result for a rider who does not
   exist.
2. **Python's older way of handling SQLite transactions keeps a change to
   the schema** even when the work around it is taken back. A migration
   that failed half-way would leave half a schema.
3. **A connection left open keeps the file open.** On Windows such a file
   cannot be moved or removed, and the tests of the next task remove one
   after every test.

This is the second third of the old "DAT-002 – Store settings and
connection module" (PLAN-013).

## Design in short

- **SQLAlchemy 2 joins the pipeline** (`sqlalchemy>=2.1`, locked at
  2.1.9 today; it brings no further package that is not already there).
  `ARCHITECTURE.md` §4 has named it as the pipeline's way to its database
  since the hosting decision.
- One new module, `motosphere.db.store`, with one function,
  `open_store(path)`, and one error, `StoreError`. The function returns
  the engine. It does not read the settings: the caller passes the path
  (`get_settings().store_path` in the pipeline, a temporary folder in a
  test).
- **Asked first, written last.** `open_store` calls `missing()` of
  DAT-001 before it touches the disk. If the SQLite lacks anything, the
  store is refused with everything it lacks in one sentence, and no file
  and no folder is made.
- **Foreign keys on every connection**, switched on in the engine's
  `connect` event, as SQLAlchemy's documentation gives it for SQLite.
- **SQLite's own transactions**: `connect_args={"autocommit": False}`,
  the setting Python 3.12 brought and SQLAlchemy documents ("Enabling
  Non-Legacy SQLite Transactional Modes"). A connection is then always
  inside a transaction, and a new table is taken back with the rest of a
  failed piece of work. Inside a transaction SQLite ignores
  `PRAGMA foreign_keys`, so the event leaves that mode for the one
  statement and returns to it.
- **No connection is kept**: `NullPool`. A connection is closed when its
  work is done. The pipeline is one batch job at a time, so nothing is
  lost by opening a connection for each piece of work.
- **The path is made whole when the store is opened**, so a later change
  of the current folder cannot move the store, and every message names
  the whole path. The file's folder is made if it is not there; the file
  is created, empty, by the first connection, which `open_store` makes
  itself to find out whether the file is a database at all.
- **Four refusals, each one plain sentence** that begins "The data store
  cannot be opened:": the SQLite lacks something; the path is a folder;
  the folder cannot be made; the file cannot be read as an SQLite database
  (it is left as it was).
- No unit of work, no session, no fixture, no table of the application, no
  command: DAT-022, DAT-003 and later.

### 2. `backend/src/motosphere/db/store.py` – new, the whole file

```python
"""Opening the data store: the one place where the pipeline connects to its SQLite file.

``open_store`` gives the SQLAlchemy engine for a store's file. Every
connection that engine makes enforces foreign keys and uses SQLite's own
transactions, so that work which fails is taken back as a whole, a change
to the schema included. No connection is kept open after it has been used.
"""

import sqlite3
from collections.abc import Callable
from pathlib import Path

from sqlalchemy import URL, Engine, create_engine, event
from sqlalchemy.exc import DBAPIError
from sqlalchemy.pool import NullPool

from motosphere.db.sqlite import missing

__all__ = ["StoreError", "open_store"]


class StoreError(Exception):
    """The store cannot be opened. The message is one plain sentence for the user."""


def _refuse(reason: str) -> StoreError:
    return StoreError(f"The data store cannot be opened: {reason}.")


def _switch_on_foreign_keys(connection: sqlite3.Connection, _record: object) -> None:
    """Make a new connection enforce foreign keys.

    SQLite ignores the statement inside a transaction, and with
    ``autocommit=False`` a connection is always inside one. So the
    connection leaves that mode for this one statement.
    """
    before = connection.autocommit
    connection.autocommit = True
    connection.execute("PRAGMA foreign_keys = ON")
    connection.autocommit = before


def open_store(path: Path, lacking: Callable[[], list[str]] = missing) -> Engine:
    """Open the store kept in the file at ``path`` and return its engine.

    A file that is not there yet is created, empty, with its folder. A
    relative path is taken from the current folder now, so the engine keeps
    pointing at the same file whatever the current folder is later.

    ``lacking`` says what this machine's SQLite lacks for the store; if it
    names anything, the store is refused before anything is written.

    Raises ``StoreError`` when the store cannot be opened.
    """
    problems = lacking()
    if problems:
        raise _refuse("; ".join(problems))
    path = path.resolve()
    if path.is_dir():
        raise _refuse(f"{path} is a folder, not a file")
    try:
        path.parent.mkdir(parents=True, exist_ok=True)
    except OSError as error:
        raise _refuse(f"the folder {path.parent} cannot be made ({error.strerror})") from error

    engine = create_engine(
        URL.create("sqlite+pysqlite", database=str(path)),
        # No connection is kept: a store that is not in use is a closed file.
        poolclass=NullPool,
        # SQLite's own transactions (Python 3.12 and newer): one is always
        # open, so a change to the schema is taken back like any other.
        connect_args={"autocommit": False},
    )
    event.listen(engine, "connect", _switch_on_foreign_keys)
    try:
        with engine.connect() as connection:
            connection.exec_driver_sql("SELECT count(*) FROM sqlite_master").scalar_one()
    except DBAPIError as error:
        raise _refuse(f"{path} cannot be read as an SQLite database ({error.orig})") from error
    return engine
```

`_record: object` and `connection: sqlite3.Connection` in the event's
function: SQLAlchemy hands the event the driver's own connection, which
for SQLite is Python's `sqlite3.Connection`, and the function needs its
`autocommit` attribute.

### 3. `backend/tests/integration/test_store.py` – new, the whole file, 19 tests

```python
"""Tests of opening the data store, against a real SQLite file in the test's own folder."""

import sqlite3
from pathlib import Path

import pytest
from sqlalchemy import Engine, event
from sqlalchemy.exc import IntegrityError

from motosphere.db.sqlite import text_of, version_of
from motosphere.db.store import StoreError, open_store

PARENT = "CREATE TABLE parent (id INTEGER PRIMARY KEY)"
CHILD = "CREATE TABLE child (parent_id INTEGER NOT NULL REFERENCES parent (id))"
A_PARENT = "INSERT INTO parent (id) VALUES (1)"
AN_ORPHAN = "INSERT INTO child (parent_id) VALUES (7)"
BROKEN_KEY = "FOREIGN KEY constraint failed"


def with_parent_and_child(path: Path) -> Engine:
    engine = open_store(path)
    with engine.begin() as connection:
        connection.exec_driver_sql(PARENT)
        connection.exec_driver_sql(CHILD)
    return engine


def tables(engine: Engine) -> list[str]:
    with engine.connect() as connection:
        found = connection.exec_driver_sql("SELECT name FROM sqlite_master ORDER BY name")
        return [str(name) for (name,) in found]


def parents(engine: Engine) -> int:
    with engine.connect() as connection:
        return int(connection.exec_driver_sql("SELECT count(*) FROM parent").scalar_one())


def fail_after(engine: Engine, *statements: str) -> None:
    """Do the statements as one piece of work, and fail before it is committed."""
    with engine.begin() as connection:
        for statement in statements:
            connection.exec_driver_sql(statement)
        raise RuntimeError("the work failed part-way")


def this_sqlite() -> str:
    connection = sqlite3.connect(":memory:")
    try:
        return text_of(version_of(connection))
    finally:
        connection.close()


def test_opening_a_store_makes_its_file_and_its_folder(tmp_path: Path) -> None:
    path = tmp_path / "a folder" / "inside it" / "store.sqlite3"

    open_store(path)

    assert path.is_file()


def test_a_store_can_be_opened_again_before_anything_was_written(tmp_path: Path) -> None:
    path = tmp_path / "store.sqlite3"
    open_store(path)

    assert tables(open_store(path)) == []


def test_a_relative_path_is_taken_from_the_folder_the_store_was_opened_in(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch
) -> None:
    elsewhere = tmp_path / "elsewhere"
    elsewhere.mkdir()
    engine = open_store(Path("kept here") / "store.sqlite3")
    monkeypatch.chdir(elsewhere)

    with engine.begin() as connection:
        connection.exec_driver_sql(PARENT)

    assert (tmp_path / "kept here" / "store.sqlite3").stat().st_size > 0
    assert list(elsewhere.iterdir()) == []


def test_a_row_without_its_parent_is_refused_on_the_first_connection(tmp_path: Path) -> None:
    engine = open_store(tmp_path / "store.sqlite3")

    with engine.connect() as connection:
        connection.exec_driver_sql(PARENT)
        connection.exec_driver_sql(CHILD)
        with pytest.raises(IntegrityError, match=BROKEN_KEY):
            connection.exec_driver_sql(AN_ORPHAN)


def test_a_row_without_its_parent_is_refused_on_every_later_connection(tmp_path: Path) -> None:
    engine = with_parent_and_child(tmp_path / "store.sqlite3")

    for _ in range(3):
        with engine.connect() as connection, pytest.raises(IntegrityError, match=BROKEN_KEY):
            connection.exec_driver_sql(AN_ORPHAN)


def test_a_row_without_its_parent_is_refused_on_two_connections_open_at_once(
    tmp_path: Path,
) -> None:
    engine = with_parent_and_child(tmp_path / "store.sqlite3")

    with engine.connect() as first, engine.connect() as second:
        with pytest.raises(IntegrityError, match=BROKEN_KEY):
            first.exec_driver_sql(AN_ORPHAN)
        first.rollback()
        with pytest.raises(IntegrityError, match=BROKEN_KEY):
            second.exec_driver_sql(AN_ORPHAN)


def test_a_row_without_its_parent_is_refused_when_the_store_is_opened_again(
    tmp_path: Path,
) -> None:
    path = tmp_path / "store.sqlite3"
    with_parent_and_child(path)

    with open_store(path).connect() as connection, pytest.raises(IntegrityError, match=BROKEN_KEY):
        connection.exec_driver_sql(AN_ORPHAN)


def test_a_row_with_its_parent_is_accepted(tmp_path: Path) -> None:
    engine = with_parent_and_child(tmp_path / "store.sqlite3")

    with engine.begin() as connection:
        connection.exec_driver_sql(A_PARENT)
        connection.exec_driver_sql("INSERT INTO child (parent_id) VALUES (1)")

    assert parents(engine) == 1


def test_work_that_is_committed_is_there_when_the_store_is_opened_again(tmp_path: Path) -> None:
    path = tmp_path / "store.sqlite3"
    engine = with_parent_and_child(path)

    with engine.begin() as connection:
        connection.exec_driver_sql(A_PARENT)

    assert parents(open_store(path)) == 1


def test_a_row_of_work_that_fails_is_taken_back(tmp_path: Path) -> None:
    engine = with_parent_and_child(tmp_path / "store.sqlite3")

    with pytest.raises(RuntimeError, match="part-way"):
        fail_after(engine, A_PARENT)

    assert parents(engine) == 0


def test_a_new_table_of_work_that_fails_is_taken_back(tmp_path: Path) -> None:
    engine = open_store(tmp_path / "store.sqlite3")

    with pytest.raises(RuntimeError, match="part-way"):
        fail_after(engine, PARENT, A_PARENT)

    assert tables(engine) == []


def test_work_that_is_not_committed_is_not_kept(tmp_path: Path) -> None:
    engine = with_parent_and_child(tmp_path / "store.sqlite3")

    with engine.connect() as connection:
        connection.exec_driver_sql(A_PARENT)

    assert parents(engine) == 0


def test_every_connection_is_closed_after_use(tmp_path: Path) -> None:
    engine = with_parent_and_child(tmp_path / "store.sqlite3")
    opened: list[object] = []
    closed: list[object] = []
    event.listen(engine, "connect", lambda connection, _record: opened.append(connection))
    event.listen(engine, "close", lambda connection, _record: closed.append(connection))

    for _ in range(3):
        assert parents(engine) == 0

    assert len(opened) == 3
    assert closed == opened


def test_the_file_can_be_removed_after_use(tmp_path: Path) -> None:
    path = tmp_path / "store.sqlite3"
    engine = with_parent_and_child(path)
    assert parents(engine) == 0

    path.unlink()

    assert not path.exists()


def test_an_sqlite_that_is_too_old_is_refused_in_one_sentence_and_nothing_is_written(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch
) -> None:
    monkeypatch.setattr("motosphere.db.sqlite.LEAST_VERSION", (99, 0, 0))

    with pytest.raises(StoreError) as refusal:
        open_store(tmp_path / "a folder" / "store.sqlite3")

    assert str(refusal.value) == (
        f"The data store cannot be opened: SQLite {this_sqlite()} is older than 99.0.0, "
        "the least version the data store works with."
    )
    assert list(tmp_path.iterdir()) == []


def test_everything_the_sqlite_lacks_is_in_the_one_sentence(tmp_path: Path) -> None:
    def lacking() -> list[str]:
        return ["this SQLite has no JSON functions", "this SQLite has no full-text search (FTS5)"]

    with pytest.raises(StoreError) as refusal:
        open_store(tmp_path / "store.sqlite3", lacking)

    assert str(refusal.value) == (
        "The data store cannot be opened: this SQLite has no JSON functions; "
        "this SQLite has no full-text search (FTS5)."
    )
    assert list(tmp_path.iterdir()) == []


def test_a_folder_is_refused_and_named_with_its_whole_path(tmp_path: Path) -> None:
    folder = tmp_path / "store.sqlite3"
    folder.mkdir()

    with pytest.raises(StoreError) as refusal:
        open_store(Path("store.sqlite3"))

    assert str(refusal.value) == (
        f"The data store cannot be opened: {folder.resolve()} is a folder, not a file."
    )
    assert list(folder.iterdir()) == []


def test_a_file_that_is_not_a_database_is_refused_and_left_as_it_was(tmp_path: Path) -> None:
    path = tmp_path / "store.sqlite3"
    notes = b"These are somebody's notes, not a database.\n" * 40
    path.write_bytes(notes)

    with pytest.raises(StoreError) as refusal:
        open_store(path)

    assert str(refusal.value) == (
        f"The data store cannot be opened: {path.resolve()} cannot be read as an SQLite "
        "database (file is not a database)."
    )
    assert path.read_bytes() == notes


def test_a_folder_that_cannot_be_made_is_refused(tmp_path: Path) -> None:
    taken = tmp_path / "taken"
    taken.write_text("a file where the store's folder should be", encoding="utf-8")

    with pytest.raises(StoreError) as refusal:
        open_store(taken / "store.sqlite3")

    assert str(refusal.value).startswith(
        f"The data store cannot be opened: the folder {taken.resolve()} cannot be made ("
    )
    assert taken.is_file()
```

## Acceptance criteria

1. `open_store(path)` returns an engine for the SQLite file at `path`. A
   file that is not there is created with its folder; a relative path is
   taken from the current folder at that moment and the engine keeps to
