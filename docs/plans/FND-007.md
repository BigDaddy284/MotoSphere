## Objective

A FastAPI application, built by a factory function, that answers a health
check. This is the seed of the backend API; every later endpoint is added to
the application this task creates.

## Implementation detail

### 1. Dependencies

In `backend/pyproject.toml`, keeping both lists sorted alphabetically:

```toml
dependencies = [
    "fastapi>=0.115",
    "pydantic>=2.9",
    "pydantic-settings>=2.6",
]

[dependency-groups]
dev = [
    "httpx2>=2.0",
    "mypy>=1.13",
    "pytest>=8.3",
    "ruff>=0.9",
]
```

Run `uv lock`.

**Why `httpx2` and not `httpx`:** FastAPI's test client comes from Starlette.
The planner's trial run (fastapi 0.163, starlette 1.10) found that Starlette
now prefers `httpx2` and emits a deprecation warning when only `httpx` is
installed. This project turns warnings into test failures, so `httpx` makes
every API test fail at collection. With `httpx2` installed the trial passed
with no warnings. Use plain `fastapi`, not `fastapi[standard]`: the extras
pull in a server and tooling this task must not add.

### 2. `motosphere/api/health.py`

Public names (set `__all__`): `APP_NAME`, `HealthResponse`, `router`.

- `APP_NAME = "MotoSphere"`.
- `HealthResponse(pydantic.BaseModel)` with fields `status: Literal["ok"]`,
  `name: str`, `version: str`, each with a plain-language `description`.
- `router = APIRouter(tags=["Health"])` with one route:
  `GET /api/health`, summary "Health check", response model `HealthResponse`.
  It returns `status="ok"`, `name=APP_NAME`,
  `version=motosphere.__version__`, and sets the response header
  `Cache-Control: no-store` (the frontend will poll this endpoint to show
  whether the backend is reachable, so a cached answer would be a wrong
  answer).

  The handler is a plain `def`, not `async def` (ARCHITECTURE.md §4: the
  backend is synchronous).

### 3. `motosphere/api/app.py`

Public names: `API_TITLE`, `create_app`.

```python
def create_app(settings: Settings | None = None) -> FastAPI:
```

- Uses the given settings, or `get_settings()` when none are given.
- Creates `FastAPI(title="MotoSphere API", version=motosphere.__version__,
  docs_url="/api/docs", redoc_url=None, openapi_url="/api/openapi.json")`.
  Everything the API serves lives under `/api/`, so the frontend can own every
  other path.
- Stores the settings on `app.state.settings`.
- Includes the health router.
- Returns a **new, independent** application on every call. No global state.

### 4. `backend/tests/api/test_app.py`

Use `fastapi.testclient.TestClient` on `create_app(Settings())`. Fully
type-annotated. A small fixture returning a client is fine. Exactly these 10
tests:

1. `test_health_returns_ok` – `GET /api/health` → 200, content type starts
   with `application/json`, body equals exactly
   `{"status": "ok", "name": "MotoSphere", "version": motosphere.__version__}`.
2. `test_health_is_never_cached` – the response has `Cache-Control: no-store`.
3. `test_health_rejects_other_methods` – `POST`, `PUT` and `DELETE` on
   `/api/health` each return 405.
4. `test_unknown_path_returns_json_404` – `GET /api/does-not-exist` → 404 with
   a JSON body containing a `detail` key.
5. `test_openapi_schema_describes_health` – `GET /api/openapi.json` → 200;
   `info.title == "MotoSphere API"`; `info.version == motosphere.__version__`;
   `paths["/api/health"]` has a `get` operation whose 200 response references
   the `HealthResponse` schema; that schema requires `status`, `name` and
   `version`.
6. `test_docs_are_served_under_api` – `GET /api/docs` → 200 with an HTML
   content type.
7. `test_default_documentation_paths_are_not_served` – `GET /docs`, `/redoc`
   and `/openapi.json` each return 404.
8. `test_create_app_uses_given_settings` – a `Settings(api_port=9123)` object
   passed to `create_app` is the same object as `app.state.settings`.
9. `test_create_app_falls_back_to_get_settings` – with the environment
   variable `MOTOSPHERE_API_PORT=9456` set (`monkeypatch.setenv`),
   `create_app().state.settings.api_port == 9456`. (The shared fixture in
   `conftest.py` already clears the settings cache around each test.)
10. `test_create_app_returns_independent_applications` – two calls return
    different objects, and both answer the health check.

## Acceptance criteria

1. `GET /api/health` returns 200 and exactly
   `{"status": "ok", "name": "MotoSphere", "version": <package version>}` with
   `Cache-Control: no-store`.
2. Other methods on the health path return 405; unknown paths return a JSON
   404.
3. The OpenAPI schema describes the endpoint and its response model;
   documentation is served only under `/api/`.
4. `create_app` uses the settings it is given, falls back to `get_settings()`,
   and returns a new application on each call.
5. All gates pass with no suppressions and no warnings, and no file outside
   "Scope" is touched.

files`; ruff clean; `46 passed` (10 new + 36 existing) with no warnings;
`Ran 9 tests` / `OK`; clean status once committed.

Then prove the tests can fail (do not commit these changes). Python reuses
stale bytecode if a file is changed and restored within the same second, so
set `PYTHONDONTWRITEBYTECODE=1` and delete any `__pycache__` folders under
`backend/src` and `backend/tests` before each re-run.

1. Temporarily change `status="ok"` handling so the endpoint returns
   `name="Motosphere"` (lower-case s) → `test_health_returns_ok` must fail.
   Restore it.
2. Temporarily remove the `Cache-Control` header →
   `test_health_is_never_cached` must fail. Restore it.
3. Temporarily change `docs_url` back to `"/docs"` →
   `test_docs_are_served_under_api` and
   `test_default_documentation_paths_are_not_served` must fail. Restore it.

Finish with `git status` clean and every gate green.
