**Phase:** 2 – Data store and published data
**Depends on:** DAT-028 and DAT-029 (merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §11, §12, `docs/WORKFLOW.md`, `DATABASE.md`
("The rules every table keeps", "Times"), `TESTING.md` ("The rules every
table keeps", "Times in the store", "A data store of its own for every
test"), `backend/src/motosphere/db/base.py`,
`backend/src/motosphere/db/times.py`, `backend/tests/conftest.py`,
`backend/tests/integration/test_key.py`

## Objective

Every row of every table says when it was first stored and when it was last
changed, in two columns a model gets without naming them, and the store's
code sets them from one clock that a test can set.

## Why

A record of the store is collected again and again. Whether what was
collected changed the record, and when, is what the site will say of its
data ("last updated"), what the collectors will go by, and what the history
of a record hangs on. So every table gets the two times, in the same way,
before the first table: a model cannot leave them out, and no caller has to
remember to set them.

This is the first half of what PLAN-018 called "DAT-031 – Every table's
timestamps". The planner's trial found the rule that names a table without
them to be a task of its own (PLAN-019, in `PROGRESS.md`); it follows as
DAT-032.

## Design in short

- **The store has one clock**: `now()` in `motosphere.db.times`, which says
  the moment it is, in UTC. Whatever the store's code needs the present
  moment for, it asks this function, and it asks it by its module
  (`times.now()`), so that a test can set the clock.
- **`Base` gives every model two more columns**, `created_at` and
  `updated_at`. Both are times as DAT-028 stores them, both must be there,
  and the table gives neither a value of its own. They are the last two
  columns of every table. A model does not name them.
- **The store's code sets them, when the statement runs** that stores or
  changes the row, with SQLAlchemy's `default` and `onupdate` of a column:
  - `created_at` has the default `_this_moment`, which asks the clock;
  - `updated_at` has the default `_when_first_stored`, which gives the row
    the very moment its `created_at` got, and `onupdate=_this_moment`.
- **A new row has the same moment in both columns**: one reading of the
  clock, not two. So a row that was never changed is one whose two times
  are the same.
- **A changed row** gets a new `updated_at` and keeps its `created_at`. A
  row whose values are set to what they already are is not changed: both
  times stay, and the clock is not asked.
- **A row may be stored with times of its own**, and keeps them. The store
  that is rebuilt from its text files (DAT-020) needs that, as it needs to
  store rows with their keys.
- **A test sets the clock** with a new fixture, `clock`, in
  `backend/tests/conftest.py`. The set clock says 19 November 2026, 08:00
  UTC, first and one second more at every asking; the fixture is the list
  of the moments it said. No two askings get the same moment, so a test
  can tell one reading of the clock from two, and `len(clock)` says how
  often the store asked.
- No new package, no table, no migration. `broken_rules` does not change
  (DAT-032).

## Existing tests that change, and why

Two columns that must be there in every row reach every test that writes a
row with plain SQL or lists the columns of a table. Nothing is taken out to
get a pass; each test still asks what it asked, and three ask for more.
They are 12 tests in six functions, the 12 that failed in the trial with
only the two modules changed.

- `backend/tests/integration/test_base.py`: the five plain `INSERT`
  statements of `test_a_value_that_is_not_of_its_columns_type_is_refused`
  now say the two times too, as the two `?` of each statement. Without
  them SQLite would refuse the rows for the missing times, and the test
  would no longer show what it is there to show: its assertion that the
  refusal says "cannot store" failed in the trial for exactly that reason.
  `test_python_types_become_the_column_types_a_strict_table_takes` expects
  the two new columns, as TEXT.
- `backend/tests/integration/test_key.py`:
  `test_the_key_is_the_first_column_and_a_whole_number` expects the two new
  columns after the model's own, and the plain `INSERT` of
  `test_a_row_written_past_the_model_gets_a_key_that_was_never_given` says
  the two times.
- `backend/tests/integration/test_times.py`:
  `test_a_models_time_is_the_stores_own_type_and_text_in_a_strict_table`
  expects the two new columns, as TEXT that must be there, and the plain
  `INSERT` of
  `test_text_put_into_the_store_in_another_form_is_refused_when_it_is_read`
  gives the row two times in the store's form, so that only `seen_at` is in
  another form.
- `backend/tests/unit/test_db_times.py` gets two new tests, of the clock.
  Its other 32 tests do not change.
- `backend/tests/unit/test_db_base.py` does not change.

  are the prove-it steps below.

  the other 351 backend tests passed.
- **Where the two columns stand.** Columns a model gets from `Base` come
  after the model's own, in the order `Base` names them. So they are the
  last two, `created_at` first, with nothing said about their place. (The
  key needs `sort_order=-1` to come first.)
- **One reading of the clock for a new row.** SQLAlchemy asks the defaults
  of a row in the order of its columns, and hands each the values the row
  has so far. `_when_first_stored` reads `created_at` there. A statement
  that stores several rows at once (`insert(Model).values([...])`) is the
  one case where the name of that value is not `created_at`: SQLAlchemy
  gives the columns of each later row an ending of their own
  (`created_at_m1`, `updated_at_m1`). So the function takes the ending
  from the column it is asked for. Tried in three ways of storing two
  rows, each a test: both rows get one moment of their own in both
  columns, and the clock is asked twice.
- **SQLAlchemy's own way of reading the row's values does not do**
  (`context.get_current_parameters()`): for a statement with several rows
  it gives only the values the caller named, and `created_at` is not among
  them (`KeyError`).
- **What the object holds.** After the unit of work the model object holds
  the two moments the store was given, without reading the store again.
- **A change that changes nothing.** Setting a column to the value it has
  writes nothing: the clock is not asked and both times stay.
- **Where it ends**, each shown by a test: a row written with plain SQL
  without its times is refused ("NOT NULL constraint failed"); a change
  written with plain SQL leaves `updated_at` as it was; and so does a
  statement that stores a row or changes the one that is there
  (`INSERT … ON CONFLICT DO UPDATE`) when it changes a row. The store's
  code uses none of the three. `DATABASE.md` says so, and that the first
  code to use such a statement has to set `updated_at` in it.
- **The real clock** is used by one test, which expects the row's time
  between a reading before and one after. A test that compares two times
  uses the set clock, because two readings of the real clock need not
  differ.

### 1. `backend/tests/integration/test_row_times.py` – new, the whole file, 18 tests

```python
"""Tests of the two times every row has, with a table made in a real SQLite file.

The model here is made for the tests. It is a subclass of the real ``Base``
and names no time, so it proves what ``Base`` gives it, but it is kept in a
schema of its own (``Proof.metadata``), so the real schema never sees it.

Most tests set the store's clock with the fixture ``clock``: it is the list
of the moments the clock said, a second apart, in order.
"""

import sqlite3
from datetime import UTC, datetime, timedelta

import pytest
from sqlalchemy import Engine, MetaData, insert, select, update
from sqlalchemy.dialects import sqlite
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Mapped, mapped_column

from motosphere.db.base import Base
from motosphere.db.times import to_text
from motosphere.db.work import unit_of_work

LONG_AGO = datetime(2019, 3, 9, 14, 30, tzinfo=UTC)
ITS_TEXT = "2019-03-09T14:30:00.000000+00:00"


class Proof(Base):
    """Models of the tests' own: the times ``Base`` gives, in a schema apart from the real one."""

    __abstract__ = True
    metadata = MetaData(naming_convention=Base.metadata.naming_convention)


class ProofNote(Proof):
    __tablename__ = "proof_note"

    words: Mapped[str] = mapped_column(unique=True)
    stars: Mapped[int | None]


@pytest.fixture
def made(store: Engine) -> Engine:
    """The store, with the table of the tests made in it."""
    with store.begin() as connection:
        Proof.metadata.create_all(connection)
    return store


def add(made: Engine, *words: str) -> None:
    """Store a note of each of the words, each in a unit of work of its own."""
    for its_words in words:
        with unit_of_work(made) as work:
            work.add(ProofNote(words=its_words))


def stored(made: Engine) -> list[tuple[str, str, str]]:
    """What the file itself holds, read without the model."""
    with made.connect() as connection:
        rows = connection.exec_driver_sql(
            "SELECT words, created_at, updated_at FROM proof_note ORDER BY id"
        ).all()
    return [(words, created_at, updated_at) for words, created_at, updated_at in rows]


def test_the_two_times_are_the_last_columns_and_the_table_does_not_set_them(made: Engine) -> None:
    with made.connect() as connection:
        columns = [
            (name, declared, bool(required), set_by_the_table)
            for _, name, declared, required, set_by_the_table, _ in connection.exec_driver_sql(
                "PRAGMA table_info(proof_note)"
            )
        ]

    assert [name for name, _, _, _ in columns] == [
        "id",
        "words",
        "stars",
        "created_at",
        "updated_at",
    ]
    assert columns[-2:] == [("created_at", "TEXT", True, None), ("updated_at", "TEXT", True, None)]


def test_a_new_row_says_when_it_was_first_stored_and_was_last_changed_then(
    made: Engine, clock: list[datetime]
) -> None:
    with unit_of_work(made) as work:
        note = ProofNote(words="first")
        work.add(note)

    assert len(clock) == 1
    assert stored(made) == [("first", to_text(clock[0]), to_text(clock[0]))]
    assert (note.created_at, note.updated_at) == (clock[0], clock[0])


def test_the_times_come_back_as_aware_utc_times(made: Engine, clock: list[datetime]) -> None:
    add(made, "first")

    with unit_of_work(made) as work:
        note = work.scalars(select(ProofNote)).one()

    assert (note.created_at, note.updated_at) == (clock[0], clock[0])
    assert note.created_at.utcoffset() == timedelta(0)
    assert note.updated_at.utcoffset() == timedelta(0)


def test_a_changed_row_says_when_it_was_changed_and_keeps_when_it_was_first_stored(
    made: Engine, clock: list[datetime]
) -> None:
    add(made, "first")

    with unit_of_work(made) as work:
        note = work.scalars(select(ProofNote)).one()
        note.words = "changed"

    assert len(clock) == 2
    assert stored(made) == [("changed", to_text(clock[0]), to_text(clock[1]))]
    assert (note.created_at, note.updated_at) == (clock[0], clock[1])


def test_a_row_stored_again_as_it_was_keeps_both_times(made: Engine, clock: list[datetime]) -> None:
    add(made, "first")

    with unit_of_work(made) as work:
        note = work.scalars(select(ProofNote)).one()
        note.words = "first"
        note.stars = None
        work.add(note)

    assert len(clock) == 1
    assert stored(made) == [("first", to_text(clock[0]), to_text(clock[0]))]


def test_only_the_row_that_changed_gets_a_new_time(made: Engine, clock: list[datetime]) -> None:
    add(made, "first", "second")

    with unit_of_work(made) as work:
        note = work.scalars(select(ProofNote).where(ProofNote.words == "second")).one()
        note.stars = 5

    assert len(clock) == 3
    assert stored(made) == [
        ("first", to_text(clock[0]), to_text(clock[0])),
        ("second", to_text(clock[1]), to_text(clock[2])),
    ]


def test_rows_changed_in_one_unit_of_work_each_get_a_moment_of_their_own(
    made: Engine, clock: list[datetime]
) -> None:
    add(made, "first", "second")

    with unit_of_work(made) as work:
        for note in work.scalars(select(ProofNote).order_by(ProofNote.id)):
            note.stars = 5

    assert len(clock) == 4
    assert stored(made) == [
        ("first", to_text(clock[0]), to_text(clock[2])),
        ("second", to_text(clock[1]), to_text(clock[3])),
    ]


@pytest.mark.parametrize(
    "way",
    ["added to one unit of work", "a list of rows", "rows in the statement itself"],
)
def test_every_row_stored_together_gets_one_moment_of_its_own_for_both_times(
    made: Engine, clock: list[datetime], way: str
) -> None:
    with unit_of_work(made) as work:
        if way == "added to one unit of work":
            work.add_all([ProofNote(words="first"), ProofNote(words="second")])
        elif way == "a list of rows":
            work.execute(insert(ProofNote), [{"words": "first"}, {"words": "second"}])
        else:
            work.execute(insert(ProofNote).values([{"words": "first"}, {"words": "second"}]))

    assert len(clock) == 2
    assert stored(made) == [
        ("first", to_text(clock[0]), to_text(clock[0])),
        ("second", to_text(clock[1]), to_text(clock[1])),
    ]


def test_rows_changed_by_one_statement_all_say_when(made: Engine, clock: list[datetime]) -> None:
    add(made, "first", "second", "third")

    with unit_of_work(made) as work:
        work.execute(update(ProofNote).where(ProofNote.words != "second").values(stars=5))

    assert len(clock) == 4
    assert stored(made) == [
        ("first", to_text(clock[0]), to_text(clock[3])),
        ("second", to_text(clock[1]), to_text(clock[1])),
        ("third", to_text(clock[2]), to_text(clock[3])),
    ]


def test_a_row_stored_with_times_of_its_own_keeps_them(made: Engine, clock: list[datetime]) -> None:
    changed = LONG_AGO + timedelta(days=400)

    with unit_of_work(made) as work:
        work.add(ProofNote(words="old", created_at=LONG_AGO, updated_at=changed))

    assert clock == []
    assert stored(made) == [("old", ITS_TEXT, to_text(changed))]


def test_a_row_stored_with_only_its_first_time_was_last_changed_then(
    made: Engine, clock: list[datetime]
) -> None:
    with unit_of_work(made) as work:
        work.add(ProofNote(words="old", created_at=LONG_AGO))

    assert clock == []
    assert stored(made) == [("old", ITS_TEXT, ITS_TEXT)]


@pytest.mark.parametrize(
    ("statement", "missing"),
    [
        ("INSERT INTO proof_note (words) VALUES ('past')", "created_at"),
        (
            "INSERT INTO proof_note (words, created_at) "
            "VALUES ('past', '2019-03-09T14:30:00.000000+00:00')",
            "updated_at",
        ),
    ],
    ids=["neither time", "only when it was first stored"],
)
def test_a_row_written_past_the_model_without_its_times_is_refused(
    made: Engine, statement: str, missing: str
) -> None:
    with pytest.raises(IntegrityError) as refused, made.begin() as connection:
        connection.exec_driver_sql(statement)

    assert isinstance(refused.value.orig, sqlite3.IntegrityError)
    assert str(refused.value.orig) == f"NOT NULL constraint failed: proof_note.{missing}"
    assert stored(made) == []


def test_a_change_written_past_the_model_does_not_say_when(
    made: Engine, clock: list[datetime]
) -> None:
    add(made, "first")

    with made.begin() as connection:
        connection.exec_driver_sql("UPDATE proof_note SET words = 'changed'")

    assert len(clock) == 1
    assert stored(made) == [("changed", to_text(clock[0]), to_text(clock[0]))]


def test_a_change_by_a_statement_that_stores_or_changes_does_not_say_when(
    made: Engine, clock: list[datetime]
) -> None:
    add(made, "first")
    store_or_change = sqlite.insert(ProofNote).values(words="first", stars=5)

    with unit_of_work(made) as work:
        work.execute(
            store_or_change.on_conflict_do_update(
                index_elements=["words"], set_={"stars": store_or_change.excluded.stars}
            )
        )
        stars = work.scalars(select(ProofNote.stars)).one()

    assert stars == 5
    assert stored(made) == [("first", to_text(clock[0]), to_text(clock[0]))]


def test_without_a_set_clock_a_row_gets_the_moment_it_is(made: Engine) -> None:
    before = datetime.now(UTC)
    with unit_of_work(made) as work:
        note = ProofNote(words="now")
        work.add(note)
    after = datetime.now(UTC)

    assert before <= note.created_at <= after
    assert note.updated_at == note.created_at
    assert stored(made) == [("now", to_text(note.created_at), to_text(note.created_at))]
```

## Acceptance criteria

1. A model that names no time has the columns `created_at` and
   `updated_at` as the last two of its table: TEXT, they must be there,
   and the table gives them no value of its own.
2. A new row has the one moment the clock said in both columns, in the
   store's form, and the clock was asked once. Read through the model,
   both come back as aware UTC times.

   stored again as it was keeps both, and the clock was not asked. Only
   the row that changed gets a new time.

   own each, in both columns. Rows changed in one unit of work each get a
   moment of their own; rows changed by one statement all get that
   statement's moment.

   same.
