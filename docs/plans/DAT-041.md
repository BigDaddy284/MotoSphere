## Objective

The store says how each source is doing: its last attempted and last
successful scan, its last error and its health (DESIGN §7.3).

## Why

The registry of the design says four things of a source that change
with every scan: when it was last attempted, when that last worked, what
last went wrong, and how it is doing. The table of the sources has no
columns for them (PLAN-023): the runs say all four already (DAT-007),
and a second copy with the source could come to disagree with the runs.
So one function reads them from the runs whenever it is asked. What
decides when a source is due, and what shows an administrator which
sources need a look, both start from it.

## Design in short

- **One new module, `motosphere.db.source_health`**, with three names:
  - `SourceHealth`, a list of four texts;
  - `SourceStanding`, what is said of one source: `last_attempt`,
    `last_success`, `last_error` and `health`, in a frozen dataclass;
  - `standing_of(work, source_id)`, which reads it from the table
    `collection_run`.
- **Nothing is stored**: no table, no column, no migration. The schema
  stays at version 3.
- No change to any code file that exists, no new fixture, no new
  package from outside.

## What the task left open, and what the trial settled

- **The health is one of four texts**, told by the newest of the
  source's runs that is over. A run that is still running says nothing
  yet, so it is passed over.

  | `SourceHealth` | Text | When |
  |---|---|---|
  | `NOT_YET_SCANNED` | `not yet scanned` | No run of the source is over yet: it has none, or only one that is running |
  | `HEALTHY` | `healthy` | Its newest run that is over succeeded |
  | `FAILING` | `failing` | Its newest run that is over failed |
  | `INTERRUPTED` | `interrupted` | Its newest run that is over was cut off, because its job died |

- **Interrupted is not failing.** A run that failed says what went wrong
  at the source. A run that was interrupted says that the job died,
  which is a thing to look at in the job and not in the source. Counted
  as failing, an interrupted source would be failing without an error.
- **No rule with a number in it.** "Failing after three failures in a
  row" and the like would need a number that nothing gives today. The
  health is what one run says; the task that scores the sources
  (COL-009) can make it finer.
- **A scan is said by when it started**, the one time every run has: a
  run that was interrupted has no end. So `last_attempt` and
  `last_success` are both starts, and they are the same moment exactly
  when the newest run succeeded.
- **The newest run is the one that started last**, not the one stored
  last: a run may be stored late. Of two that started at the same moment
  the one stored last, with the larger key, is the newer, so that the
  answer is the same every time it is asked.
- **The last error** is that of the newest run that failed, and is no
  longer said once a later run succeeded (the task's own words). A later
  run that is running or was interrupted does not take it away: nothing
  has shown yet that the trouble is over. So the error is that of the
  newest of the runs that said how they ended, which has one only if it
  failed (the table holds it to that, DAT-007).
- **A key that no source has is refused** with a `LookupError`, "There
  is no source with the key 7." Of a source that does not exist nothing
  is true, also not that it was never scanned.
- **It takes the session of a unit of work**, as `mark_interrupted`
  does, and asks for columns, not for whole rows: nothing is loaded
  into the session that the caller could change by mistake. It asks the
  table four small questions (the newest run of any outcome; of those
  that are over; that succeeded; that said how it ended) and one about
  the source.
- **One source at a time.** What needs all sources at once (a report
  for the administrator) comes with that report, and can be written on
  the same rules.
- **The list is not stored**, so it is not in the package of the
  models, and a text of it can be changed without a migration. Its texts
  follow the rule of the stored lists all the same: words in small
  letters with one space between two.
- **The reliability score of the design is not here.** How often a
  source could be collected from says whether it answers, not whether
  what it says is right; a score from the runs alone would be a number
  with nothing behind it (CLAUDE.md §11). It comes with COL-009, from
  records that were checked.
- **The index.** DAT-007 left to this task whether the table of the
  runs needs an index. The trial read SQLite's own account of its plan
  for the function's statement: without an index, `SCAN collection_run`
  and `USE TEMP B-TREE FOR ORDER BY`; with an index over
  (`source_id`, `started_at`), `SEARCH collection_run USING INDEX …
  (source_id=?)` and no sorting. So that index is what the function
  wants. It is a change to the schema, with a migration and a test of
  its own, and so a task of its own: **DAT-042**, added by the planner
  (PLAN-024). The table has no rows yet, so nothing is slow until then.

### 1. `backend/src/motosphere/db/source_health.py` – new, the whole file

```python
"""How a source is doing, told by its collection runs.

The registry of the design says of each source when it was last scanned,
when that last worked, what last went wrong and how it is doing. All of
that is what the source's runs say already, so it is not stored a second
time with the source, where the two could come to disagree:
:func:`standing_of` reads it from the runs whenever it is asked, and
writes nothing.

A scan is said by when it started, which is the one time every run has:
a run that was interrupted has no end. The newest run is the one that
started last, and of two that started together the one that was stored
last.
"""

from dataclasses import dataclass
from datetime import datetime
from enum import StrEnum

from sqlalchemy import Row, select
from sqlalchemy.orm import Session

from motosphere.db.models.collection_run import CollectionRun, RunOutcome
from motosphere.db.models.source import Source

__all__ = ["SourceHealth", "SourceStanding", "standing_of"]


class SourceHealth(StrEnum):
    """How a source is doing: what became of the newest of its runs that is over.

    A run that is still running says nothing yet, so it is passed over.
    """

    # No run of it is over yet: it has none, or only one that is running.
    NOT_YET_SCANNED = "not yet scanned"
    # Its newest run that is over succeeded.
    HEALTHY = "healthy"
    # Its newest run that is over failed.
    FAILING = "failing"
    # Its newest run that is over was cut off, because its job died.
    INTERRUPTED = "interrupted"


_HEALTH_AFTER = {
    RunOutcome.SUCCEEDED: SourceHealth.HEALTHY,
    RunOutcome.FAILED: SourceHealth.FAILING,
    RunOutcome.INTERRUPTED: SourceHealth.INTERRUPTED,
}


@dataclass(frozen=True, slots=True)
class SourceStanding:
    """How one source is doing, as its runs say it at the moment it is asked."""

    # When its newest run started, whatever became of it. No value: it has no run.
    last_attempt: datetime | None
    # When its newest run that succeeded started. No value: none has succeeded.
    last_success: datetime | None
    # What went wrong in its newest run that failed, in plain words. No
    # value: none has failed, or one has succeeded since.
    last_error: str | None
    health: SourceHealth


def standing_of(work: Session, source_id: int) -> SourceStanding:
    """Say how the source with this key is doing. Nothing is written.

    A key that no source has is refused with a ``LookupError``: of a
    source that does not exist nothing is true, also not that it was
    never scanned.
    """
    if work.scalar(select(Source.id).where(Source.id == source_id)) is None:
        raise LookupError(f"There is no source with the key {source_id}.")

    def newest(*outcomes: RunOutcome) -> Row[datetime, RunOutcome, str | None] | None:
        """The newest run of the source that has one of these outcomes."""
        return work.execute(
            select(CollectionRun.started_at, CollectionRun.outcome, CollectionRun.error)
            .where(CollectionRun.source_id == source_id, CollectionRun.outcome.in_(outcomes))
            .order_by(CollectionRun.started_at.desc(), CollectionRun.id.desc())
            .limit(1)
        ).first()

    attempted = newest(*RunOutcome)
    over = newest(*_HEALTH_AFTER)
    succeeded = newest(RunOutcome.SUCCEEDED)
    # A run that succeeded takes the error of an older run away: only the
    # newest of the runs that said how they ended has a say.
    said = newest(RunOutcome.SUCCEEDED, RunOutcome.FAILED)
    return SourceStanding(
        last_attempt=None if attempted is None else attempted.started_at,
        last_success=None if succeeded is None else succeeded.started_at,
        last_error=None if said is None else said.error,
        health=SourceHealth.NOT_YET_SCANNED if over is None else _HEALTH_AFTER[over.outcome],
    )
```

### 2. `backend/tests/integration/test_source_health.py` – new, the whole file, 32 tests

```python
"""Tests of how a source is doing, told by its runs, against a real SQLite file.

The store of every test is built by the migrations, and its runs are of
every outcome. What a test asks is asked of the store itself: nothing
here is a mock.
"""

from datetime import UTC, datetime, timedelta
from pathlib import Path

import pytest
from sqlalchemy import Engine

from motosphere.db.models import CollectionRun, Source
from motosphere.db.models.collection_run import RunOutcome
from motosphere.db.models.source import CollectionMethod, SourceCategory
from motosphere.db.source_health import SourceHealth, SourceStanding, standing_of
from motosphere.db.work import unit_of_work

# The moments runs start at, an hour apart: HOUR[3] is three hours after HOUR[0].
HOUR = [datetime(2026, 11, 24, 6, 0, tzinfo=UTC) + timedelta(hours=hours) for hours in range(8)]
RUNNING = RunOutcome.RUNNING
SUCCEEDED = RunOutcome.SUCCEEDED
FAILED = RunOutcome.FAILED
INTERRUPTED = RunOutcome.INTERRUPTED
HEALTH_AFTER = {
    SUCCEEDED: SourceHealth.HEALTHY,
    FAILED: SourceHealth.FAILING,
    INTERRUPTED: SourceHealth.INTERRUPTED,
}


def a_source(store: Engine, name: str = "Example Federation") -> int:
    """Store a source, and give its key."""
    source = Source(
        name=name,
        website="https://federation.example",
        category=SourceCategory.GOVERNING_BODY,
        collection_method=CollectionMethod.RSS,
    )
    with unit_of_work(store) as work:
        work.add(source)
    return source.id


def a_run(store: Engine, source: int, started: datetime, outcome: RunOutcome) -> None:
    """Store a run of this outcome as the table takes it. One that failed says so by its start."""
    over = outcome in (SUCCEEDED, FAILED)
    with unit_of_work(store) as work:
        work.add(
            CollectionRun(
                source_id=source,
                started_at=started,
                ended_at=started + timedelta(minutes=4) if over else None,
                outcome=outcome,
                error=error_of(started) if outcome is FAILED else None,
            )
        )


def error_of(started: datetime) -> str:
    """The error of the run that started then and failed."""
    return f"The feed did not answer at {started:%H:%M}."


def asked(store: Engine, source: int) -> SourceStanding:
    with unit_of_work(store) as work:
        return standing_of(work, source)


def test_of_a_source_that_has_no_run_nothing_is_said_but_that(newest: Engine) -> None:
    source = a_source(newest)

    assert asked(newest, source) == SourceStanding(
        last_attempt=None,
        last_success=None,
        last_error=None,
        health=SourceHealth.NOT_YET_SCANNED,
    )


def test_a_source_whose_first_run_is_still_running_was_attempted_and_not_yet_scanned(
    newest: Engine,
) -> None:
    source = a_source(newest)
    a_run(newest, source, HOUR[0], RUNNING)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[0],
        last_success=None,
        last_error=None,
        health=SourceHealth.NOT_YET_SCANNED,
    )


def test_a_source_whose_only_run_succeeded_is_healthy(newest: Engine) -> None:
    source = a_source(newest)
    a_run(newest, source, HOUR[0], SUCCEEDED)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[0], last_success=HOUR[0], last_error=None, health=SourceHealth.HEALTHY
    )


def test_a_source_whose_only_run_failed_is_failing_and_says_why(newest: Engine) -> None:
    source = a_source(newest)
    a_run(newest, source, HOUR[0], FAILED)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[0],
        last_success=None,
        last_error="The feed did not answer at 06:00.",
        health=SourceHealth.FAILING,
    )


def test_a_source_whose_only_run_was_interrupted_says_so_and_has_no_error(newest: Engine) -> None:
    source = a_source(newest)
    a_run(newest, source, HOUR[0], INTERRUPTED)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[0],
        last_success=None,
        last_error=None,
        health=SourceHealth.INTERRUPTED,
    )


@pytest.mark.parametrize("last", list(RunOutcome))
def test_the_last_attempt_is_the_newest_run_whatever_became_of_it(
    newest: Engine, last: RunOutcome
) -> None:
    source = a_source(newest)
    for started, outcome in zip(HOUR, [SUCCEEDED, FAILED, INTERRUPTED, last], strict=False):
        a_run(newest, source, started, outcome)

    assert asked(newest, source).last_attempt == HOUR[3]


@pytest.mark.parametrize("later", [RUNNING, FAILED, INTERRUPTED])
def test_the_last_success_is_the_newest_run_that_succeeded_whatever_came_after(
    newest: Engine, later: RunOutcome
) -> None:
    source = a_source(newest)
    for started, outcome in zip(HOUR, [SUCCEEDED, SUCCEEDED, later], strict=False):
        a_run(newest, source, started, outcome)

    said = asked(newest, source)

    assert said.last_success == HOUR[1]
    assert said.last_attempt == HOUR[2]


@pytest.mark.parametrize("over", [SUCCEEDED, FAILED, INTERRUPTED])
def test_the_health_is_told_by_the_newest_run_that_is_over(
    newest: Engine, over: RunOutcome
) -> None:
    source = a_source(newest)
    # Before it, a run of each other kind; after it, one that is still running.
    for started, outcome in zip(
        HOUR, [*(other for other in HEALTH_AFTER if other is not over), over, RUNNING], strict=False
    ):
        a_run(newest, source, started, outcome)

    assert asked(newest, source).health is HEALTH_AFTER[over]


def test_the_last_error_is_that_of_the_newest_run_that_failed(newest: Engine) -> None:
    source = a_source(newest)
    for started, outcome in zip(HOUR, [FAILED, SUCCEEDED, FAILED, FAILED], strict=False):
        a_run(newest, source, started, outcome)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[3],
        last_success=HOUR[1],
        last_error="The feed did not answer at 09:00.",
        health=SourceHealth.FAILING,
    )


def test_the_last_error_is_no_longer_said_once_a_later_run_succeeded(newest: Engine) -> None:
    source = a_source(newest)
    for started, outcome in zip(HOUR, [FAILED, FAILED, SUCCEEDED], strict=False):
        a_run(newest, source, started, outcome)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[2], last_success=HOUR[2], last_error=None, health=SourceHealth.HEALTHY
    )


@pytest.mark.parametrize("later", [RUNNING, INTERRUPTED])
def test_the_last_error_is_still_said_while_no_later_run_has_succeeded(
    newest: Engine, later: RunOutcome
) -> None:
    source = a_source(newest)
    for started, outcome in zip(HOUR, [SUCCEEDED, FAILED, later], strict=False):
        a_run(newest, source, started, outcome)

    said = asked(newest, source)

    assert said.last_error == "The feed did not answer at 07:00."
    assert said.last_success == HOUR[0]
    assert said.health is (SourceHealth.FAILING if later is RUNNING else SourceHealth.INTERRUPTED)


def test_the_newest_run_is_the_one_that_started_last_not_the_one_stored_last(
    newest: Engine,
) -> None:
    source = a_source(newest)
    # Stored in this order; the run that failed started last.
    a_run(newest, source, HOUR[1], SUCCEEDED)
    a_run(newest, source, HOUR[2], FAILED)
    a_run(newest, source, HOUR[0], SUCCEEDED)

    assert asked(newest, source) == SourceStanding(
        last_attempt=HOUR[2],
        last_success=HOUR[1],
        last_error="The feed did not answer at 08:00.",
        health=SourceHealth.FAILING,
    )


@pytest.mark.parametrize(
    ("stored", "health", "error"),
    [
        ([FAILED, SUCCEEDED], SourceHealth.HEALTHY, None),
        ([SUCCEEDED, FAILED], SourceHealth.FAILING, "The feed did not answer at 06:00."),
    ],
)
def test_of_two_runs_that_started_together_the_one_stored_last_is_the_newer(
    newest: Engine, stored: list[RunOutcome], health: SourceHealth, error: str | None
) -> None:
    source = a_source(newest)
    for outcome in stored:
        a_run(newest, source, HOUR[0], outcome)

    said = asked(newest, source)

    assert said.health is health
    assert said.last_error == error


def test_a_source_is_told_by_its_own_runs_and_not_by_those_of_another(newest: Engine) -> None:
    first = a_source(newest)
    second = a_source(newest, "Example Club")
    third = a_source(newest, "Example Track")
    a_run(newest, first, HOUR[0], SUCCEEDED)
    a_run(newest, second, HOUR[1], FAILED)
    a_run(newest, second, HOUR[2], RUNNING)

    assert asked(newest, first) == SourceStanding(
        last_attempt=HOUR[0], last_success=HOUR[0], last_error=None, health=SourceHealth.HEALTHY
    )
    assert asked(newest, second) == SourceStanding(
        last_attempt=HOUR[2],
        last_success=None,
        last_error="The feed did not answer at 07:00.",
        health=SourceHealth.FAILING,
    )
    assert asked(newest, third) == SourceStanding(
        last_attempt=None,
        last_success=None,
        last_error=None,
        health=SourceHealth.NOT_YET_SCANNED,
    )


def test_the_times_come_back_as_times_in_utc(newest: Engine) -> None:
    source = a_source(newest)
    a_run(newest, source, HOUR[0], SUCCEEDED)

    said = asked(newest, source)

    assert said.last_attempt is not None
    assert said.last_attempt.utcoffset() == timedelta(0)
    assert said.last_success is not None
    assert said.last_success.utcoffset() == timedelta(0)


@pytest.mark.parametrize("key", [2, 0, -1])
def test_a_key_that_no_source_has_is_refused_in_plain_words(newest: Engine, key: int) -> None:
    source = a_source(newest)
    a_run(newest, source, HOUR[0], SUCCEEDED)

    with pytest.raises(LookupError) as refusal:
        asked(newest, key)

    assert str(refusal.value) == f"There is no source with the key {key}."


def test_asking_writes_nothing_to_the_store(newest: Engine, clock: list[datetime]) -> None:
    file = Path(str(newest.url.database))
    source = a_source(newest)
    for started, outcome in zip(HOUR, list(RunOutcome), strict=False):
        a_run(newest, source, started, outcome)
    before = file.read_bytes()
    asked_the_clock = len(clock)

    with unit_of_work(newest) as work:
        standing_of(work, source)
        assert not work.new
        assert not work.dirty
        assert not work.deleted

    assert file.read_bytes() == before
    assert len(clock) == asked_the_clock


@pytest.mark.parametrize("name", ["last_attempt", "last_success", "last_error", "health"])
def test_what_is_said_cannot_be_changed_afterwards(newest: Engine, name: str) -> None:
    source = a_source(newest)
    said = asked(newest, source)

    with pytest.raises(AttributeError):
        setattr(said, name, None)

    assert said == SourceStanding(None, None, None, SourceHealth.NOT_YET_SCANNED)
```

"""Tests of the list of how a source can be doing. They need no store."""

import re

import pytest

from motosphere.db.source_health import SourceHealth

# The texts, written out: a text changed by mistake fails here.
HEALTH = ["not yet scanned", "healthy", "failing", "interrupted"]


def test_the_list_has_exactly_its_four_texts_in_their_order() -> None:

## Acceptance criteria

1. `SourceHealth` has exactly its four texts in their order, and no
   text has two names.
2. Of a source that has no run, nothing is said of a last scan or a last
   error, and its health is `not yet scanned`; the same health holds
   while its only run is still running, and that run is its last
   attempt.
3. The last attempt is the start of the source's newest run, whatever
   became of it; the last success is the start of its newest run that
   succeeded.
4. The health is told by the newest run that is over: `healthy` after
   one that succeeded, `failing` after one that failed, `interrupted`
   after one that was interrupted.
5. The last error is that of the newest run that failed; it is no
   longer said once a later run succeeded, and is still said while a
   later run is running or was interrupted.
6. The newest run is the one that started last, and of two that started
   together the one stored last. A source is told by its own runs only.
7. A key that no source has is refused with a `LookupError` in one plain
   sentence.
8. Nothing is written to the store when it is asked, and what is said
   cannot be changed afterwards.
9. No existing test changed, and all pass. The type check passes with no
   `ignore` and the lint with no `noqa`.
