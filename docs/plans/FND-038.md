# FND-038 – Narrow screens: an open panel lies over the globe

**Phase:** 1 – Foundation
**Depends on:** FND-014, FND-015 (both merged)
**Base branch:** `main`
**Read first:** `CLAUDE.md` §3, §8, `docs/WORKFLOW.md`, `TESTING.md`
("Frontend"), `frontend/src/layout/AppShell.tsx`,
`frontend/src/layout/AppShell.module.css`, `frontend/e2e/layout.spec.ts`,
`frontend/e2e/panels.spec.ts`

## Objective

On a narrow screen the globe stage is never squeezed by the side panels: it
keeps the whole width, and an open panel lies over it.

## Why

The owner opened the published site on a phone on 2026-11-17 and found it
not usable there. Measured by the planner at 390 by 844 pixels on `main`:
the two panels take 220 and 360 pixels, the layout becomes 580 pixels wide,
the globe stage gets a width of **0**, and the Details button lies at 724
pixels, outside the screen. At 768 pixels (a tablet held upright) the stage
gets 188 pixels.

This is the first of five small tasks (PLAN-009). It changes only where the
panels are drawn. After it, on a phone, both panels are still open when the
page opens and cover the stage, and the top bar is still cut off: the next
tasks make the top bar fit (FND-039) and make the panels start closed, one
at a time (FND-040). Do not solve those here.

## Design in short

- A screen **under 900 pixels wide** is a narrow one: a phone, or a tablet
  held upright. From 900 pixels on nothing changes. (Below about 810 pixels
  the top bar's content does not fit on one line even without the tagline,
  and at 900 the stage still gets 320 pixels between the panels.)
- On a narrow screen the layout has one column. The top bar and the stage
  each have the whole width. The two panels are placed in the stage's own
  cell of the grid and drawn over it: the sections panel at the left edge,
  the details panel at the right edge, each as tall as the stage, with
  their usual widths (220 and 360 pixels) but never wider than the screen.
- Style sheet only: one `@media (max-width: 899px)` block at the end of
  `AppShell.module.css`. No change to any component, no new element, no
  script. A closed panel is still hidden by the `hidden` attribute, as
  today.
- The width is written once, in that style sheet. (The build rewrites the
  query as `(width<=899px)`; that is the same rule.)

## Implementation detail

### 1. `frontend/src/layout/AppShell.module.css` – append this block at the end

Leave everything above it as it is. One empty line between `.hint { … }` and
the comment.

```css
/*
 * A narrow screen: a phone, or a tablet held upright. There is no room for the
 * panels beside the globe stage, so the stage keeps the whole width and an open
 * panel lies over it, the sections from the left and the details from the right.
 */
@media (max-width: 899px) {
  .shell {
    grid-template-areas:
      'top'
      'stage';
    grid-template-columns: minmax(0, 1fr);
  }

  .sections,
  .details {
    grid-area: stage;
    z-index: 1;
    max-width: 100%;
  }

  .details {
    justify-self: end;
  }
}
```

Why each line is there:

- `grid-template-areas` and `grid-template-columns`: one column, so the top
  bar and the stage are exactly as wide as the screen.
- `grid-area: stage`: both panels share the stage's cell instead of having
  columns of their own.
- `z-index: 1`: the stage is a positioned element and would otherwise be
  drawn over the panels.
- `max-width: 100%`: on a screen narrower than a panel (320 pixels against
  the details panel's 360) the panel ends at the screen's edge.
- `justify-self: end`: the details panel stays at the right. The sections
  panel needs no rule: with a width of its own it starts at the left.

### 2. `frontend/e2e/narrow.spec.ts` – new, the whole file, 26 tests

```ts
import type { Locator, Page } from '@playwright/test'
import { expect, test } from './fixtures'

// Below this width the screen is narrow: the panels lie over the globe stage.
const NARROW_BELOW = 900
// The widths the panels have when the screen has room for them.
const SECTIONS_WIDTH = 220
const DETAILS_WIDTH = 360

interface Box {
  x: number
  y: number
  width: number
  height: number
}

async function box(locator: Locator): Promise<Box> {
  const result = await locator.boundingBox()
  if (result === null) {
    throw new Error(`${locator.toString()} has no bounding box: it is not visible`)
  }
  return result
}

function regions(page: Page) {
  return {
    topBar: page.getByRole('banner'),
    sections: page.getByRole('navigation', { name: 'Sections' }),
    stage: page.getByRole('main', { name: 'Globe' }),
    details: page.getByRole('complementary', { name: 'Details' }),
  }
}

/** Opens the page as a visitor who closed these side panels earlier in the session. */
async function openWithClosed(page: Page, ...panels: ('sections' | 'details')[]): Promise<void> {
  await page.addInitScript((names) => {
    for (const name of names) {
      window.sessionStorage.setItem(`motosphere.panel.${name}`, 'closed')
    }
  }, panels)
  await page.goto('./')
}

/** Which region is on top at a point of the screen. */
async function regionAt(page: Page, x: number, y: number): Promise<string | undefined> {
  return page.evaluate(
    ([px, py]) =>
      document.elementFromPoint(px, py)?.closest('header, nav, main, aside')?.tagName.toLowerCase(),
    [x, y] as const,
  )
}

const NARROW_SCREENS = [
  { width: 320, height: 568 },
  { width: 360, height: 740 },
  { width: 390, height: 844 },
  { width: 768, height: 1024 },
  { width: NARROW_BELOW - 1, height: 700 },
]

for (const viewport of NARROW_SCREENS) {
  test.describe(`narrow screen, ${viewport.width}×${viewport.height}`, () => {
    test.use({ viewport })

    test('the top bar and the globe stage each have the whole width', async ({ page }) => {
      await page.goto('./')
      const region = regions(page)
      const topBar = await box(region.topBar)
      const stage = await box(region.stage)

      expect(topBar).toMatchObject({ x: 0, y: 0, width: viewport.width })
      expect(stage).toEqual({
        x: 0,
        y: topBar.height,
        width: viewport.width,
        height: viewport.height - topBar.height,
      })
    })

    test('the globe stage keeps the whole width when the panels are closed', async ({ page }) => {
      await openWithClosed(page, 'sections', 'details')
      const region = regions(page)
      await expect(region.sections).toBeHidden()
      await expect(region.details).toBeHidden()

      expect(await box(region.stage)).toMatchObject({ x: 0, width: viewport.width })
      expect(await regionAt(page, viewport.width / 2, viewport.height / 2)).toBe('main')
    })

    test('the sections panel lies over the globe stage, from the left', async ({ page }) => {
      await openWithClosed(page, 'details')
      const region = regions(page)
      const stage = await box(region.stage)
      const sections = await box(region.sections)

      expect(stage).toMatchObject({ x: 0, width: viewport.width })
      expect(sections).toEqual({
        x: 0,
        y: stage.y,
        width: Math.min(SECTIONS_WIDTH, viewport.width),
        height: stage.height,
      })
      expect(await regionAt(page, sections.width / 2, viewport.height / 2)).toBe('nav')
      await expect(region.sections.getByRole('button', { name: 'Explore' })).toBeVisible()
    })

    test('the details panel lies over the globe stage, from the right', async ({ page }) => {
      await openWithClosed(page, 'sections')
      const region = regions(page)
      const stage = await box(region.stage)
      const details = await box(region.details)

      expect(stage).toMatchObject({ x: 0, width: viewport.width })
      const width = Math.min(DETAILS_WIDTH, viewport.width)
      expect(details).toEqual({
        x: viewport.width - width,
        y: stage.y,
        width,
        height: stage.height,
      })
      expect(await regionAt(page, viewport.width - width / 2, viewport.height / 2)).toBe('aside')
    })

    test('the page itself does not scroll', async ({ page }) => {
      await page.goto('./')
      const overflow = await page.evaluate(() => {
        const root = document.documentElement
        return {
          horizontal: root.scrollWidth - root.clientWidth,
          vertical: root.scrollHeight - root.clientHeight,
        }
      })
      expect(overflow).toEqual({ horizontal: 0, vertical: 0 })
    })
  })
}

test.describe(`the narrowest wide screen, ${NARROW_BELOW} pixels`, () => {
  test.use({ viewport: { width: NARROW_BELOW, height: 700 } })

  test('has the panels beside the globe stage', async ({ page }) => {
    await page.goto('./')
    const region = regions(page)
    const sections = await box(region.sections)
    const stage = await box(region.stage)
    const details = await box(region.details)

    expect(sections).toMatchObject({ x: 0, width: SECTIONS_WIDTH })
    expect(stage).toMatchObject({
      x: SECTIONS_WIDTH,
      width: NARROW_BELOW - SECTIONS_WIDTH - DETAILS_WIDTH,
    })
    expect(details).toMatchObject({ x: NARROW_BELOW - DETAILS_WIDTH, width: DETAILS_WIDTH })
  })
})
```

The tests open the page as a visitor who closed one panel, or both, earlier
in the session (the session's own memory, set before the page loads),
because on `main` today the Details button cannot be reached on a phone.

## Acceptance criteria

1. At 320, 360, 390, 768 and 899 pixels wide, the top bar and the globe
   stage each have the whole width of the screen, with both panels open,
   with one open and with none.
2. There, an open sections panel lies over the stage from the left edge
   and an open details panel from the right edge, each as tall as the
   stage, on top of it, and never wider than the screen.
3. There, the page itself does not scroll, sideways or down.
4. At 900 pixels wide the panels stand beside the stage, as on any wider
   screen.
5. No existing test changed, and all pass.
6. `npx playwright test e2e/narrow.spec.ts` reports 26 passed; the full run
   reports 19 of 19 gates and 631 tests (browser tests 113).
7. On the pull request, "All gates (Linux)" and "All gates (Windows)" are
   green with those numbers, and the three jobs after the gates are
   skipped.
